Bits, Bytes and Bigger Units

lesson 2.033 of 6 in milestone 25 min1 practice task

Eight bits make a byte, the unit memory is counted in. Kilobytes, megabytes and gigabytes are multiples of it - with the twist that computers count in powers of 2, so a kibibyte is 1,024 bytes while a kilobyte is 1,000. Bits per second measure speed; bytes measure size.

The byte

A byte is 8 bits. It is the smallest piece of memory a modern computer can give an address to: memory is a long row of bytes, numbered 0, 1, 2, and so on (lesson 4.03). One byte holds a number from 0 to 255, or one character of plain English text.

Half a byte, 4 bits, is a nibble. It matters because one nibble is exactly one hexadecimal digit (lesson 2.04).

Unit Bits Patterns Holds
bit 1 2 on / off
nibble 4 16 one hexadecimal digit
byte 8 256 one plain character, a number from 0 to 255
Why eight?

Early computers used bytes of 6, 7 or 9 bits. IBM's System/360 of 1964 settled on 8, which fits a character plus room to spare and splits neatly into two nibbles, and almost everyone followed.

Bigger units

Name Symbol Bytes (decimal) Feels like
kilobyte kB 1,000 a short text message is a few hundred bytes
megabyte MB 1,000,000 a photo is a few MB
gigabyte GB 1,000,000,000 a film is a few GB
terabyte TB 1,000,000,000,000 a big hard drive
petabyte PB 10¹⁵ a data centre's storage

The 1,000 or 1,024 problem

Computers think in powers of 2, and 2¹⁰ = 1,024 is very close to 1,000. So for decades "a kilobyte" meant 1,024 bytes in some places and 1,000 in others. To fix the confusion, separate names were made for the powers of 2:

Power of 10 Power of 2 Difference
kilobyte, kB = 1,000 kibibyte, KiB = 1,024 2.4%
megabyte, MB = 1,000² mebibyte, MiB = 1,024² = 1,048,576 4.9%
gigabyte, GB = 1,000³ gibibyte, GiB = 1,024³ = 1,073,741,824 7.4%
terabyte, TB = 1,000⁴ tebibyte, TiB = 1,024⁴ 10%

This is why a "1 TB" drive shows up as about 931 GB in Windows: the box counts in powers of 10 (a trillion bytes), and Windows divides by 1,024³ but still writes "GB". Nobody stole your space; the two sides count differently. (macOS counts in powers of 10, so it shows 1 TB.)

Memory chips (RAM) come in powers of 2, so 16 GB of RAM is really 16 GiB.

Bits per second vs bytes

Two units, easy to mix up:

  • Size is usually in bytes: B (capital).
  • Speed of a network is usually in bits per second: b (small). "100 Mbps" is 100 megabits per second.

Since a byte is 8 bits, divide by 8: a 100 Mbps connection moves about 12.5 MB per second at best. A 5 GB game download takes at least 5,000 ÷ 12.5 = 400 seconds, nearly seven minutes.

How many bits do you need?

To count n different things you need enough bits for at least n patterns. With b bits there are 2ᵇ patterns, so you need the smallest b with 2ᵇ ≥ n:

Things to tell apart Bits needed Because
2 1 2¹ = 2
10 (decimal digits) 4 2³ = 8 is too few, 2⁴ = 16 is enough
26 letters 5 2⁵ = 32
100 7 2⁷ = 128
1,000 10 2¹⁰ = 1,024
1,000,000 20 2²⁰ = 1,048,576

A handy fact: 2¹⁰ ≈ 1,000. So 20 bits is about a million, 30 bits about a billion, 40 bits about a trillion.
