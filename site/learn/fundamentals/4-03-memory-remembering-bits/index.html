Memory: Remembering Bits

lesson 4.033 of 6 in milestone 45 min1 practice task

Gates connected in a loop can remember a bit - a latch or flip-flop. A row of them is a register. Main memory (RAM) is billions of tiny cells arranged as a long row of bytes, each with a numbered address. Programs read and write memory by address, and RAM forgets everything when the power goes off.

A circuit that remembers

The gates in 4.01 and 4.02 have no memory: their output depends only on their inputs right now. To store a bit, a circuit must keep its value after the input is gone. The trick is feedback: connect a gate's output back into its own input.

Two NAND gates wired to feed into each other form a latch. It has two stable states, and stays in whichever one it was put into:

Signal Effect
"set" the stored bit becomes 1
"reset" the stored bit becomes 0
neither the bit stays as it was, for as long as there is power

Add a little control (a clock signal saying when to store) and it becomes a flip-flop, the basic memory cell inside a CPU.

Registers

A row of flip-flops that store a whole number together is a register. A 64-bit CPU's registers are 64 flip-flops each. Registers are inside the CPU itself, next to the ALU, so they are the fastest memory there is - but there are only a few dozen of them. x86-64 has 16 general registers, called rax, rbx, rcx and so on (you will use them all in the Assembly course).

RAM: a long row of bytes

The program and its data cannot all fit in registers, so they live in main memory, RAM (random-access memory). RAM is made differently - each bit is a tiny capacitor that holds a charge, with one transistor to read or write it - which makes it far denser and cheaper than flip-flops, but slower.

The important idea is how a program sees it: one long row of bytes, each with a number called its address.

Address 0x1000 0x1001 0x1002 0x1003 0x1004 ...
Byte 48 105 0 2A 0 ...

To read memory, the CPU sends an address and gets back the byte (or several bytes) stored there. To write, it sends an address and a value. "Random access" means any address can be reached as quickly as any other, unlike a tape you would have to wind through.

Every variable in a program lives at some address. A 4-byte integer takes four neighbouring addresses; which byte goes first is the byte order from 2.06.

Addresses are numbers too

An address is just a number, so it can be stored in memory like any other number. A variable holding an address is called a pointer: it "points at" another place in memory. Pointers are central to C and assembly, and every language uses them under the hood (Python's variables are pointers to objects).

Memory forgets

RAM is volatile: when the power goes off, the capacitors drain and every bit is lost. That is why there are two kinds of storage:

RAM (memory) SSD or hard drive (storage)
Keeps data without power No Yes
Speed Very fast (tens of nanoseconds) Slower (SSD: tens of microseconds; hard drive: milliseconds)
Typical size 8 to 64 GB 256 GB to several TB
Holds The programs running now and their data Files, installed programs, the operating system

When you open an app, its program file is copied from storage into RAM so the CPU can run it. When you "save", data is copied from RAM to storage so it survives.
