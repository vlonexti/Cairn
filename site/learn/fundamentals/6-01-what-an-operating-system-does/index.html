What an Operating System Does

lesson 6.011 of 6 in milestone 65 min

The operating system is the program that runs the computer for every other program - it shares the CPU and memory between programs, gives them files and devices through one safe interface, keeps them from interfering with each other, and starts and stops them. Its core, the kernel, is the only code allowed to touch the hardware directly.

The program that runs the programs

Turn on a computer with no operating system and you get a CPU fetching instructions from memory - and nothing to share it, no files, no windows, no way to start an app. The operating system (OS) is the software that turns bare hardware into something many programs and people can use at once.

Operating system Runs on
Windows most PCs
macOS, iOS, iPadOS Apple computers, phones, tablets
Linux most servers, supercomputers, many devices; Android is built on it

The kernel and user mode

The core of the operating system is the kernel. It is the only code allowed to touch the hardware directly. The CPU itself enforces this with two modes:

Mode Who runs in it May...
Kernel mode (privileged) The kernel and drivers Do anything: any memory, any device, any instruction
User mode (restricted) Every app: your browser, a game, Python Use only its own memory; cannot talk to devices; certain instructions cause an error

When an app needs something only the kernel may do - read a file, print, open a network connection, get more memory - it makes a system call (5.06): a special instruction (syscall on x86-64) that switches the CPU into kernel mode and jumps to a fixed entry point in the kernel. The kernel checks the request, does it, and switches back.

This separation is why one crashing app does not crash the whole computer: it can only damage its own memory, and the kernel cleans up after it. A bug in the kernel or a driver, on the other hand, can bring everything down (the Windows "blue screen").

What you see vs. the kernel

What people usually call "the operating system" includes much more than the kernel: the desktop and windows, the file browser, settings, the command line (a shell), and many background services. Those are ordinary user-mode programs that come with the kernel. On Linux, the kernel is Linux itself; the rest (GNOME, KDE, the GNU tools) are separate projects packaged together into a distribution such as Ubuntu or Fedora.
