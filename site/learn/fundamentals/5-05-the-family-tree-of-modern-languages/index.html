The Family Tree of Modern Languages

lesson 5.055 of 6 in milestone 55 min

The languages of today descend from a few ancestors - C's syntax, Simula's objects, Lisp's functions. C++ added objects to C; Python made code read like plain English; Java and C# brought virtual machines and garbage collection; JavaScript took over the web; Rust and Go rethought systems programming. Each one trades speed, safety and convenience differently.

Objects: Simula and Smalltalk

A new idea arrived in Norway: Simula (1967), by Ole-Johan Dahl and Kristen Nygaard, was built to simulate things like ships and queues, and introduced classes and objects: a bundle of data and the functions that work on it. Smalltalk (1972, Alan Kay and others at Xerox PARC) made objects the centre of everything, and also gave us much of the modern graphical interface.

Choosing a trade-off

Languages differ mostly in what they make easy and what they make you handle yourself:

Question Closer to the machine Further from it
Who frees memory? You (C, C++), or the compiler's rules (Rust) A garbage collector (Java, C#, Python, JavaScript, Go)
When are types checked? Before running: static (C, C++, Java, C#, Rust, Go, TypeScript) While running: dynamic (Python, JavaScript)
How is it run? Compiled to machine code (C, C++, Rust, Go, Swift) Bytecode and a VM, or an interpreter (Java, C#, Python, JavaScript)
Typical speed Fastest Slower, but JITs close much of the gap
Typical effort More code, more control Less code, less control

There is no best language, only better fits. A game engine wants C++; a quick data analysis wants Python; a web page needs JavaScript; an operating system kernel wants C or, more and more, Rust.

Paradigms

Languages also differ in style, called paradigms, and most modern ones mix several:

  • Procedural: a sequence of steps and functions (C, early Python).
  • Object-oriented: objects with data and methods (Java, C#, C++, Python).
  • Functional: functions that take and return functions, values that do not change (Lisp, Haskell, and parts of JavaScript, Python and Rust).

Still all the same underneath

Whatever the language, the end is the same: machine code running on a CPU, fetch, decode, execute, bits in registers and memory. A Python list, a Java object and a C array are all, in the end, bytes at addresses. The next lesson follows one line of Python all the way there.
