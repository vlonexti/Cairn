The CPU: Fetch, Decode, Execute

lesson 4.044 of 6 in milestone 46 min1 practice task

A CPU repeats one cycle billions of times a second - fetch the instruction its program counter points at, decode what it means, execute it, and move on. A tiny computer with one register and seven instructions shows the whole idea, including how a loop is just a jump back.

The parts of a CPU

A CPU has three main parts:

Part Job
Registers A few fast storage slots (4.03). One special register, the program counter (PC), holds the address of the next instruction
ALU Does the arithmetic and logic (4.02)
Control unit Reads each instruction and switches the right circuits on to carry it out

A clock ticks billions of times a second (that is the "GHz" in 1.05), and on each tick the CPU moves one step forward.

The cycle

Everything a CPU does is this loop, forever:

flowchart LR
    F["Fetch<br/>read the instruction<br/>at the address in the PC"] --> D["Decode<br/>work out what it means"] --> E["Execute<br/>do it: add, copy,<br/>jump..."] --> N["Move the PC on<br/>(unless the instruction<br/>jumped)"] --> F
  1. Fetch: read the instruction stored at the address in the program counter.
  2. Decode: split it into its parts - which operation, which register, which address.
  3. Execute: do it, using the ALU, registers and memory.
  4. Next: add one to the program counter (the size of the instruction), so the next fetch gets the next instruction.

A tiny computer

Here is a complete computer, small enough to watch. It has 16 memory cells, holding both the program and the data (the stored-program idea from 1.03), one register A (the accumulator), and seven instructions. Each instruction is a number: the hundreds digit is the operation, the rest is a memory address.

Code Instruction Does
1xx LOAD xx A = the number in cell xx
2xx ADD xx A = A + the number in cell xx
3xx SUB xx A = A − the number in cell xx
4xx STORE xx the number in cell xx = A
5xx JUMP xx the PC = xx: the next instruction comes from cell xx
6xx JUMPZ xx if A is 0, the PC = xx; otherwise carry on
000 HALT stop

So the number 110 means "LOAD 10", and 412 means "STORE 12".

Loops are jumps back

There is no "repeat" instruction. A loop is just a jump to an earlier address, and stopping the loop is a conditional jump that skips out when something becomes zero:

Cell Code Instruction Meaning
0 110 LOAD 10 A = the counter
1 605 JUMPZ 5 if A is 0, jump to 5 (the end)
2 311 SUB 11 A = A − 1
3 410 STORE 10 save the counter
4 501 JUMP 1 go back to the test
5 000 HALT stop

Real CPUs

A real CPU follows the same cycle, with refinements that make it fast:

  • Many registers (x86-64 has 16 general ones, each 64 bits) instead of one.
  • Hundreds of instructions, including multiply, divide, floating point, and instructions that work on several numbers at once.
  • Pipelining: while one instruction executes, the next is being decoded and the one after is being fetched, like an assembly line.
  • Several instructions at once: modern cores look ahead and run independent instructions side by side, often 4 to 8 per tick.
  • Branch prediction: before a conditional jump is decided, the CPU guesses which way it will go and starts on that path, undoing the work if it guessed wrong.

But it is still fetch, decode, execute. In this milestone's project you will build the tiny computer above in Python, and in the next milestone, an assembler for it.
