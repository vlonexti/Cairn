What a Computer Is

lesson 1.011 of 5 in milestone 16 min1 practice task

A computer is a machine that follows a list of instructions, very fast and without getting bored. Every computer, from the first one to your phone, has the same four parts - input, processing, memory and output - and all of them are built from switches that are either on or off.

A machine that follows instructions

A calculator can add. A computer can add too, but that is not what makes it a computer. What makes it a computer is that it follows a list of instructions - a program - and the list can be changed.

Give a computer a list that says "add up these marks and work out the average", and it is a school report tool. Give it a different list and the very same machine plays music, draws a game or sends a message. Nothing inside it changes except the list.

In one sentence

A computer is a machine that stores a list of instructions and carries them out one after another, very fast, and can store and change the information it is working on.

Each instruction is tiny: "add these two numbers", "copy this number over there", "if this number is zero, jump to that instruction". A computer is not clever. It is fast - billions of tiny steps a second - and exact: it never skips a step and never gets bored. Everything impressive a computer does is built out of a huge number of simple steps.

The four parts

Every computer ever built has the same four jobs, done by different parts:

    I["Input<br/>keyboard, mouse,<br/>touch screen, microphone"] --> P["Processing<br/>the CPU follows<br/>the instructions"]
    P <--> M["Memory<br/>holds the program<br/>and its data"]
    P --> O["Output<br/>screen, speaker,<br/>printer"]
Part Job Examples
Input Gets information into the computer Keyboard, mouse, touch screen, camera, microphone, network
Processing Carries out the instructions The CPU (central processing unit), the GPU for graphics
Memory Holds the program and the data it is working on RAM while running, an SSD or hard drive to keep things when the power is off
Output Gets results out Screen, speakers, printer, network

Your phone has all four: the touch screen is both input and output, the chip inside does the processing, and it has memory for the apps that are running and storage for your photos.

Hardware and software

  • Hardware is the part you can touch: chips, wires, the screen.
  • Software is the instructions: the programs. You cannot touch a program; it is information, like the words of a recipe are different from the paper they are printed on.

The same hardware runs different software. That is the whole trick, and it is why a computer is so much more useful than a machine built for one job.

Everything is switches

Deep down, a computer is made of switches. Not light switches you flip by hand, but microscopic electronic ones called transistors, which can be turned on and off by electricity - billions of times a second. A modern chip has billions of them.

A switch has only two states: on or off. Write on as 1 and off as 0, and you have a bit (short for binary digit). Every number, letter, photo and program inside a computer is stored as patterns of bits. This course spends a whole milestone on that, because it is the foundation everything else stands on.

Layers

A computer is built in layers, each one hiding the details of the one below:

Layer What it deals in Course milestone
Apps you use Buttons, pictures, words
Programming languages print("Hello") 5
Operating system Files, windows, running programs 6
Machine code Instructions as numbers 4
Logic gates and the CPU AND, OR, adding bits 4
Bits 0 and 1 2, 3
Transistors Switches made of silicon 1, 4

Programmers mostly work in the top layers, but knowing what is underneath explains why computers behave the way they do: why a number can "overflow", why 0.1 + 0.2 is not exactly 0.3, why a program can crash. By the end of this course you will be able to follow a single line of code all the way down to the switches.
