Files and File Formats

lesson 3.055 of 5 in milestone 35 min2 practice tasks

A file is a named row of bytes. Its format is the agreement about what those bytes mean - text, a PNG image, a program. Many formats start with a few fixed "magic" bytes that say what they are, and a hex dump shows a file's bytes as they really are.

A file is just bytes

A file on your disk is a name and a row of bytes. That is all. The file system (lesson 6.04) remembers which bytes belong to which name; the bytes themselves carry no label saying "I am a photo".

What turns the bytes into a photo, a song or a document is the file format: an agreement about what each byte means, followed by the program that wrote the file and the program that reads it.

Text files

A text file is the simplest format: just the encoded characters (3.01), one after another, with new-line bytes (10) between lines. A text file holding

Output
Hi
Bye

is exactly these 7 bytes: 48 69 0A 42 79 65 0A in hex (H, i, new line, B, y, e, new line). Programs, web pages, CSV spreadsheets and JSON data are all text files.

Looking at the bytes: a hex dump

A hex dump shows a file's bytes as hex, with the printable characters beside them. Here are the first bytes of a PNG image:

Output
offset    bytes                                              text
00000000  89 50 4E 47 0D 0A 1A 0A  00 00 00 0D 49 48 44 52   .PNG........IHDR
00000010  00 00 00 64 00 00 00 32  08 02 00 00 00 ...        ...d...2.....
  • The offset is how far into the file the row starts, in hex.
  • Each byte is two hex digits; 16 per row.
  • The right side shows each byte as a character if it is printable ASCII, or a dot if not.

Tools: xxd and hexdump on Linux and macOS, Format-Hex in PowerShell, or any hex editor. You will write a small hex dump yourself in this lesson's practice.

Magic numbers

Many formats begin with a fixed signature, a magic number, so a program can recognise the file whatever its name:

Format First bytes (hex) As text
PNG image 89 50 4E 47 0D 0A 1A 0A .PNG....
JPEG image FF D8 FF
GIF image 47 49 46 38 GIF8
PDF document 25 50 44 46 %PDF
ZIP archive (also .docx, .xlsx, .jar, .apk) 50 4B 03 04 PK.. (Phil Katz, its author)
Windows program (.exe) 4D 5A MZ (Mark Zbikowski)
Linux program (ELF) 7F 45 4C 46 .ELF
Java class file CA FE BA BE

The file extension (.png, .exe) is only part of the name: a hint for people and for the operating system about which program to open. Rename photo.png to photo.txt and the bytes do not change; a text editor will show nonsense because the bytes are not text.

Inside a format

After the magic number, a format usually has a header that describes the rest, then the data:

Part In a PNG, for example
Magic number 89 50 4E 47 0D 0A 1A 0A
Header Width and height (4 bytes each, big-endian), colour type, bits per channel
Data The pixels, compressed
End marker A block called IEND

In the dump above, 00 00 00 64 is the width: 0x64 = 100 pixels, and 00 00 00 32 is the height: 0x32 = 50. Big-endian, as lesson 2.06 warned.

Programs are files too

A program you run is also a file of bytes: a header describing it (where the code goes in memory, what libraries it needs), the machine code (instructions as numbers, lesson 4.05), and its data (texts, constants). On Windows that format is PE (starting with MZ); on Linux, ELF; on macOS, Mach-O. Lesson 6.04 shows what the operating system does with it when you run it.
