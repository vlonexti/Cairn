Computer Fundamentals

6 milestones34 lessons35 practice tasks30 projects

Start here, before any language. Where computers came from, from counting machines and the first electronic computers to the phone in your pocket; why everything inside is binary, and how 8, 16, 32 and 64 bits differ; how text, pictures and sound become numbers, and how a letter gets from a program onto the screen; how logic gates add, how a CPU fetches and runs machine code, and how assembly, the first readable languages and today's languages are built on one another; and what an operating system does. Every lesson has interactive demonstrations and quizzes, and short Python exercises that let you build the ideas yourself.
