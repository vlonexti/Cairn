The First Readable Languages

lesson 5.022 of 6 in milestone 55 min1 practice task

In the 1950s programmers wanted to write maths and business rules, not registers. Grace Hopper built the first compilers and argued for English-like code; FORTRAN (1957) let scientists write formulas; COBOL (1959) business rules; Lisp (1958) and ALGOL (1960) brought ideas every language still uses; BASIC (1964) brought programming to students.

The problem with assembly

Assembly was a big step up from raw numbers, but it is still the machine's language with names. To work out (a + b) * c / 2 you write a handful of instructions and choose which register holds what. And a program written for one computer has to be rewritten from scratch for the next one.

In the early 1950s people asked: why not write what we mean, and let a program translate it into machine code? That program is a compiler, and the language it reads is a high-level language.

Grace Hopper and the first compilers

Grace Hopper, a US Navy officer and mathematician who had programmed the Harvard Mark I, built the A-0 system in 1952: you wrote a list of calls to ready-made routines, and the machine put them together into a program. It is often called the first compiler.

Many people then thought computers could only do arithmetic. Hopper argued they could understand words. Her team's FLOW-MATIC (1955-59) let business programs be written in English-like sentences:

Output
INPUT INVENTORY FILE-A PRICE FILE-B ; OUTPUT PRICED-INV FILE-C .
COMPARE PRODUCT-NO (A) WITH PRODUCT-NO (B) ; IF GREATER GO TO OPERATION 10 .

FORTRAN (1957): formulas

At IBM, John Backus's team spent three years building FORTRAN (FORmula TRANslation), released in 1957. Scientists could now write

Output
      Y = (A + B) * C / 2.0

and the compiler produced machine code nearly as fast as a person's hand-written assembly. That speed was the point: nobody would have used it otherwise. Programs that took weeks in assembly took days, and a FORTRAN program could be compiled for a different computer. FORTRAN, updated many times, is still used for weather and physics simulations.

COBOL (1959): business

A committee drawing on Hopper's FLOW-MATIC designed COBOL (COmmon Business-Oriented Language) in 1959, for payrolls, banks and stock records, written to be readable by managers:

Output
       MULTIPLY HOURS-WORKED BY HOURLY-RATE GIVING GROSS-PAY.
       IF GROSS-PAY IS GREATER THAN 1000
           DISPLAY "HIGH EARNER".

Billions of lines of COBOL still run banks and governments today.

Lisp (1958) and ALGOL (1960): ideas

Two languages from this time had fewer users but enormous influence:

Language By Ideas that every language uses now
Lisp (1958) John McCarthy, MIT Functions as values, recursion, automatic memory management (garbage collection), code as data. Its descendants include Scheme and Clojure
ALGOL 60 (1960) An international committee Blocks with their own local variables, nested functions, recursion, and a precise written grammar. C, Pascal, Java and most languages you know are ALGOL's descendants

ALGOL's begin ... end blocks became C's { ... }, which became the braces of C++, Java, JavaScript, C# and Rust.

BASIC (1964): for everyone

At Dartmouth College, John Kemeny and Thomas Kurtz designed BASIC (Beginner's All-purpose Symbolic Instruction Code) so that any student, not just scientists, could program:

Output
10 PRINT "WHAT IS YOUR NAME";
20 INPUT N$
30 PRINT "HELLO, "; N$
40 GOTO 10

When home computers arrived in the late 1970s (1.04), nearly every one had BASIC built in. It was the first language of a whole generation of programmers, and Microsoft's first product was a BASIC.

timeline
    1952 : A-0 (Hopper)
    1957 : FORTRAN
    1958 : Lisp
    1959 : COBOL

What changed

Assembly A high-level language
You write One machine instruction per line What you mean: y = (a + b) * c / 2
Registers and addresses Chosen by you Chosen by the compiler
One line becomes One instruction Many instructions
Runs on One CPU family Any computer with a compiler for it

The compiler takes on the dull, error-prone work, and the program can move between computers. Every language since is built on this bargain.
