The Preprocessor

lesson 5.044 of 5 in milestone 55 min1 practice task

Before compiling, the preprocessor runs the lines starting with #. #include pastes in a file, #define replaces names with text, and #if keeps or drops code. Macros are text replacement, not functions, so parenthesise everything and avoid arguments with side effects. assert checks your assumptions while you develop.

Text before code

The first stage of building (lesson 1.01) is the preprocessor. It knows nothing about C; it edits text, following the lines that start with #, and hands the result to the compiler.

Directive Does
#include <file> pastes in a system header
#include "file" pastes in your own file (looks in the current folder first)
#define NAME text from here on, replaces NAME with text
#if, #ifdef, #else, #endif keeps or removes lines
#undef NAME forgets a definition

Constants

C
#include <stdio.h>

#define MAX_PLAYERS 8
#define GAME_NAME "Xenon Quest"

int main(void)
{
    int scores[MAX_PLAYERS] = {0};
    printf("%s has room for %d players (%zu bytes)\n", GAME_NAME, MAX_PLAYERS, sizeof scores);
    return 0;
}

The compiler never sees MAX_PLAYERS, only 8. By convention macro names are in capitals so they stand out. For typed constants inside functions, const variables and enum values are often better, because they follow C's rules for types and scope.

Macros with parameters

C
#include <stdio.h>

#define SQUARE_BAD(x) x * x
#define SQUARE(x) ((x) * (x))

int main(void)
{
    printf("%d\n", SQUARE_BAD(1 + 2));   // 1 + 2 * 1 + 2 = 5 !
    printf("%d\n", SQUARE(1 + 2));       // ((1 + 2) * (1 + 2)) = 9
    return 0;
}
Macros paste text
  • Put parentheses around every parameter and around the whole body.
  • An argument may be evaluated twice: SQUARE(i++) becomes ((i++) * (i++)), which is undefined.
  • For anything bigger than a line, write a function. A static inline function is just as fast and has real types.

Two special operators: #x turns an argument into a string, and a ## b glues two names together:

C
#include <stdio.h>

#define SHOW(expr) printf("%s = %d\n", #expr, (expr))

int main(void)
{
    int width = 7, height = 3;
    SHOW(width * height);           // prints: width * height = 21
    return 0;
}

Built-in names

__FILE__, __LINE__ and __func__ give the current file, line and function, which is handy for messages:

C
#include <stdio.h>

#define LOG(msg) fprintf(stderr, "%s:%d in %s: %s\n", __FILE__, __LINE__, __func__, msg)

int main(void)
{
    LOG("starting");
    printf("done\n");
    return 0;
}

Conditional code

C
#include <stdio.h>

#define DEBUG 1

int main(void)
{
#if DEBUG
    printf("debug build\n");
#endif
#ifdef _WIN32
    printf("compiled for Windows\n");
#elif defined(__APPLE__)
    printf("compiled for macOS\n");
#elif defined(__linux__)
    printf("compiled for Linux\n");
#endif
    return 0;
}

Compilers predefine names for the system they build for, which is how one source file supports several systems. gcc -DDEBUG=0 defines a macro from the command line.

Include guards

If a header is included twice (directly and through another header), its definitions appear twice and the compiler complains. An include guard makes the second copy vanish:

C
#ifndef SHAPES_H
#define SHAPES_H

struct point { double x, y; };
double distance(struct point a, struct point b);

#endif

Most compilers also accept #pragma once at the top, which does the same.

assert

assert(condition) from assert.h stops the program with a message naming the file, line and condition if the condition is false:

C
#include <assert.h>
#include <stdio.h>

double average(const int *values, int count)
{
    assert(values != NULL && count > 0);
    long long sum = 0;
    for (int i = 0; i < count; i++) sum += values[i];
    return (double)sum / count;
}

int main(void)
{
    int v[] = {2, 4, 9};
    printf("%.2f\n", average(v, 3));
    printf("%.2f\n", average(v, 0));     // stops here
    return 0;
}

Asserts check things that can only be false if the program has a bug. Release builds often define NDEBUG, which removes them, so never put work that must happen inside an assert.
