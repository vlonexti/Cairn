Operators and Expressions

lesson 1.044 of 5 in milestone 15 min1 practice task

C's arithmetic works on the types you give it - dividing two ints throws away the fraction, % gives the remainder, and mixing int and double converts to double. Casts convert on purpose. Increment, compound assignment and precedence work as in most languages, and signed overflow is a bug the language does not catch.

Arithmetic

Operator Meaning 17 ? 5
+ - * add, subtract, multiply 22, 12, 85
/ divide 3 for ints, 3.4 for doubles
% remainder (ints only) 2

Integer division

When both sides of / are integers, C does integer division: the fraction is thrown away (rounded towards zero).

C
#include <stdio.h>

int main(void)
{
    printf("%d\n", 17 / 5);       // 3
    printf("%d\n", -17 / 5);      // -3: towards zero
    printf("%d\n", 17 % 5);       // 2
    printf("%f\n", 17 / 5.0);     // 3.400000: one side is a double
    int total = 7, count = 2;
    printf("%f\n", (double)total / count);   // 3.500000
    printf("%f\n", (double)(total / count)); // 3.000000: too late, already divided
    return 0;
}

This is the most common surprise in C. If you want a fraction, make one side a double first.

/ and % together split a number: seconds / 60 is the minutes, seconds % 60 the seconds left over. n % 2 == 0 tests for even, and n % 10 is the last digit.

Mixing types: conversions

When an expression mixes types, C converts the smaller to the larger before doing the sum:

Expression Converted to Result
int + double double 3 + 0.5 is 3.5
char + int int 'A' + 1 is 66
int * long long long long

Assigning converts too, sometimes losing information:

C
#include <stdio.h>

int main(void)
{
    int whole = 3.99;         // 3: the fraction is dropped (a warning with -Wconversion)
    double d = 7;             // 7.0
    char small = 300;         // 44: 300 does not fit in a char, only the low 8 bits are kept
    printf("%d %f %d\n", whole, d, small);
    return 0;
}

Casts

A cast converts on purpose: (type)value.

C
double average = (double)sum / count;     // a real division
int rounded = (int)(x + 0.5);             // round a positive double to the nearest int
unsigned char byte = (unsigned char)value;   // keep the low 8 bits, on purpose

Increment and compound assignment

C
#include <stdio.h>

int main(void)
{
    int n = 5;
    n += 3;      // n = n + 3  -> 8
    n *= 2;      // 16
    n -= 1;      // 15
    n /= 4;      // 3
    n %= 2;      // 1
    n++;         // 2
    n--;         // 1
    printf("%d\n", n);
    return 0;
}

n++ and ++n both add one. The difference matters only when the expression's value is used: a = n++ gives a the old value, a = ++n the new one. Keep increments on their own line and the difference never bites.

Precedence

*, / and % happen before + and -, as in maths; use brackets when in doubt.

C
int x = 2 + 3 * 4;      // 14
int y = (2 + 3) * 4;    // 20

Overflow

Integers have fixed sizes (INT_MAX is 2,147,483,647). What happens when a result is too big depends on the type:

  • unsigned types wrap around, defined and predictable: UINT_MAX + 1 is 0.
  • signed overflow is undefined behaviour (lesson 6.02): the C standard does not say what happens, and optimising compilers may assume it never does. In practice you often see a wrap to a negative number, but you must not rely on it.
C
#include <limits.h>
#include <stdio.h>

int main(void)
{
    unsigned int u = UINT_MAX;
    u = u + 1;
    printf("%u\n", u);                       // 0: defined wrap-around
    long long big = (long long)INT_MAX + 1;  // widen first, then add: no overflow
    printf("%lld\n", big);
    return 0;
}

When a sum might not fit, do it in a wider type.
