Variables and Types

lesson 1.022 of 5 in milestone 15 min1 practice task

Every variable in C has a type that decides its size in bytes and what its bits mean - char, short, int, long, long long, float, double, and their unsigned forms. sizeof tells you the size, limits.h the ranges. Always give a variable a value before using it, and use const for values that never change.

Declaring variables

A variable is a named piece of memory. In C you must say its type when you create it:

C
#include <stdio.h>

int main(void)
{
    int age = 15;              // a whole number
    double height = 1.72;      // a number with a fraction
    char grade = 'A';          // one character (a small number: 65)
    printf("%d %.2f %c\n", age, height, grade);
    return 0;
}

The type decides two things: how many bytes the variable takes, and what its bits mean - a whole number, a fraction, a character.

The basic types

Type Typical size Holds Range (typical)
char 1 byte a character, or a small number −128 to 127
short 2 bytes a whole number −32,768 to 32,767
int 4 bytes the usual whole number about ±2.1 billion
long 8 bytes on Linux and macOS, 4 on Windows a bigger whole number
long long 8 bytes a big whole number about ±9.2 × 10¹⁸
float 4 bytes a fraction, about 7 digits
double 8 bytes a fraction, about 15 digits: use this one

"Typical", because C only guarantees minimums: an int is at least 16 bits, and on every desktop and phone today it is 32. When you need an exact size, use the fixed-width types of stdint.h (int32_t, uint8_t), covered in milestone 5.

Put unsigned in front of a whole-number type for no negatives and twice the positive range: unsigned char is 0 to 255, unsigned int 0 to about 4.29 billion.

sizeof

sizeof gives the size of a type or variable in bytes. Its result has the type size_t, printed with %zu:

C
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("char %zu, int %zu, long long %zu, double %zu bytes\n",
           sizeof(char), sizeof(int), sizeof(long long), sizeof(double));
    printf("int goes from %d to %d\n", INT_MIN, INT_MAX);
    printf("unsigned char goes up to %d\n", UCHAR_MAX);
    return 0;
}

limits.h has the ranges: INT_MAX, INT_MIN, LLONG_MAX, UCHAR_MAX and so on.

Always initialise

A variable created inside a function holds whatever bits were left in that memory until you give it a value. Reading it before then is a bug:

C
int total;            // garbage
total = total + 5;    // undefined: total was never set
C
int total = 0;        // always give a starting value
total = total + 5;

The compiler warns about many of these (-Wall turns the warnings on), but not all. Make it a habit: declare and initialise in one line.

Characters are numbers

A char is a 1-byte number. 'A' in single quotes is the character's ASCII number, 65:

C
#include <stdio.h>

int main(void)
{
    char c = 'A';
    printf("%c is %d\n", c, c);           // A is 65
    printf("%c\n", c + 1);                // B
    printf("%c\n", 'a' - 'A' + 'Q');      // q: lower case is 32 more
    return 0;
}

'A' (single quotes) is one character; "A" (double quotes) is a string, which is different (lesson 2.05).

const

Mark values that never change with const. The compiler then refuses any attempt to change them, which catches mistakes and documents your intent:

C
#include <stdio.h>

int main(void)
{
    const double PI = 3.14159265358979;
    const int DAYS_IN_WEEK = 7;
    double r = 2.0;
    printf("area %.3f, %d days\n", PI * r * r, DAYS_IN_WEEK);
    // PI = 3.0;   // error: assignment of read-only variable 'PI'
    return 0;
}

Names

Names may contain letters, digits and _, and must not start with a digit. Case matters: total and Total are different. Common style is lower_case_with_underscores for variables and functions, and UPPER_CASE for constants.
