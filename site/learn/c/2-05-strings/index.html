Strings

lesson 2.055 of 6 in milestone 25 min1 practice task

A C string is an array of chars ending in a zero byte, '\0', which is how every string function knows where the text stops. A literal like "hi" is three bytes. Strings cannot be compared with == or assigned with =. Read a line with fgets, which keeps the new line, and loop over characters until the '\0'.

Characters with a zero at the end

C has no string type. A string is an array of char with a zero byte after the last character: '\0', called the terminator or null character.

The text Hi C takes 5 bytes: H, i, space, C, and 0. Every function that works on strings walks along the bytes until it meets the 0. That is the only way it knows where the string ends.

C
#include <stdio.h>

int main(void)
{
    char word[] = "cat";            // 4 bytes: 'c' 'a' 't' '\0'
    printf("%s has %zu bytes\n", word, sizeof word);
    word[0] = 'b';
    printf("%s\n", word);           // bat
    return 0;
}

char word[] = "cat"; makes an array and copies the text in, so you can change it. %s prints characters until the terminator.

Forget the terminator and the string never ends

char word[3] = "cat"; has no room for the '\0' (C allows it, sadly). printf("%s", word) then keeps printing whatever bytes follow in memory. Always leave room: a string of n characters needs n + 1 bytes.

Literals are read-only

C
const char *name = "Ada";       // points at a literal, stored in read-only memory
char copy[] = "Ada";            // an array of your own, filled from the literal

name points at text built into the program. Changing it (name[0] = 'a') crashes on most systems, so always point at literals with const char *. copy is your own array and can change. Lesson 3.02 explains the *.

What does not work

C
char a[] = "hello";
char b[] = "hello";
if (a == b) { }          // compares ADDRESSES: false, they are different arrays
a = "bye";               // error: arrays cannot be assigned

Comparing and copying strings is done by functions (strcmp, snprintf, lesson 2.06), or by a loop over the characters.

Looping over a string

Walk until the terminator:

C
#include <stdio.h>

int count_vowels(const char text[])
{
    int count = 0;
    for (int i = 0; text[i] != '\0'; i++) {
        char c = text[i];
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }
    return count;
}

int main(void)
{
    printf("%d\n", count_vowels("the quick brown fox"));   // 5
    return 0;
}

Since a char is just a small number, arithmetic works on letters: c - 'a' is a letter's position in the alphabet, '0' + 7 is the character '7', and c - 32 turns a lower-case ASCII letter into upper case (the Fundamentals course shows why: one bit).

Reading a line: fgets

scanf("%s", buffer) stops at the first space and does not know how big the buffer is, which makes it dangerous. Read lines with fgets:

C
#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[50];
    printf("Your full name: ");
    if (fgets(name, sizeof name, stdin) == NULL) {
        return 1;                       // no input at all
    }
    name[strcspn(name, "\n")] = '\0';   // cut off the new line
    printf("Hello, %s!\n", name);
    return 0;
}
  • fgets(buffer, size, stdin) reads up to the end of the line, but never more than size - 1 characters, and always adds the '\0'.
  • It keeps the '\n' at the end if there was room for it. strcspn(name, "\n") is the position of the first new line (or the length, if there is none), so writing a 0 there removes it.
  • It returns NULL when there is no more input, so while (fgets(...) != NULL) reads every line.
Lines, then numbers

To read numbers safely, read the line with fgets, then pick the numbers out of it with sscanf(line, "%d", &n). A bad line can then be reported and skipped, instead of leaving scanf stuck on it.
