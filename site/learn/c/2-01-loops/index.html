Loops

lesson 2.011 of 6 in milestone 25 min2 practice tasks

while repeats while a condition holds, for packs the start, the test and the step into one line, and do-while always runs once. break leaves a loop and continue skips to the next round. Watch for off-by-one mistakes and loops that never end.

while

C
#include <stdio.h>

int main(void)
{
    int countdown = 5;
    while (countdown > 0) {
        printf("%d...\n", countdown);
        countdown--;
    }
    printf("Lift off!\n");
    return 0;
}

while checks the condition before each round. If it is false at the start, the body never runs. Something inside the loop must eventually make the condition false, or the loop runs forever.

for

Most loops count. for puts the three parts of counting on one line:

C
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 5; i++) {
        printf("%d squared is %d\n", i, i * i);
    }
    return 0;
}
Part Runs
int i = 1 once, before the loop
i <= 5 before every round; the loop stops when it is false
i++ after every round

A variable declared in the for line (C99 and later) exists only inside the loop.

Count from 0

Arrays in C start at index 0, so the most common loop is for (int i = 0; i < n; i++): it runs exactly n times, with i going from 0 to n - 1. Writing i <= n by mistake runs one time too many: an off-by-one error.

do-while

do { ... } while (condition); runs the body first and checks afterwards, so it always runs at least once. It suits "ask until the answer is valid":

C
#include <stdio.h>

int main(void)
{
    int age = 0;
    do {
        printf("Your age (1-130): ");
        if (scanf("%d", &age) != 1) return 1;
    } while (age < 1 || age > 130);
    printf("Thanks, %d it is.\n", age);
    return 0;
}

Note the semicolon after while (...).

break and continue

  • break leaves the loop immediately.
  • continue skips the rest of this round and goes on with the next one (in a for, the step still runs).
C
#include <stdio.h>

int main(void)
{
    // the first number above 100 that is divisible by 7 and by 11
    for (int n = 101; ; n++) {          // no condition: loop until break
        if (n % 7 != 0) continue;
        if (n % 11 != 0) continue;
        printf("%d\n", n);
        break;
    }
    return 0;
}

Loops inside loops

C
#include <stdio.h>

int main(void)
{
    for (int row = 1; row <= 4; row++) {
        for (int col = 1; col <= row; col++) {
            printf("*");
        }
        printf("\n");
    }
    return 0;
}

The inner loop runs completely for every round of the outer one. break only leaves the innermost loop.

Reading until the input ends

scanf returns how many values it read. At the end of the input it returns EOF (a negative number), so this loop adds up numbers until there are no more:

C
#include <stdio.h>

int main(void)
{
    int number = 0;
    int total = 0;
    int count = 0;
    while (scanf("%d", &number) == 1) {
        total += number;
        count++;
    }
    printf("%d numbers, total %d\n", count, total);
    return 0;
}

When you type input in the console, press Ctrl+D to end it, the same key as in a Linux or Mac terminal. In checked tasks the input ends when the test's lines run out.
