Bitwise Operators

lesson 5.011 of 5 in milestone 55 min1 practice task

& | ^ and ~ work on each bit separately, and << and >> slide bits left and right. With a mask you can test, set, clear and flip single bits, which is how flags, permissions and hardware registers are handled. Shift unsigned values, and keep shift counts below the width of the type.

Working on bits

C can work on the individual bits of an integer. Each operator treats the bits one position at a time:

Operator Bit is 1 when Example (8 bits)
a & b both bits are 1 (AND) 1100 & 1010 = 1000
a | b either bit is 1 (OR) 1100 | 1010 = 1110
a ^ b the bits differ (XOR) 1100 ^ 1010 = 0110
~a the bit is 0 (NOT) ~00001111 = 11110000
a << n bits slide n places left, 0s come in on the right 00000011 << 2 = 00001100
a >> n bits slide n places right 00001100 >> 2 = 00000011

Shifting left by n multiplies by 2ⁿ; shifting right divides by 2ⁿ (rounding down). 1u << 10 is 1024.

Don't confuse them with the logical operators: && and || treat whole values as true or false; & and | combine bit by bit. 6 && 1 is 1, but 6 & 1 is 0.

Masks

A mask is a number with 1s in the positions you care about. 1u << n is the mask for bit n:

C
#include <stdio.h>

int main(void)
{
    unsigned int flags = 0;
    flags |= 1u << 3;               // set bit 3
    flags |= 1u << 0;               // set bit 0
    printf("%u\n", flags);          // 9: binary 1001
    flags &= ~(1u << 3);            // clear bit 3
    flags ^= 1u << 5;               // flip bit 5
    printf("%u\n", flags);          // 33: binary 100001
    if (flags & (1u << 5)) {        // test bit 5
        printf("bit 5 is set\n");
    }
    return 0;
}

Flags

Bits make compact on/off settings, each named by a constant:

C
#include <stdio.h>

enum {
    PERM_READ = 1 << 2,     // 4
    PERM_WRITE = 1 << 1,    // 2
    PERM_EXEC = 1 << 0,     // 1
};

void show(unsigned perms)
{
    printf("%c%c%c\n",
           perms & PERM_READ ? 'r' : '-',
           perms & PERM_WRITE ? 'w' : '-',
           perms & PERM_EXEC ? 'x' : '-');
}

int main(void)
{
    unsigned owner = PERM_READ | PERM_WRITE;
    show(owner);                    // rw-
    show(owner | PERM_EXEC);        // rwx
    show(05);                       // r-x: an octal number, like chmod 755
    return 0;
}

This is exactly how Unix file permissions work: chmod 755 is three octal digits, each one 3 bits of read, write and execute.

Pulling fields out of a number

Shift down, then mask: an RGB colour packed as 0xRRGGBB:

C
#include <stdio.h>

int main(void)
{
    unsigned colour = 0x3A7BD5;
    unsigned red = (colour >> 16) & 0xFF;
    unsigned green = (colour >> 8) & 0xFF;
    unsigned blue = colour & 0xFF;
    printf("%u %u %u\n", red, green, blue);       // 58 123 213
    unsigned back = (red << 16) | (green << 8) | blue;
    printf("%06X\n", back);                       // 3A7BD5
    return 0;
}

XOR tricks

XOR is its own undo: x ^ k ^ k == x. That makes it the heart of simple ciphers and checksums, and x ^ x is always 0 (compilers zero registers with xor eax, eax, as the Assembly course shows).

Shifting safely
  • Shift unsigned values. Shifting a negative number left is undefined, and shifting one right may or may not copy the sign bit.
  • The shift count must be less than the type's width: 1u << 32 on a 32-bit unsigned is undefined. For bit 40 use 1ull << 40.
  • 1 << 31 overflows a signed int: write 1u << 31.
