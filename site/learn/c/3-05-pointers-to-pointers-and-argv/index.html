Pointers to Pointers and argv

lesson 3.055 of 5 in milestone 35 min1 practice task

A pointer is a variable too, so it has an address, and a pointer to a pointer (char **) lets a function move the caller's pointer. An array of strings is an array of char pointers, and main's argc and argv are exactly that - the words typed after the program's name. Sorting strings means swapping pointers, not text.

A pointer to a pointer

A pointer is a variable, so it lives at an address too:

C
#include <stdio.h>

int main(void)
{
    int value = 7;
    int *p = &value;
    int **pp = &p;              // the address of the pointer

    printf("%d %d %d\n", value, *p, **pp);   // 7 7 7
    **pp = 8;                   // follow twice: changes value
    printf("%d\n", value);      // 8
    return 0;
}

Why bother? For the same reason as lesson 3.03: to let a function change the caller's pointer, the function needs the pointer's address.

C
#include <ctype.h>
#include <stdio.h>

// Reads one word starting at *cursor, copies it into out, and moves *cursor past it.
int next_word(const char **cursor, char *out, size_t size)
{
    const char *s = *cursor;
    while (isspace((unsigned char)*s)) s++;
    if (*s == '\0') return 0;
    size_t n = 0;
    while (*s != '\0' && !isspace((unsigned char)*s)) {
        if (n + 1 < size) out[n++] = *s;
        s++;
    }
    out[n] = '\0';
    *cursor = s;                // the caller's pointer moves on
    return 1;
}

int main(void)
{
    const char *text = "  three little  words ";
    char word[20];
    while (next_word(&text, word, sizeof word)) {
        printf("[%s]\n", word);
    }
    return 0;
}

This is how strtol(text, &end, 10) hands back end: its parameter is a char **.

Arrays of strings

An array of strings is usually an array of pointers, each pointing at its own text:

C
#include <stdio.h>

int main(void)
{
    const char *planets[] = {"Mercury", "Venus", "Earth", "Mars"};
    size_t count = sizeof planets / sizeof planets[0];
    for (size_t i = 0; i < count; i++) {
        printf("%zu: %s (starts with %c)\n", i, planets[i], planets[i][0]);
    }
    return 0;
}

planets holds 4 addresses (32 bytes), not the letters. planets[i][0] follows pointer i and takes its first character. Passed to a function, it becomes const char **.

Compare a real two-dimensional array, char names[4][8], which holds 4 × 8 = 32 characters in place, every row the same length. The pointer version lets every string have its own length.

argc and argv

main can take the words typed after the program's name in a terminal:

C
int main(int argc, char *argv[])

Running ./greet Ada Grace gives argc = 3 and
argv[0] "./greet": the program's own name
argv[1] "Ada"
argv[2] "Grace"
argv[3] NULL: the end marker
C
#include <stdio.h>

int main(int argc, char *argv[])
{
    printf("%d argument(s)\n", argc);
    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }
    return 0;
}

On the website, type arguments under Program arguments in the editor's Input tab, then run. Command-line tools such as gcc -Wall hello.c are just programs reading their argv.

Sorting strings: move the pointers

To put an array of strings in order, swap the pointers, never the characters. Every swap moves 8 bytes, however long the text:

C
#include <stdio.h>
#include <string.h>

void sort_words(const char *words[], size_t count)
{
    for (size_t i = 1; i < count; i++) {          // insertion sort
        const char *current = words[i];
        size_t j = i;
        while (j > 0 && strcmp(words[j - 1], current) > 0) {
            words[j] = words[j - 1];
            j--;
        }
        words[j] = current;
    }
}

int main(void)
{
    const char *words[] = {"pear", "apple", "fig", "banana"};
    sort_words(words, 4);
    for (int i = 0; i < 4; i++) printf("%s\n", words[i]);
    return 0;
}
