Addresses and Pointers

lesson 3.011 of 5 in milestone 35 min1 practice task

Every variable lives at an address in memory. & gives a variable's address, a pointer variable stores one, and * follows it to the value there. A pointer's type says what it points at. NULL means "points at nothing", and following NULL or a pointer that was never set crashes the program or worse.

Every variable has an address

Memory is one long row of bytes, each with a number: its address. A variable is a few of those bytes. & gives the address of a variable, and %p prints it (in hex):

C
#include <stdio.h>

int main(void)
{
    int score = 1200;
    double ratio = 0.75;
    printf("score is at %p and holds %d\n", (void *)&score, score);
    printf("ratio is at %p and holds %.2f\n", (void *)&ratio, ratio);
    return 0;
}

The addresses change from run to run (the operating system places the stack at a random spot each time, a protection called ASLR), but each variable has one for as long as it exists.

A pointer stores an address

C
#include <stdio.h>

int main(void)
{
    int score = 1200;
    int *p = &score;        // p is "a pointer to int", holding score's address

    printf("%d\n", *p);     // follow the pointer: 1200
    *p = 1500;              // change the int that p points at
    printf("%d\n", score);  // 1500: score itself changed
    return 0;
}

The two meanings of *:

Where Means
in a declaration: int *p p is a pointer to int
in an expression: *p the thing p points at (dereference)

& and * undo each other: *&score is score.

Pointer types

The type tells C what is at the address, and so how many bytes *p reads and how to read them:

C
int *ip;        // *ip reads 4 bytes as an int
double *dp;     // *dp reads 8 bytes as a double
char *cp;       // *cp reads 1 byte as a char

Every pointer is the same size (8 bytes on a 64-bit machine), whatever it points at. void * is a pointer with no type: it can hold any address but cannot be dereferenced until it is converted (that is why %p wants (void *)).

NULL: pointing at nothing

NULL is the pointer that points nowhere. Use it to mean "no value yet" or "not found", and check for it before following a pointer:

C
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *found = strchr("hello", 'z');
    if (found == NULL) {
        printf("no z\n");
    } else {
        printf("found: %s\n", found);
    }
    return 0;
}
Bad pointers
  • Following NULL (*p when p is NULL) crashes with a segmentation fault: the operating system stops a program that touches memory it does not own.
  • A pointer that was never set holds garbage, so *p = 5 writes to a random address. It may crash, or quietly damage other data. Give every pointer a value when you declare it: an address, or NULL.

Why pointers?

They let a function change the caller's variables (lesson 3.03), walk through arrays and strings (3.02), hand over big structures without copying them, and build memory that grows while the program runs (module 4). Every other language uses them too; C just shows them to you.
