printf and scanf

lesson 1.033 of 5 in milestone 15 min1 practice task

printf prints with a format string where each % specifier stands for a value - %d, %f, %c, %s, %zu, %x - with optional width and precision. scanf reads input with the same kind of specifiers, into variables whose addresses you pass with &, and returns how many values it managed to read, which you should always check.

printf

printf prints a format string. Each % specifier in it is replaced by the next value after the string:

C
#include <stdio.h>

int main(void)
{
    int apples = 3;
    double price = 0.4;
    printf("%d apples at %f each\n", apples, price);
    printf("%d apples at %.2f each, %.2f in total\n", apples, price, apples * price);
    return 0;
}
Specifier For Example output
%d int (and char, short) as a decimal number 42
%ld, %lld long, long long 9000000000
%u unsigned int 4000000000
%f double (6 decimals by default) 3.141593
%.2f double with 2 decimals 3.14
%e, %g scientific, or the shorter of %f and %e 1.5e+06
%c a character A
%s a string hello
%x, %X hexadecimal ff, FF
%zu size_t (what sizeof and strlen give) 8
%p a pointer (an address) 0x7ffd5e3c
%% a literal % %
The type must match

The compiler does not convert values for printf: %d must get an int, %f a double. printf("%d", 3.5) prints garbage. GCC warns about mismatches when warnings are on - read them.

Width and alignment

A number between % and the letter sets the minimum width; - aligns left; 0 pads with zeros:

C
#include <stdio.h>

int main(void)
{
    printf("[%5d]\n", 42);       // [   42]  right-aligned in 5
    printf("[%-5d]\n", 42);      // [42   ]  left-aligned
    printf("[%05d]\n", 42);      // [00042]  zero-padded
    printf("[%8.3f]\n", 3.14159);// [   3.142]
    printf("[%-8s]|\n", "tea");  // [tea     ]|
    return 0;
}

Tables of numbers line up neatly this way.

Escape sequences

Inside a string, \ starts an escape:

Escape Means
\n new line
\t tab
\\ a backslash
\" a double quote
\0 the zero byte, which ends a string (lesson 2.05)

scanf

scanf reads input with the same kind of specifiers. Pass the address of each variable with &, so scanf can store into it (pointers come in milestone 3; for now, remember the &):

C
#include <stdio.h>

int main(void)
{
    int a = 0;
    int b = 0;
    printf("Two numbers: ");
    scanf("%d %d", &a, &b);
    printf("%d + %d = %d\n", a, b, a + b);
    return 0;
}

Press Run, and when it asks, type two numbers such as 20 22 and press Enter.

Specifier in scanf Reads into
%d int
%lf double (note: lf in scanf, but plain %f in printf)
%c char; " %c" with a space first skips spaces and new lines
%s a word, into a char array (lesson 2.05)

Always check what scanf returns

scanf returns how many values it read. If the user types hello where a number was expected, it reads nothing, leaves your variable unchanged, and returns 0. At the end of the input it returns EOF (−1).

C
#include <stdio.h>

int main(void)
{
    int n = 0;
    if (scanf("%d", &n) != 1) {
        printf("That was not a whole number.\n");
        return 1;
    }
    printf("Twice that is %d\n", 2 * n);
    return 0;
}

Reading until the input runs out is a loop on that return value:

C
#include <stdio.h>

int main(void)
{
    int n = 0;
    int total = 0;
    while (scanf("%d", &n) == 1) {
        total += n;
    }
    printf("Total: %d\n", total);
    return 0;
}
