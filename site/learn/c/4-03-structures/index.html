Structures

lesson 4.033 of 6 in milestone 45 min1 practice task

A struct groups named fields of different types into one value. Fields are reached with a dot, or with an arrow through a pointer. Structs are copied when assigned or passed, so large ones go by pointer. The compiler adds padding between fields so each one sits at an address that suits it.

Grouping data

C
#include <stdio.h>

struct point {
    int x;
    int y;
};

struct player {
    char name[20];
    int score;
    struct point position;      // a struct inside a struct
};

int main(void)
{
    struct player p = {"Ada", 1200, {3, 4}};
    p.score += 50;
    p.position.x = 10;
    printf("%s has %d points at (%d, %d)\n", p.name, p.score, p.position.x, p.position.y);
    return 0;
}
  • struct point { ... }; defines a new type called struct point. Note the semicolon at the end.
  • . reaches a field.
  • Initialise in order with { }, or by name with designated initialisers, which are clearer and leave the rest as 0:
C
struct player q = {.name = "Grace", .score = 900};   // position is {0, 0}

Structs are values

Unlike arrays, structs can be assigned, passed and returned, and that copies every field:

C
#include <stdio.h>

struct point {
    int x;
    int y;
};

struct point moved(struct point p, int dx, int dy)
{
    p.x += dx;              // changes the copy
    p.y += dy;
    return p;
}

int main(void)
{
    struct point a = {1, 2};
    struct point b = moved(a, 10, 0);
    printf("a=(%d,%d) b=(%d,%d)\n", a.x, a.y, b.x, b.y);   // a unchanged
    return 0;
}

Even an array inside a struct is copied. But == does not work on structs: compare field by field.

Pointers to structs: the arrow

To change a caller's struct, or to avoid copying a big one, pass a pointer. p->field is short for (*p).field:

C
#include <stdio.h>

struct account {
    char owner[32];
    long cents;
};

void deposit(struct account *a, long cents)
{
    a->cents += cents;
}

void print_account(const struct account *a)
{
    printf("%s: %ld.%02ld\n", a->owner, a->cents / 100, a->cents % 100);
}

int main(void)
{
    struct account acc = {"Ken", 1050};
    deposit(&acc, 299);
    print_account(&acc);       // Ken: 13.49
    return 0;
}

Structs on the heap work the same way: struct account *a = malloc(sizeof *a); then a->cents = 0;.

Arrays of structs

C
#include <stdio.h>

struct item {
    const char *name;
    int quantity;
    double price;
};

int main(void)
{
    struct item cart[] = {
        {"tea", 2, 3.50},
        {"bread", 1, 2.25},
        {"jam", 3, 4.00},
    };
    double total = 0;
    for (size_t i = 0; i < sizeof cart / sizeof cart[0]; i++) {
        total += cart[i].quantity * cart[i].price;
    }
    printf("%.2f\n", total);
    return 0;
}

Padding: structs in memory

Fields are stored in the order you write them, but the compiler may add unused padding bytes so that each field is aligned: an int at an address divisible by 4, a double by 8. The processor reads aligned values faster, and some processors cannot read unaligned ones at all.

C
#include <stdio.h>
#include <stddef.h>

struct messy { char a; double b; char c; };     // 1 + 7 padding + 8 + 1 + 7 padding
struct tidy { double b; char a; char c; };      // 8 + 1 + 1 + 6 padding

int main(void)
{
    printf("messy: %zu bytes, b at offset %zu\n", sizeof(struct messy), offsetof(struct messy, b));
    printf("tidy: %zu bytes\n", sizeof(struct tidy));
    return 0;
}

Putting the biggest fields first often makes a struct smaller. It matters when you have millions of them, or when the struct must match a file format byte for byte (lesson 5.02).
