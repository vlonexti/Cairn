Pointers as Parameters

lesson 3.033 of 5 in milestone 35 min1 practice task

Passing a variable's address lets a function change it, which is how swap works and why scanf needs &. Out-parameters return extra results, with the return value saying whether it worked. Never return the address of a local variable - it dies when the function returns.

Changing the caller's variables

Arguments are copies (lesson 2.02). To let a function change a variable, give it the variable's address:

C
#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 1, y = 2;
    swap(&x, &y);
    printf("x=%d y=%d\n", x, y);    // x=2 y=1
    return 0;
}

The pointers are copies too, but copies of an address still lead to the same variables.

This is also why scanf("%d", &n) needs the &: scanf has to store into your variable, so it needs its address.

Out-parameters

A function returns one value. For more, the caller passes addresses where the extra results go. The return value usually says whether it worked:

C
#include <stdio.h>
#include <stdbool.h>

bool divide(int a, int b, int *quotient, int *remainder)
{
    if (b == 0) return false;
    *quotient = a / b;
    *remainder = a % b;
    return true;
}

int main(void)
{
    int q = 0, r = 0;
    if (divide(17, 5, &q, &r)) {
        printf("17 = 5 x %d + %d\n", q, r);
    }
    if (!divide(1, 0, &q, &r)) {
        printf("cannot divide by zero\n");
    }
    return 0;
}

The standard library does this everywhere: strtol(text, &end, 10) returns the number and stores where it stopped in end.

Optional outputs

Let the caller pass NULL for a result it does not want, and check before writing: if (remainder != NULL) *remainder = a % b;.

Pointers to big things

Copying a large structure into a parameter takes time; passing its address costs 8 bytes. const (next lesson) says the function only reads through it: void print_report(const struct report *r).

Never return a local's address

Dangling pointers
C
int *broken(void)
{
    int result = 42;
    return &result;      // result dies when the function returns
}

The caller gets the address of a stack frame that is already gone. The next function call reuses that memory, and the "42" turns into something else. GCC warns: "function returns address of local variable". A function can return pointers to: the caller's memory (that it was given), static or global variables, string literals, or memory from malloc (lesson 4.01).
