The String Library

lesson 2.066 of 6 in milestone 25 min1 practice task

string.h has strlen, strcmp, strchr, strstr and memcpy. Copying and joining text safely means knowing the buffer size - snprintf is the safe tool, while strcpy and strcat trust you. ctype.h classifies and converts characters, and strtol turns text into numbers and tells you where it stopped.

Length and comparison

C
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *a = "apple";
    const char *b = "banana";
    printf("%zu\n", strlen(a));          // 5: the terminator is not counted
    printf("%d\n", strcmp(a, a) == 0);   // 1: equal
    printf("%d\n", strcmp(a, b) < 0);    // 1: "apple" comes first
    printf("%d\n", strncmp("prefix-x", "prefix-y", 6) == 0);   // 1: first 6 match
    return 0;
}

strcmp returns 0 when the strings are equal, a negative number when the first comes before the second, and a positive one when it comes after. if (strcmp(a, b)) is true when they are different, which reads backwards: always write == 0.

strlen walks the whole string every time it is called. In for (i = 0; i < strlen(s); i++) it runs on every round; store it in a variable first.

Copying and joining: know your sizes

Function Danger
strcpy(dest, src) copies the whole of src, however small dest is
strcat(dest, src) appends after dest's text, however full dest is
strncpy(dest, src, n) does not add '\0' if src is too long
snprintf(dest, size, format, ...) safe: never writes more than size bytes, always terminates

snprintf is printf into a buffer, and it handles copying, joining and formatting in one:

C
#include <stdio.h>

int main(void)
{
    char label[20];
    const char *first = "Ada";
    const char *last = "Lovelace";
    int n = snprintf(label, sizeof label, "%s, %s", last, first);
    printf("%s (%d characters)\n", label, n);

    char tiny[8];
    n = snprintf(tiny, sizeof tiny, "%s, %s", last, first);
    printf("%s - wanted %d, so it was cut\n", tiny, n);
    return 0;
}

It returns the length the full text would have had; if that is size or more, the text was cut short.

Searching

C
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *email = "grace@example.org";
    const char *at = strchr(email, '@');        // first '@', or NULL
    if (at != NULL) {
        printf("domain: %s\n", at + 1);
        printf("name is %d characters\n", (int)(at - email));
    }
    printf("%d\n", strstr(email, "example") != NULL);   // 1: found
    return 0;
}

strchr and strstr return a pointer into the string where the match starts, or NULL. Pointer arithmetic like at - email is lesson 3.02; for now, at + 1 is "the text after the @".

Raw bytes: memcpy, memset, memcmp

The mem functions work on any bytes and take an explicit count, terminator or not:

C
int a[5] = {1, 2, 3, 4, 5};
int b[5];
memcpy(b, a, sizeof a);       // copy 20 bytes
memset(b, 0, sizeof b);       // set all 20 bytes to 0

ctype.h: kinds of character

Function True for
isalpha(c) a letter
isdigit(c) '0' to '9'
isalnum(c) a letter or digit
isspace(c) space, tab, new line and friends
isupper(c), islower(c) upper or lower case letters

toupper(c) and tolower(c) convert letters and leave everything else alone.

Cast to unsigned char

These functions take an int that must be an unsigned char value or EOF. A plain char can be negative (for bytes above 127, such as UTF-8 text), which is undefined. Write isalpha((unsigned char)c).

Text to numbers: strtol

atoi("42") gives 42 but cannot tell you about errors (atoi("cat") is just 0). strtol reports where it stopped:

C
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *inputs[] = {"42", "  -17 apples", "cat", "ff"};
    for (int i = 0; i < 4; i++) {
        char *end = NULL;
        long value = strtol(inputs[i], &end, 10);
        if (end == inputs[i]) {
            printf("'%s': not a number\n", inputs[i]);
        } else {
            printf("'%s': %ld, then '%s'\n", inputs[i], value, end);
        }
    }
    printf("%ld\n", strtol("ff", NULL, 16));   // base 16: 255
    return 0;
}

The last argument is the base: 10, 16, 2, or 0 to accept 0x for hex. strtod does the same for double.
