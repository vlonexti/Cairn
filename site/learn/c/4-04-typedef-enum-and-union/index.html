typedef, enum and union

lesson 4.044 of 6 in milestone 45 min1 practice task

typedef gives a type a new name, often used to drop the word struct. enum names a set of integer constants and makes switch statements readable. A union stores one of several types in the same memory, and a tagged union pairs it with an enum saying which one is there.

typedef

typedef makes a new name for an existing type:

C
#include <stdio.h>

typedef struct {
    double x;
    double y;
} Vec2;

typedef unsigned char byte;

Vec2 add(Vec2 a, Vec2 b)
{
    return (Vec2){a.x + b.x, a.y + b.y};     // a compound literal: a struct value on the spot
}

int main(void)
{
    Vec2 v = add((Vec2){1.5, 2}, (Vec2){0.5, 1});
    byte flags = 255;
    printf("(%.1f, %.1f) %d\n", v.x, v.y, flags);
    return 0;
}

Styles differ: the Linux kernel avoids typedefs for structs so you always see struct; many other projects typedef everything. Both are fine; be consistent. A struct that points to its own type (the next lesson) needs its struct name too:

C
typedef struct node {
    int value;
    struct node *next;      // the typedef name does not exist yet at this point
} Node;

enum

An enum names a set of whole-number constants:

C
#include <stdio.h>

enum direction { NORTH, EAST, SOUTH, WEST };        // 0, 1, 2, 3

enum direction turn_right(enum direction d)
{
    return (enum direction)((d + 1) % 4);
}

const char *direction_name(enum direction d)
{
    switch (d) {
    case NORTH: return "north";
    case EAST: return "east";
    case SOUTH: return "south";
    case WEST: return "west";
    }
    return "?";
}

int main(void)
{
    enum direction facing = WEST;
    facing = turn_right(facing);
    printf("now facing %s (%d)\n", direction_name(facing), facing);
    return 0;
}
  • Values count up from 0 unless you set them: enum http { OK = 200, NOT_FOUND = 404 };.
  • An enum is really an int; C will not stop you storing 17 in one. But -Wall warns when a switch over an enum forgets a value, which catches bugs when you add a new one.
  • Use enums instead of "magic numbers" like if (state == 3).

union

A union looks like a struct, but all its fields share the same memory: it holds one of them at a time, and its size is that of the biggest.

C
#include <stdio.h>

union number {
    int i;
    float f;
    unsigned char bytes[4];
};

int main(void)
{
    union number n;
    n.f = 1.0f;
    printf("%zu bytes\n", sizeof n);
    printf("1.0f is stored as %02x %02x %02x %02x\n", n.bytes[3], n.bytes[2], n.bytes[1], n.bytes[0]);
    return 0;
}

Writing one field and reading another reinterprets the bytes. Here it shows that 1.0f is 3f 80 00 00 in IEEE 754 (the Fundamentals course explains the format).

Tagged unions

The useful pattern pairs a union with an enum saying which field is in use. It is how a value can be "one of several kinds", like a number or a piece of text:

C
#include <stdio.h>

enum kind { NUMBER, TEXT };

struct value {
    enum kind kind;
    union {
        double number;
        const char *text;
    };                          // an anonymous union (C11): fields used directly
};

void print_value(struct value v)
{
    switch (v.kind) {
    case NUMBER: printf("number %g\n", v.number); break;
    case TEXT: printf("text \"%s\"\n", v.text); break;
    }
}

int main(void)
{
    struct value list[] = {
        {.kind = NUMBER, .number = 3.5},
        {.kind = TEXT, .text = "hello"},
    };
    for (int i = 0; i < 2; i++) print_value(list[i]);
    return 0;
}

This is exactly how interpreters for Python or JavaScript store their values, and what Rust's enum and C++'s std::variant do safely for you.
