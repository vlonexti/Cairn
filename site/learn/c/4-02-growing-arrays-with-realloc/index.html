Growing Arrays with realloc

lesson 4.022 of 6 in milestone 45 min1 practice task

realloc resizes a heap block, moving it if it has to. Assign its result to a temporary so a failure does not lose the old block. A growing array keeps a length and a capacity and doubles the capacity when it is full, so adding stays fast on average - the same trick as Python lists and C++ vectors.

realloc

realloc(pointer, new_size) makes a heap block bigger or smaller and returns its (possibly new) address. If there is no room right after the block, it allocates a new one, copies the old contents across, and frees the old one.

C
int *bigger = realloc(numbers, 2 * capacity * sizeof *numbers);
if (bigger == NULL) {
    // numbers is still valid and still needs freeing
} else {
    numbers = bigger;          // the old address may now be invalid
    capacity *= 2;
}
Never write p = realloc(p, ...)

If realloc fails it returns NULL and leaves the old block alone. p = realloc(p, size) would then overwrite your only pointer to that block: a leak. Use a temporary.

Also, after a successful realloc, any other pointers into the old block are dangling: the data may have moved.

Length and capacity

A growing array keeps three things together: the pointer, how many elements are used (length) and how many fit (capacity). When length reaches capacity, grow:

C
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    size_t length = 0;
    size_t capacity = 4;
    int *numbers = malloc(capacity * sizeof *numbers);
    if (numbers == NULL) return 1;

    int value = 0;
    while (scanf("%d", &value) == 1) {
        if (length == capacity) {
            size_t new_capacity = capacity * 2;
            int *bigger = realloc(numbers, new_capacity * sizeof *numbers);
            if (bigger == NULL) {
                free(numbers);
                return 1;
            }
            numbers = bigger;
            capacity = new_capacity;
            printf("(grew to %zu)\n", capacity);
        }
        numbers[length++] = value;
    }

    for (size_t i = length; i > 0; i--) {
        printf("%d ", numbers[i - 1]);       // backwards
    }
    printf("\n");
    free(numbers);
    return 0;
}

Try it with ten or so numbers (press Ctrl+D to end the input in the console).

Why double?

Growing by one each time would copy every element on every addition: adding n elements would copy about n²/2 of them. Doubling means copies happen rarely: after adding n elements the total copying is less than 2n, so each addition costs a constant amount on average ("amortised O(1)"). Python's list, C++'s std::vector, Rust's Vec and Java's ArrayList all work exactly like this underneath.

Wrapping it up in functions

Passing three separate variables everywhere is clumsy. The next lesson's structures bundle them into one thing:

C
struct int_list {
    int *items;
    size_t length;
    size_t capacity;
};

bool list_push(struct int_list *list, int value);   // grows when needed
void list_free(struct int_list *list);

That is your first real data structure, and you will build it in the practice.
