Variadic Functions

lesson 7.011 of 5 in milestone 75 min2 practice tasks

Functions that take any number of arguments - how printf does it, va_list, va_start, va_arg and va_end, telling the function how many arguments came (a count, a sentinel or a format), default argument promotions, va_copy, wrapping vsnprintf, and letting the compiler check format strings.

How printf takes any number of arguments

printf("%d %s\n", n, name) takes a format and then however many values the format asks for. A function like that is variadic: its parameter list ends with .... Lesson 6.04 showed one quickly; this lesson goes through the details that make them correct.

C
#include <stdarg.h>
#include <stdio.h>

/* Adds count integers. */
int sum(int count, ...)
{
    va_list args;
    va_start(args, count);              /* start after the last named parameter */
    int total = 0;
    for (int i = 0; i < count; i++)
        total += va_arg(args, int);     /* take the next argument as an int */
    va_end(args);                        /* always pair va_start with va_end */
    return total;
}

int main(void)
{
    printf("%d %d %d\n", sum(3, 10, 20, 30), sum(1, 7), sum(0));
    return 0;
}

There must be at least one named parameter before ... (until C23), and va_start names the last one.

The function cannot know how many arguments came

Nothing in C tells a variadic function how many arguments were passed, or their types. It must be told, in one of three ways:

Way Example Risk
a count sum(3, 10, 20, 30) the count is wrong
a sentinel at the end join(", ", "a", "b", NULL) the sentinel is forgotten
a format describing them printf("%d %s", n, s) the format does not match

Reading more arguments than were passed, or reading one as the wrong type, is undefined behaviour: the function reads whatever happens to be in the registers or on the stack.

C
#include <stdarg.h>
#include <stdio.h>
#include <string.h>

/* Writes the strings separated by sep; the list ends with NULL. */
void print_joined(const char *sep, ...)
{
    va_list args;
    va_start(args, sep);
    const char *s = va_arg(args, const char *);
    int first = 1;
    while (s != NULL)
    {
        printf("%s%s", first ? "" : sep, s);
        first = 0;
        s = va_arg(args, const char *);
    }
    va_end(args);
    printf("\n");
}

int main(void)
{
    print_joined(", ", "apples", "pears", "figs", (const char *)NULL);
    return 0;
}

Pass the sentinel as (const char *)NULL: a bare NULL may be an int 0 on some systems, which is not the same size as a pointer.

Default argument promotions

Arguments matching ... are promoted before they are passed: char and short become int, and float becomes double. So inside the function you must ask for the promoted type:

C
#include <stdarg.h>
#include <stdio.h>

double average(int count, ...)
{
    va_list args;
    va_start(args, count);
    double total = 0;
    for (int i = 0; i < count; i++)
        total += va_arg(args, double);   /* never va_arg(args, float) */
    va_end(args);
    return count ? total / count : 0;
}

int main(void)
{
    float a = 1.5f, b = 2.5f;
    printf("%.2f\n", average(2, a, b));  /* the floats arrive as doubles */
    return 0;
}

va_arg(args, char) and va_arg(args, float) are always wrong.

Passing a va_list on: the v-functions

To write your own printf-like function, do not re-implement formatting: hand the va_list to the library's v versions, vprintf, vfprintf, vsnprintf:

C
#include <stdarg.h>
#include <stdio.h>

/* Prints a message with a level in front, like a tiny logger. */
void log_message(const char *level, const char *format, ...)
{
    va_list args;
    va_start(args, format);
    printf("[%s] ", level);
    vprintf(format, args);
    va_end(args);
    printf("\n");
}

int main(void)
{
    log_message("WARN", "disk %d%% full on %s", 91, "C:");
    return 0;
}

A va_list can be walked only once. To walk it twice (for example, once to measure and once to write), make a copy with va_copy:

C
#include <stdarg.h>
#include <stdio.h>
#include <stdlib.h>

/* Like sprintf, but allocates a buffer of the right size. The caller frees it. */
char *format_new(const char *format, ...)
{
    va_list args, again;
    va_start(args, format);
    va_copy(again, args);
    int needed = vsnprintf(NULL, 0, format, args);   /* how long the text will be */
    va_end(args);
    char *text = needed >= 0 ? malloc((size_t)needed + 1) : NULL;
    if (text != NULL)
        vsnprintf(text, (size_t)needed + 1, format, again);
    va_end(again);
    return text;
}

int main(void)
{
    char *s = format_new("%s scored %d (%.1f%%)", "Ada", 42, 87.5);
    if (s != NULL)
    {
        puts(s);
        free(s);
    }
    return 0;
}

Let the compiler check formats

GCC and Clang can check calls to your own printf-like functions if you say which parameter is the format:

C
void log_message(const char *level, const char *format, ...)
    __attribute__((format(printf, 2, 3)));      /* format is parameter 2, the values start at 3 */

Then log_message("INFO", "%d", "oops") gives a warning, exactly as printf would.
