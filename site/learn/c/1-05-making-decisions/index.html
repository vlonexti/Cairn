Making Decisions

lesson 1.055 of 5 in milestone 15 min1 practice task

if and else choose what runs, using comparisons that give 1 (true) or 0 (false). Combine conditions with &&, || and !, which stop as soon as the answer is known. bool comes from stdbool.h. switch picks among whole-number cases - remember break - and the ternary operator chooses between two values.

if and else

C
#include <stdio.h>

int main(void)
{
    int temperature = 0;
    if (scanf("%d", &temperature) != 1) return 1;
    if (temperature < 0) {
        printf("Freezing\n");
    } else if (temperature < 15) {
        printf("Cold\n");
    } else if (temperature < 25) {
        printf("Mild\n");
    } else {
        printf("Hot\n");
    }
    return 0;
}

The conditions are tested in order, and only the first true one runs. Always use braces { }, even for one line: it prevents a classic bug where a second line looks like it belongs to the if but does not.

Comparisons give 1 or 0

Operator Means
== equal
!= not equal
< <= > >= less, less or equal, greater, greater or equal

In C a comparison is just an int: 1 for true, 0 for false. And any number used as a condition counts as true unless it is 0.

C
#include <stdio.h>

int main(void)
{
    printf("%d %d\n", 3 > 2, 3 == 2);   // 1 0
    int lives = 3;
    if (lives) {                         // same as lives != 0
        printf("Still alive\n");
    }
    return 0;
}
= is not ==

if (x = 5) assigns 5 to x, and then tests 5, which is true - always. It compiles. -Wall warns ("suggest parentheses around assignment"). Read your warnings.

bool

C99 added a proper boolean type in stdbool.h: bool, true and false (which are really 1 and 0):

C
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    int year = 2024;
    bool leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
    printf("%d is %sa leap year\n", year, leap ? "" : "not ");
    return 0;
}

&& || !

Operator True when
a && b both are true
a || b at least one is true
!a a is false

&& and || short-circuit: they stop as soon as the answer is known. In count != 0 && total / count > 10, the division never happens when count is 0, so there is no division by zero. Put the safety check first.

switch

switch compares one whole number (or char) against several constants:

C
#include <stdio.h>

int main(void)
{
    char command = 'q';
    switch (command) {
    case 'a':
        printf("add\n");
        break;
    case 'd':
    case 'x':                 // two cases sharing the same code
        printf("delete\n");
        break;
    case 'q':
        printf("quit\n");
        break;
    default:
        printf("unknown command\n");
        break;
    }
    return 0;
}
Don't forget break

Without break, execution falls through into the next case and runs its code too. Sometimes that is what you want ('d' and 'x' above share code), but a forgotten break is a common bug. GCC's -Wimplicit-fallthrough warns about it.

switch works only with integer types: not strings, not doubles.

The conditional operator

condition ? a : b is a value: a if the condition is true, otherwise b.

C
int bigger = (x > y) ? x : y;
printf("%d item%s\n", n, n == 1 ? "" : "s");

Use it for short choices of a value; use if for choosing what to do.
