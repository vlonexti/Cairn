The Standard Library Tour

lesson 6.044 of 5 in milestone 65 min1 practice task

The C standard library is small but covers the basics - input and output, strings, memory, maths, time, random numbers, sorting, characters and errors. Knowing what is there saves rewriting it. Beyond it, POSIX adds the operating system's services, and C23 brings a few modern conveniences.

The headers

Header Gives
stdio.h printf, scanf, fgets, files, snprintf, perror
stdlib.h malloc, free, qsort, bsearch, strtol, strtod, rand, exit, abs, getenv
string.h strlen, strcmp, strchr, strstr, memcpy, memmove, memset, memcmp, strerror
ctype.h isalpha, isdigit, isspace, toupper, tolower
math.h sqrt, pow, sin, cos, floor, ceil, round, fabs, hypot, NAN, INFINITY
stdint.h, inttypes.h exact-width integers and their formats
stdbool.h, stddef.h bool; size_t, NULL, offsetof
limits.h, float.h INT_MAX, LLONG_MIN, DBL_EPSILON
time.h time, clock, localtime, strftime
assert.h, errno.h assert; errno and its codes
stdarg.h functions like printf that take any number of arguments

On Linux, GCC needs -lm to link the maths library; the website adds it for you.

memmove, for overlapping memory

memcpy must not be used when the source and destination overlap; memmove handles that correctly:

C
#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[] = "abcdef";
    memmove(text + 2, text, 4);      // shift right by 2, overlapping
    printf("%s\n", text);            // ababcd
    return 0;
}

Time

C
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);                 // seconds since 1 January 1970 (UTC)
    struct tm *utc = gmtime(&now);
    char text[64];
    strftime(text, sizeof text, "%Y-%m-%d %H:%M:%S UTC", utc);
    printf("%s\n", text);

    clock_t start = clock();                 // processor time used so far
    volatile double x = 0;
    for (int i = 0; i < 10000000; i++) x += i * 0.5;
    printf("the loop took %.3f s of processor time\n", (double)(clock() - start) / CLOCKS_PER_SEC);
    return 0;
}

volatile tells the compiler the variable may change in ways it cannot see, so the loop is not optimised away.

Random numbers

rand() returns a number from 0 to RAND_MAX; srand(seed) chooses where the sequence starts. The same seed always gives the same sequence, which is useful for tests and replays:

C
#include <stdio.h>
#include <stdlib.h>

int roll(void)
{
    return rand() % 6 + 1;        // 1 to 6 (very slightly uneven, fine for games)
}

int main(void)
{
    srand(42);                    // srand((unsigned)time(NULL)) for different runs
    for (int i = 0; i < 5; i++) printf("%d ", roll());
    printf("\n");
    return 0;
}

rand is fine for games and simulations, never for passwords or keys: use the operating system's secure generator (getrandom on Linux, arc4random on BSD and Mac, BCryptGenRandom on Windows).

Variable arguments

printf takes any number of arguments through stdarg.h. Your own functions can too:

C
#include <stdarg.h>
#include <stdio.h>

int sum_ints(int count, ...)
{
    va_list args;
    va_start(args, count);
    int total = 0;
    for (int i = 0; i < count; i++) total += va_arg(args, int);
    va_end(args);
    return total;
}

void log_message(const char *level, const char *format, ...)
{
    va_list args;
    va_start(args, format);
    fprintf(stderr, "[%s] ", level);
    vfprintf(stderr, format, args);      // the v versions take a va_list
    fprintf(stderr, "\n");
    va_end(args);
}

int main(void)
{
    printf("%d\n", sum_ints(4, 10, 20, 30, 40));
    log_message("info", "loaded %d items in %.1f ms", 120, 3.5);
    return 0;
}

The function cannot know how many arguments it got or their types; the caller must say (here count, in printf the format string). Getting it wrong is undefined.

Leaving the program

return from main ends the program; so does exit(status) from anywhere, which still flushes and closes files. atexit(function) registers clean-up to run then. EXIT_SUCCESS and EXIT_FAILURE are the portable status codes.

Beyond the standard

  • POSIX (Linux, Mac, BSD) adds the operating system's services: open, read, write, fork, exec, pthread_create for threads, sockets for networking, getline, strdup.
  • Windows has its own API (CreateFile, CreateThread) alongside the standard library.
  • C11 added threads.h and stdatomic.h; C23 adds bool as a keyword, nullptr, typeof, constexpr, binary literals like 0b1010, strdup and checked arithmetic.
