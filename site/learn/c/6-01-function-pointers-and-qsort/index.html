Function Pointers and qsort

lesson 6.011 of 5 in milestone 65 min1 practice task

A function has an address too, and a function pointer can be stored, passed and called. That lets code take behaviour as a parameter - qsort sorts anything given a comparison function, and tables of function pointers replace long switch statements. A void * parameter lets callbacks carry data of any type.

Functions have addresses

A compiled function is a sequence of machine instructions somewhere in memory, so it has an address. A function pointer stores it:

C
#include <stdio.h>

int add(int a, int b) { return a + b; }
int multiply(int a, int b) { return a * b; }

int main(void)
{
    int (*operation)(int, int) = add;     // a pointer to a function taking (int, int), returning int
    printf("%d\n", operation(6, 7));      // 13
    operation = multiply;
    printf("%d\n", operation(6, 7));      // 42
    return 0;
}

The declaration reads from the name outwards: operation is a pointer (*operation) to a function taking (int, int) and returning int. The parentheses matter: int *operation(int, int) would declare a function returning int *. A typedef makes it readable:

C
typedef int (*binary_op)(int, int);
binary_op op = add;

Passing behaviour as a parameter

C
#include <stdio.h>

typedef int (*transform)(int);

int twice(int x) { return 2 * x; }
int square(int x) { return x * x; }

void apply(int *values, size_t count, transform f)
{
    for (size_t i = 0; i < count; i++) {
        values[i] = f(values[i]);
    }
}

int main(void)
{
    int v[] = {1, 2, 3, 4};
    apply(v, 4, square);
    apply(v, 4, twice);
    for (int i = 0; i < 4; i++) printf("%d ", v[i]);   // 2 8 18 32
    printf("\n");
    return 0;
}

The function passed in is called a callback. It is C's version of passing a lambda in other languages.

qsort

qsort in stdlib.h sorts an array of anything. It knows nothing about your elements, so you tell it their size and give it a comparison function:

C
void qsort(void *base, size_t count, size_t size, int (*compare)(const void *, const void *));

The comparison gets pointers to two elements and returns negative, zero or positive, like strcmp:

C
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct city {
    const char *name;
    int population;
};

int by_population(const void *a, const void *b)
{
    const struct city *x = a;
    const struct city *y = b;
    if (x->population < y->population) return 1;     // biggest first
    if (x->population > y->population) return -1;
    return 0;
}

int by_name(const void *a, const void *b)
{
    const struct city *x = a;
    const struct city *y = b;
    return strcmp(x->name, y->name);
}

int main(void)
{
    struct city cities[] = {{"Oslo", 709000}, {"Lagos", 15400000}, {"Lima", 10900000}, {"Bern", 134000}};
    size_t n = sizeof cities / sizeof cities[0];

    qsort(cities, n, sizeof cities[0], by_population);
    for (size_t i = 0; i < n; i++) printf("%s %d\n", cities[i].name, cities[i].population);

    qsort(cities, n, sizeof cities[0], by_name);
    for (size_t i = 0; i < n; i++) printf("%s ", cities[i].name);
    printf("\n");
    return 0;
}
Don't compare by subtracting

return x->population - y->population; is a popular shortcut that overflows for large or negative values and then sorts wrongly. Compare with < and >.

bsearch uses the same kind of function to find an element in a sorted array.

Tables of functions

An array of function pointers maps a choice to behaviour without a long switch:

C
#include <stdio.h>
#include <string.h>

static double add(double a, double b) { return a + b; }
static double sub(double a, double b) { return a - b; }
static double mul(double a, double b) { return a * b; }

struct command {
    const char *name;
    double (*run)(double, double);
};

static const struct command commands[] = {
    {"add", add}, {"sub", sub}, {"mul", mul},
};

int main(void)
{
    const char *wanted = "mul";
    for (size_t i = 0; i < sizeof commands / sizeof commands[0]; i++) {
        if (strcmp(commands[i].name, wanted) == 0) {
            printf("%g\n", commands[i].run(6, 7));
        }
    }
    return 0;
}

This is also how C does what other languages call methods or interfaces: a struct full of function pointers. The Linux kernel describes every kind of file this way, with a struct file_operations holding pointers to its read, write and open functions.

Carrying data: void *

A callback often needs extra information. The C convention passes a void * alongside, which the callback converts back to what it really is:

C
void for_each(const int *values, size_t count, void (*visit)(int value, void *data), void *data);

void add_up(int value, void *data)
{
    long *total = data;
    *total += value;
}

long total = 0;
for_each(values, n, add_up, &total);
