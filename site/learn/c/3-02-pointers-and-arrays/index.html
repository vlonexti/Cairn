Pointers and Arrays

lesson 3.022 of 5 in milestone 35 min1 practice task

An array's name turns into a pointer to its first element. Adding 1 to a pointer moves it by one element, not one byte, so p[i] is exactly *(p + i). Pointers can walk through arrays and strings, subtracting two pointers gives the distance between them, and a pointer just past the end is allowed as a stopping point.

The array name is a pointer to element 0

In almost every expression, an array's name turns into ("decays to") a pointer to its first element:

C
#include <stdio.h>

int main(void)
{
    int values[4] = {10, 20, 30, 40};
    int *p = values;              // the same as &values[0]
    printf("%d %d\n", *p, values[0]);
    return 0;
}

That is why a function "receiving an array" really receives a pointer (lesson 2.04): int values[] in a parameter list means exactly int *values.

Pointer arithmetic

Adding 1 to a pointer moves it to the next element: the address grows by the size of the type, 4 bytes for an int, 8 for a double, 1 for a char.

C
#include <stdio.h>

int main(void)
{
    int values[4] = {10, 20, 30, 40};
    int *p = values;
    printf("%d\n", *(p + 2));       // 30
    printf("%p\n%p\n", (void *)p, (void *)(p + 1));   // 4 apart
    return 0;
}

And now the secret of [ ]: p[i] is defined as *(p + i). Indexing is pointer arithmetic with nicer clothes on. It works the same on arrays and on pointers.

Walking with a pointer

C
#include <stdio.h>

size_t length(const char *s)
{
    const char *start = s;
    while (*s != '\0') {
        s++;                        // move to the next character
    }
    return (size_t)(s - start);     // the distance between two pointers
}

int main(void)
{
    printf("%zu\n", length("pointer"));   // 7
    return 0;
}
  • s++ moves the pointer itself (the parameter is a copy, so the caller's pointer is untouched).
  • Subtracting two pointers into the same array gives the number of elements between them, of type ptrdiff_t.
  • *s != '\0' is often written as just *s.

The famous one-line copy reads: while ((*dest++ = *src++) != '\0') { } - copy a character, move both pointers, stop after copying the terminator.

Begin and end

A common style passes a pointer to the first element and one just past the last:

C
#include <stdio.h>

long long total(const int *begin, const int *end)
{
    long long sum = 0;
    for (const int *p = begin; p != end; p++) {
        sum += *p;
    }
    return sum;
}

int main(void)
{
    int values[] = {3, 1, 4, 1, 5, 9};
    size_t n = sizeof values / sizeof values[0];
    printf("%lld\n", total(values, values + n));        // all: 23
    printf("%lld\n", total(values + 2, values + 4));    // the 4 and the 1: 5
    return 0;
}

C allows a pointer to the position one past the end of an array, as long as you never dereference it. Any further, or before the start, and even computing the pointer is undefined.

Arrays are not quite pointers

int a[4] int *p
sizeof 16: the whole array 8: one address
can be assigned (a = ...) no yes
storage holds 4 ints holds one address

The array is the memory; the pointer only points at memory somewhere else.
