C

8 milestones43 lessons58 practice tasks40 projects

C is the language of operating systems, embedded chips and the interpreters of other languages: small, fast, and close to the hardware. Starting from the first program, the course covers types, input and output, decisions, loops, functions and arrays, strings, pointers, memory you allocate and free yourself, structures and linked lists, the bugs C lets you make and how to catch them, bit operations, binary data and files, the preprocessor and programs in several files, function pointers, undefined behaviour, how C turns into assembly, a hash table of your own, and finally the advanced language: variadic functions, struct layout and bit fields, modern C from C11 to C23, error-handling patterns, and threads with atomics, then the practice of real C: dynamic strings, generic containers, dates, command-line tools, safe integer arithmetic and random numbers. Every lesson has checked practice compiled with GCC, and every milestone ends with five projects, from small to large.
