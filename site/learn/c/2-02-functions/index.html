Functions

lesson 2.022 of 6 in milestone 25 min1 practice task

A function has a return type, a name and parameters. Arguments are copied into the parameters, so a function cannot change the caller's variables. A prototype declares a function before its definition, and every call gets its own frame on the stack.

Writing a function

C
#include <stdio.h>

int square(int n)
{
    return n * n;
}

void greet(const char *name)
{
    printf("Hello, %s!\n", name);
}

int main(void)
{
    printf("%d\n", square(12));
    greet("Grace");
    return 0;
}
  • int square(int n): returns an int, takes one int called n.
  • void as the return type means nothing is returned; a plain return; (or the end of the function) leaves it.
  • return ends the function at once, wherever it is.
Every path must return

If a function returning int can reach its end without a return, the caller gets garbage. GCC warns: "control reaches end of non-void function".

Arguments are copies

C passes arguments by value: the parameter is a new variable holding a copy.

C
#include <stdio.h>

void try_to_double(int n)
{
    n = n * 2;              // changes the copy only
}

int main(void)
{
    int x = 21;
    try_to_double(x);
    printf("%d\n", x);      // still 21
    return 0;
}

To change the caller's variable, a function needs its address: that is what pointers are for (lesson 3.03). Until then, return the new value: x = doubled(x);.

Declare before use

The compiler reads the file from top to bottom. A function must be declared before the line that calls it. Either define functions above main, or put a prototype (the first line, ending in a semicolon) at the top:

C
#include <stdio.h>

int add(int a, int b);          // prototype: the promise

int main(void)
{
    printf("%d\n", add(2, 3));
    return 0;
}

int add(int a, int b)           // definition: the body
{
    return a + b;
}

Prototypes are what header files are full of: stdio.h holds the prototype of printf, and the code itself is in the C library that the linker adds (lesson 1.01).

(void) means no parameters

int main(void) takes no arguments. In C before C23, an empty list int f() meant "unknown parameters", which turns off argument checking. Write (void).

Each call gets a frame

Every call gets its own stack frame holding its parameters, its local variables and the address to go back to. When the function returns, the frame is released.

Because each call has its own frame, a function can even call itself (recursion):

C
#include <stdio.h>

long long factorial(int n)
{
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int main(void)
{
    printf("20! = %lld\n", factorial(20));
    return 0;
}

Every recursive call adds a frame; recurse a million levels deep and the stack (a few megabytes) runs out: a crash called stack overflow.
