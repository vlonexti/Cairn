Styling, Fonts and Icons

lesson 4.055 of 6 in milestone 45 min2 practice tasks

The default look is fine for debug views, but a tool people use all day deserves care. This lesson covers the style object, colours and sizes, temporary style changes with Push/Pop, loading fonts at the right size for the display's scale, and merging an icon font so buttons can show symbols.

The style

All sizes and colours live in one ImGuiStyle:

C++
ImGuiStyle& style = ImGui::GetStyle();
ImGui::StyleColorsDark();                 // start from a built-in theme: Dark, Light or Classic
style.WindowRounding   = 4.0f;
style.FrameRounding    = 3.0f;
style.FramePadding     = ImVec2(8, 5);
style.ItemSpacing      = ImVec2(8, 6);
style.ScrollbarSize    = 12.0f;
style.Colors[ImGuiCol_WindowBg]      = ImVec4(0.09f, 0.10f, 0.12f, 1.0f);
style.Colors[ImGuiCol_Header]        = ImVec4(0.95f, 0.70f, 0.27f, 0.35f);
style.Colors[ImGuiCol_HeaderHovered] = ImVec4(0.95f, 0.70f, 0.27f, 0.55f);

There are about 55 colours (ImGuiCol_Text, Button, ButtonHovered, ButtonActive, FrameBg, CheckMark, SliderGrab...) and dozens of sizes. Tune them live with the style editor (lesson 1.06), then press "Export" to copy the code.

A good theme usually comes from a small palette: a background, a slightly lighter panel, an accent, and the same accent at three strengths for normal, hovered and active. The practice generates such a theme from one accent colour.

Temporary changes

C++
ImGui::PushStyleColor(ImGuiCol_Button, ImVec4(0.8f, 0.2f, 0.2f, 1.0f));
ImGui::PushStyleVar(ImGuiStyleVar_FrameRounding, 8.0f);
if (ImGui::Button("Delete level")) confirmDelete();
ImGui::PopStyleVar();
ImGui::PopStyleColor();

Every Push needs a Pop (with a count: PopStyleColor(2) pops two).

Scaling for the display

On a 4K laptop at 200% scale, a 13-pixel font is unreadable. Get the window's scale and apply it to both the font size and the style:

C++
const float scale = ImGui_ImplWin32_GetDpiScaleForHwnd(hwnd);   // 1.0 at 96 DPI, 1.5 at 144, 2.0 at 192
style.ScaleAllSizes(scale);                                       // paddings, roundings, spacing
io.Fonts->AddFontFromFileTTF("fonts/Inter-Regular.ttf", 15.0f * scale);

Load the font at the real size rather than scaling a small font up, which looks blurry. (ImGui 1.92 added dynamic font sizes, which handles much of this for you; the idea is the same.)

Fonts

C++
ImFont* body = io.Fonts->AddFontFromFileTTF("fonts/Inter-Regular.ttf", 16.0f);
ImFont* mono = io.Fonts->AddFontFromFileTTF("fonts/JetBrainsMono-Regular.ttf", 15.0f);
// ...
ImGui::PushFont(mono);
ImGui::TextUnformatted(logText);
ImGui::PopFont();

The first font added becomes the default. Fonts are rasterised into the font atlas texture (lesson 1.03) when the back end builds it; add them before the first NewFrame.

Icon fonts

Icon fonts such as Font Awesome or Material Symbols put pictures in Unicode's "private use" area. Merge one into your text font so a single label can mix words and icons:

C++
io.Fonts->AddFontFromFileTTF("fonts/Inter-Regular.ttf", 16.0f);

ImFontConfig config;
config.MergeMode = true;                      // add these glyphs to the previous font
config.GlyphMinAdvanceX = 16.0f;              // icons all the same width
static const ImWchar iconRange[] = { 0xE000, 0xF8FF, 0 };   // the private use area
io.Fonts->AddFontFromFileTTF("fonts/fa-solid-900.ttf", 14.0f, &config, iconRange);

ImGui::Button("\xef\x83\x87 Save");           // U+F0C7 (a floppy disk in Font Awesome) as UTF-8

ImGui strings are UTF-8. A code point above U+007F is written as two to four bytes; U+F0C7 becomes EF 83 87. Projects usually use a header with named constants (ICON_FA_FLOPPY_DISK) generated for the icon font. The practice has you write the UTF-8 encoder.

Common mistakes

Scaling a small font up instead of loading it at the right size

The text is blurry. Load fonts at the size they will be drawn.

Mismatched Push and Pop counts

ImGui asserts at the end of the frame. Pop as many as you pushed.

Writing non-ASCII text in a source file without UTF-8

Save source files as UTF-8 (and compile with /utf-8) or write the bytes as escapes.
