Plots and Live Graphs

lesson 5.011 of 4 in milestone 55 min1 practice task

A number that changes every frame is hard to read; a graph of its last few seconds is easy. This lesson covers ImGui's built-in PlotLines and PlotHistogram, the ring buffer that feeds them, scaling and statistics, drawing your own graph with the draw list, and when to reach for the ImPlot library.

Built-in plots

C++
static float frameTimes[120] = {};
static int offset = 0;
frameTimes[offset] = ImGui::GetIO().DeltaTime * 1000.0f;   // this frame, in ms
offset = (offset + 1) % IM_ARRAYSIZE(frameTimes);

ImGui::PlotLines("Frame ms", frameTimes, IM_ARRAYSIZE(frameTimes), offset,
                 nullptr, 0.0f, 33.3f, ImVec2(0, 80));
ImGui::PlotHistogram("Enemies per room", roomCounts, roomCount, 0, nullptr, 0.0f, FLT_MAX, ImVec2(0, 60));

Arguments: label, values, count, values_offset, overlay text, scale min, scale max, size. Pass FLT_MAX for the scale and ImGui fits it to the data each frame.

The values_offset is the key to live graphs: the array is a ring buffer where the newest value overwrites the oldest, and the offset tells PlotLines where the oldest value now is, so the graph scrolls from left to right without shifting the whole array every frame.

A ring buffer class

Wrap that pattern so every graph in your tools can use it:

C++
template <std::size_t N>
class History
{
public:
    void push(float v) { m_data[m_next] = v; m_next = (m_next + 1) % N; if (m_count < N) ++m_count; }
    int offset() const { return m_count < N ? 0 : static_cast<int>(m_next); }   // where the oldest sample is
    int count() const { return static_cast<int>(m_count); }
    const float* data() const { return m_data.data(); }
    // plus min(), max(), average() for the overlay text
private:
    std::array<float, N> m_data{};
    std::size_t m_next{ 0 }, m_count{ 0 };
};

Before the buffer is full, the samples are in 0 .. count-1 and the offset is 0. After it fills, the oldest sample is wherever the next write will go. The practice writes this class with its statistics, which go well in the overlay: "avg 16.7 ms max 21.3".

Smoothing

Raw values jitter. Two cheap smoothers:

  • Moving average over the last N samples (the ring buffer has them).
  • Exponential smoothing: smoothed += (value - smoothed) * k with k around 0.1, which reacts quickly but filters noise, and needs no buffer.

Your own graph with the draw list

For anything the built-ins do not do (several lines in one graph, thresholds, labels), draw it yourself:

C++
ImDrawList* dl = ImGui::GetWindowDrawList();
const ImVec2 p0 = ImGui::GetCursorScreenPos();
const ImVec2 size(ImGui::GetContentRegionAvail().x, 100);
dl->AddRectFilled(p0, ImVec2(p0.x + size.x, p0.y + size.y), IM_COL32(20, 22, 28, 255));
// the 16.6 ms (60 fps) budget line
const float budgetY = p0.y + size.y * (1.0f - 16.6f / 33.3f);
dl->AddLine(ImVec2(p0.x, budgetY), ImVec2(p0.x + size.x, budgetY), IM_COL32(240, 180, 70, 160));
// the data as a polyline: map sample i to x and value to y
std::vector<ImVec2> pts;
for (int i = 0; i < history.count(); ++i) { /* x = p0.x + i * size.x / (N - 1); y = p0.y + size.y * (1 - value / maxValue) */ }
dl->AddPolyline(pts.data(), (int)pts.size(), IM_COL32(120, 200, 255, 255), ImDrawFlags_None, 1.5f);
ImGui::Dummy(size);                           // reserve the space in the layout

Mapping a value to a pixel row is the same linear mapping as a slider (lesson 2.01), upside down: larger values are higher on screen, which means smaller y.

ImPlot

For serious charts (axes with ticks, zoom and pan, legends, many series, scatter plots, heat maps), use ImPlot (epezent/implot), a companion library built on ImGui:

C++
if (ImPlot::BeginPlot("Frame time"))
{
    ImPlot::SetupAxes("frame", "ms");
    ImPlot::PlotLine("cpu", cpuMs, count, 1.0, 0.0, 0, offset);
    ImPlot::PlotLine("gpu", gpuMs, count, 1.0, 0.0, 0, offset);
    ImPlot::EndPlot();
}

It needs its own context (ImPlot::CreateContext() after ImGui's).

Common mistakes

Shifting the whole array every frame

Use a ring buffer and pass the offset; nothing needs to move.

Auto-scaling a graph that should be compared over time

FLT_MAX rescales every frame, so a spike shrinks everything else. Fix the scale for budgets like frame time.
