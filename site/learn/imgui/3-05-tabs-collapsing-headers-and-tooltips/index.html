Tabs, Collapsing Headers and Tooltips

lesson 3.055 of 5 in milestone 35 min1 practice task

Tools have more settings than fit on one screen. This lesson covers the ways to organise them - collapsing headers, tab bars, and the old Columns API you will meet in existing code - plus tooltips and help markers, so every setting can explain itself.

Collapsing headers

A collapsing header is a full-width bar that hides or shows the section below it. Inspectors are usually a stack of them:

C++
if (ImGui::CollapsingHeader("Transform", ImGuiTreeNodeFlags_DefaultOpen))
{
    ImGui::DragFloat3("Position", &t.pos.x, 0.1f);
    ImGui::DragFloat3("Rotation", &t.rot.x, 1.0f);
}
if (ImGui::CollapsingHeader("Physics"))
{
    ImGui::DragFloat("Mass", &body.mass, 0.1f, 0.0f, 1000.0f);
}

It is a tree node that does not push to the ID stack and needs no TreePop. Pass a bool* as a second argument and it also gets a close button, handy for "remove this component" in an inspector.

Tab bars

C++
if (ImGui::BeginTabBar("settings", ImGuiTabBarFlags_Reorderable))
{
    if (ImGui::BeginTabItem("Graphics")) { drawGraphics(); ImGui::EndTabItem(); }
    if (ImGui::BeginTabItem("Audio"))    { drawAudio();    ImGui::EndTabItem(); }
    if (ImGui::BeginTabItem("Controls")) { drawControls(); ImGui::EndTabItem(); }
    ImGui::EndTabBar();
}

Both pairs follow the "End only if Begin returned true" rule. A bool* open on BeginTabItem gives the tab a close button (an editor with one tab per open file). To switch to a tab from code, pass ImGuiTabItemFlags_SetSelected on that frame.

The old Columns API

Older code uses ImGui::Columns(2), NextColumn() and Columns(1) to split a window into columns. It still works but is legacy: tables (lesson 3.03) do everything it did and more. When you meet Columns in an existing tool, consider converting it to a two-column table with ImGuiTableFlags_SizingStretchProp.

Tooltips

C++
ImGui::DragFloat("Drag", &body.drag, 0.01f);
ImGui::SetItemTooltip("Air resistance. 0 = none, 1 = moves through syrup.");   // shown when the last item is hovered

if (ImGui::IsItemHovered(ImGuiHoveredFlags_DelayNormal))      // a richer tooltip after a short delay
{
    ImGui::BeginTooltip();
    ImGui::Text("Drag curve");
    ImGui::PlotLines("##curve", samples, IM_ARRAYSIZE(samples));
    ImGui::EndTooltip();
}

SetItemTooltip covers most cases. With BeginTooltip/EndTooltip you can put any widgets inside.

The help marker

A common pattern from the demo window: a small greyed "(?)" after a setting that shows an explanation when hovered:

C++
static void HelpMarker(const char* text)
{
    ImGui::SameLine();
    ImGui::TextDisabled("(?)");
    if (ImGui::BeginItemTooltip())
    {
        ImGui::PushTextWrapPos(ImGui::GetFontSize() * 30.0f);    // wrap at about 30 characters wide
        ImGui::TextUnformatted(text);
        ImGui::PopTextWrapPos();
        ImGui::EndTooltip();
    }
}

Wrapping long help text matters: an unwrapped tooltip can be wider than the screen. The practice writes a word-wrap function like the one ImGui uses for TextWrapped.

Common mistakes

Calling EndTabItem for a tab that is not selected

BeginTabItem returns true only for the visible tab. EndTabItem goes inside the if.

Tooltips with very long unwrapped text

Push a text wrap position, or use TextWrapped.
