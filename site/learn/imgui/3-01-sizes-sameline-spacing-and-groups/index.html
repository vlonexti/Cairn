Sizes, SameLine, Spacing and Groups

lesson 3.011 of 5 in milestone 35 min1 practice task

ImGui places widgets with a cursor that moves down after each one. This lesson shows how to control it - SameLine, item widths, spacing, indentation, groups, alignment and disabled sections - so a tool's window reads cleanly at any font size.

The cursor

Every window has a layout cursor. Each widget is placed at the cursor, then the cursor moves to the start of the next line. That is why widgets stack vertically by default. Everything in this lesson changes where the cursor goes, or how wide the next widget is.

SameLine

C++
ImGui::Text("Stones:");
ImGui::SameLine();                    // the next widget goes to the right of the last one
ImGui::Text("%d", count);
ImGui::SameLine(200.0f);              // ...at x = 200 from the window's left edge
ImGui::Button("Add");
ImGui::SameLine(0.0f, 2.0f);          // default position, but only 2 pixels of spacing
ImGui::Button("-");

Widths

By default, widgets with a frame (sliders, inputs, combos) take about two thirds of the window width, leaving room for the label on the right. Change it:

C++
ImGui::SetNextItemWidth(120.0f);                 // the next widget only
ImGui::DragFloat("Mass", &mass);

ImGui::PushItemWidth(-FLT_MIN);                  // all following widgets: fill to the right edge
ImGui::InputText("##notes", &notes);             // (hide the label with ##, or it would be cut off)
ImGui::PopItemWidth();

ImGui::PushItemWidth(ImGui::GetFontSize() * 10); // ten "M" widths: scales with the font

Prefer sizes based on GetFontSize(), GetFrameHeight() and GetContentRegionAvail() over fixed pixel numbers, so the tool still looks right when someone raises the font size or the display scale.

C++
const float avail = ImGui::GetContentRegionAvail().x;            // width left on this line
ImGui::Button("Half", ImVec2(avail * 0.5f, 0));                  // 0 height = the normal height

Spacing, separators, indentation

C++
ImGui::Spacing();                 // a little vertical space
ImGui::Separator();               // a horizontal line
ImGui::SeparatorText("Physics");  // a line with a title
ImGui::Indent();                  // move the left edge right (by the style's indent width)
ImGui::Text("indented");
ImGui::Unindent();
ImGui::Dummy(ImVec2(0, 20));      // an invisible widget that takes space
ImGui::NewLine();                 // move to the next line, like pressing Enter

Groups

A group makes several widgets act as one item for layout: you can put the whole group on the same line as something else, and IsItemHovered asks about the whole group.

C++
ImGui::BeginGroup();
ImGui::Text("Player");
ImGui::Text("HP %d", hp);
ImGui::Text("MP %d", mp);
ImGui::EndGroup();
ImGui::SameLine();                // the next group sits to the right of the whole first group
ImGui::BeginGroup();
ImGui::Text("Enemy");
ImGui::Text("HP %d", enemyHp);
ImGui::EndGroup();

Alignment

ImGui lays text from the top of the line. Next to a framed widget (a button, an input) plain text looks too high. Call ImGui::AlignTextToFramePadding() before such text to line it up with the frames on the same line.

To right-align something, move the cursor yourself:

C++
const float w = ImGui::CalcTextSize("Delete").x + ImGui::GetStyle().FramePadding.x * 2;
ImGui::SameLine(ImGui::GetContentRegionMax().x - w);
ImGui::Button("Delete");

CalcTextSize measures text with the current font. The practice uses that kind of measurement to lay out a row of buttons.

Disabled sections

C++
ImGui::BeginDisabled(!level.loaded);    // greyed out and not interactive while no level is loaded
if (ImGui::Button("Save")) saveLevel();
ImGui::EndDisabled();

Better than hiding the button: the user sees it exists and why it cannot be used yet (add a tooltip, lesson 4.02).

Common mistakes

Fixed pixel sizes everywhere

They break at other font sizes and display scales. Measure from the font and the available width.

A full-width widget with a visible label

The label is pushed off the right edge. Hide it with ## and put a Text in front instead.
