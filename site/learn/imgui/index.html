Tool Interfaces with Dear ImGui

6 milestones29 lessons34 practice tasks30 projects

Dear ImGui builds interfaces in a few lines of code inside any game or tool. The course covers setting it up with a graphics back end, every common widget, layout, tables, trees, menus, popups, docking and styling, then the data views tools need, and finishes with a complete level editor and an in-game profiler. It assumes the first milestones of the C++ course. You build the interfaces in Visual Studio; the practice on the site checks the logic inside them.
