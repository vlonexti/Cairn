Combo Boxes and List Boxes

lesson 2.033 of 5 in milestone 25 min1 practice task

Choosing one item from many is everywhere in tools - a material, a level, an enemy type. This lesson covers BeginCombo with Selectable, the simple Combo overloads, list boxes, filtering a long list as you type, and showing enums by name.

BeginCombo and Selectable

The flexible way to make a drop-down:

C++
static const char* materials[] = { "Granite", "Basalt", "Slate", "Marble", "Limestone" };
static int current = 0;

if (ImGui::BeginCombo("Material", materials[current]))      // the text shown when closed
{
    for (int i = 0; i < IM_ARRAYSIZE(materials); ++i)
    {
        const bool selected = (i == current);
        if (ImGui::Selectable(materials[i], selected))
            current = i;
        if (selected)
            ImGui::SetItemDefaultFocus();                       // keyboard navigation starts here
    }
    ImGui::EndCombo();                                          // only if BeginCombo returned true!
}

BeginCombo returns true while the drop-down is open; then you draw its contents and call EndCombo. If it returns false, you do not call EndCombo (lesson 1.04's second rule).

Selectable is a full-width clickable row that can be shown as selected. You will use it in lists, tables and trees too.

The simple overloads

For a plain list of strings there is a one-line version:

C++
ImGui::Combo("Material", &current, materials, IM_ARRAYSIZE(materials));
ImGui::Combo("Quality", &quality, "Low\0Medium\0High\0\0");     // items separated by \0, ending with \0\0

Use BeginCombo when the items are not a simple array: a std::vector of objects, items with icons, items you want to filter.

Enums by name

A table of names next to the enum keeps a combo honest:

C++
enum class Weather { Clear, Rain, Snow, Fog, Count };
constexpr const char* weatherNames[] = { "Clear", "Rain", "Snow", "Fog" };
static_assert(IM_ARRAYSIZE(weatherNames) == static_cast<int>(Weather::Count));

int w = static_cast<int>(level.weather);
if (ImGui::Combo("Weather", &w, weatherNames, IM_ARRAYSIZE(weatherNames)))
    level.weather = static_cast<Weather>(w);

The static_assert fails the build if someone adds an enum value without a name.

List boxes

A list box is the same idea, always open, with a fixed height:

C++
if (ImGui::BeginListBox("##levels", ImVec2(-FLT_MIN, 8 * ImGui::GetTextLineHeightWithSpacing())))
{
    for (int i = 0; i < (int)levels.size(); ++i)
        if (ImGui::Selectable(levels[i].name.c_str(), i == selectedLevel))
            selectedLevel = i;
    ImGui::EndListBox();
}

Size the height in lines (GetTextLineHeightWithSpacing) so it adapts to the font.

Filtering long lists

A list of 400 assets needs a search box. Keep a filter string, and only draw matching items:

C++
static std::string filter;
ImGui::InputTextWithHint("##filter", "Filter...", &filter);
for (const Asset& a : assets)
    if (matches(a.name, filter))
        if (ImGui::Selectable(a.name.c_str(), &a == selected)) selected = &a;

A good matches ignores case and lets the words of the filter appear anywhere, in any order: "rock big" matches "big_mossy_rock". The practice writes it. ImGui also ships ImGuiTextFilter for include/exclude filters, which lesson 5.02 uses.

Common mistakes

Calling EndCombo when BeginCombo returned false

ImGui asserts. EndCombo belongs inside the if.

Selectables with the same text

They share an ID (lesson 1.05). PushID per item, or add ## and the index.
