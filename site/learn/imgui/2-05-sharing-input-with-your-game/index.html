Sharing Input with Your Game

lesson 2.055 of 5 in milestone 25 min2 practice tasks

When ImGui runs on top of a game, the same click could mean "press this button" or "shoot". ImGui tells you which with io.WantCaptureMouse and io.WantCaptureKeyboard. This lesson shows how to route input correctly, read keys and the mouse through ImGui yourself, and add keyboard shortcuts to your tools.

Who gets the click?

Your game reads the mouse and keyboard too. Without care, typing a level name into a text field also walks the player around, and clicking a button also fires the gun. ImGui sets three flags every frame:

Flag True when
io.WantCaptureMouse The mouse is over an ImGui window, or ImGui is using it (dragging a slider that left the window)
io.WantCaptureKeyboard An ImGui widget has keyboard focus (a text field, or keyboard navigation is active)
io.WantTextInput A text field wants characters (on consoles and phones: show the on-screen keyboard)

The rule is simple: ImGui first; the game only if ImGui does not want it.

C++
ImGuiIO& io = ImGui::GetIO();
if (!io.WantCaptureMouse)
{
    if (mouse.leftPressed) player.shoot(mouse.worldPosition);
    camera.zoom(mouse.wheel);
}
if (!io.WantCaptureKeyboard)
{
    player.move(keys.wasd());
}

Read the flags after ImGui::NewFrame() and use them for this frame's game input. They are computed from last frame's layout, which is fine: windows do not move faster than a frame.

Reading input through ImGui

Your tool code can ask ImGui directly about keys and the mouse, using the same input the back end fed in:

C++
if (ImGui::IsKeyPressed(ImGuiKey_F5)) reloadLevel();          // pressed this frame (with key repeat by default)
if (ImGui::IsKeyDown(ImGuiKey_LeftShift)) speed *= 4.0f;     // held
if (ImGui::IsMouseClicked(ImGuiMouseButton_Right)) openMenuAt(ImGui::GetMousePos());
if (ImGui::IsMouseDragging(ImGuiMouseButton_Middle)) pan(ImGui::GetIO().MouseDelta);
if (ImGui::IsMouseDoubleClicked(ImGuiMouseButton_Left)) focusSelection();

ImGuiKey_ values name every key independent of the platform: ImGuiKey_A, ImGuiKey_Escape, ImGuiKey_Delete, ImGuiKey_LeftCtrl, ImGuiMod_Ctrl (either Ctrl key).

Keyboard shortcuts

Recent versions of ImGui have a proper shortcut system that respects focus (a shortcut in one window does not fire while you type in another):

C++
if (ImGui::Shortcut(ImGuiMod_Ctrl | ImGuiKey_S)) saveLevel();
if (ImGui::Shortcut(ImGuiMod_Ctrl | ImGuiKey_Z)) undo();
if (ImGui::Shortcut(ImGuiMod_Ctrl | ImGuiMod_Shift | ImGuiKey_Z)) redo();

For a global shortcut that should work whichever window has focus, pass ImGuiInputFlags_RouteGlobal. Menu items show their shortcut text but do not trigger it by themselves (lesson 4.01).

Tools often store shortcuts as text in a settings file: "Ctrl+Shift+S". Parsing that text into modifiers and a key is a good small exercise, which the practice has you write.

Gamepads

With io.ConfigFlags |= ImGuiConfigFlags_NavEnableGamepad and a back end that reports the gamepad (the Win32 back end supports XInput), the D-pad moves between widgets and A activates them. Useful for debug menus on a game being tested with a controller.

Common mistakes

The game reading input before ImGui

Typing in a text field moves the player. Check WantCaptureKeyboard before the game handles keys.

Checking the flags before NewFrame

They are only updated in NewFrame. Check them after it.

    • io.WantCaptureKeyboard

    io.WantCaptureKeyboard It is true while an ImGui widget has keyboard focus.

  2. The mouse is over an ImGui window and the player clicks. Should the game fire?
    • No; io.WantCaptureMouse is true
    • Yes; games always get the mouse
    • Only on a double click
    Show the answer

    No; io.WantCaptureMouse is true ImGui gets first claim on the input.

  3. Which call checks the shortcut Ctrl+S with ImGui's focus rules?
    • ImGui::Shortcut(ImGuiMod_Ctrl | ImGuiKey_S)
    • ImGui::IsKeyDown(ImGuiKey_S)
    • ImGui::MenuItem("Save", "Ctrl+S")
    Show the answer

    ImGui::Shortcut(ImGuiMod_Ctrl | ImGuiKey_S) MenuItem only shows the text; Shortcut detects the keys.
