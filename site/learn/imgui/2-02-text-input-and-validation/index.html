Text Input and Validation

lesson 2.022 of 5 in milestone 25 min1 practice task

Text fields in ImGui write into a buffer you own. This lesson covers InputText with character arrays and std::string, number fields, multi-line text, flags that restrict what can be typed, callbacks for custom filtering and completion, and validating a value before you accept it.

InputText with a buffer

C++
static char name[64] = "Granite";
ImGui::InputText("Name", name, IM_ARRAYSIZE(name));      // edits the array in place

ImGui edits your buffer directly and never writes more than its size (including the terminating zero). IM_ARRAYSIZE gives the number of elements of an array.

InputText with std::string

The file misc/cpp/imgui_stdlib.cpp (add it to your project) gives overloads that resize a std::string as you type:

C++
#include "misc/cpp/imgui_stdlib.h"

ImGui::InputText("Name", &stone.name);                         // std::string*
ImGui::InputTextMultiline("Notes", &level.notes, ImVec2(-FLT_MIN, 120));   // full width, 120 high
ImGui::InputTextWithHint("##search", "Search stones...", &search);          // grey hint when empty

-FLT_MIN as a width means "all the space up to the right edge"; it is ImGui's idiom for "fill".

Number fields

C++
ImGui::InputInt("Count", &count);                  // with - and + buttons
ImGui::InputInt("Count", &count, 0);               // step 0: no buttons
ImGui::InputFloat("Weight", &weight, 0.1f, 1.0f, "%.2f");
ImGui::InputScalar("Seed", ImGuiDataType_U64, &seed);   // any numeric type

Restricting what can be typed

Flags filter characters as they are typed:

Flag Allows
ImGuiInputTextFlags_CharsDecimal 0123456789.+-*/
ImGuiInputTextFlags_CharsHexadecimal 0123456789ABCDEFabcdef
ImGuiInputTextFlags_CharsUppercase Turns letters to upper case
ImGuiInputTextFlags_CharsNoBlank No spaces or tabs
ImGuiInputTextFlags_CharsScientific Decimal plus e/E

Others change behaviour: EnterReturnsTrue (return true only when Enter is pressed, ideal for a console), ReadOnly, Password (shows *), AutoSelectAll, EscapeClearsAll.

Callbacks: custom filters, history, completion

For anything the flags cannot do, pass a callback:

C++
int onlyIdentifierChars(ImGuiInputTextCallbackData* data)
{
    const ImWchar c = data->EventChar;
    const bool ok = (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || (c >= '0' && c <= '9') || c == '_';
    return ok ? 0 : 1;                // return 1 to reject the character
}

ImGui::InputText("Id", id, sizeof(id), ImGuiInputTextFlags_CallbackCharFilter, onlyIdentifierChars);

ImGuiInputTextFlags_CallbackCompletion calls you when Tab is pressed (for auto-completing a console command), and CallbackHistory when Up or Down is pressed (for recalling previous commands). The console example in the demo window shows both.

Validating a value

Filtering stops characters; validation checks the whole value. A common, friendly pattern: edit a copy, show what is wrong, and only apply it when it is valid and the edit is finished.

C++
static std::string editing = level.name;
ImGui::InputText("Level name", &editing);
const std::string problem = validateLevelName(editing);   // "" if fine
if (!problem.empty())
    ImGui::TextColored(ImVec4(1, 0.4f, 0.4f, 1), "%s", problem.c_str());
if (ImGui::IsItemDeactivatedAfterEdit() && problem.empty())
    level.name = editing;

The practice writes validateLevelName and a character filter.

Keyboard focus

ImGui::SetKeyboardFocusHere() before a text field gives it the keyboard focus on that frame: useful when a search window or console opens. ImGui::IsItemFocused() tells whether the field has focus.

Common mistakes

Passing sizeof of a pointer as the buffer size

InputText("x", ptr, sizeof(ptr)) passes 8. Use the real buffer size, IM_ARRAYSIZE for arrays, or the std::string overload.

Applying invalid text immediately

Edit a copy and apply when it validates, so half-typed values never reach your data.
