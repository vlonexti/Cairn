Data Structures and Algorithms

6 milestones30 lessons30 practice tasks30 projects

Lists, trees, graphs, hashing, sorting and dynamic programming, each built from scratch in C++ and then measured. You learn how to reason about running time, build every classic structure yourself, and choose the right one for a problem, finishing with a spelling checker built on a trie and edit distance. It assumes the first milestones of the C++ course: functions, classes, vectors, references and templates.
