Binary Trees and Traversals

lesson 4.011 of 5 in milestone 48 min1 practice task

Trees as recursive structures - nodes, roots, leaves, depth and height, binary trees with unique_ptr children, writing functions recursively (size, height, mirror), the depth-first orders pre-, in- and post-order, doing them without recursion using an explicit stack, level-order traversal with a queue, rebuilding a tree from two traversals, and serialising a tree to text.

Trees

A tree is a set of nodes connected so that there is exactly one path between any two of them. One node is the root; every other node has exactly one parent, and the nodes below a node are its children. Nodes without children are leaves.

Trees are everywhere in computing: file systems, the HTML of a web page, the syntax tree a compiler builds from your code, organisation charts, decision trees, and the search trees and heaps of this course.

In a binary tree every node has at most two children, a left and a right.

Representing a binary tree

Each node owns its children, so std::unique_ptr is a natural fit: destroying the root frees the whole tree.

C++
struct Node
{
    int value;
    std::unique_ptr<Node> left;
    std::unique_ptr<Node> right;
};

(Destroying through unique_ptr recurses once per level. That is fine for balanced trees, whose height is about log n, but a degenerate tree shaped like a long list can overflow the stack, as lesson 1.04 showed for lists.)

Thinking recursively

A binary tree is either empty, or a node with a left subtree and a right subtree, both binary trees. That recursive definition makes most tree functions two lines long: handle the empty tree, then combine the answers for the two subtrees.

C++
#include <algorithm>
#include <iostream>
#include <memory>

struct Node
{
    int value;
    std::unique_ptr<Node> left, right;
};

std::unique_ptr<Node> leaf(int v) { return std::make_unique<Node>(Node{ v, nullptr, nullptr }); }
std::unique_ptr<Node> node(int v, std::unique_ptr<Node> l, std::unique_ptr<Node> r)
{
    return std::make_unique<Node>(Node{ v, std::move(l), std::move(r) });
}

int size(const Node* n) { return n ? 1 + size(n->left.get()) + size(n->right.get()) : 0; }
int height(const Node* n) { return n ? 1 + std::max(height(n->left.get()), height(n->right.get())) : -1; }
int sum(const Node* n) { return n ? n->value + sum(n->left.get()) + sum(n->right.get()) : 0; }
void mirror(Node* n)
{
    if (!n) return;
    std::swap(n->left, n->right);
    mirror(n->left.get());
    mirror(n->right.get());
}

int main()
{
    auto root = node(8, node(3, leaf(1), node(6, leaf(4), leaf(7))), node(10, nullptr, node(14, leaf(13), nullptr)));
    std::cout << "size " << size(root.get()) << ", height " << height(root.get()) << ", sum " << sum(root.get()) << '\n';
    mirror(root.get());
    std::cout << "after mirroring, the root's left child is " << root->left->value << '\n';
}

The height of an empty tree is −1, so that a single leaf has height 0. Each function visits every node once: O(n). The recursion goes as deep as the tree is tall.

Depth-first traversals

A traversal visits every node once. The three depth-first orders differ only in when a node is visited relative to its subtrees:

Order Visit For the tree above
pre-order node, left, right 8 3 1 6 4 7 10 14 13
in-order left, node, right 1 3 4 6 7 8 10 13 14
post-order left, right, node 1 4 7 6 3 13 14 10 8
  • Pre-order visits a parent before its children: copying a tree, printing an outline, prefix notation.
  • In-order visits a binary search tree's values in sorted order (lesson 4.02).
  • Post-order visits children before their parent: deleting a tree, computing sizes, evaluating an expression tree.

Traversals without recursion

Recursion uses the call stack. You can use your own std::vector as the stack instead, which avoids stack overflow on deep trees and is needed for iterators. In-order is the trickiest: go left as far as possible pushing nodes, then visit the top and move to its right subtree.

C++
#include <iostream>
#include <memory>
#include <vector>

struct Node
{
    int value;
    std::unique_ptr<Node> left, right;
};

std::unique_ptr<Node> leaf(int v) { return std::make_unique<Node>(Node{ v, nullptr, nullptr }); }
std::unique_ptr<Node> node(int v, std::unique_ptr<Node> l, std::unique_ptr<Node> r)
{
    return std::make_unique<Node>(Node{ v, std::move(l), std::move(r) });
}

std::vector<int> preorder(const Node* root)
{
    std::vector<int> out;
    std::vector<const Node*> stack;
    if (root) stack.push_back(root);
    while (!stack.empty())
    {
        const Node* n = stack.back();
        stack.pop_back();
        out.push_back(n->value);
        if (n->right) stack.push_back(n->right.get());       // pushed first, so visited after the left subtree
        if (n->left) stack.push_back(n->left.get());
    }
    return out;
}

std::vector<int> inorder(const Node* root)
{
    std::vector<int> out;
    std::vector<const Node*> stack;
    const Node* n = root;
    while (n || !stack.empty())
    {
        while (n) { stack.push_back(n); n = n->left.get(); }  // slide down to the leftmost node
        n = stack.back();
        stack.pop_back();
        out.push_back(n->value);
        n = n->right.get();
    }
    return out;
}

int main()
{
    auto root = node(8, node(3, leaf(1), node(6, leaf(4), leaf(7))), node(10, nullptr, node(14, leaf(13), nullptr)));
    for (int v : preorder(root.get())) std::cout << v << ' ';
    std::cout << '\n';
    for (int v : inorder(root.get())) std::cout << v << ' ';
    std::cout << '\n';
}

Level order

Level-order (breadth-first) traversal visits the root, then all nodes at depth 1, then depth 2, and so on. It uses a queue: take a node from the front, visit it, put its children at the back. Processing the queue one level at a time (by remembering its size at the start of the level) groups the output by depth.

C++
#include <iostream>
#include <memory>
#include <queue>
#include <vector>

struct Node
{
    int value;
    std::unique_ptr<Node> left, right;
};

std::unique_ptr<Node> leaf(int v) { return std::make_unique<Node>(Node{ v, nullptr, nullptr }); }
std::unique_ptr<Node> node(int v, std::unique_ptr<Node> l, std::unique_ptr<Node> r)
{
    return std::make_unique<Node>(Node{ v, std::move(l), std::move(r) });
}

std::vector<std::vector<int>> levels(const Node* root)
{
    std::vector<std::vector<int>> out;
    std::queue<const Node*> q;
    if (root) q.push(root);
    while (!q.empty())
    {
        out.emplace_back();
        for (std::size_t count = q.size(); count > 0; --count)
        {
            const Node* n = q.front();
            q.pop();
            out.back().push_back(n->value);
            if (n->left) q.push(n->left.get());
            if (n->right) q.push(n->right.get());
        }
    }
    return out;
}

int main()
{
    auto root = node(8, node(3, leaf(1), node(6, leaf(4), leaf(7))), node(10, nullptr, node(14, leaf(13), nullptr)));
    for (const auto& level : levels(root.get()))
    {
        for (int v : level) std::cout << v << ' ';
        std::cout << '\n';
    }
}

Rebuilding a tree from traversals

One traversal does not determine a tree, but pre-order plus in-order does (when the values are distinct). The first pre-order value is the root; finding it in the in-order sequence splits the rest into the left subtree's values (before it) and the right subtree's (after it); recurse. Practice 4.01 implements this.

Serialising a tree

To save a tree to a file or send it over a network, write a pre-order traversal with a marker for every missing child. 8 3 1 # # 6 # # 10 # # describes a root 8 with children 3 and 10, where 3 has children 1 and 6. Reading it back is the same recursion: read a token; if it is #, return an empty tree; otherwise make a node and read its left, then its right subtree.

Summary

  • A tree has one root and one path between any two nodes; a binary tree has at most two children per node.
  • Tree functions are naturally recursive: handle the empty tree, combine the subtrees.
  • Pre-, in- and post-order are depth-first and can use an explicit stack; level order uses a queue.
  • Pre-order plus in-order determines a tree with distinct values; pre-order with null markers serialises one.
