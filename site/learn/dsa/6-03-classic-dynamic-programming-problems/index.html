Classic Dynamic Programming Problems

lesson 6.033 of 5 in milestone 67 min1 practice task

The problems every programmer meets - the 0/1 knapsack and why its one-row version loops backwards, the longest common subsequence (behind diff tools), edit distance (behind spelling correction and DNA alignment) with a one-row optimisation, and the longest increasing subsequence in O(n log n) with patience sorting.

The 0/1 knapsack

A hiker can carry W kilograms. Each item has a weight and a value, and must be taken whole or left. Which items maximise the total value? Greedy by value per kilogram fails here (a heavy valuable item can leave awkward unused space), but DP solves it:

  • State: best[i][w] = the highest value using only the first i items within capacity w.
  • Transition: item i is either left (best[i−1][w]) or taken, if it fits (best[i−1][w − weight] + value): take the larger.
  • Base case: best[0][w] = 0.

That is O(n × W) time. Since row i only needs row i − 1, one row is enough, if you loop over capacities backwards: going downwards, best[w − weight] still holds the previous row's value, so each item is used at most once. Looping forwards would let an item be taken again and again (which is exactly the "unbounded knapsack").

C++
#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> weight{ 1, 3, 4, 5 }, value{ 1, 4, 5, 7 };
    int W = 7;

    std::vector<int> best(W + 1, 0);
    for (std::size_t i = 0; i < weight.size(); ++i)
        for (int w = W; w >= weight[i]; --w)                   // backwards: each item at most once
            best[w] = std::max(best[w], best[w - weight[i]] + value[i]);
    std::cout << "best value with capacity " << W << ": " << best[W] << '\n';

    // Keeping the full table lets us rebuild which items were taken.
    std::size_t n = weight.size();
    std::vector<std::vector<int>> t(n + 1, std::vector<int>(W + 1, 0));
    for (std::size_t i = 1; i <= n; ++i)
        for (int w = 0; w <= W; ++w)
        {
            t[i][w] = t[i - 1][w];
            if (weight[i - 1] <= w) t[i][w] = std::max(t[i][w], t[i - 1][w - weight[i - 1]] + value[i - 1]);
        }
    std::cout << "take items:";
    for (std::size_t i = n, w = W; i > 0; --i)
        if (t[i][w] != t[i - 1][w])                            // the value changed, so item i - 1 was taken
        {
            std::cout << ' ' << i - 1;
            w -= weight[i - 1];
        }
    std::cout << '\n';
}

Longest common subsequence

A subsequence keeps some characters of a string in order, not necessarily adjacent: "ACE" is a subsequence of "ABCDE". The longest common subsequence (LCS) of two strings is the longest string that is a subsequence of both. diff and version control systems use LCS on lines to show what changed between two files; biologists use it on DNA.

  • State: L[i][j] = the LCS length of the first i characters of a and the first j characters of b.
  • Transition: if a[i−1] == b[j−1], that character extends the LCS: L[i−1][j−1] + 1. Otherwise one of the two characters is not in it: max(L[i−1][j], L[i][j−1]).
C++
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

std::string lcs(const std::string& a, const std::string& b)
{
    std::vector<std::vector<int>> L(a.size() + 1, std::vector<int>(b.size() + 1, 0));
    for (std::size_t i = 1; i <= a.size(); ++i)
        for (std::size_t j = 1; j <= b.size(); ++j)
            L[i][j] = a[i - 1] == b[j - 1] ? L[i - 1][j - 1] + 1 : std::max(L[i - 1][j], L[i][j - 1]);

    std::string out;                                           // walk back from the corner
    for (std::size_t i = a.size(), j = b.size(); i > 0 && j > 0;)
    {
        if (a[i - 1] == b[j - 1]) { out += a[i - 1]; --i; --j; }
        else if (L[i - 1][j] >= L[i][j - 1]) --i;
        else --j;
    }
    std::reverse(out.begin(), out.end());
    return out;
}

int main()
{
    std::cout << lcs("AGGTAB", "GXTXAYB") << '\n';
    std::cout << lcs("dynamic programming", "dramatic programs") << '\n';
}

O(|a| × |b|) time and space.

Edit distance

The edit distance (Levenshtein distance) between two words is the fewest single-character insertions, deletions and substitutions that turn one into the other. "kitten" → "sitting" takes 3: substitute k→s, substitute e→i, insert g. Spelling checkers suggest dictionary words at a small edit distance (the milestone project does), and DNA alignment uses weighted versions.

  • State: D[i][j] = the edit distance between the first i characters of a and the first j of b.
  • Base cases: D[i][0] = i (delete everything), D[0][j] = j (insert everything).
  • Transition: D[i][j] is the smallest of
    • D[i−1][j] + 1 (delete a[i−1]),
    • D[i][j−1] + 1 (insert b[j−1]),
    • D[i−1][j−1] + (a[i−1] == b[j−1] ? 0 : 1) (keep or substitute).

Each row only needs the previous one, so two rows (or one row plus a variable) are enough: O(|a| × |b|) time, O(|b|) space.

C++
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int editDistance(const std::string& a, const std::string& b)
{
    std::vector<int> prev(b.size() + 1), cur(b.size() + 1);
    for (std::size_t j = 0; j <= b.size(); ++j) prev[j] = static_cast<int>(j);
    for (std::size_t i = 1; i <= a.size(); ++i)
    {
        cur[0] = static_cast<int>(i);
        for (std::size_t j = 1; j <= b.size(); ++j)
            cur[j] = std::min({ prev[j] + 1, cur[j - 1] + 1, prev[j - 1] + (a[i - 1] == b[j - 1] ? 0 : 1) });
        std::swap(prev, cur);
    }
    return prev[b.size()];
}

int main()
{
    for (auto [a, b] : { std::pair{ "kitten", "sitting" }, std::pair{ "flaw", "lawn" }, std::pair{ "", "abc" }, std::pair{ "same", "same" } })
        std::cout << a << " -> " << b << ": " << editDistance(a, b) << '\n';
}

Longest increasing subsequence

Given a sequence of numbers, how long is the longest strictly increasing subsequence? For 3 1 4 1 5 9 2 6 5 3 5, one answer is 1 4 5 6... or 1 2 3 5: length 4.

The direct DP, lis[i] = 1 + max(lis[j]) over earlier j with a smaller value, is O(n²). A cleverer method, patience sorting, is O(n log n). Keep an array tails, where tails[k] is the smallest possible last value of an increasing subsequence of length k + 1 seen so far. The array is always sorted, so for each new value, binary search for the first tail that is ≥ it, and replace it (or append if there is none). The answer is the length of tails.

C++
#include <algorithm>
#include <iostream>
#include <vector>

int lisLength(const std::vector<int>& values)
{
    std::vector<int> tails;
    for (int x : values)
    {
        auto it = std::lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);       // extends the longest run so far
        else *it = x;                                    // a smaller tail for runs of that length
    }
    return static_cast<int>(tails.size());
}

int main()
{
    std::cout << lisLength({ 3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5 }) << '\n';
    std::cout << lisLength({ 10, 9, 8, 7 }) << '\n';
}

tails is not itself an increasing subsequence of the input; it only tracks the best possible ends. Rebuilding an actual subsequence needs a parent index per element, as with coin change.

Recognising these patterns

Pattern Typical state Examples
prefix of one sequence dp[i] Fibonacci, coin change, LIS, house robber
prefixes of two sequences dp[i][j] LCS, edit distance, sequence alignment
items and capacity dp[i][w] knapsack, subset sum, partition into equal halves
interval dp[l][r] matrix chain multiplication, palindromes, optimal BSTs
subset of a small set dp[mask] travelling salesman on ~20 cities

Summary

  • 0/1 knapsack: take or leave each item, O(n × W); one row looped backwards.
  • LCS and edit distance fill a table over prefixes of two strings, O(|a| × |b|); edit distance needs only two rows.
  • Rebuild solutions by walking back through the table.
  • LIS takes O(n log n) with patience sorting and binary search.
  • Most DP problems follow a handful of state patterns.
