Graphs and Breadth-First Search

lesson 5.011 of 5 in milestone 57 min1 practice task

Modelling connections - vertices and edges, directed, undirected and weighted graphs, adjacency matrices, adjacency lists and edge lists with their costs, breadth-first search and why it finds shortest paths in unweighted graphs, rebuilding the path from parent links, connected components, two-colouring (bipartite graphs), grids as implicit graphs, and multi-source BFS.

Graphs

A graph is a set of vertices (nodes) joined by edges. It is the most general structure in this course: lists and trees are special graphs. Graphs model anything with connections:

Domain Vertices Edges
maps places roads (weighted by distance or time)
social networks people friendships (undirected) or follows (directed)
the web pages links (directed)
build systems tasks "must happen before" (directed, no cycles)
games board positions moves

Vocabulary: an edge is directed (one way, u → v) or undirected (both ways). Edges may carry a weight. The degree of a vertex is its number of edges. A path is a sequence of vertices joined by edges; a cycle is a path that returns to its start. We write V for the number of vertices and E for the number of edges.

Representing a graph

Number the vertices 0 to V − 1. Then there are three common representations:

Representation Memory Is u–v an edge? List u's neighbours
adjacency matrix: bool m[V][V] O(V²) O(1) O(V)
adjacency list: vector<vector<int>> adj O(V + E) O(degree) O(degree)
edge list: vector<pair<int,int>> O(E) O(E) O(E)

Most real graphs are sparse (E is much smaller than V²: a road network has a few roads per junction), so the adjacency list is the default. A matrix suits small, dense graphs. An edge list suits algorithms that process edges in sorted order, like Kruskal's (lesson 5.04).

C++
#include <iostream>
#include <vector>

int main()
{
    int V = 5;
    std::vector<std::vector<int>> adj(V);
    auto addEdge = [&](int u, int v) { adj[u].push_back(v); adj[v].push_back(u); };   // undirected: both directions
    addEdge(0, 1); addEdge(0, 2); addEdge(1, 3); addEdge(2, 3); addEdge(3, 4);

    for (int u = 0; u < V; ++u)
    {
        std::cout << u << ":";
        for (int v : adj[u]) std::cout << ' ' << v;
        std::cout << '\n';
    }
}

For a weighted graph, store pairs: std::vector<std::vector<std::pair<int, int>>> adj with (neighbour, weight).

Breadth-first search

Breadth-first search (BFS) explores a graph in layers, exactly like level-order traversal of a tree (lesson 4.01): first the start vertex, then all its neighbours, then all their unvisited neighbours, and so on. A queue holds the frontier, and a visited (or distance) array makes sure each vertex is processed once, since unlike a tree, a graph can reach a vertex by several routes.

Because BFS reaches vertices in order of distance, the first time it reaches a vertex is along a shortest path (fewest edges). Recording each vertex's parent, the vertex it was discovered from, lets you rebuild that path backwards from the target.

C++
#include <algorithm>
#include <iostream>
#include <queue>
#include <vector>

int main()
{
    int V = 8;
    std::vector<std::vector<int>> adj(V);
    for (auto [u, v] : std::vector<std::pair<int, int>>{ { 0, 1 }, { 0, 2 }, { 1, 3 }, { 2, 3 }, { 3, 4 }, { 4, 5 }, { 2, 6 }, { 6, 5 } })
    {
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    std::vector<int> dist(V, -1), parent(V, -1);
    std::queue<int> q;
    dist[0] = 0;
    q.push(0);
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        for (int v : adj[u])
            if (dist[v] == -1)                  // first time we see v: that is the shortest way there
            {
                dist[v] = dist[u] + 1;
                parent[v] = u;
                q.push(v);
            }
    }

    for (int u = 0; u < V; ++u) std::cout << "dist[" << u << "] = " << dist[u] << '\n';

    std::vector<int> path;
    for (int v = 5; v != -1; v = parent[v]) path.push_back(v);
    std::reverse(path.begin(), path.end());
    std::cout << "a shortest path from 0 to 5:";
    for (int v : path) std::cout << ' ' << v;
    std::cout << '\n';
}

Vertex 7 has no edges, so its distance stays −1: unreachable. BFS visits each vertex once and looks at each edge once (twice for undirected), so it runs in O(V + E).

Mark a vertex as visited when it is pushed, not when it is popped. Otherwise the same vertex can enter the queue many times.

Connected components

In an undirected graph, a connected component is a maximal set of vertices that can all reach each other. Run BFS from every vertex not yet visited; each run discovers one whole component. The total is still O(V + E). (Union-find, lesson 4.05, also counts components, and handles edges arriving over time.)

Two-colouring: bipartite graphs

A graph is bipartite if its vertices can be split into two groups with every edge going between the groups: students and courses, jobs and machines. BFS tests it: colour the start 0, its neighbours 1, their neighbours 0, and so on; the graph is bipartite exactly when no edge joins two vertices of the same colour. (Equivalently: it has no cycle of odd length.)

C++
#include <iostream>
#include <queue>
#include <vector>

bool bipartite(const std::vector<std::vector<int>>& adj)
{
    std::vector<int> colour(adj.size(), -1);
    for (std::size_t s = 0; s < adj.size(); ++s)
    {
        if (colour[s] != -1) continue;              // a new component
        colour[s] = 0;
        std::queue<int> q;
        q.push(static_cast<int>(s));
        while (!q.empty())
        {
            int u = q.front();
            q.pop();
            for (int v : adj[u])
            {
                if (colour[v] == -1) { colour[v] = 1 - colour[u]; q.push(v); }
                else if (colour[v] == colour[u]) return false;
            }
        }
    }
    return true;
}

int main()
{
    std::vector<std::vector<int>> square{ { 1, 3 }, { 0, 2 }, { 1, 3 }, { 2, 0 } };   // a 4-cycle
    std::vector<std::vector<int>> triangle{ { 1, 2 }, { 0, 2 }, { 0, 1 } };            // a 3-cycle
    std::cout << "square bipartite? " << bipartite(square) << ", triangle bipartite? " << bipartite(triangle) << '\n';
}

Grids are graphs

A maze or a game map stored as a grid of characters is a graph in disguise: each open cell is a vertex, with edges to its open neighbours up, down, left and right. You never build an adjacency list; you compute the neighbours on the fly with direction offsets.

C++
#include <iostream>
#include <queue>
#include <string>
#include <vector>

int main()
{
    std::vector<std::string> maze{
        "S.#.....",
        ".##.###.",
        "....#...",
        "#.#.#.#.",
        "..#...#G" };
    int rows = static_cast<int>(maze.size()), cols = static_cast<int>(maze[0].size());
    const int dr[] = { -1, 1, 0, 0 }, dc[] = { 0, 0, -1, 1 };

    std::vector<std::vector<int>> dist(rows, std::vector<int>(cols, -1));
    std::queue<std::pair<int, int>> q;
    dist[0][0] = 0;
    q.push({ 0, 0 });
    while (!q.empty())
    {
        auto [r, c] = q.front();
        q.pop();
        for (int d = 0; d < 4; ++d)
        {
            int nr = r + dr[d], nc = c + dc[d];
            if (nr < 0 || nr >= rows || nc < 0 || nc >= cols || maze[nr][nc] == '#' || dist[nr][nc] != -1) continue;
            dist[nr][nc] = dist[r][c] + 1;
            q.push({ nr, nc });
        }
    }
    std::cout << "steps from S to G: " << dist[4][7] << '\n';
}

Multi-source BFS starts with several vertices in the queue at distance 0. It computes, for every cell, the distance to the nearest source in a single O(V + E) pass: the nearest exit for every room, how long fire takes to spread from several starting points, the distance from every pixel to the nearest edge.

Summary

  • Graphs are vertices and edges, directed or undirected, weighted or not; use adjacency lists for sparse graphs.
  • BFS explores in layers with a queue in O(V + E), giving shortest paths by number of edges; parent links rebuild the path.
  • Repeated BFS finds connected components; BFS two-colouring tests for bipartite graphs.
  • Grids are implicit graphs; multi-source BFS gives the distance to the nearest of several sources.
