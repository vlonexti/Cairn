Strings and Template Literals

lesson 1.044 of 5 in milestone 15 min1 practice task

Working with text - template literals with ${} expressions, indexing and length, the most useful string methods, splitting and joining, padding and formatting numbers, and Unicode characters.

Three kinds of quotes

JavaScript
const single = 'It\'s';
const double = "She said \"hi\"";
const name = "Ada";
const template = `Hello, ${name}! 2 + 3 = ${2 + 3}`;
console.log(single, double, template);

Template literals (backticks) insert any expression with ${...} and can span several lines. Use them whenever text and values are mixed.

Reading strings

JavaScript
const word = "JavaScript";
console.log(word.length, word[0], word.at(-1), word.slice(4), word.slice(0, 4), word.slice(-6));

at(-1) counts from the end; slice(start, end) takes a part (end not included; negative values count from the end). Strings are immutable: methods return new strings.

Useful methods

Method Example Gives
toUpperCase, toLowerCase "Ada".toUpperCase() "ADA"
trim, trimStart, trimEnd " hi ".trim() "hi"
includes, startsWith, endsWith "photo.png".endsWith(".png") true
indexOf "banana".indexOf("na") 2 (-1 if absent)
split "a,b,c".split(",") ["a", "b", "c"]
replace, replaceAll "a-b-c".replaceAll("-", "+") "a+b+c"
repeat "ab".repeat(3) "ababab"
padStart, padEnd "7".padStart(3, "0") "007"

replace with a string replaces only the first match; use replaceAll (or a regular expression with the g flag, lesson 2.02's practice) for all.

Joining a list: ["a", "b"].join(", ") is "a, b".

Formatting numbers

JavaScript
const price = 1234.5;
console.log(price.toFixed(2));                                   // "1234.50"
console.log(price.toLocaleString("en-US"));                      // "1,234.5"
console.log(price.toLocaleString("en-US", { style: "currency", currency: "USD" }));
console.log(String(5).padStart(3, " "), (0.256 * 100).toFixed(1) + "%");

Intl.NumberFormat and toLocaleString format numbers, currencies and dates for a language and region.

Comparing strings

< and > compare strings by character codes: "Zebra" < "apple" is true because capitals come first. For human sorting, use a.localeCompare(b) (lesson 2.02 uses it with sort).

Unicode

JavaScript strings are UTF-16 (the Win32 course's lesson 1.02 explains the encoding). "é".length is 1, but an emoji such as "😀".length is 2, because it is stored as two code units. To count or walk characters properly, use [...text] or for (const ch of text), which handle such pairs:

JavaScript
const text = "hi 😀";
console.log(text.length, [...text].length);   // 5 4
