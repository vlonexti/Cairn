What JavaScript Is and Running It

lesson 1.011 of 5 in milestone 15 min1 practice task

JavaScript is the language every web browser runs, and with Node.js it runs on servers and in tools too. This lesson explains where it runs, how it is executed, the console, and how TypeScript relates to it.

The language of the web

Every web browser contains a JavaScript engine. HTML describes a page, CSS styles it, and JavaScript makes it do things: respond to clicks, check forms, fetch data, draw, play games. Because every browser runs it, it is the most widely deployed programming language there is.

JavaScript also runs outside the browser:

Where Engine / runtime Used for
Browsers V8 (Chrome, Edge), SpiderMonkey (Firefox), JavaScriptCore (Safari) Web pages and apps
Node.js, Deno, Bun V8 or JavaScriptCore Servers, command-line tools, build tools
Desktop apps Electron (VS Code, Discord, this site's desktop app) Apps built with web technology

How it runs

Like Python, JavaScript is not compiled ahead of time by you. The engine parses your code and runs it, compiling hot parts to machine code on the fly (just-in-time compilation), which makes modern JavaScript fast.

A first program

JavaScript
console.log("Hello, Xenon!");
console.log("2 + 3 =", 2 + 3);
console.log([1, 2, 3], { name: "Ada", age: 36 });

console.log prints its arguments separated by spaces; arrays and objects are shown in a readable form. Press Run to try it.

Statements end with a semicolon. JavaScript inserts missing semicolons automatically in most places, but the rules have surprising corners, so this course always writes them.

Running it yourself

  • In a browser: open the developer tools (F12), choose the Console tab, and type JavaScript; it runs on the current page.
  • With Node.js: install it from nodejs.org, save code in hello.js, and run node hello.js. Running node alone opens an interactive prompt.

An editor such as VS Code understands JavaScript out of the box and shows errors as you type.

JavaScript and TypeScript

TypeScript is JavaScript with types added: you write let count: number = 0, and a checker tells you before running that count = "ten" is a mistake. TypeScript compiles to plain JavaScript by removing the types, so it runs everywhere JavaScript does. Most large JavaScript projects today are written in TypeScript. This course teaches JavaScript first (milestones 1-4), then TypeScript on top (milestone 5); everything you learn about JavaScript applies to TypeScript unchanged.
