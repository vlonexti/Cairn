Values, Variables and Types

lesson 1.022 of 5 in milestone 15 min1 practice task

JavaScript's types - number, string, boolean, undefined, null, bigint, symbol and objects - declaring variables with const and let (and why not var), typeof, and how values are copied or shared.

Declaring variables

JavaScript
const name = "Ada";       // cannot be reassigned
let score = 10;           // can be reassigned
score = score + 5;
console.log(name, score);

Use const by default and let only when the variable really must change. The old var has confusing rules (function scope, hoisting): never use it in new code.

const means the name cannot be pointed at another value. If the value is an object or array, its contents can still change:

JavaScript
const list = [1, 2];
list.push(3);             // fine: the same array, changed
console.log(list);
// list = [];             // TypeError: Assignment to constant variable

The types

Type Examples Notes
number 42, 3.14, -0, NaN, Infinity One type for whole and fractional numbers (64-bit floats)
bigint 9007199254740993n Arbitrarily large whole numbers
string "hi", 'hi', `hi` Text
boolean true, false
undefined undefined A variable with no value yet, a missing property
null null "Deliberately nothing"
symbol Symbol("id") Unique keys (advanced)
object { a: 1 }, [1, 2], functions, dates Everything else
JavaScript
console.log(typeof 42, typeof "x", typeof true, typeof undefined, typeof 10n);
console.log(typeof {}, typeof [], typeof null, typeof function () {});

Two famous oddities: typeof null is "object" (a historical bug that cannot be fixed), and arrays are objects too; use Array.isArray(x) to check for an array.

Numbers

All numbers are 64-bit floating point, so whole numbers are exact only up to Number.MAX_SAFE_INTEGER (about 9 × 10¹⁵), and decimal fractions are approximate (0.1 + 0.2 is 0.30000000000000004, exactly as in Python's lesson 1.04). Invalid arithmetic gives NaN ("not a number"), which is not even equal to itself: test it with Number.isNaN(x).

undefined and null

JavaScript
let pending;
console.log(pending);          // undefined: declared but not assigned
const user = { name: "Ada" };
console.log(user.email);       // undefined: no such property
const selected = null;         // "no selection", on purpose

Treat undefined as "not set" and null as "set to nothing". Both are falsy, and x == null is true for both (one of the few good uses of ==, lesson 1.03).

Copying and sharing

Primitive values (numbers, strings, booleans...) are copied; objects and arrays are shared by reference:

JavaScript
let a = 5;
let b = a;
b += 1;                        // a is still 5

const p = { x: 1 };
const q = p;
q.x = 99;                      // p.x is also 99: one object, two names
const r = { ...p };            // a (shallow) copy
r.x = 0;
console.log(a, p.x, r.x);

Naming

Variables and functions use camelCase; classes use PascalCase; constants that are true configuration values are often UPPER_CASE. Names are case-sensitive.
