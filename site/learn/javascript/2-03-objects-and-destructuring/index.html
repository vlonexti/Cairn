Objects and Destructuring

lesson 2.033 of 5 in milestone 25 min1 practice task

Objects as collections of named values - creating and reading them, dot and bracket access, adding and deleting properties, shorthand and computed names, Object.keys, values and entries, spread and copying, and destructuring objects and arrays.

Object literals

JavaScript
const book = {
  title: "Dune",
  author: "Frank Herbert",
  year: 1965,
  "page count": 412,          // names with spaces need quotes
};
console.log(book.title, book["page count"]);
book.rating = 5;               // add
delete book.year;              // remove
console.log(book, "year" in book, book.missing);   // undefined for missing properties

Use dot access for fixed names and brackets when the name is in a variable: book[field].

Shorthand and computed names

JavaScript
const title = "Dune";
const year = 1965;
const field = "genre";
const entry = { title, year, [field]: "sci-fi", describe() { return `${this.title} (${this.year})`; } };
console.log(entry, entry.describe());

{ title } is short for { title: title }; [field] uses the variable's value as the name; describe() {...} is a method.

Looping over an object

JavaScript
const scores = { ada: 95, grace: 88, linus: 72 };
console.log(Object.keys(scores), Object.values(scores));
for (const [name, score] of Object.entries(scores)) {
  console.log(`${name}: ${score}`);
}
const curved = Object.fromEntries(Object.entries(scores).map(([n, s]) => [n, s + 5]));
console.log(curved);

Object.entries and Object.fromEntries turn an object into [key, value] pairs and back, so array methods can transform objects.

Copying and merging

Spread copies properties into a new object; later properties win:

JavaScript
const defaults = { theme: "light", size: 12 };
const user = { size: 14 };
const settings = { ...defaults, ...user, wrap: true };
console.log(settings);

Spread makes a shallow copy: nested objects are still shared. structuredClone(obj) makes a deep copy.

Destructuring

Destructuring takes values out of objects and arrays into variables:

JavaScript
const person = { name: "Ada", age: 36, address: { city: "London" } };
const { name, age: years, email = "none", address: { city } } = person;
console.log(name, years, email, city);

const [first, second = 0, ...others] = [10, 20, 30, 40];
console.log(first, second, others);

let a = 1, b = 2;
[a, b] = [b, a];                       // swap
console.log(a, b);

age: years renames; = "none" gives a default when the property is undefined; nested patterns reach inside.

It is especially useful in parameters:

JavaScript
function formatUser({ name, age, city = "unknown" }) {
  return `${name}, ${age}, ${city}`;
}
console.log(formatUser({ name: "Grace", age: 85 }));
