Regular Expressions

lesson 7.011 of 6 in milestone 75 min2 practice tasks

Patterns that find and take apart text - writing a RegExp, character classes and quantifiers, anchors, groups and named groups, flags (g, i, m, s, u, y), test, match, matchAll, replace with a function, split, and keeping patterns readable.

A pattern language for text

A regular expression describes a set of strings: "a word", "a date like 2026-11-20", "anything between quotes". JavaScript writes them between slashes:

JavaScript
const datePattern = /\d{4}-\d{2}-\d{2}/;
console.log(datePattern.test("due 2026-11-20"));   // true
console.log(datePattern.test("due tomorrow"));     // false

new RegExp("\\d+", "g") builds one from a string, which you need when the pattern is only known at run time (note the doubled backslash inside a string).

The building blocks

Pattern Matches
abc exactly those characters
. any character except a new line
\d \w \s a digit, a word character (letter, digit, _), whitespace
\D \W \S anything but those
[aeiou] [a-z0-9] [^,] one character from a set, a range, or not in a set
x* x+ x? zero or more, one or more, zero or one
x{3} x{2,5} x{2,} exactly 3, 2 to 5, at least 2
^ $ start and end of the text (of each line with the m flag)
\b a word boundary
a|b either
\. \( \\ a special character taken literally

Quantifiers are greedy: ".+" on "a" and "b" takes everything from the first quote to the last. Add ? to make them lazy: ".+?" stops at the first closing quote.

Groups

Parentheses group part of a pattern and capture what it matched. match (without the g flag) returns the whole match and every group:

JavaScript
const m = "Order #4512 shipped".match(/#(\d+)\s+(\w+)/);
console.log(m[0], "|", m[1], "|", m[2]);   // #4512 shipped | 4512 | shipped

Named groups make the result readable:

JavaScript
const { groups } = "2026-11-20".match(/(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/);
console.log(groups.year, groups.month, groups.day);

(?:...) groups without capturing, when you only need the grouping for | or a quantifier.

Flags

Flag Meaning
g global: find every match, not just the first
i ignore case
m ^ and $ match at each line
s . matches new lines too
u Unicode: \u{1F600} and \p{L} (any letter) work
y sticky: match only at lastIndex (for tokenizers)

Finding every match

With g, match returns just the matched strings. matchAll gives each match with its groups and position, which is usually what you want:

JavaScript
const text = "x=1, y=22, z=333";
console.log(text.match(/\d+/g));                    // [ '1', '22', '333' ]
for (const m of text.matchAll(/(\w)=(\d+)/g)) {
  console.log(m[1], Number(m[2]), "at", m.index);
}

Replacing and splitting

replace with g (or replaceAll) changes every match. The replacement can use $1 or $<name>, or be a function that receives the match and its groups:

JavaScript
console.log("2026-11-20".replace(/(\d+)-(\d+)-(\d+)/, "$3/$2/$1"));    // 20/11/2026
const shouted = "make it loud".replace(/\b\w/g, letter => letter.toUpperCase());
console.log(shouted);                                                    // Make It Loud
console.log("a, b;c ,d".split(/\s*[,;]\s*/));                            // [ 'a', 'b', 'c', 'd' ]

A word of caution

A regular expression is great for finding and checking shapes of text. It is a poor tool for nested structures such as HTML or JSON: use a real parser (JSON.parse, the DOM) for those. And a long pattern is hard to read, so build it from named pieces:

JavaScript
const number = String.raw`\d+(?:\.\d+)?`;
const unit = String.raw`(?:kg|g|lb)`;
const weight = new RegExp(`^(${number})\\s*(${unit})$`, "i");
console.log("2.5 KG".match(weight).slice(1));

String.raw keeps backslashes as written, so you do not have to double them.
