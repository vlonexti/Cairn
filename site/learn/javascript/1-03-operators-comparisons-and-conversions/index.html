Operators, Comparisons and Conversions

lesson 1.033 of 5 in milestone 15 min1 practice task

Arithmetic and assignment operators, strict versus loose equality, truthiness, the logical operators and the nullish operators ?? and ?., and converting between strings and numbers without surprises.

Arithmetic

Operator Meaning Example
+ - * / Add, subtract, multiply, divide 7 / 2 is 3.5
% Remainder (keeps the sign of the left side) -7 % 3 is -1
** Power 2 ** 10 is 1024
++, -- Add or subtract 1 count++
+=, -=, *=, ... Update total += price

Whole-number division is Math.trunc(a / b) (towards zero) or Math.floor(a / b) (down). Note % differs from Python for negative numbers.

Strict equality

Always compare with === and !==: equal value and type.

JavaScript
console.log(1 === 1, 1 === "1", "a" === "a");      // true false true
console.log(1 == "1", 0 == "", null == undefined);  // true true true: loose equality converts types

Loose == converts its operands with complicated rules ([] == false is true). The one common use is x == null, which is true for both null and undefined. Objects (including arrays) are equal only if they are the same object: [1] === [1] is false.

Truthiness

In conditions, these values are falsy: false, 0, -0, 0n, "", null, undefined, NaN. Everything else is truthy, including "0", "false", [] and {}.

Logical operators

&& and || return one of their operands, not necessarily true or false:

JavaScript
console.log("" || "default");      // "default": the first truthy value
console.log("Ada" && "admin");     // "admin": the first falsy value, or the last
console.log(!0, !!"text");         // true true: !! converts to a boolean

a || b is often used for defaults, but it replaces every falsy value, including 0 and "". The nullish operators only react to null and undefined:

JavaScript
const volume = 0;
console.log(volume || 50);   // 50: wrong, 0 was a real value
console.log(volume ?? 50);   // 0: ?? only replaces null and undefined

const user = { profile: null };
console.log(user.profile?.email);          // undefined instead of a TypeError
console.log(user.settings?.theme ?? "light");

?. (optional chaining) stops and gives undefined if the left side is null or undefined.

Converting

Want Use Watch out
Number from text Number("42") Number("") is 0; Number("4x") is NaN
Whole number from text parseInt("42px", 10) Reads until the first non-digit: 42; always pass the base 10
Decimal from text parseFloat("3.5kg") 3.5
Text from a number String(42), `${42}`, (3.14159).toFixed(2) toFixed returns a string
Boolean Boolean(x) or !!x Truthiness rules above

+ with a string concatenates: "5" + 3 is "53", while "5" - 3 is 2. Convert explicitly before doing arithmetic on text from forms or files.
