Arrays and Array Methods

lesson 2.022 of 5 in milestone 25 min1 practice task

Creating and changing arrays, and the methods that make array code short and clear - map, filter, reduce, find, some and every, includes, sort with a compare function, slice versus splice, flat and flatMap, and which methods change the array.

Basics

JavaScript
const fruits = ["apple", "pear"];
fruits.push("plum");             // add at the end
fruits.unshift("fig");           // add at the start
const last = fruits.pop();       // remove from the end
console.log(fruits, last, fruits.length, fruits.includes("pear"), fruits.indexOf("pear"));

Transforming without loops

Method Returns
map(f) A new array of f(item) for each item
filter(f) A new array of the items where f(item) is truthy
reduce(f, start) One value built up from all items
find(f) / findIndex(f) The first matching item / its index (undefined / -1 if none)
some(f) / every(f) Whether any / all items match
forEach(f) Nothing: just runs f on each item
JavaScript
const orders = [
  { item: "tea", qty: 2, price: 2.5 },
  { item: "cake", qty: 1, price: 4 },
  { item: "mug", qty: 3, price: 8 },
];
const totals = orders.map(o => o.qty * o.price);
const big = orders.filter(o => o.qty * o.price > 5).map(o => o.item);
const sum = totals.reduce((acc, t) => acc + t, 0);
console.log(totals, big, sum, orders.find(o => o.item === "cake"), orders.some(o => o.qty > 2));

Chaining filter then map then reduce reads like a description of the result. The callbacks also receive the index as a second argument: map((item, i) => ...).

Sorting

sort() changes the array and, without arguments, compares items as strings: [10, 9, 1].sort() gives [1, 10, 9]. Always give numbers a compare function, which returns a negative number when a comes first:

JavaScript
const nums = [10, 9, 1, 100];
console.log([...nums].sort((a, b) => a - b));          // ascending
const people = [{ name: "bob", age: 30 }, { name: "Ada", age: 36 }, { name: "carol", age: 30 }];
people.sort((a, b) => a.age - b.age || a.name.localeCompare(b.name));
console.log(people.map(p => p.name));                  // by age, then name

a.localeCompare(b) compares text the way people expect. || chains criteria: if the first difference is 0, the second decides. toSorted() returns a sorted copy instead of changing the array.

Changing versus copying

Changes the array Returns a new array
push, pop, shift, unshift map, filter, concat
splice(start, deleteCount, ...items) slice(start, end)
sort, reverse, fill toSorted, toReversed, with(i, value)

Copy an array with [...arr] or arr.slice(). Code that does not change its inputs is easier to reason about: prefer the right-hand column.

Nested arrays

JavaScript
console.log([[1, 2], [3], []].flat());                        // [1, 2, 3]
console.log(["a b", "c"].flatMap(s => s.split(" ")));         // ["a", "b", "c"]
const grid = Array.from({ length: 2 }, () => Array(3).fill(0));   // 2 separate rows of 3 zeros

Array.from({ length: n }, (_, i) => ...) builds an array of n computed items.
