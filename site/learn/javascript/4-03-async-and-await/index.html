async and await

lesson 4.033 of 5 in milestone 45 min1 practice task

Writing asynchronous code that reads like ordinary code - async functions always return promises, await pauses only the function, try/catch/finally for errors, running steps in sequence versus in parallel, awaiting in loops, and top-level await.

async functions

An async function always returns a promise. Inside it, await pauses the function until a promise settles, then gives its value (or throws its error):

JavaScript
const wait = ms => new Promise(r => setTimeout(r, ms));
const fetchUser = async id => { await wait(10); return { id, name: `user${id}` }; };
const fetchOrders = async user => { await wait(10); return [`${user.name}-order1`, `${user.name}-order2`]; };

async function firstOrder(id) {
  const user = await fetchUser(id);
  const orders = await fetchOrders(user);
  return orders[0];
}

firstOrder(7).then(o => console.log(o));
console.log("this prints first: await only paused firstOrder");

This is the callback-hell example from lesson 4.01, written as straight lines.

Errors

A rejected promise makes await throw, so ordinary try/catch/finally works:

JavaScript
async function risky(n) {
  await new Promise(r => setTimeout(r, 5));
  if (n > 2) throw new RangeError(`${n} is too big`);
  return n;
}

async function main() {
  try {
    console.log(await risky(1));
    console.log(await risky(5));
    console.log("not reached");
  } catch (err) {
    console.log("caught", err.name, err.message);
  } finally {
    console.log("clean up");
  }
}
main();

A throw inside an async function rejects the promise it returns.

Sequence or parallel

Each await waits before the next line starts. When steps do not depend on each other, start them all first and await them together:

JavaScript
const wait = (ms, v) => new Promise(r => setTimeout(() => r(v), ms));

async function sequential() {
  const t = Date.now();
  const a = await wait(50, "a");
  const b = await wait(50, "b");
  return `${a}${b} in about ${Math.round((Date.now() - t) / 50) * 50} ms`;
}

async function parallel() {
  const t = Date.now();
  const [a, b] = await Promise.all([wait(50, "a"), wait(50, "b")]);
  return `${a}${b} in about ${Math.round((Date.now() - t) / 50) * 50} ms`;
}

sequential().then(console.log);
parallel().then(console.log);

Loops

await inside for...of processes items one at a time, in order. forEach with an async callback does not wait: it starts everything and returns at once, and errors go unhandled.

JavaScript
for (const id of ids) {
  const user = await fetchUser(id);     // one after another
  console.log(user.name);
}

const users = await Promise.all(ids.map(id => fetchUser(id)));   // all at once, results in order

ids.forEach(async id => { await fetchUser(id); });   // BUG: nothing waits for these

To process many items with a limit (say 3 at a time), see lesson 4.05.

Top-level await

In modules (and in this course's sandbox), await works at the top level of a file, outside any function. In older scripts, wrap the code in async function main() { ... } and call main().catch(console.error).
