Maps, Sets and JSON

lesson 2.055 of 5 in milestone 25 min1 practice task

Map for key-value data with any key type and reliable ordering, Set for unique values, when to use them instead of plain objects and arrays, grouping with Map and Object.groupBy, and converting data to and from JSON text.

Map

A Map stores key-value pairs. Unlike a plain object, its keys can be any value (numbers, objects), it remembers insertion order, and it has a size:

JavaScript
const stock = new Map();
stock.set("apples", 4).set("pears", 0);
stock.set("apples", stock.get("apples") + 1);
console.log(stock.get("apples"), stock.has("plums"), stock.size);
for (const [fruit, count] of stock) console.log(fruit, count);
stock.delete("pears");
console.log([...stock.keys()], Object.fromEntries(stock));

Counting with a Map:

JavaScript
const words = "the cat and the hat".split(" ");
const counts = new Map();
for (const w of words) counts.set(w, (counts.get(w) ?? 0) + 1);
console.log(counts);

Use a Map when keys are data (user names, ids) and change at run time; use a plain object for a fixed set of named fields (a record).

Set

A Set holds unique values with fast has:

JavaScript
const tags = new Set(["js", "web", "js"]);
tags.add("ts");
console.log(tags.size, tags.has("web"), [...tags]);
const unique = [...new Set([3, 1, 3, 2, 1])];
console.log(unique);
const a = new Set([1, 2, 3]), b = new Set([2, 3, 4]);
console.log([...a].filter(x => b.has(x)));      // intersection

Recent engines also have a.union(b), a.intersection(b) and a.difference(b).

Objects in Maps and Sets are compared by identity: new Set([{}, {}]).size is 2.

Grouping

Object.groupBy (and Map.groupBy) group items by a key function:

JavaScript
const people = [{ name: "Ada", team: "red" }, { name: "Bob", team: "blue" }, { name: "Cy", team: "red" }];
const byTeam = Object.groupBy(people, p => p.team);
console.log(Object.keys(byTeam), byTeam.red.map(p => p.name));

In older environments, the same is a few lines with reduce or a loop and a Map.

JSON

JSON is the text format of web APIs, written exactly like JavaScript literals (with double-quoted keys):

JavaScript
const order = { id: 7, items: ["tea", "cake"], paid: true, note: null };
const text = JSON.stringify(order);
console.log(text);
console.log(JSON.stringify(order, null, 2));       // pretty-printed
const back = JSON.parse(text);
console.log(back.items[1], back.paid);

JSON has strings, numbers, booleans, null, arrays and objects. undefined and functions are left out, Date objects become strings, and Maps and Sets become {}: convert them first (Object.fromEntries(map), [...set]). JSON.parse throws a SyntaxError on invalid text (lesson 3.03 shows how to handle it).
