Scope and Closures

lesson 2.044 of 5 in milestone 25 min1 practice task

Where variables live - block scope with let and const, function scope, the scope chain, closures that remember variables, private state with closures, and the classic closure-in-a-loop bug that let fixes.

Block scope

let and const are visible only inside the block (the braces) where they are declared:

JavaScript
const x = "outer";
{
  const x = "inner";        // a different variable, hiding the outer one inside this block
  console.log(x);
}
console.log(x);

for (let i = 0; i < 2; i++) { }
// console.log(i);          // ReferenceError: i only exists inside the loop

When a name is used, JavaScript looks in the current block, then the enclosing ones, then the function, then the module and global scope: the scope chain.

Closures

A function remembers the variables of the scope where it was created, even after that scope has finished. A function together with those variables is a closure:

JavaScript
function makeCounter() {
  let count = 0;
  return () => ++count;
}
const a = makeCounter();
const b = makeCounter();
console.log(a(), a(), a(), b());     // 1 2 3 1: separate counts

count cannot be reached from outside except through the returned function: closures give private state.

Modules of functions

Closures can bundle several functions around shared private data:

JavaScript
function createStack() {
  const items = [];
  return {
    push(x) { items.push(x); },
    pop() { return items.pop(); },
    get size() { return items.length; },
  };
}
const s = createStack();
s.push(1); s.push(2);
console.log(s.pop(), s.size);       // 2 1: items itself is unreachable

Classes (lesson 3.01) with private #fields do the same job; both styles are common.

The loop bug

With var, there is one variable for the whole loop, so every callback sees its final value. let creates a new binding for each iteration:

JavaScript
const fns = [];
for (let i = 0; i < 3; i++) fns.push(() => i);
console.log(fns.map(f => f()));     // [0, 1, 2]; with var it would be [3, 3, 3]

Functions that make functions

Closures let you configure a function once and use it many times:

JavaScript
const multiplier = n => x => x * n;
const double = multiplier(2);
const triple = multiplier(3);
console.log(double(5), triple(5));

function once(fn) {
  let done = false, result;
  return (...args) => {
    if (!done) { done = true; result = fn(...args); }
    return result;
  };
}
const init = once(() => { console.log("initialising"); return 42; });
console.log(init(), init());        // prints "initialising" only once
