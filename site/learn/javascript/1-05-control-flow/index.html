Control Flow

lesson 1.055 of 5 in milestone 15 min1 practice task

Making decisions and repeating work - if and else, the conditional operator, switch, for loops in their three forms, while and do-while, break and continue, and labelled loops.

if and else

JavaScript
const temperature = 18;
if (temperature < 0) {
  console.log("Freezing");
} else if (temperature < 15) {
  console.log("Cold");
} else {
  console.log("Mild or warm");
}

Conditions go in parentheses, blocks in braces. Braces are optional for a single statement, but always writing them avoids a classic bug when a second line is added later.

The conditional operator chooses between two values:

JavaScript
const age = 20;
const label = age >= 18 ? "adult" : "minor";
console.log(label);

switch

switch compares one value against several cases with ===:

JavaScript
function dayType(day) {
  switch (day) {
    case "Sat":
    case "Sun":
      return "weekend";
    case "Mon":
      return "start of the week";
    default:
      return "weekday";
  }
}
console.log(dayType("Sun"), dayType("Wed"));

Without return or break, execution falls through into the next case. That is useful for grouping cases ("Sat" and "Sun" above) and a bug when forgotten.

for loops

JavaScript
for (let i = 0; i < 3; i++) {                // counting
  console.log("round", i);
}

const fruits = ["apple", "pear", "plum"];
for (const fruit of fruits) {                 // the VALUES of an array (or string, Map, Set...)
  console.log(fruit);
}

const scores = { ada: 95, grace: 88 };
for (const key in scores) {                   // the KEYS of an object
  console.log(key, scores[key]);
}

Use for...of for arrays and strings; for...in is for object keys only (on arrays it gives the indexes as strings, which is rarely what you want). To get indexes with for...of: for (const [i, fruit] of fruits.entries()).

while and do...while

JavaScript
let n = 27;
let steps = 0;
while (n !== 1) {
  n = n % 2 === 0 ? n / 2 : 3 * n + 1;
  steps++;
}
console.log(steps);

let attempt = 0;
do {
  attempt++;
} while (attempt < 3);                        // the body runs at least once
console.log(attempt);

break and continue

break leaves the loop; continue skips to the next round. In nested loops, a label says which loop to leave:

JavaScript
outer: for (let row = 0; row < 3; row++) {
  for (let col = 0; col < 3; col++) {
    if (row * col === 2) {
      console.log("found at", row, col);
      break outer;
    }
  }
}
