Iterators and Generators

lesson 3.044 of 5 in milestone 35 min1 practice task

What for...of and spread really use - the iteration protocol, making your own objects iterable with Symbol.iterator, generator functions with yield, lazy and infinite sequences, and helpers that combine generators.

The iteration protocol

for...of, spread [...x], destructuring and Array.from work on any iterable: an object with a [Symbol.iterator]() method that returns an iterator. An iterator has next(), which returns { value, done }.

JavaScript
const letters = ["a", "b"];
const it = letters[Symbol.iterator]();
console.log(it.next(), it.next(), it.next());

Arrays, strings, Maps and Sets are iterable; plain objects are not (use Object.entries).

Making a class iterable

JavaScript
class Range {
  constructor(start, end, step = 1) { Object.assign(this, { start, end, step }); }
  [Symbol.iterator]() {
    let current = this.start;
    const { end, step } = this;
    return {
      next() {
        if (current >= end) return { value: undefined, done: true };
        const value = current;
        current += step;
        return { value, done: false };
      },
    };
  }
}
console.log([...new Range(0, 10, 3)]);
for (const n of new Range(1, 3)) console.log(n);

Generators

Writing next() by hand is tedious. A generator function (function*) does it for you: each yield hands out one value and pauses until the next one is asked for.

JavaScript
function* range(start, end, step = 1) {
  for (let n = start; n < end; n += step) yield n;
}
console.log([...range(0, 10, 3)]);

class Bag {
  #items = [];
  add(x) { this.#items.push(x); return this; }
  *[Symbol.iterator]() { yield* this.#items; }      // yield* hands out everything from another iterable
}
console.log([...new Bag().add("x").add("y")]);

Lazy and infinite sequences

A generator does no work until a value is requested, so it can describe a sequence that never ends, as long as the consumer stops:

JavaScript
function* naturals() { let n = 1; while (true) yield n++; }

function* take(iterable, count) {
  if (count <= 0) return;
  for (const x of iterable) { yield x; if (--count === 0) return; }
}
function* mapIter(iterable, f) { for (const x of iterable) yield f(x); }
function* filterIter(iterable, keep) { for (const x of iterable) if (keep(x)) yield x; }

const firstSquaresOfOdds = take(mapIter(filterIter(naturals(), n => n % 2), n => n * n), 5);
console.log([...firstSquaresOfOdds]);

Only the first nine natural numbers are ever produced: each stage asks the one before it for exactly as many values as it needs. This is useful for reading large data piece by piece, paging through API results, or game loops that produce states on demand.

Iterators are single-use: once a generator is finished, iterating it again gives nothing. Call the generator function again for a fresh one.
