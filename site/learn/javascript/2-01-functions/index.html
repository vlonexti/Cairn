Functions

lesson 2.011 of 5 in milestone 25 min1 practice task

Function declarations, function expressions and arrow functions, parameters with defaults, rest parameters and spread, returning values, functions as values, and callbacks.

Three ways to write a function

JavaScript
function area(width, height) {          // declaration: usable anywhere in its scope
  return width * height;
}

const perimeter = function (w, h) {     // expression assigned to a variable
  return 2 * (w + h);
};

const square = x => x * x;              // arrow function: short form for one expression
const describe = (w, h) => {
  const a = area(w, h);
  return `${w}x${h} has area ${a}`;
};

console.log(area(3, 4), perimeter(3, 4), square(5), describe(2, 3));

Arrow functions with one expression return it automatically; with braces they need return. To return an object literal from a one-line arrow, wrap it in parentheses: () => ({ ok: true }).

A function without return returns undefined.

Parameters

Missing arguments are undefined; extra ones are ignored. Default values apply when an argument is undefined:

JavaScript
function greet(name, greeting = "Hello") {
  return `${greeting}, ${name}!`;
}
console.log(greet("Ada"), greet("Ada", "Hi"));

A rest parameter collects any number of arguments into an array; spread does the reverse:

JavaScript
function total(...numbers) {
  return numbers.reduce((sum, n) => sum + n, 0);
}
const prices = [3, 4, 5];
console.log(total(1, 2), total(...prices), Math.max(...prices));

For functions with many options, pass one object and destructure it (lesson 2.03): function connect({ host, port = 443, timeout = 10 }). Calls then name every option.

Functions are values

Functions can be stored, passed and returned like any value. A function passed to another function is a callback:

JavaScript
function repeat(times, action) {
  for (let i = 0; i < times; i++) action(i);
}
repeat(3, i => console.log("round", i));

const operations = { double: x => x * 2, negate: x => -x };
console.log(operations.double(21), operations["negate"](5));

The array methods of lesson 2.02 (map, filter, sort) and all asynchronous code (milestone 4) are built on callbacks.

Pure functions

A pure function's result depends only on its arguments, and it changes nothing outside itself. Pure functions are the easiest to test and reuse; keep reading files, printing and changing shared data at the edges of a program, and the logic in pure functions in between.

Hoisting

Function declarations are hoisted: they can be called before the line that defines them. Functions assigned to const cannot, because the variable does not exist yet ("temporal dead zone"). Define helpers before use, or rely on declarations deliberately.
