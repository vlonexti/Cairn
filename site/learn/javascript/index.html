JavaScript and TypeScript

8 milestones41 lessons52 practice tasks40 projects

From the basics of the language to typed, structured programs that run in the browser and on the server. The course covers values and control flow, functions, arrays and objects, classes, errors and modules, asynchronous code with promises and async/await, TypeScript's type system, and the browser: the DOM, events, storage and tooling, a complete web app, and finally the advanced language: regular expressions, Proxy and Symbols, BigInt, dates and Intl, TypeScript’s computed types, and Node.js, then binary data, async generators, cancellation, testing and immutable data. Practice runs in a sandbox in your browser, with TypeScript type-checked as you type.
