Reverse Engineering

6 milestones30 lessons27 practice tasks30 projects

How to understand a program from its compiled form: the ground rules, the tools, the PE file format, reading x64 disassembly of functions, loops, structs and C++ classes, debuggers from the inside, tracing and finding where data is used, patching and hooking programs you build yourself, and writing your own pattern scanner, memory scanner, disassembler and symbol lookup. It ends with reversing a file format, a protocol and a small virtual machine the course provides. Every target is a program you compiled yourself or one the course gives you. It assumes the C++ course and some x64 assembly (the Assembly course or the Game Development course's milestone 7).
