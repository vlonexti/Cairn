Windows Kernel Driver Development

5 milestones22 lessons22 practice tasks25 projects

An educational course on the Windows kernel and the Windows Driver Kit, done entirely in a virtual machine: kernel architecture, a safe lab with kernel debugging, the I/O model, IOCTLs and a user-mode client, kernel memory, IRQLs and locks, DPCs and work items, observing the system through documented notifications, Driver Verifier, static analysis, secure driver design and signing. The drivers you write only echo, count and log; nothing here touches other programs. It assumes the C++ course and the Win32 API course. You build and run the drivers in a virtual machine; the practice on the site checks the logic inside them.
