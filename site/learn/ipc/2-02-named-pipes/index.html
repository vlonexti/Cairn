Named Pipes

lesson 2.022 of 5 in milestone 25 min1 practice task

Pipes any program can find by name - creating a server instance, waiting for a client to connect, connecting as a client and handling a busy server, byte and message modes, disconnecting, and the rules for pipe names.

A pipe with a name

A named pipe is created by a server under a name such as \\.\pipe\xenon-indexer. Any program on the machine that knows the name can connect as a client. Each connection is a private, two-way channel between the server and that one client.

The server

C++
HANDLE pipe{ CreateNamedPipeW(
    LR"(\\.\pipe\xenon-indexer)",
    PIPE_ACCESS_DUPLEX,                                         // read and write
    PIPE_TYPE_MESSAGE | PIPE_READMODE_MESSAGE | PIPE_WAIT |    // message mode (below)
        PIPE_REJECT_REMOTE_CLIENTS,                             // this machine only
    PIPE_UNLIMITED_INSTANCES,                                   // how many clients at once
    64 * 1024, 64 * 1024,                                       // out and in buffer sizes
    0,                                                          // default client wait timeout
    nullptr) };                                                 // security: lesson 5.05
if (pipe == INVALID_HANDLE_VALUE) /* GetLastError() */;

if (!ConnectNamedPipe(pipe, nullptr) && GetLastError() != ERROR_PIPE_CONNECTED)
    /* failed */;
// a client is connected: ReadFile / WriteFile on `pipe`

CreateNamedPipeW creates one instance: a single connection slot. ConnectNamedPipe waits until a client connects to it. (ERROR_PIPE_CONNECTED means a client connected between the create and the connect call, which is success.) To serve another client at the same time you create another instance (lesson 2.04).

When the conversation ends, DisconnectNamedPipe drops the client and the same instance can ConnectNamedPipe again; or close it.

The client

C++
HANDLE pipe{};
for (;;)
{
    pipe = CreateFileW(LR"(\\.\pipe\xenon-indexer)", GENERIC_READ | GENERIC_WRITE, 0, nullptr, OPEN_EXISTING, 0, nullptr);
    if (pipe != INVALID_HANDLE_VALUE) break;
    if (GetLastError() != ERROR_PIPE_BUSY) /* no server: ERROR_FILE_NOT_FOUND (2) */ return;
    if (!WaitNamedPipeW(LR"(\\.\pipe\xenon-indexer)", 2000)) return;   // every instance busy: wait up to 2 s
}
DWORD mode{ PIPE_READMODE_MESSAGE };
SetNamedPipeHandleState(pipe, &mode, nullptr, nullptr);              // read whole messages too

The client opens the pipe like a file. Two errors matter: ERROR_FILE_NOT_FOUND means no server is running (start it, or report that), and ERROR_PIPE_BUSY means the server exists but every instance is in use, so wait with WaitNamedPipeW and try again. Another client can win the race after the wait, which is why it is a loop.

Byte mode and message mode

  • Byte mode (PIPE_TYPE_BYTE): a stream like an anonymous pipe. Boundaries are lost.
  • Message mode (PIPE_TYPE_MESSAGE with PIPE_READMODE_MESSAGE on the reading side): each WriteFile is one message, and each ReadFile returns at most one message. If your buffer is too small, the read returns what fits and fails with ERROR_MORE_DATA; keep reading to get the rest of the same message.

Message mode is convenient, but it is Windows-only and ties your protocol to pipes. Many programs use byte mode with their own framing (lesson 2.03), which then works unchanged over sockets too.

Names

  • Local pipes are \\.\pipe\ followed by the name. Remote ones are \\server\pipe\name (blocked by PIPE_REJECT_REMOTE_CLIENTS, which you should set unless you need them).
  • The name part may contain any character except \. The whole string can be up to 256 characters. Names are not case-sensitive.
  • Names are global to the machine: two programs, or two users, choosing \\.\pipe\server collide. Make names specific: product, purpose, and usually the user or session (\\.\pipe\xenon-indexer-S-1-5-21-... or a per-user random suffix stored where the client can find it).
  • A name that another program created first can be squatted: your client might connect to an impostor. Lesson 5.05 covers how to guard against it.
