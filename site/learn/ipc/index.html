Processes and Communication

6 milestones30 lessons28 practice tasks30 projects

How separate programs on one Windows machine cooperate: what a process is, starting and supervising them, job objects, standard streams, anonymous and named pipes, message framing, serving many clients, overlapped I/O, shared memory with file mappings, ring buffers and seqlocks, named events, mutexes and semaphores, window messages between programs, deadlocks, local sockets, protocol design and serialisation, and securing it all. It ends with single-instance apps, worker processes, out-of-process plugins and a full client and server. It assumes the C++ course and the first milestones of the Win32 API course.
