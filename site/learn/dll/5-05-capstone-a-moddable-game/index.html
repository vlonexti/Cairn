Courses/DLLs and Modular Programs/Plugins and Hot Reload

Capstone: A Moddable Game

lesson 5.055 of 5 in milestone 55 min

Bring the whole course together in one Visual Studio solution - a small game whose gameplay hot-reloads while it runs, and which loads plugins that add new content through a versioned C interface. This lesson is the plan, the checklist and the order to build it in.

What you build

A small top-down game, "Xenon Builder": the player walks around a field and stacks stones into towers. It has three kinds of module:

XenonBuilder.sln
├── Host/               XenonBuilder.exe: window, loop, input, memory, plugin loader, hot reload
├── Gameplay/           gameplay.dll: rules and movement, hot-reloaded
├── PluginApi/          xenon_plugin.h, xenon.hpp: shared headers only (no code)
└── Plugins/
    ├── Fog/            fog.dll: a new stone type and a console command
    └── Seasons/        seasons.dll: requires Fog; changes stone colours over time

Order to build in

  1. Get the host working with the gameplay code statically linked first: the simplest version that runs.
  2. Move gameplay into a DLL loaded with LoadLibraryW. Fix everything that breaks: globals, ownership, the interface.
  3. Add hot reload. Edit, rebuild, watch it change. This is the part you will enjoy most.
  4. Add the plugin loader with one plugin, then the registry, then the second plugin with its dependency.
  5. Shut down cleanly and ship.

Checklist before you call it finished

  • dumpbin /exports on each DLL shows only plain, intended names.
  • dumpbin /dependents on the Release build shows no debug runtime.
  • Removing fog.dll makes Seasons skip with a clear message, and the game still runs.
  • A DLL that is not a plugin in the plugin folder is skipped, not loaded into the game.
  • Ten hot reloads in a row leave no leaked plugin registrations and no growing memory.
  • Building while the game runs never fails with a locked file (DLL or PDB).
  • A plugin built against an older contract version is refused with a message, not a crash.
