DLLs and Modular Programs

5 milestones28 lessons42 practice tasks25 projects

Everything about dynamic-link libraries in your own software: exporting functions and classes, import libraries, run-time loading, the loader and its search order, DllMain and its rules, designing stable interfaces across versions, plugin systems and hot reloading during development. It assumes the first milestones of the C++ course. You build the real DLLs in Visual Studio; the practice on the site checks the logic behind each idea.
