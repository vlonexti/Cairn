ArrayList and Wrapper Types

lesson 2.033 of 5 in milestone 25 min1 practice task

The growable ArrayList - adding, getting, setting, removing, searching and sorting - the List interface, wrapper classes like Integer and Double, autoboxing and its traps (remove by index or value, == on Integers, null unboxing), List.of, and iterating while removing safely.

ArrayList

An ArrayList is a list that grows and shrinks as needed. The type in angle brackets says what it holds:

Java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>();
        names.add("Grace");
        names.add("Ada");
        names.add(0, "Ken");                 // insert at index 0
        names.set(1, "Linus");               // replace index 1
        System.out.println(names + " " + names.size());
        System.out.println(names.get(0) + " " + names.contains("Ada") + " " + names.indexOf("Ada"));
        names.remove("Ken");                 // by value
        names.remove(0);                     // by index
        Collections.addAll(names, "Barbara", "Margaret");
        Collections.sort(names);
        System.out.println(names);
        System.out.println(names.isEmpty());
    }
}

Declare variables with the interface type List<String> and create an ArrayList<>(): the rest of the code then works with any kind of list. <> (the diamond) lets the compiler fill in the type.

Wrapper types

Collections hold objects, not primitives. Each primitive has a wrapper class: Integer, Double, Boolean, Character, Long... Java converts automatically between them (autoboxing and unboxing):

Java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<Integer> numbers = new ArrayList<>();
        numbers.add(5);                       // int 5 is boxed into an Integer
        numbers.add(10);
        int first = numbers.get(0);           // unboxed back to int
        int total = 0;
        for (int n : numbers) total += n;
        System.out.println(first + " " + total);
        System.out.println(Integer.parseInt("42") + Integer.MAX_VALUE % 10 + " " + Character.isDigit('7'));
    }
}

Three traps to know:

Java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>(List.of(10, 20, 30));
        list.remove(1);                        // removes INDEX 1 (the 20), not the value 1
        list.remove(Integer.valueOf(30));      // removes the VALUE 30
        System.out.println(list);

        Integer a = 1000, b = 1000;
        System.out.println(a == b);            // false: two different Integer objects
        System.out.println(a.equals(b));       // true: compare wrapper values with equals

        Integer missing = null;
        try {
            int n = missing;                   // unboxing null throws NullPointerException
        } catch (NullPointerException e) {
            System.out.println("cannot unbox null");
        }
    }
}

Fixed lists and copies

List.of(1, 2, 3) makes an unmodifiable list: add and set throw UnsupportedOperationException. It is ideal for constants and test data. To get a list you can change, copy it: new ArrayList<>(List.of(1, 2, 3)).

Removing while looping

Removing items inside an enhanced for over the same list throws ConcurrentModificationException. Loop backwards with indexes, or use removeIf:

Java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<Integer> values = new ArrayList<>(List.of(4, 7, 10, 13, 16));
        for (int i = values.size() - 1; i >= 0; i--) {
            if (values.get(i) % 2 == 1) values.remove(i);
        }
        System.out.println(values);
        values.removeIf(v -> v > 12);           // a lambda (lesson 6.01): remove what matches
        System.out.println(values);
    }
}
