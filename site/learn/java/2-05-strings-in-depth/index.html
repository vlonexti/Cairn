Strings in Depth

lesson 2.055 of 5 in milestone 25 min1 practice task

Characters as numbers and the Character class, walking through strings, why repeated concatenation is slow and how StringBuilder fixes it, string comparison and sorting, splitting with regular expressions, a first look at Pattern and Matcher, and converting between strings, chars and numbers.

Characters

A char is a 16-bit number that stands for a character. Arithmetic on chars works on those numbers:

Java
public class Main {
    public static void main(String[] args) {
        char c = 'b';
        System.out.println((int) c);                 // 98
        System.out.println((char) (c + 1));          // c
        System.out.println('7' - '0');               // 7: a digit character to its value
        System.out.println(Character.isLetter(c) + " " + Character.isDigit('7') + " " + Character.isWhitespace(' '));
        System.out.println(Character.toUpperCase(c) + " " + Character.isUpperCase('Q'));
        System.out.println((char) ('a' + 25));       // z
    }
}

c - 'a' gives a letter's position in the alphabet (0 for a), which is the trick behind Caesar ciphers and letter counts.

Walking through a string

Java
public class Main {
    public static void main(String[] args) {
        String text = "Hello, World 2026!";
        int letters = 0, digits = 0, upper = 0;
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (Character.isLetter(ch)) letters++;
            if (Character.isDigit(ch)) digits++;
            if (Character.isUpperCase(ch)) upper++;
        }
        System.out.println(letters + " letters, " + digits + " digits, " + upper + " capitals");

        int[] counts = new int[26];
        for (char ch : text.toLowerCase().toCharArray()) {
            if (ch >= 'a' && ch <= 'z') counts[ch - 'a']++;
        }
        System.out.println("l appears " + counts['l' - 'a'] + " times");
    }
}

StringBuilder

Strings are immutable, so s += x creates a brand-new string and copies everything each time. In a loop that is slow (quadratic). A StringBuilder is a mutable buffer:

Java
public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= 5; i++) {
            sb.append(i);
            if (i < 5) sb.append(", ");
        }
        System.out.println(sb);
        sb.insert(0, "[").append("]");
        sb.reverse();
        System.out.println(sb + " " + sb.length());
        sb.setLength(0);                                 // clear it
        sb.append("caesar").setCharAt(0, 'C');
        System.out.println(sb.toString());
    }
}
Method Does
append(x) Add to the end (returns the builder, so calls chain)
insert(i, x), deleteCharAt(i), delete(a, b) Insert and remove
setCharAt(i, c), reverse() Change in place
length(), charAt(i), toString() Read

Comparing and sorting

compareTo orders strings by character codes: all capitals come before all lower-case letters ("Zoe" before "adam"). For human ordering ignore case:

Java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>(List.of("bob", "Alice", "carol", "Bob"));
        names.sort(null);                                    // natural (code) order
        System.out.println(names);
        names.sort(String.CASE_INSENSITIVE_ORDER);
        System.out.println(names);
        System.out.println("apple".compareTo("apricot") < 0);
    }
}

Regular expressions

split, matches and replaceAll take regular expressions, a small language for text patterns:

Pattern Matches
\\d, \\s, \\w A digit, a white-space character, a word character
[aeiou], [^0-9] One of these / anything but these
+, *, ?, {2,4} One or more, zero or more, optional, 2 to 4 times
^, $ Start, end

In Java source, each backslash is written twice: the regex \d+ is the string "\\d+".

Java
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class Main {
    public static void main(String[] args) {
        System.out.println(String.join("|", "a, b;c  d".split("[,;\\s]+")));
        System.out.println("2026-03-14".matches("\\d{4}-\\d{2}-\\d{2}"));
        System.out.println("call 555-1234 or 555-9876".replaceAll("\\d{3}-\\d{4}", "<number>"));

        Matcher m = Pattern.compile("(\\w+)@(\\w+\\.\\w+)").matcher("ada@math.org, grace@navy.mil");
        while (m.find()) System.out.println(m.group(1) + " at " + m.group(2));
    }
}
