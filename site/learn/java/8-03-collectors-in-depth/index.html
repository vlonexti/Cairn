Collectors in Depth

lesson 8.033 of 5 in milestone 85 min2 practice tasks

Getting the most out of collect - groupingBy with downstream collectors (counting, summing, mapping, averaging, maxBy), choosing the map type, partitioningBy, toMap with merge functions, joining, summarizing statistics, teeing two collectors at once, and writing your own Collector with Collector.of.

Collect is a toolbox

Lesson 6.02 ended streams with toList(), count() and a simple groupingBy. The Collectors class has much more: most "report" questions are one collect call.

The examples use this record:

Java
record Sale(String region, String product, int qty, double price) {
    double value() { return qty * price; }
}

Grouping with a second step

groupingBy(key) alone gives lists. Its second argument, a downstream collector, decides what to do with each group:

Java
import java.util.*;
import java.util.stream.*;

public class Main {
    record Sale(String region, String product, int qty, double price) {
        double value() { return qty * price; }
    }

    public static void main(String[] args) {
        List<Sale> sales = List.of(
                new Sale("North", "tea", 3, 2.5), new Sale("South", "tea", 1, 2.5),
                new Sale("North", "cake", 2, 4.0), new Sale("North", "tea", 4, 2.5),
                new Sale("South", "coffee", 5, 3.0));

        Map<String, Long> count = sales.stream().collect(Collectors.groupingBy(Sale::region, Collectors.counting()));
        Map<String, Integer> qty = sales.stream().collect(Collectors.groupingBy(Sale::product, Collectors.summingInt(Sale::qty)));
        Map<String, Double> avg = sales.stream().collect(Collectors.groupingBy(Sale::region, Collectors.averagingDouble(Sale::value)));
        Map<String, Set<String>> products = sales.stream().collect(
                Collectors.groupingBy(Sale::region, TreeMap::new, Collectors.mapping(Sale::product, Collectors.toCollection(TreeSet::new))));
        Map<String, Optional<Sale>> biggest = sales.stream().collect(
                Collectors.groupingBy(Sale::region, Collectors.maxBy(Comparator.comparingDouble(Sale::value))));

        System.out.println(new TreeMap<>(count));
        System.out.println(new TreeMap<>(qty));
        System.out.println(new TreeMap<>(avg));
        System.out.println(products);
        System.out.println(biggest.get("North").map(Sale::value).orElse(0.0));
    }
}
  • The middle argument (TreeMap::new) picks the map type; a TreeMap gives sorted keys.
  • mapping(fn, downstream) transforms each item before collecting it.
  • Downstream collectors nest: groupingBy(region, groupingBy(product, counting())) gives a two-level map.

Two groups: partitioningBy

Java
import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        Map<Boolean, List<Integer>> evenOdd = IntStream.rangeClosed(1, 10).boxed()
                .collect(Collectors.partitioningBy(n -> n % 2 == 0));
        System.out.println(evenOdd.get(true) + " " + evenOdd.get(false));
        Map<Boolean, Long> passed = Stream.of(91, 48, 77, 50, 12).collect(Collectors.partitioningBy(s -> s >= 50, Collectors.counting()));
        System.out.println(passed);
    }
}

The map always has both true and false keys, even when one group is empty.

toMap and duplicate keys

toMap(keyFn, valueFn) throws IllegalStateException if two items have the same key. A third argument, the merge function, says how to combine them:

Java
import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<String> words = List.of("apple", "avocado", "banana", "blueberry", "cherry");
        Map<Character, String> longestByLetter = words.stream().collect(Collectors.toMap(
                w -> w.charAt(0),
                w -> w,
                (a, b) -> a.length() >= b.length() ? a : b,
                TreeMap::new));
        System.out.println(longestByLetter);

        Map<String, Integer> lengths = words.stream().collect(Collectors.toMap(w -> w, String::length));
        System.out.println(lengths.get("cherry"));
    }
}

Joining and statistics

Java
import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        System.out.println(Stream.of("tea", "cake", "milk").collect(Collectors.joining(", ", "[", "]")));
        IntSummaryStatistics s = Stream.of(4, 8, 15, 16, 23, 42).collect(Collectors.summarizingInt(n -> n));
        System.out.println(s.getMin() + " " + s.getMax() + " " + s.getAverage() + " " + s.getSum() + " " + s.getCount());
    }
}

Two results in one pass: teeing

teeing(c1, c2, combine) sends every item to two collectors and combines their results:

Java
import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        String range = Stream.of(4, 8, 15, 16, 23, 42).collect(Collectors.teeing(
                Collectors.minBy(Integer::compare),
                Collectors.maxBy(Integer::compare),
                (min, max) -> min.get() + ".." + max.get()));
        System.out.println(range);
    }
}

Your own collector

Collector.of(supplier, accumulator, combiner, finisher) builds one from four functions: make an empty container, add one item, merge two containers (for parallel streams), and turn the container into the result.

Java
import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        // collects into the top 3 values, largest first
        Collector<Integer, PriorityQueue<Integer>, List<Integer>> top3 = Collector.of(
                PriorityQueue::new,
                (q, x) -> { q.add(x); if (q.size() > 3) q.poll(); },
                (a, b) -> { b.forEach(x -> { a.add(x); if (a.size() > 3) a.poll(); }); return a; },
                q -> q.stream().sorted(Comparator.reverseOrder()).toList());
        System.out.println(Stream.of(5, 1, 9, 3, 7, 8).collect(top3));
    }
}
