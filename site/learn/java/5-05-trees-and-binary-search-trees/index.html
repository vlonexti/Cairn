Trees and Binary Search Trees

lesson 5.055 of 5 in milestone 55 min1 practice task

Trees and their vocabulary, binary trees, the binary search tree property, recursive insert, search and delete including the two-child case, in-order, pre-order, post-order and level-order traversal, height and balance, why balanced trees like Java's TreeMap guarantee O(log n), and heaps for priority queues.

Trees

A tree is made of nodes connected by edges, with one root at the top. Each node has zero or more children; nodes without children are leaves. The height of a tree is the number of edges on the longest path from the root to a leaf. File systems, HTML pages, organisation charts and parsed expressions (practice 3.05) are trees.

In a binary tree every node has at most two children, left and right.

Binary search trees

A binary search tree (BST) keeps this property at every node: everything in the left subtree is smaller, and everything in the right subtree is larger. Searching follows one path down, discarding half the tree at each step when the tree is balanced:

  A --> C((70))

Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Bst tree = new Bst();
        for (int x : new int[] {50, 30, 70, 20, 40, 60, 80, 30}) tree.insert(x);
        System.out.println(tree.inOrder() + " size " + tree.size() + " height " + tree.height());
        System.out.println(tree.contains(60) + " " + tree.contains(65) + " min " + tree.min());
        tree.delete(30);                                   // a node with two children
        tree.delete(80);                                   // a leaf
        System.out.println(tree.inOrder() + " " + tree.preOrder() + " " + tree.levelOrder());
    }
}

class Bst {
    private static class Node {
        int key;
        Node left, right;
        Node(int key) { this.key = key; }
    }

    private Node root;
    private int size;

    void insert(int key) { root = insert(root, key); }

    private Node insert(Node n, int key) {
        if (n == null) { size++; return new Node(key); }
        if (key < n.key) n.left = insert(n.left, key);
        else if (key > n.key) n.right = insert(n.right, key);
        return n;                                          // duplicates are ignored
    }

    boolean contains(int key) {
        Node n = root;
        while (n != null) {
            if (key == n.key) return true;
            n = key < n.key ? n.left : n.right;
        }
        return false;
    }

    int min() {
        if (root == null) throw new NoSuchElementException();
        Node n = root;
        while (n.left != null) n = n.left;
        return n.key;
    }

    void delete(int key) { root = delete(root, key); }

    private Node delete(Node n, int key) {
        if (n == null) return null;
        if (key < n.key) n.left = delete(n.left, key);
        else if (key > n.key) n.right = delete(n.right, key);
        else {
            if (n.left == null) { size--; return n.right; }       // zero or one child: replace by the child
            if (n.right == null) { size--; return n.left; }
            Node successor = n.right;                             // two children: take the smallest key on the right
            while (successor.left != null) successor = successor.left;
            n.key = successor.key;
            n.right = delete(n.right, successor.key);
        }
        return n;
    }

    int size() { return size; }

    int height() { return height(root); }
    private int height(Node n) { return n == null ? -1 : 1 + Math.max(height(n.left), height(n.right)); }

    List<Integer> inOrder() { List<Integer> out = new ArrayList<>(); inOrder(root, out); return out; }
    private void inOrder(Node n, List<Integer> out) {
        if (n == null) return;
        inOrder(n.left, out); out.add(n.key); inOrder(n.right, out);       // left, node, right: sorted
    }

    List<Integer> preOrder() { List<Integer> out = new ArrayList<>(); preOrder(root, out); return out; }
    private void preOrder(Node n, List<Integer> out) {
        if (n == null) return;
        out.add(n.key); preOrder(n.left, out); preOrder(n.right, out);     // node first: copies the shape
    }

    List<Integer> levelOrder() {                                           // breadth first, with a queue
        List<Integer> out = new ArrayList<>();
        Deque<Node> queue = new ArrayDeque<>();
        if (root != null) queue.add(root);
        while (!queue.isEmpty()) {
            Node n = queue.poll();
            out.add(n.key);
            if (n.left != null) queue.add(n.left);
            if (n.right != null) queue.add(n.right);
        }
        return out;
    }
}

Recursive methods that return the (possibly new) subtree, like insert and delete, avoid special cases for the root: root = insert(root, key).

Deleting

Deleting has three cases:

  1. a leaf: just remove it;
  2. a node with one child: replace it by that child;
  3. a node with two children: copy in its in-order successor (the smallest key in its right subtree), then delete the successor from the right subtree, which has at most one child.

Traversals

Order Visits Typical use
In-order left, node, right A BST's keys in sorted order
Pre-order node, left, right Copying or printing the tree's structure
Post-order left, right, node Deleting a tree, evaluating an expression tree
Level-order level by level, with a queue Shortest paths in unweighted trees, printing by depth

Balance

A BST's operations take time proportional to its height. Random insertions give a height of about 2 log n, but inserting keys in sorted order makes every node a right child: the "tree" becomes a linked list and everything is O(n).

Self-balancing trees fix this by restructuring (rotating) nodes during insertions and deletions so the height stays O(log n). Java's TreeMap and TreeSet are red-black trees: their get, put and remove are O(log n) guaranteed, and they iterate in sorted order.

Heaps

A binary heap is a different tree property: every parent is smaller than (or equal to) its children, so the minimum is always at the root. It is stored compactly in an array (the children of index i are 2i + 1 and 2i + 2), and both adding and removing the minimum are O(log n). Java's PriorityQueue is a binary heap; heap sort and Dijkstra's shortest-path algorithm are built on one.
