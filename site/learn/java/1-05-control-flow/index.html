Control Flow

lesson 1.055 of 5 in milestone 15 min1 practice task

Making decisions with if and else, the classic switch statement and the modern switch expression with arrows, loops with while, do-while, for and the enhanced for, break and continue, labelled breaks for nested loops, and input loops with a sentinel.

if and else

Java
public class Main {
    public static void main(String[] args) {
        int temperature = 23;
        if (temperature >= 30) {
            System.out.println("Hot");
        } else if (temperature >= 18) {
            System.out.println("Pleasant");
        } else {
            System.out.println("Cold");
        }
    }
}

Always use braces, even for one statement: without them, only the first line belongs to the if, however it is indented.

switch

The modern switch expression (Java 14+) uses arrows, needs no break, and produces a value:

Java
public class Main {
    public static void main(String[] args) {
        int day = 6;
        String kind = switch (day) {
            case 6, 7 -> "weekend";
            case 1, 2, 3, 4, 5 -> "weekday";
            default -> "not a day";
        };
        System.out.println(kind);

        String command = "stop";
        switch (command) {
            case "go", "start" -> System.out.println("Starting");
            case "stop" -> System.out.println("Stopping");
            default -> System.out.println("Unknown command");
        }
    }
}

You will also meet the classic form with colons. There, each case falls through into the next unless it ends with break, a frequent source of bugs:

Java
switch (command) {
    case "go":
        System.out.println("Starting");
        break;                         // without this, "Stopping" would print too
    case "stop":
        System.out.println("Stopping");
        break;
    default:
        System.out.println("Unknown");
}

Prefer the arrow form in new code.

while and do-while

Java
public class Main {
    public static void main(String[] args) {
        int n = 27, steps = 0;
        while (n != 1) {
            n = (n % 2 == 0) ? n / 2 : 3 * n + 1;
            steps++;
        }
        System.out.println(steps + " steps");

        int tries = 0;
        do {
            tries++;                   // runs at least once
        } while (tries < 3);
        System.out.println(tries);
    }
}

for loops

Java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.print(i + " ");
        }
        System.out.println();

        String[] names = {"Ada", "Grace", "Linus"};
        for (String name : names) {                     // the enhanced for: every item
            System.out.println(name.toUpperCase());
        }

        for (int row = 1; row <= 3; row++) {            // nested loops: a times table
            for (int col = 1; col <= 4; col++) {
                System.out.printf("%4d", row * col);
            }
            System.out.println();
        }
    }
}

Use the classic for when you need the index or count; the enhanced for (for (Type x : collection)) when you just need every item.

break and continue

Java
public class Main {
    public static void main(String[] args) {
        int[] numbers = {4, 7, -1, 12, 0, 9};
        int sum = 0;
        for (int x : numbers) {
            if (x < 0) continue;     // skip this one
            if (x == 0) break;       // stop the loop
            sum += x;
        }
        System.out.println(sum);     // 23

        outer:
        for (int i = 0; i < 5; i++) {
            for (int j = 0; j < 5; j++) {
                if (i * j == 6) {
                    System.out.println("found " + i + " x " + j);
                    break outer;     // leaves both loops
                }
            }
        }
    }
}

Input loops

A common pattern reads until a special sentinel value or the end of input:

Java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int total = 0;
        while (in.hasNextLine()) {
            String line = in.nextLine().trim();
            if (line.equals("done")) break;
            try {
                total += Integer.parseInt(line);
            } catch (NumberFormatException e) {
                System.out.println("Not a number: " + line);
            }
        }
        System.out.println("Total: " + total);
    }
}

try/catch handles text that is not a number; exceptions are covered fully in lesson 4.04.
