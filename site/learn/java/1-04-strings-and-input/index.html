Strings and Input

lesson 1.044 of 5 in milestone 15 min1 practice task

Working with String - its common methods, immutability, comparing with equals instead of ==, escapes and text blocks, formatting with printf and String.format - and reading keyboard input with Scanner, including the nextInt/nextLine trap.

Strings

A String is a sequence of characters. Strings are immutable: methods return new strings and never change the original.

Java
public class Main {
    public static void main(String[] args) {
        String s = "  Ada Lovelace  ";
        String t = s.trim();
        System.out.println("[" + t + "] " + t.length());
        System.out.println(t.toUpperCase() + " " + t.toLowerCase());
        System.out.println(t.charAt(0) + " " + t.charAt(t.length() - 1));
        System.out.println(t.substring(4) + "|" + t.substring(0, 3));       // from 4 / from 0 up to 3
        System.out.println(t.indexOf("Love") + " " + t.indexOf('z'));        // position, or -1
        System.out.println(t.contains("Love") + " " + t.startsWith("Ada") + " " + t.endsWith("x"));
        System.out.println(t.replace("Ada", "Augusta"));
        System.out.println(String.join("-", t.split(" ")));
        System.out.println("ha".repeat(3) + " " + "".isEmpty() + " " + "  ".isBlank());
    }
}
Method Gives
length(), charAt(i) Number of characters, the character at index i (from 0)
substring(start), substring(start, end) Part of the string (end excluded)
indexOf(x), lastIndexOf(x) Position, or -1
toUpperCase(), toLowerCase(), trim(), strip() New strings
contains, startsWith, endsWith, isEmpty, isBlank Tests
replace(a, b), split(regex), String.join(sep, parts) Change, split, join
equals, equalsIgnoreCase, compareTo Comparisons

equals, not ==

== on objects asks "is this the same object?". Two strings with the same text can be different objects, so always compare text with equals:

Java
public class Main {
    public static void main(String[] args) {
        String a = "hello";
        String b = new String("hello");
        System.out.println(a == b);              // false: different objects
        System.out.println(a.equals(b));         // true: same text
        System.out.println("Hello".equalsIgnoreCase(a));
        System.out.println("apple".compareTo("banana") < 0);   // alphabetical order
    }
}

"hello" == "hello" sometimes happens to be true (Java reuses identical literals), which makes the bug hard to notice. Use equals every time.

Escapes and text blocks

Java
public class Main {
    public static void main(String[] args) {
        System.out.println("Tab:\tQuote:\" Backslash:\\ Newline:\nnext line");
        String json = """
            {
              "name": "Ada",
              "langs": ["Java", "C"]
            }
            """;                                   // a text block (Java 15+): no escaping needed
        System.out.print(json);
    }
}

Formatting

printf and String.format use format specifiers:

Java
public class Main {
    public static void main(String[] args) {
        String name = "Tea";
        double price = 2.5;
        int qty = 3;
        System.out.printf("%s x%d = %.2f%n", name, qty, price * qty);   // %n: a new line
        System.out.printf("[%-10s][%8.2f][%05d]%n", name, price, 42);   // left-aligned, width 8, zero-padded
        String line = String.format("%,d people", 1234567);
        System.out.println(line);
        System.out.println("%s is %d".formatted("Ada", 36));
    }
}
Specifier For
%s Any value as text
%d Whole numbers
%.2f Decimals with 2 places
%10s, %-10s Right / left aligned in 10 characters
%05d, %,d Zero-padded, thousands separators
%n A line break

Reading input with Scanner

Java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        System.out.print("What is your name? ");
        String name = in.nextLine();
        System.out.print("Your age? ");
        int age = in.nextInt();
        System.out.println("Hello, " + name + "! Next year you will be " + (age + 1) + ".");
    }
}

import java.util.Scanner; at the top of the file makes the Scanner class available. nextLine() reads a whole line, nextInt() and nextDouble() read the next number, and hasNextInt() / hasNextLine() check what comes next.

The classic trap: nextInt() reads the number but leaves the line break after it. A nextLine() right after returns that empty rest of the line. Either call an extra nextLine() after the number, or read every line with nextLine() and convert it with Integer.parseInt(line.trim()), which is what this course does.
