Stacks, Queues and Hash Tables

lesson 5.044 of 5 in milestone 55 min1 practice task

Implementing a growable array list with amortised O(1) appends, a stack and its uses (undo, bracket matching, expression evaluation), a circular-buffer queue, and a hash table with chaining - hash functions, buckets, load factor and resizing - and why equals and hashCode matter.

A growable array

ArrayList is an array with spare room. When the array is full, it allocates a bigger one (typically 1.5 or 2 times bigger) and copies everything:

Java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        IntList list = new IntList();
        for (int i = 0; i < 20; i++) list.add(i * i);
        System.out.println(list.size() + " " + list.get(19) + " capacity " + list.capacity());
    }
}

class IntList {
    private int[] data = new int[4];
    private int size;

    void add(int value) {
        if (size == data.length) data = Arrays.copyOf(data, data.length * 2);   // grow: O(n), but rarely
        data[size++] = value;
    }

    int get(int i) {
        if (i < 0 || i >= size) throw new IndexOutOfBoundsException(i);
        return data[i];
    }

    int size() { return size; }
    int capacity() { return data.length; }
}

Because the capacity doubles, adding n items copies at most 1 + 2 + 4 + ... + n < 2n items in total: amortised O(1) per add.

Stacks

A stack is last in, first out: push on top, pop from the top, peek at the top, all O(1). Stacks undo actions, track nested structure, and evaluate expressions:

Java
import java.util.ArrayDeque;
import java.util.Deque;

public class Main {
    public static void main(String[] args) {
        System.out.println(evalPostfix("3 4 + 2 *"));          // (3 + 4) * 2
        System.out.println(evalPostfix("5 1 2 + 4 * + 3 -"));  // 5 + (1 + 2) * 4 - 3
    }

    static int evalPostfix(String expr) {
        Deque<Integer> stack = new ArrayDeque<>();
        for (String tok : expr.split(" ")) {
            switch (tok) {
                case "+", "-", "*", "/" -> {
                    int b = stack.pop(), a = stack.pop();       // note the order
                    stack.push(switch (tok) {
                        case "+" -> a + b;
                        case "-" -> a - b;
                        case "*" -> a * b;
                        default -> a / b;
                    });
                }
                default -> stack.push(Integer.parseInt(tok));
            }
        }
        return stack.pop();
    }
}

The method-call stack itself (lesson 2.04) is the same idea: each call is pushed, and returning pops it.

Queues

A queue is first in, first out: offer at the back, poll from the front. A circular buffer implements it in an array without shifting: front and back indexes move forward and wrap around.

Java
public class Main {
    public static void main(String[] args) {
        RingQueue q = new RingQueue(3);
        q.offer(1); q.offer(2); q.offer(3);
        System.out.println(q.poll() + " " + q.poll());
        q.offer(4); q.offer(5);                       // wraps around the end of the array
        StringBuilder out = new StringBuilder();
        while (!q.isEmpty()) out.append(q.poll()).append(' ');
        System.out.println(out);
    }
}

class RingQueue {
    private final int[] data;
    private int front, size;

    RingQueue(int capacity) { data = new int[capacity]; }

    boolean offer(int x) {
        if (size == data.length) return false;        // full
        data[(front + size) % data.length] = x;
        size++;
        return true;
    }

    int poll() {
        if (size == 0) throw new IllegalStateException("empty");
        int x = data[front];
        front = (front + 1) % data.length;
        size--;
        return x;
    }

    boolean isEmpty() { return size == 0; }
}

Queues schedule work fairly (print jobs, requests, breadth-first search in graphs).

Hash tables

A hash table finds a key in O(1) on average. A hash function turns the key into a number; that number modulo the array length chooses a bucket. Different keys can land in the same bucket (a collision); with chaining, each bucket holds a small list of entries.

Java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        HashTable<String, Integer> ages = new HashTable<>();
        ages.put("Ada", 36);
        ages.put("Grace", 85);
        ages.put("Ada", 37);
        for (int i = 0; i < 50; i++) ages.put("user" + i, i);
        System.out.println(ages.get("Ada") + " " + ages.get("Bob") + " size " + ages.size() + " buckets " + ages.buckets());
    }
}

class HashTable<K, V> {
    private record Entry<K, V>(K key, V value) { }

    private List<LinkedList<Entry<K, V>>> table = newTable(8);
    private int size;

    private static <K, V> List<LinkedList<Entry<K, V>>> newTable(int n) {
        List<LinkedList<Entry<K, V>>> t = new ArrayList<>(n);
        for (int i = 0; i < n; i++) t.add(new LinkedList<>());
        return t;
    }

    private int indexFor(K key, int buckets) {
        return Math.floorMod(key.hashCode(), buckets);     // hashCode may be negative
    }

    V get(K key) {
        for (Entry<K, V> e : table.get(indexFor(key, table.size()))) {
            if (e.key().equals(key)) return e.value();
        }
        return null;
    }

    void put(K key, V value) {
        LinkedList<Entry<K, V>> bucket = table.get(indexFor(key, table.size()));
        for (var it = bucket.listIterator(); it.hasNext(); ) {
            if (it.next().key().equals(key)) { it.set(new Entry<>(key, value)); return; }   // replace
        }
        bucket.add(new Entry<>(key, value));
        size++;
        if (size > table.size() * 3 / 4) resize();           // load factor 0.75
    }

    private void resize() {
        List<LinkedList<Entry<K, V>>> bigger = newTable(table.size() * 2);
        for (LinkedList<Entry<K, V>> bucket : table)
            for (Entry<K, V> e : bucket)
                bigger.get(indexFor(e.key(), bigger.size())).add(e);
        table = bigger;
    }

    int size() { return size; }
    int buckets() { return table.size(); }
}
  • The load factor is entries ÷ buckets. Keeping it below about 0.75 (by doubling and re-inserting everything) keeps buckets short, so get and put stay O(1) on average.
  • A poor hash function that sends many keys to the same bucket turns the table into a linked list: O(n). Java's HashMap even turns long buckets into small trees to limit the damage.
  • This is why keys must have consistent equals and hashCode (lesson 4.02): hashCode picks the bucket, equals finds the entry inside it.
