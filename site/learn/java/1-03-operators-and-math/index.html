Operators and Math

lesson 1.033 of 5 in milestone 15 min1 practice task

Arithmetic with integer division and remainder, compound assignment and increment, comparison and logical operators with short-circuiting, the ternary operator, precedence, the Math class, and comparing doubles safely.

Arithmetic

Java
public class Main {
    public static void main(String[] args) {
        int a = 17, b = 5;
        System.out.println(a + b);       // 22
        System.out.println(a - b);       // 12
        System.out.println(a * b);       // 85
        System.out.println(a / b);       // 3: int / int is integer division
        System.out.println(a % b);       // 2: the remainder
        System.out.println(a / 5.0);     // 3.4: a double operand makes it a double division
        System.out.println((double) a / b);
        System.out.println(-17 / 5);     // -3: rounds toward zero
        System.out.println(-17 % 5);     // -2: the sign follows the left side
        System.out.println(Math.floorMod(-17, 5));   // 3: always 0 to 4
    }
}

minutes / 60 and minutes % 60 split minutes into hours and the rest. n % 2 == 0 tests for even numbers. Integer division by zero throws ArithmeticException; double division by zero gives Infinity or NaN.

Watch out for + with strings: once a String is involved, + joins text. "Total: " + 2 + 3 is "Total: 23"; write "Total: " + (2 + 3).

Assignment shortcuts

Java
public class Main {
    public static void main(String[] args) {
        int score = 10;
        score += 5;      // 15
        score *= 2;      // 30
        score -= 1;      // 29
        score++;         // 30
        score--;         // 29
        System.out.println(score);
        int i = 5;
        System.out.println(i++);   // prints 5, then i becomes 6
        System.out.println(++i);   // i becomes 7, then prints 7
    }
}

Comparisons and logic

Operator Meaning
==, != Equal, not equal (for primitives)
<, <=, >, >= Ordering
&& And (short-circuit)
|| Or (short-circuit)
! Not
Java
public class Main {
    public static void main(String[] args) {
        int age = 20;
        boolean hasTicket = true;
        boolean canEnter = age >= 18 && hasTicket;
        boolean discount = age < 12 || age >= 65;
        System.out.println(canEnter + " " + discount + " " + !canEnter);

        String name = null;
        if (name != null && name.length() > 3) System.out.println("long name");   // safe: && stops early
        System.out.println(age >= 18 ? "adult" : "minor");                         // the ternary operator
    }
}

&& and || short-circuit: the right side is only evaluated when needed, which makes the null check above safe. Conditions must be boolean: if (count) does not compile in Java.

For objects, == compares references (is it the same object?), not contents. Strings are compared with equals (lesson 1.04).

Precedence

*, /, % before +, -; then comparisons; then &&; then ||; then ?:; then assignment. Use parentheses when in doubt.

Math

Java
public class Main {
    public static void main(String[] args) {
        System.out.println(Math.sqrt(16));          // 4.0
        System.out.println(Math.pow(2, 10));        // 1024.0
        System.out.println(Math.abs(-3.5));         // 3.5
        System.out.println(Math.max(3, 9));         // 9
        System.out.println(Math.round(2.5));        // 3: rounds halves up, returns long
        System.out.println(Math.round(-2.5));       // -2
        System.out.println(Math.floor(-2.5) + " " + Math.ceil(2.1));   // -3.0 3.0
        System.out.println(Math.clamp(15, 0, 10));  // 10 (Java 21+)
        System.out.println(Math.PI);
        System.out.println((int) (Math.random() * 6) + 1 > 0);         // a dice roll 1-6
    }
}

Comparing doubles

Because of rounding, 0.1 + 0.2 == 0.3 is false. Compare floating-point numbers with a tolerance:

Java
public class Main {
    public static void main(String[] args) {
        double x = 0.1 + 0.2;
        System.out.println(x == 0.3);                      // false
        System.out.println(Math.abs(x - 0.3) < 1e-9);      // true
    }
}
