Formatting, Locales and Text

lesson 8.055 of 5 in milestone 85 min2 practice tasks

Turning values into text people can read - format specifiers in String.format and formatted, padding and alignment, NumberFormat and DecimalFormat, Locale and why numbers and dates look different around the world, text blocks, Unicode code points and characters outside the basic plane, and comparing text for people with Collator.

Format strings

String.format (and the method form "...".formatted(...)) build text from a pattern of format specifiers:

Java
public class Main {
    public static void main(String[] args) {
        System.out.println(String.format("%s scored %d (%.1f%%)", "Ada", 91, 91.25));
        System.out.println("|%8s|%-8s|%08.3f|".formatted("right", "left", 3.14159));
        System.out.println("%,d bytes".formatted(1234567));
        System.out.println("%x %X %o %e".formatted(255, 255, 8, 12345.678));
        System.out.println("%b %c %n".formatted(true, 'Z').trim());
    }
}
specifier meaning
%s, %d, %f, %c, %b text, whole number, decimal, character, boolean
%x, %e hexadecimal, scientific notation
%8s, %-8s width 8, right- or left-aligned
%.2f, %08.3f 2 decimals; width 8 with leading zeros
%,d thousands separators
%%, %n a literal %, the system's new line

Locale

People in different countries write numbers and dates differently. A Locale names a language and region, and formatting uses it:

Java
import java.text.NumberFormat;
import java.util.Locale;

public class Main {
    public static void main(String[] args) {
        double amount = 1234567.891;
        for (Locale l : new Locale[] { Locale.UK, Locale.GERMANY, Locale.FRANCE, Locale.of("en", "IN") }) {
            System.out.println(l + ": " + String.format(l, "%,.2f", amount)
                    + "  " + NumberFormat.getCurrencyInstance(l).format(amount)
                    + "  " + NumberFormat.getPercentInstance(l).format(0.256));
        }
    }
}

String.format without a locale uses the computer's default locale, which may differ between your machine and a server. For text meant for people, pass their locale. For text meant for programs (files, logs, network messages), use Locale.ROOT, so the format never changes:

Java
import java.util.Locale;

public class Main {
    public static void main(String[] args) {
        String forAFile = String.format(Locale.ROOT, "%.2f", 3.5);
        System.out.println(forAFile + " " + Double.parseDouble(forAFile));
    }
}

DecimalFormat: patterns for numbers

Java
import java.math.RoundingMode;
import java.text.*;
import java.util.Locale;

public class Main {
    public static void main(String[] args) {
        DecimalFormat money = new DecimalFormat("#,##0.00", DecimalFormatSymbols.getInstance(Locale.UK));
        System.out.println(money.format(1234.5) + " " + money.format(0.5));
        DecimalFormat compact = new DecimalFormat("0.##");
        compact.setRoundingMode(RoundingMode.HALF_UP);
        System.out.println(compact.format(2.0) + " " + compact.format(2.345));
        System.out.println(NumberFormat.getCompactNumberInstance(Locale.US, NumberFormat.Style.SHORT).format(1_250_000));
    }
}

0 is a digit that is always shown, # a digit shown only if needed, , a grouping separator.

Text blocks

Multi-line text (JSON, SQL, HTML) is easiest with a text block. Indentation common to all lines is removed, and quotes need no escaping:

Java
public class Main {
    public static void main(String[] args) {
        String json = """
                {
                  "name": "%s",
                  "level": %d
                }
                """.formatted("Ada", 3);
        System.out.print(json);
        String oneLine = """
                a long sentence that \
                continues here""";
        System.out.println(oneLine);
    }
}

A \ at the end of a line joins it with the next.

Characters and code points

A Java char is a 16-bit UTF-16 unit. Most characters fit in one, but emoji and some rare scripts need two (a surrogate pair), so length() counts units, not characters:

Java
public class Main {
    public static void main(String[] args) {
        String s = "café 😀";
        System.out.println(s.length() + " units, " + s.codePointCount(0, s.length()) + " characters");
        s.codePoints().forEach(cp -> System.out.print(Character.charCount(cp) + " "));   // 1 1 1 1 1 2: the emoji takes two units
        System.out.println();
        String reversed = new StringBuilder(s).reverse().toString();
        System.out.println(reversed.codePointCount(0, reversed.length()));   // StringBuilder keeps pairs together
        System.out.println(Character.isLetter('é') + " " + Character.isDigit('٣') + " " + Character.toUpperCase('ß'));
    }
}

Loop with codePoints() instead of charAt when text may contain any character.

Comparing for people

compareTo compares character codes, so "Zoe" comes before "anna" and "Émile" after everything. A Collator sorts the way a dictionary in a given language does:

Java
import java.text.Collator;
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>(List.of("Zoe", "anna", "Émile", "Eve", "bob"));
        Collections.sort(names);
        System.out.println(names);
        names.sort(Collator.getInstance(Locale.FRANCE));
        System.out.println(names);
        System.out.println("STRASSE".equalsIgnoreCase("straße"));       // false: simple case rules only
    }
}

Use plain comparison for identifiers and keys, and a Collator for lists people read.
