Variables and Primitive Types

lesson 1.022 of 5 in milestone 15 min1 practice task

Declaring and assigning variables, the eight primitive types and their ranges, literals, var, constants with final, primitive versus reference types, widening and narrowing conversions with casts, integer overflow, and naming conventions.

Variables

A variable is a named place that holds a value of one type, fixed when it is declared:

Java
public class Main {
    public static void main(String[] args) {
        int count = 3;
        double price = 2.50;
        boolean done = false;
        char grade = 'A';                 // one character, in single quotes
        String name = "Ada";              // text, in double quotes (a class, not a primitive)

        count = count + 1;                // fine: still an int
        // count = "four";                // error: incompatible types: String cannot be converted to int

        var total = count * price;        // var: the compiler infers double
        final int MAX_PLAYERS = 4;        // final: cannot be assigned again
        System.out.println(name + ": " + count + " x " + price + " = " + total + ", max " + MAX_PLAYERS + ", " + grade + " " + done);
    }
}

A local variable must be assigned before it is read; reading an unassigned one is a compile error ("variable might not have been initialized").

The primitive types

Type Size Range / precision Literal
byte 8 bits -128 to 127 (byte) 10
short 16 bits -32 768 to 32 767 (short) 10
int 32 bits about ±2.1 billion 42, 1_000_000, 0xFF
long 64 bits about ±9.2 × 10¹⁸ 42L
float 32 bits about 7 digits 3.14f
double 64 bits about 15 digits 3.14, 1e-9
char 16 bits one UTF-16 character 'a', '\n'
boolean true or false true

Use int for whole numbers, long when they may exceed two billion (milliseconds, file sizes, populations), double for measurements, and boolean for yes/no. For money, use long cents or java.math.BigDecimal: double cannot store 0.1 exactly.

Java
public class Main {
    public static void main(String[] args) {
        System.out.println(0.1 + 0.2);              // 0.30000000000000004
        System.out.println(Integer.MAX_VALUE);
        int big = Integer.MAX_VALUE;
        big = big + 1;                               // overflows silently
        System.out.println(big);                     // -2147483648
        System.out.println(Math.addExact(5, 6));     // throws ArithmeticException on overflow instead
        long population = 8_100_000_000L;            // too big for int: needs long and the L suffix
        System.out.println(population);
    }
}

Primitive and reference types

The eight primitives hold their value directly. Every other type (String, arrays, your own classes) is a reference type: the variable holds a reference to an object. Assigning a reference copies the reference, so both variables see the same object:

Java
public class Main {
    public static void main(String[] args) {
        int a = 1;
        int b = a;          // a copy of the value
        b = 2;
        System.out.println(a);               // 1

        int[] x = {1, 2, 3};
        int[] y = x;        // the same array
        y[0] = 99;
        System.out.println(x[0]);            // 99
    }
}

A reference variable can also be null: no object at all. Using it then throws a NullPointerException.

Conversions

Converting to a wider type is automatic (no information can be lost); converting to a narrower type needs a cast and may lose information:

Java
public class Main {
    public static void main(String[] args) {
        int i = 42;
        long l = i;               // widening: automatic
        double d = i;             // widening: automatic
        int back = (int) 3.99;    // narrowing: cast, cuts off to 3
        byte small = (byte) 300;  // wraps around: 44
        char c = (char) ('a' + 1);
        int code = 'A';           // a char is a number: 65
        System.out.println(l + " " + d + " " + back + " " + small + " " + c + " " + code);
        System.out.println(Integer.parseInt("123") + 1);       // text to number
        System.out.println(Double.parseDouble("2.5") * 2);
        System.out.println(String.valueOf(42) + "!");          // number to text
    }
}

Names

Java naming conventions: camelCase for variables and methods (totalPrice), PascalCase for classes (ShoppingCart), and UPPER_SNAKE_CASE for constants (MAX_PLAYERS). Choose names that say what a value means: secondsElapsed, not s.
