The Collections Framework

lesson 4.022 of 5 in milestone 45 min1 practice task

The interfaces and implementations of java.util - List, Set, Map, Queue and Deque with ArrayList, LinkedList, HashSet, LinkedHashSet, TreeSet, HashMap, LinkedHashMap, TreeMap, ArrayDeque and PriorityQueue - choosing between them, iterating, counting and grouping with maps, the equals and hashCode contract, and immutable collections.

The big picture

flowchart TD
  C[Collection] --> L[List: ordered, by index]
  C --> S[Set: no duplicates]
  C --> Q[Queue / Deque: ends]
  L --> AL[ArrayList]
  L --> LL[LinkedList]
  S --> HS[HashSet]
  S --> LHS[LinkedHashSet]
  S --> TS[TreeSet: sorted]
  Q --> AD[ArrayDeque]
  Q --> PQ[PriorityQueue]
  M[Map: key to value] --> HM[HashMap]
  M --> LHM[LinkedHashMap]
  M --> TM[TreeMap: sorted keys]

Program to the interface (List, Set, Map) and pick the implementation for its performance and ordering.

Need Use
A sequence, access by index ArrayList
Unique items, fast contains HashSet (no order), LinkedHashSet (insertion order), TreeSet (sorted)
Look up by key HashMap (no order), LinkedHashMap (insertion order), TreeMap (sorted keys)
A stack or a queue ArrayDeque
Always take the smallest (or largest) next PriorityQueue

LinkedList is rarely the right choice: ArrayList and ArrayDeque are faster for almost everything.

Sets

Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> words = List.of("pear", "apple", "pear", "fig", "apple");
        System.out.println(new HashSet<>(words));          // some order
        System.out.println(new LinkedHashSet<>(words));    // first-seen order
        System.out.println(new TreeSet<>(words));          // sorted

        Set<Integer> a = new TreeSet<>(Set.of(1, 2, 3, 4));
        Set<Integer> b = Set.of(3, 4, 5);
        Set<Integer> both = new TreeSet<>(a);
        both.retainAll(b);                                 // intersection
        Set<Integer> either = new TreeSet<>(a);
        either.addAll(b);                                  // union
        a.removeAll(b);                                    // difference
        System.out.println(both + " " + either + " " + a);
        System.out.println(new HashSet<>(words).add("fig")); // false: already there
    }
}

Maps

Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Map<String, Integer> ages = new HashMap<>();
        ages.put("Ada", 36);
        ages.put("Grace", 85);
        ages.put("Ada", 37);                                // replaces
        System.out.println(ages.get("Ada") + " " + ages.get("Bob") + " " + ages.getOrDefault("Bob", -1));
        System.out.println(ages.containsKey("Grace") + " " + ages.size());

        String text = "the cat and the hat and the bat";
        Map<String, Integer> counts = new TreeMap<>();
        for (String w : text.split(" ")) counts.merge(w, 1, Integer::sum);     // counting
        System.out.println(counts);

        Map<Character, List<String>> byLetter = new TreeMap<>();
        for (String w : List.of("apple", "avocado", "banana", "cherry")) {
            byLetter.computeIfAbsent(w.charAt(0), k -> new ArrayList<>()).add(w);   // grouping
        }
        System.out.println(byLetter);

        for (Map.Entry<String, Integer> e : counts.entrySet()) {
            if (e.getValue() > 1) System.out.print(e.getKey() + "=" + e.getValue() + " ");
        }
        System.out.println();
    }
}

map.get(missing) returns null, and unboxing that null into an int throws NullPointerException. Use getOrDefault, containsKey, or merge/computeIfAbsent.

Queues and stacks

Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Deque<String> stack = new ArrayDeque<>();
        stack.push("a"); stack.push("b"); stack.push("c");
        System.out.println(stack.pop() + " " + stack.peek());          // c b: last in, first out

        Queue<String> queue = new ArrayDeque<>();
        queue.offer("first"); queue.offer("second");
        System.out.println(queue.poll() + " " + queue.size());         // first 1: first in, first out

        PriorityQueue<Integer> pq = new PriorityQueue<>(List.of(5, 1, 4, 2));
        StringBuilder out = new StringBuilder();
        while (!pq.isEmpty()) out.append(pq.poll()).append(' ');     // always the smallest next
        System.out.println(out);
    }
}

equals and hashCode

HashSet and HashMap find objects by hashCode() first, then confirm with equals(). For your own classes used as keys or set members:

  • override both equals and hashCode, using the same fields;
  • objects that are equals must have the same hashCode;
  • do not change those fields while the object is in a hash set or map key (it would be filed under the old hash).

Records do all of this for you, which makes them ideal keys.

TreeSet and TreeMap use compareTo (or a Comparator) instead, and treat items that compare as 0 as duplicates.

Iterating and removing

All collections work with the enhanced for. To remove while iterating, use removeIf(...) or an explicit Iterator and its remove(); removing through the collection itself during a for loop throws ConcurrentModificationException.

Immutable collections

List.of, Set.of and Map.of create unmodifiable collections; List.copyOf(list) makes an unmodifiable copy. Returning unmodifiable views (Collections.unmodifiableList(items)) from a class protects its internal lists from outside changes.
