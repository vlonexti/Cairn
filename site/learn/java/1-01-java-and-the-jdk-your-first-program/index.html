Java and the JDK: Your First Program

lesson 1.011 of 5 in milestone 15 min1 practice task

What Java is and how it runs - source code, the compiler, bytecode and the JVM - installing the JDK, the shape of a Java program with a class and a main method, printing with System.out, comments, compiling and running from the command line, and reading compiler errors.

Java

Java is one of the most widely used programming languages: university courses, Android apps, banking and business systems, big-data tools and many games servers are written in it. It is statically typed (every variable has a fixed type, checked before the program runs) and object-oriented (programs are built from classes and objects, milestone 3).

How Java runs

flowchart LR
  A[Main.java: source code] -->|javac compiles| B[Main.class: bytecode]
  B -->|java runs| C[JVM: Java Virtual Machine]
  C --> D[Windows / macOS / Linux]

The compiler javac turns your source code into bytecode: instructions for the Java Virtual Machine (JVM), not for any real processor. The JVM runs that bytecode on whatever computer it is installed on, compiling the busiest parts to fast machine code while the program runs. That is Java's motto: write once, run anywhere.

The JDK (Java Development Kit) contains the compiler, the JVM and the standard library. Install a current LTS version (Java 21 or 25) from adoptium.net or oracle.com. The practice editor here compiles and runs your code on Java 25 for you.

Your first program

Java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Xenon!");
        System.out.println(2 + 3);
    }
}

Every part matters:

  • public class Main declares a class named Main. All Java code lives inside classes. A public class must be in a file with the same name: Main.java.
  • public static void main(String[] args) is the main method, where the program starts. args holds any command-line arguments.
  • System.out.println(...) prints a line. System.out.print(...) prints without moving to a new line.
  • Statements end with ;, and braces { } group code into blocks.
  • Java is case-sensitive: system.out.println does not exist.

Compiling and running

Terminal
javac Main.java        # creates Main.class
java Main              # runs it (class name, without .class)
java Main.java         # since Java 11: compile and run a single file in one step

IDEs such as IntelliJ IDEA, VS Code with the Java extensions, and Eclipse do this for you with a Run button, and underline errors as you type.

Java 25 also accepts a shorter form for small programs, with no class written out:

Java
void main() {
    IO.println("Hello from a compact source file");
}

This course uses the full form, which every Java version and every course you will meet uses.

Comments

Java
public class Main {
    public static void main(String[] args) {
        // A comment to the end of the line.
        /* A comment that can
           span lines. */
        System.out.println("Comments are ignored by the compiler.");
    }

    /**
     * A Javadoc comment: tools turn these into documentation pages.
     */
    static void documented() { }
}

Compiler errors

The compiler checks the whole program before it runs. An error names the file, line and problem:

Text
Main.java:3: error: ';' expected
        System.out.println("Hello")
                                   ^
Main.java:4: error: cannot find symbol
        System.out.printn("Hi");
                  ^
  symbol:   method printn(String)

Fix the first error first: the others are often caused by it. "cannot find symbol" almost always means a typo or a missing import.
