What a first and second computer-science course in Java cover, in modern Java 25: types, control flow and methods, arrays and ArrayList, recursion, classes, inheritance and interfaces, records, enums and sealed types, generics and the collections framework, exceptions and files, algorithm analysis, searching and sorting, linked lists, stacks, queues, hash tables and binary search trees built from scratch, lambdas and streams, threads, and finally the advanced language: nested and anonymous classes, the equals and hashCode contract, annotations and reflection, java.time, and binary data, then regular expressions, CompletableFuture and virtual threads, collectors, exact money arithmetic and locales. Practice compiles and runs in your browser.
