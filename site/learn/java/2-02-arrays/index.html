Arrays

Creating arrays

An array holds a fixed number of values of one type. Its length is set when it is created and never changes:

Java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] scores = new int[5];             // five zeros
        scores[0] = 90;
        scores[4] = 75;
        String[] days = {"Mon", "Tue", "Wed"};  // an initializer
        double[] prices = new double[] {2.5, 4.0};

        System.out.println(scores.length + " " + days.length);
        System.out.println(days[days.length - 1]);
        System.out.println(Arrays.toString(scores));    // [90, 0, 0, 0, 75]
        System.out.println(scores);                      // [I@1b6d3586: not the contents!
    }
}

Indexes run from 0 to length - 1. Using any other index throws ArrayIndexOutOfBoundsException. New arrays are filled with default values: 0, 0.0, false, '\u0000', or null for objects.

Printing an array directly shows its type and an identity code; use Arrays.toString.

Looping

Java
public class Main {
    public static void main(String[] args) {
        int[] data = {4, 8, 15, 16, 23, 42};
        int sum = 0, max = data[0];
        for (int x : data) {                  // every value
            sum += x;
            if (x > max) max = x;
        }
        System.out.println(sum + " " + max + " " + (double) sum / data.length);

        for (int i = data.length - 1; i >= 0; i--) {    // with indexes: backwards
            System.out.print(data[i] + " ");
        }
        System.out.println();
    }
}

The Arrays class

Java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] a = {5, 2, 9, 1};
        Arrays.sort(a);
        System.out.println(Arrays.toString(a));
        System.out.println(Arrays.binarySearch(a, 5));     // index 2: needs a sorted array
        int[] longer = Arrays.copyOf(a, 6);                  // copy, padded with zeros
        int[] part = Arrays.copyOfRange(a, 1, 3);            // indexes 1 and 2
        int[] sevens = new int[3];
        Arrays.fill(sevens, 7);
        System.out.println(Arrays.toString(longer) + Arrays.toString(part) + Arrays.toString(sevens));
        System.out.println(Arrays.equals(a, new int[] {1, 2, 5, 9}) + " " + (a == new int[] {1, 2, 5, 9}));
        System.out.println(Arrays.stream(a).sum());
    }
}

== on arrays compares references; Arrays.equals compares contents.

Copying versus sharing

Arrays are objects: assigning one array variable to another shares the same array.

Java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] same = a;                  // the same array
        int[] copy = a.clone();          // a new array with the same values
        same[0] = 99;
        System.out.println(Arrays.toString(a) + " " + Arrays.toString(copy));
    }
}

Two dimensions

Java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[][] grid = new int[3][4];          // 3 rows of 4
        grid[1][2] = 7;
        for (int[] row : grid) System.out.println(Arrays.toString(row));

        int[][] triangle = {{1}, {1, 1}, {1, 2, 1}};     // rows may have different lengths
        System.out.println(triangle[2].length + " " + Arrays.deepToString(triangle));
    }
}

A 2D array is an array of arrays: grid.length is the number of rows and grid[r].length the length of row r.

Classic algorithms

Many exam questions are small array algorithms. Two examples:

Java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] values = {3, 8, 1, 9, 4};
        reverse(values);
        System.out.println(Arrays.toString(values));
        System.out.println(indexOf(values, 1) + " " + indexOf(values, 7));
    }

    static void reverse(int[] a) {
        for (int i = 0, j = a.length - 1; i < j; i++, j--) {
            int tmp = a[i];
            a[i] = a[j];
            a[j] = tmp;
        }
    }

    static int indexOf(int[] a, int target) {          // linear search
        for (int i = 0; i < a.length; i++) {
            if (a[i] == target) return i;
        }
        return -1;
    }
}
