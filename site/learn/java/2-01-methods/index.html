Methods

lesson 2.011 of 5 in milestone 25 min1 practice task

Defining static methods with parameters and return types, void methods, calling methods, pass-by-value for primitives and references, overloading, variable-length arguments, local variables and scope, returning early, and designing small methods that do one thing.

Defining methods

A method is a named block of code with parameters and a return type. Until classes and objects arrive in milestone 3, our methods are static: they belong to the class and are called by name.

Java
public class Main {
    public static void main(String[] args) {
        System.out.println(area(3, 4));
        System.out.println(describe("Ada", 36));
        greet("Grace");
        System.out.println(isEven(10) + " " + isEven(7));
    }

    static double area(double width, double height) {
        return width * height;
    }

    static String describe(String name, int age) {
        return name + " (" + age + ")";
    }

    static void greet(String name) {          // void: returns nothing
        System.out.println("Hello, " + name + "!");
    }

    static boolean isEven(int n) {
        return n % 2 == 0;
    }
}

Every path through a non-void method must return a value of the declared type; the compiler checks this ("missing return statement"). A return can come early to stop the method at once:

Java
public class Main {
    public static void main(String[] args) {
        System.out.println(grade(95) + grade(72) + grade(-5));
    }

    static String grade(int score) {
        if (score < 0 || score > 100) return "?";
        if (score >= 90) return "A";
        if (score >= 70) return "C";
        return "F";
    }
}

Pass by value

Java always passes copies of values. For a primitive, the method gets a copy of the number; changing the parameter does not change the caller's variable. For an object, the method gets a copy of the reference: it can change the object the reference points to, but not make the caller's variable point somewhere else.

Java
public class Main {
    public static void main(String[] args) {
        int n = 1;
        addOne(n);
        System.out.println(n);              // 1: addOne changed its own copy

        int[] numbers = {1, 2, 3};
        doubleAll(numbers);
        System.out.println(numbers[0]);     // 2: the array itself was changed
        replace(numbers);
        System.out.println(numbers[0]);     // 2: replacing the parameter does not affect the caller
    }

    static void addOne(int x) { x = x + 1; }

    static void doubleAll(int[] values) {
        for (int i = 0; i < values.length; i++) values[i] *= 2;
    }

    static void replace(int[] values) { values = new int[] {100, 200}; }
}

Overloading

Methods may share a name when their parameter lists differ. The compiler picks the closest match:

Java
public class Main {
    public static void main(String[] args) {
        System.out.println(max(3, 9));
        System.out.println(max(2.5, 1.5));
        System.out.println(max(4, 8, 6));
        System.out.println(sum() + " " + sum(1, 2, 3) + " " + sum(new int[] {10, 20}));
    }

    static int max(int a, int b) { return a > b ? a : b; }
    static double max(double a, double b) { return a > b ? a : b; }
    static int max(int a, int b, int c) { return max(max(a, b), c); }

    static int sum(int... numbers) {          // varargs: any number of ints, as an array
        int total = 0;
        for (int n : numbers) total += n;
        return total;
    }
}

Scope

A variable exists from its declaration to the end of the block { } it is declared in. Parameters and variables of one method are invisible to other methods; the only way to share values is to pass them as arguments and return results.

Good methods

  • One method, one job, named with a verb: calculateTotal, isValid, printReport.
  • Prefer methods that return results over methods that print them: a returned value can be tested, printed, or used in further calculations.
  • Keep methods short. If you need a comment to explain a section of a method, that section probably wants to be its own method.
