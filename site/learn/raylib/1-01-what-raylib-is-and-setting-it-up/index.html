What raylib Is and Setting It Up

lesson 1.011 of 5 in milestone 15 min1 practice task

raylib is a small C library for making games - windows, drawing, input, sound and 3D in a few hundred plain functions. This lesson explains what it does and does not do, installs it with vcpkg, and runs a first window in Visual Studio.

A library, not an engine

raylib is a C library by Ramon Santamaria for learning and making games. It gives you functions; you write the game:

raylib does You do
Open a window, run at a frame rate Decide what happens each frame
Draw shapes, textures, text, 3D models Keep the game's data: positions, scores, levels
Read keyboard, mouse, gamepad and touch Turn input into movement and actions
Load and play sounds and music Decide when to play them
Basic collision tests and maths helpers Collision response, physics, AI, menus

An engine such as Unity or Godot gives you an editor, a scene tree, physics and a component system, and you fit your game into them. With raylib nothing is hidden: every pixel on screen is there because your code drew it this frame. That is why it is a good way to learn how games actually work, and it is enough for complete, polished 2D and small 3D games.

raylib is written in C99, so its API is plain functions and structs: Vector2, Rectangle, Color, Texture2D. It works fine from C++, and the course uses C++ for everything around it.

Installing with vcpkg

The simplest way on Windows is vcpkg, Microsoft's C++ package manager:

C++
git clone https://github.com/microsoft/vcpkg C:\dev\vcpkg
C:\dev\vcpkg\bootstrap-vcpkg.bat
C:\dev\vcpkg\vcpkg integrate install
C:\dev\vcpkg\vcpkg install raylib:x64-windows

integrate install makes every Visual Studio project find vcpkg's headers and libraries automatically. Then create a new Console App (C++) project, set the platform to x64, and replace the code with:

C++
#include "raylib.h"

int main()
{
    InitWindow(800, 450, "My first raylib window");
    SetTargetFPS(60);

    while (!WindowShouldClose())          // Esc or the close button
    {
        BeginDrawing();
        ClearBackground(RAYWHITE);
        DrawText("Hello, raylib!", 280, 200, 32, DARKGRAY);
        EndDrawing();
    }

    CloseWindow();
}

Press F5: a window opens with the text in it, and closes with Esc. If the build cannot find raylib.h, check that the platform is x64 (vcpkg installed the x64 version) and that integrate install was run.

Note

Other ways work too: the raylib Windows installer comes with its own compiler and editor, and CMake projects can fetch raylib with FetchContent. The code in this course is the same whichever you use.

Hiding the console window

A console app opens a black console next to the game, which is handy for printf debugging. For a release build, set Linker > System > SubSystem to Windows and Linker > Advanced > Entry Point to mainCRTStartup, so main still runs but no console appears.

raylib's cheatsheet

raylib's website has a one-page cheatsheet listing every function by module: rcore (window, input, timing), rshapes, rtextures, rtext, rmodels, raudio. Keep it open while you work; the function names are descriptive enough that it is often all you need. The examples page has more than a hundred small programs, each a single file, that show one feature each.

How the practice works

Compiler Explorer, which runs the practice on this site, has no window or GPU. So the practice checks the game logic you would put around raylib's calls: movement, collision, animation timing, cameras, tile maps, pathfinding. Each practice declares the few raylib types it needs, such as struct Vector2 { float x, y; };, exactly as raylib does, so the code moves into a real raylib project unchanged.
