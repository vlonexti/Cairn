Game Programming with raylib

6 milestones28 lessons28 practice tasks30 projects

raylib opens a window, draws shapes, sprites, text and 3D models, plays sounds and reads input, all from a few plain C functions. The course builds a series of small complete games and the game-programming ideas behind them: the game loop, frame time, sprites and animation, collision and platformer physics, cameras, tile maps, enemies and pathfinding, a first 3D scene, shaders, saving and packaging. It assumes the first milestones of the C++ course. You build the games in Visual Studio; the practice on the site checks the game logic inside them.
