Text, Fonts and a Simple Interface

lesson 2.033 of 5 in milestone 25 min1 practice task

Drawing text with raylib's default font and with your own fonts, measuring and aligning it, formatting numbers with TextFormat, and building the interface a small game needs - a score display, health bar, buttons and a menu you can use with keys or the mouse.

Drawing text

C++
DrawText("Score", 20, 20, 24, DARKGRAY);                          // default font, size in pixels
DrawText(TextFormat("Score: %05d", score), 20, 50, 24, DARKGRAY);  // printf-style formatting

TextFormat works like printf and returns a const char* to a buffer inside raylib. The buffer is reused (raylib keeps a few), so use the result straight away; do not store the pointer.

Your own fonts

The default font is small pixel art. For anything else, load a TrueType font at the size you will draw it:

C++
Font title = LoadFontEx("assets/Kenney Future.ttf", 64, nullptr, 0);   // 64 px glyphs, default characters
SetTextureFilter(title.texture, TEXTURE_FILTER_BILINEAR);
DrawTextEx(title, "XENON QUEST", { 200, 80 }, 64, 2, WHITE);           // size and letter spacing
// ...
UnloadFont(title);

A font is a texture of glyphs (an atlas) plus their positions. Drawing at a very different size from the loaded size looks blurry when bigger and grainy when smaller, so load each size you use a lot. For characters beyond basic Latin (accents, other alphabets), pass the list of code points you need.

Measuring and aligning

MeasureText(text, size) (default font) and MeasureTextEx(font, text, size, spacing) give the size of a text in pixels. With them you can align anything:

Alignment x
Left x
Centre x - width / 2
Right x - width

Score displays are usually right-aligned, so the digits do not shift left and right when the number gets longer.

A health bar

C++
void healthBar(Rectangle r, float hp, float maxHp)
{
    const float t = std::clamp(hp / maxHp, 0.0f, 1.0f);
    DrawRectangleRec(r, DARKGRAY);
    DrawRectangleRec({ r.x, r.y, r.width * t, r.height }, t > 0.3f ? LIME : RED);
    DrawRectangleLinesEx(r, 2, BLACK);
}

A nice touch is a second, slower bar behind it that catches up with the real value, so the player sees how much damage was just taken.

Buttons and menus

An interface for a small game needs only buttons:

C++
bool button(Rectangle r, const char* label)
{
    const bool hover = CheckCollisionPointRec(GetMousePosition(), r);
    DrawRectangleRec(r, hover ? SKYBLUE : LIGHTGRAY);
    const int w = MeasureText(label, 20);
    DrawText(label, static_cast<int>(r.x + (r.width - w) / 2), static_cast<int>(r.y + (r.height - 20) / 2), 20, BLACK);
    return hover && IsMouseButtonReleased(MOUSE_BUTTON_LEFT);
}

This is an immediate-mode button, like the Dear ImGui course's: it is drawn and checked in the same call. For a menu that works with keys and gamepads as well, keep a selected index, move it with up and down (wrapping around), and activate with Enter; hovering the mouse over an item also selects it.

raylib also comes with raygui, a single-header immediate-mode GUI library in the same style, with sliders, checkboxes and text boxes, when a game needs more than buttons.

Interface coordinates

The interface is drawn after the world and outside any camera (lesson 4.01), in screen coordinates, so it stays put while the world scrolls. Anchor it to the screen's edges or centre rather than fixed positions so it still fits when the window is resized.
