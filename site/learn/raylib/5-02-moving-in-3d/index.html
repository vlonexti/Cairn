Moving in 3D

lesson 5.022 of 5 in milestone 55 min1 practice task

Walking around a 3D world - raylib's built-in camera modes, then a first-person controller of your own with yaw and pitch from the mouse, movement relative to where you look, gravity and jumping, and a third-person camera that orbits the player.

The built-in camera modes

raylib can move a camera for you:

C++
DisableCursor();                                   // hide and lock the mouse
while (!WindowShouldClose())
{
    UpdateCamera(&camera, CAMERA_FIRST_PERSON);    // WASD + mouse
    // ... draw
}

Modes are CAMERA_FREE, CAMERA_ORBITAL, CAMERA_FIRST_PERSON and CAMERA_THIRD_PERSON. They are fine for trying things out, but a game needs its own controller: collision, gravity, rebindable keys and its own feel. UpdateCameraPro takes movement and rotation you computed yourself.

Yaw and pitch

A first-person view is described by two angles:

  • Yaw: turning left and right, around the y axis. The mouse's x movement changes it.
  • Pitch: looking up and down. The mouse's y movement changes it, clamped to about ±89° so the view never flips over the top.

From the angles, the direction you look in:

C++
const Vector3 forward{
    std::cos(pitch) * std::sin(yaw),
    std::sin(pitch),
    std::cos(pitch) * std::cos(yaw),
};
camera.position = eye;
camera.target = Vector3Add(eye, forward);

Mouse look: yaw -= GetMouseDelta().x * sensitivity; pitch -= GetMouseDelta().y * sensitivity;. Sensitivity is a setting players expect, along with "invert Y".

Moving where you look

Walking uses the flat forward direction: the yaw only, so looking at the floor does not make you walk slower or dig into the ground:

C++
const Vector3 flatForward{ std::sin(yaw), 0, std::cos(yaw) };
const Vector3 right{ -std::cos(yaw), 0, std::sin(yaw) };    // forward x up, for this yaw
Vector3 wish{ 0, 0, 0 };
if (IsKeyDown(KEY_W)) wish = Vector3Add(wish, flatForward);
if (IsKeyDown(KEY_S)) wish = Vector3Subtract(wish, flatForward);
if (IsKeyDown(KEY_D)) wish = Vector3Add(wish, right);
if (IsKeyDown(KEY_A)) wish = Vector3Subtract(wish, right);
if (Vector3Length(wish) > 0) wish = Vector3Normalize(wish);    // lesson 1.04's diagonal fix, in 3D

Then the 2D ideas carry over unchanged: acceleration towards wish * speed, gravity on y, jumping with coyote time and a buffer, and the eye at about 1.7 units above the feet.

Collision with the world

The simplest world is boxes (walls, crates, platforms) and the player is a box or a vertical capsule. Resolving one axis at a time (lesson 3.02) works in 3D exactly as in 2D, with three axes instead of two: move on x and push out, then z, then y (landing sets "on ground"). raylib's CheckCollisionBoxes(a, b) tests two BoundingBoxes (min and max corners).

A third-person camera

A third-person camera orbits the player at a distance, using the same yaw and pitch:

C++
const Vector3 offset{
    distance * std::cos(pitch) * std::sin(yaw),
    distance * std::sin(pitch),
    distance * std::cos(pitch) * std::cos(yaw),
};
camera.target = Vector3Add(player.pos, { 0, 1.5f, 0 });   // look at the shoulders, not the feet
camera.position = Vector3Subtract(camera.target, offset);   // behind, along the view direction

If a wall comes between the camera and the player, cast a ray from the target towards the camera (lesson 5.03) and move the camera in front of the wall, or the player sees the inside of the wall. Smooth the camera's movement (lesson 4.01's smoothTowards works per axis in 3D).
