Shaders

lesson 5.044 of 5 in milestone 55 min1 practice task

Shaders are small programs that run on the GPU for every vertex and every pixel. This lesson explains vertex and fragment shaders, writes GLSL fragment shaders for raylib, passes values in with uniforms, and builds a flash effect, a dissolve and a simple light.

Programs on the GPU

Everything raylib draws goes through two small programs on the graphics card:

flowchart LR
    V[Vertices] --> VS[Vertex shader: once per vertex, positions it on screen] --> R[Rasteriser: which pixels the triangle covers] --> FS[Fragment shader: once per pixel, chooses its colour] --> S[Screen]

raylib's default shaders just position vertices with the camera and multiply the texture colour by the tint. Writing your own fragment shader (also called a pixel shader) lets you change how every pixel looks: flashes, outlines, dissolves, lighting, water, colour grading. They are written in GLSL, a C-like language.

A first fragment shader

raylib on desktop uses OpenGL 3.3, so shaders start with #version 330:

C++
// flash.fs
#version 330
in vec2 fragTexCoord;          // from raylib's default vertex shader
in vec4 fragColor;             // the tint
uniform sampler2D texture0;    // the texture being drawn
uniform float flash;           // our own value: 0 = normal, 1 = white
out vec4 finalColor;

void main()
{
    vec4 texel = texture(texture0, fragTexCoord) * fragColor;
    finalColor = vec4(mix(texel.rgb, vec3(1.0), flash), texel.a);
}

mix(a, b, t) is linear interpolation, vec3/vec4 are vectors, and .rgb/.a pick components. The shader runs for every pixel of the sprite, in parallel.

Using it from raylib

C++
Shader shader = LoadShader(nullptr, "assets/flash.fs");       // nullptr: keep the default vertex shader
const int flashLoc = GetShaderLocation(shader, "flash");

// each frame:
const float amount = hitTimer > 0 ? 1.0f : 0.0f;
SetShaderValue(shader, flashLoc, &amount, SHADER_UNIFORM_FLOAT);
BeginShaderMode(shader);
    DrawTexturePro(sprite, src, dest, origin, 0, WHITE);
EndShaderMode();

UnloadShader(shader);

A uniform is a value that is the same for every pixel of one draw call: a time, a colour, a position. Look its location up once with GetShaderLocation, then set it every frame with SetShaderValue. Other types are SHADER_UNIFORM_VEC2, VEC3, VEC4 and INT, and SetShaderValueTexture passes extra textures.

A dissolve

A dissolve makes an object burn away. Read a noise texture, and throw away pixels whose noise value is below a threshold that rises from 0 to 1:

C++
uniform sampler2D noise;
uniform float threshold;
void main()
{
    vec4 texel = texture(texture0, fragTexCoord) * fragColor;
    float n = texture(noise, fragTexCoord).r;
    if (n < threshold) discard;                                   // this pixel is not drawn
    float edge = smoothstep(threshold, threshold + 0.05, n);      // 0 at the edge, 1 inside
    finalColor = vec4(mix(vec3(1.0, 0.5, 0.1), texel.rgb, edge), texel.a);   // glowing orange edge
}

A point light

Simple lighting in 2D: brighten pixels near a light and darken the rest:

C++
uniform vec2 lightPos;      // in screen pixels
uniform float radius;
void main()
{
    vec4 texel = texture(texture0, fragTexCoord) * fragColor;
    float d = distance(gl_FragCoord.xy, lightPos);
    float light = clamp(1.0 - d / radius, 0.15, 1.0);
    finalColor = vec4(texel.rgb * light, texel.a);
}

gl_FragCoord is the pixel's position in the window, but with y measured from the bottom, so pass screenHeight - y for the light's y. Forgetting that flips the light upside down.

Debugging shaders

A shader that fails to compile is reported in raylib's log (the console window) with a line number, and raylib falls back to the default shader. When a result is wrong, output intermediate values as colours: finalColor = vec4(vec3(n), 1.0); shows the noise as grey levels.

Shaders are calculations on numbers, so the maths behind them (interpolation, distances, smoothstep) can be tested on the CPU first, which is what this lesson's practice does.
