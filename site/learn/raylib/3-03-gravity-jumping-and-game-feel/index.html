Gravity, Jumping and Game Feel

lesson 3.033 of 5 in milestone 35 min1 practice task

Jumping that feels good is designed, not simulated. This lesson derives gravity and jump speed from the height and time you want, then adds the tricks platformers rely on - variable jump height, faster falling, coyote time, jump buffering and acceleration on the ground and in the air.

Gravity is acceleration

Gravity adds to the vertical velocity every frame (y points down, so it is positive):

C++
vel.y += gravity * dt;
vel.y = std::min(vel.y, maxFallSpeed);     // terminal velocity: falls stay readable

A jump sets the vertical velocity upwards once: vel.y = -jumpSpeed.

Design the jump, then compute the numbers

Guessing gravity = 1500, jumpSpeed = 600 and tweaking forever is the slow way. Decide what you want instead: how high (in pixels) and how long the rise takes (in seconds). Physics gives the rest:

Output
gravity   = 2 * height / time²
jumpSpeed = 2 * height / time

A jump of 96 pixels (three 32-pixel tiles) rising in 0.4 s needs gravity = 1200 px/s² and jumpSpeed = 480 px/s. Change the height and the jump still takes 0.4 s; change the time and it still reaches 96 pixels. Level designers can then rely on "the player can jump three tiles".

Variable jump height

Players expect a tap to make a small hop and holding the button to jump high. When the button is released while still rising, cut the upward speed:

C++
if (IsKeyReleased(KEY_SPACE) && vel.y < 0) vel.y *= 0.5f;

Falling faster

Real jumps are symmetrical, but they feel floaty. Most platformers use stronger gravity on the way down (1.5 to 2 times), which makes jumps feel snappy and landings decisive:

C++
const float g = vel.y > 0 ? gravity * 1.8f : gravity;

Coyote time

When a player runs off a ledge and presses jump a moment too late, a strict game says "you are in the air, no jump". It feels unfair, because the player saw themselves on the ledge. Coyote time allows a jump for a short time (about 0.1 s) after leaving the ground:

C++
if (onGround) coyote = 0.1f; else coyote -= dt;

Jump buffering

The opposite case: the player presses jump a moment before landing. Remember the press for a short time and jump as soon as it becomes possible:

C++
if (IsKeyPressed(KEY_SPACE)) buffer = 0.1f; else buffer -= dt;
if (buffer > 0 && coyote > 0) { vel.y = -jumpSpeed; buffer = 0; coyote = 0; }

Both timers must be cleared when the jump happens, or one press makes two jumps.

Running

Instant full speed feels stiff; slow acceleration feels like ice. Move the horizontal velocity towards the target speed by a maximum change per second, with different rates for speeding up, slowing down and turning, and less control in the air:

C++
float approach(float v, float target, float maxDelta)
{
    if (v < target) return std::min(v + maxDelta, target);
    return std::max(v - maxDelta, target);
}
const float target = inputX * runSpeed;
const float rate = onGround ? (inputX != 0 ? accel : decel) : airAccel;
vel.x = approach(vel.x, target, rate * dt);

Feel is the sum of small things

None of these is realistic, and all of them are in nearly every good platformer. Add the small extras too: a puff of dust on landing, a squash of the sprite, a short sound. Lesson 4.03 builds the particles.
