Coordinates, Shapes and Colours

lesson 1.033 of 5 in milestone 15 min1 practice task

Where things go on the screen and how to draw them - raylib's coordinate system with y pointing down, Vector2 and Rectangle, the shape functions, colours with alpha, and centring things on the screen.

Screen coordinates

The top-left corner of the window is (0, 0). x grows to the right and y grows downwards, in pixels. In an 800 × 450 window the bottom-right pixel is (799, 449).

(0,0) ──────────── x ──────────▶ (800,0)
  │
  y        (400,225) is the centre
  │
  ▼
(0,450)

Y pointing down surprises people used to maths graphs: "up" on screen means subtracting from y, and gravity adds to y.

The basic types

C++
typedef struct Vector2 { float x; float y; } Vector2;
typedef struct Rectangle { float x; float y; float width; float height; } Rectangle;   // x, y = top-left corner
typedef struct Color { unsigned char r, g, b, a; } Color;

C++ can build them with braces: Vector2 p{ 100, 50 }, Rectangle r{ 10, 10, 64, 32 }, Color sky{ 135, 206, 235, 255 }. raylib has named colours (RED, DARKBLUE, RAYWHITE, BLANK for fully transparent) and helpers such as Fade(RED, 0.5f) for half-transparent red.

Shapes

Function Draws
DrawPixel(x, y, c) One pixel
DrawLine(x1, y1, x2, y2, c) / DrawLineEx(a, b, thick, c) A line
DrawRectangle(x, y, w, h, c) / DrawRectangleRec(rect, c) A filled rectangle from its top-left corner
DrawRectangleLinesEx(rect, thick, c) A rectangle's outline
DrawRectangleRounded(rect, roundness, segments, c) Rounded corners
DrawCircle(cx, cy, r, c) / DrawCircleV(centre, r, c) A filled circle from its centre
DrawTriangle(a, b, c, colour) A triangle (points counter-clockwise)
DrawPoly(centre, sides, radius, rotation, c) A regular polygon

Rectangles are placed by their top-left corner, circles by their centre. Mixing the two up is the most common reason a shape is "half a size off".

Centring

To centre a rectangle of size w × h in the window:

C++
const float x = (GetScreenWidth() - w) / 2.0f;
const float y = (GetScreenHeight() - h) / 2.0f;

Text works the same way with MeasureText(text, fontSize), which returns the width in pixels:

C++
const char* title = "GAME OVER";
const int width = MeasureText(title, 48);
DrawText(title, (GetScreenWidth() - width) / 2, 180, 48, RED);

Colours and alpha

a is the alpha (opacity): 255 is solid, 0 is invisible. Drawing a half-transparent black rectangle over the whole screen is the classic "paused" dim. To mix two colours, interpolate each channel: r = a.r + (b.r - a.r) * t, which raylib's ColorLerp does (raylib 5.5).

Drawing order

Shapes drawn later appear on top. A frame is usually drawn in layers: background, world, effects, then the interface on top of everything.
