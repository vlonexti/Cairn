Loops

lesson 2.011 of 5 in milestone 25 min2 practice tasks

The numeric for loop with its start, stop and step, while and repeat-until, break, skipping to the next round with goto continue, and the loop variable belonging to the loop.

The numeric for

Lua
for i = 1, 5 do
    io.write(i, " ")
end
print()

for i = 10, 1, -3 do
    io.write(i, " ")
end
print()

for x = 0, 1, 0.25 do
    io.write(x, " ")
end
print()
Output
1 2 3 4 5 
10 7 4 1 
0 0.25 0.5 0.75 1

(The third loop counts in floats, because its step is a float. io.write writes a float like 0.0 as plain 0; print and tostring would show 0.0.)

for i = start, stop, step do ... end. The step is 1 when left out, and may be negative. Both ends are included: for i = 1, 5 runs five times. The start, stop and step are worked out once, before the first round, so changing them inside the loop has no effect.

A loop that cannot start does not run at all: for i = 5, 1 do runs zero times (the step is +1, and 5 is already past 1).

The loop variable is local to the loop. After end it is gone, and assigning to it inside the loop does not change the number of rounds.

Lua
local total = 0
for n = 1, 100 do
    total = total + n
end
print(total)
Output
5050

while

while repeats as long as its condition is true, checking it before each round:

Lua
local n, steps = 27, 0
while n ~= 1 do
    if n % 2 == 0 then n = n // 2 else n = 3 * n + 1 end
    steps = steps + 1
end
print(steps)
Output
111

repeat ... until

repeat checks its condition after each round, so the body always runs at least once. It stops when the condition becomes true:

Lua
local value = 1
repeat
    value = value * 3
until value > 100
print(value)
Output
243

A local declared inside the body is still visible in the until condition, which makes repeat natural for "ask until the answer is valid":

Lua
local age
repeat
    io.write("Age? ")
    age = tonumber(io.read())
until age and age >= 0

break

break leaves the innermost loop at once:

Lua
for i = 2, 100 do
    if i * i > 50 then
        print("first square over 50: " .. i * i)
        break
    end
end
Output
first square over 50: 64

Skipping a round

Lua has no continue. Use goto with a label at the end of the body:

Lua
for i = 1, 10 do
    if i % 3 ~= 0 then goto continue end
    io.write(i, " ")
    ::continue::
end
print()
Output
3 6 9

::continue:: is a label; goto continue jumps to it. The name is your choice, but continue is what everyone writes. Often an if around the rest of the body reads just as well.

Loops inside loops

Lua
for row = 1, 3 do
    local line = ""
    for col = 1, 4 do
        line = line .. row * col .. "\t"
    end
    print(line)
end
Output
1	2	3	4	
2	4	6	8	
3	6	9	12

break leaves only the inner loop. To leave both, put the loops in a function and return, or use a flag.

Reading until input ends

io.read() returns nil when there is no more input, which ends a while loop neatly:

Lua
local count = 0
local line = io.read()
while line do
    count = count + 1
    line = io.read()
end
print(count .. " lines")
