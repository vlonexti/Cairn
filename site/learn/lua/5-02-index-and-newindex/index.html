__index and __newindex

lesson 5.022 of 5 in milestone 55 min1 practice task

Default values for missing keys, __index as a table and as a function, rawget and rawset, watching and blocking writes with __newindex, read-only tables, catching typos in globals, and weak tables.

When a key is missing

Reading a key that a table does not have normally gives nil. If the table's metatable has __index, Lua asks it instead.

__index as a table: Lua looks the key up in that table (and, if that table has its own __index, keeps going):

Lua
local defaults = { colour = "grey", size = 10, visible = true }
local button = setmetatable({ colour = "red" }, { __index = defaults })
print(button.colour, button.size, button.visible, button.missing)
button.size = 14
print(button.size, defaults.size)
Output
red	10	true	nil
14	10

The table keeps its own values; only missing keys fall back to defaults. Writing goes into the table itself, never into defaults. This one mechanism is the whole basis of classes and inheritance in Lua (next two lessons).

__index as a function: Lua calls it with the table and the key, and uses what it returns:

Lua
local squares = setmetatable({}, {
    __index = function(t, n)
        local value = n * n
        rawset(t, n, value)      -- remember it, so next time it is a plain field
        return value
    end,
})
print(squares[12], squares[3], rawget(squares, 12), rawget(squares, 5))
Output
144	9	144	nil

rawget(t, k) and rawset(t, k, v) read and write without metamethods. They are how a metamethod reaches the table itself without calling itself again.

When a key is new

__newindex runs when you assign to a key the table does not have yet (assigning to an existing key never calls it):

Lua
local log = {}
local watched = setmetatable({}, {
    __newindex = function(t, key, value)
        log[#log + 1] = key .. "=" .. tostring(value)
        rawset(t, key, value)
    end,
})
watched.a = 1
watched.b = 2
watched.a = 10            -- a already exists: no call
print(table.concat(log, " "), watched.a)
Output
a=1 b=2	10

Read-only tables

To catch every write, keep the real data elsewhere and give out an empty proxy whose __index reads from the data and whose __newindex refuses:

Lua
local function read_only(data)
    return setmetatable({}, {
        __index = data,
        __newindex = function(_, key) error("cannot change " .. tostring(key), 2) end,
        __len = function() return #data end,
    })
end

local days = read_only({ "Mon", "Tue", "Wed" })
print(days[2], #days)
local ok, err = pcall(function() days[1] = "Sun" end)
print(ok, err)
Output
Tue	3
false	main.lua:11: cannot change 1

pcall runs a function and catches its error instead of stopping the program (lesson 6.01). error(message, 2) blames the line that did the writing, not the line inside the metamethod.

Catching typos in globals

Globals live in the table _G, and _G can have a metatable too. This makes reading or creating an unknown global an error, which catches misspelled variable names at once:

Lua
setmetatable(_G, {
    __newindex = function(_, name) error("assigning undeclared global '" .. name .. "'", 2) end,
    __index = function(_, name) error("reading undeclared global '" .. name .. "'", 2) end,
})

local count = 0
print(pcall(function() cuont = count + 1 end))
print(pcall(function() return totl end))
Output
false	main.lua:7: assigning undeclared global 'cuont'
false	main.lua:8: reading undeclared global 'totl'

Real projects use a version of this (often called strict.lua), or a language server that reports undefined globals as you type.

Weak tables

A table normally keeps everything in it alive. __mode = "k" makes its keys weak, "v" its values, "kv" both: the garbage collector may remove an entry when nothing else refers to that key or value. A weak-keyed table is how you attach extra data to objects without keeping them alive forever:

Lua
local extra = setmetatable({}, { __mode = "k" })
local obj = {}
extra[obj] = "notes about obj"
print(extra[obj])
obj = nil
collectgarbage()
local n = 0
for _ in pairs(extra) do n = n + 1 end
print(n)
Output
notes about obj
0
