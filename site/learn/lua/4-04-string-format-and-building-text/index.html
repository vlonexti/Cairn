string.format and Building Text

lesson 4.044 of 5 in milestone 45 min1 practice task

The format directives %d %s %f %x %q, width, padding, alignment and precision, lining up a table of text, building long strings with a buffer table, and turning values into text with tostring and %q.

string.format

string.format(template, ...) fills the template's directives with the values, in order:

Lua
print(string.format("%s is %d years old", "Ada", 36))
print(string.format("Pi is about %.3f", math.pi))
print(string.format("%d%% done", 75))
print(("%s = %s"):format("x", 10))
Output
Ada is 36 years old
Pi is about 3.142
75% done
x = 10
Directive Shows Example Result
%d a whole number ("%d"):format(42) 42
%f a float, 6 decimals by default ("%.2f"):format(2/3) 0.67
%g a number, short form ("%g"):format(0.5) 0.5
%e scientific notation ("%.1e"):format(12345) 1.2e+04
%x / %X hexadecimal ("%x"):format(255) ff
%o octal ("%o"):format(8) 10
%c the character with that code ("%c"):format(65) A
%s any value as text (calls tostring) ("%s"):format(true) true
%q a value as Lua source (quoted string) ("%q"):format('a"b') "a\"b"
%% a literal %

Width, padding and alignment

A number between % and the letter sets a minimum width. The value is padded on the left with spaces; - pads on the right instead; 0 pads numbers with zeros:

Lua
print(string.format("[%5d] [%-5d] [%05d]", 42, 42, 42))
print(string.format("[%8.2f] [%-8s] [%3s]", 3.14159, "left", "toolong"))
print(string.format("%02d:%02d:%02d", 7, 5, 9))
Output
[   42] [42   ] [00042]
[    3.14] [left    ] [toolong]
07:05:09

The width is a minimum: longer values are never cut. %.3s does cut a string to 3 characters.

Lining up columns

Widths make text tables line up:

Lua
local items = {
    { "Tea", 3, 2.5 },
    { "Sandwich", 1, 6.25 },
    { "Cake", 2, 3.0 },
}
local total = 0
print(string.format("%-10s %3s %8s", "Item", "Qty", "Total"))
for _, item in ipairs(items) do
    local name, qty, price = item[1], item[2], item[3]
    total = total + qty * price
    print(string.format("%-10s %3d %8.2f", name, qty, qty * price))
end
print(string.rep("-", 23))
print(string.format("%-14s %8.2f", "Sum", total))
Output
Item       Qty    Total
Tea          3     7.50
Sandwich     1     6.25
Cake         2     6.00
-----------------------
Sum               19.75

Building long text

Joining strings with .. in a loop copies the growing string every time: fine for ten pieces, slow for ten thousand. The Lua way is a buffer: collect the pieces in a table and join them once.

Lua
local buffer = {}
for i = 1, 5 do
    buffer[#buffer + 1] = string.format("line %d", i)
end
local text = table.concat(buffer, "\n")
print(text)
print(#text)
Output
line 1
line 2
line 3
line 4
line 5
34

Values as text

tostring turns any value into text. %q turns a string into Lua source that reads back as the same string, escapes and all, which is how you save data that Lua can load again:

Lua
print(tostring(12), tostring(1.5), tostring(nil), tostring(false))
local tricky = 'She said "hi"\nthen left'
print(string.format("%q", tricky))
print(string.format("%q", 1/3))
Output
12	1.5	nil	false
"She said \"hi\"\
then left"
0x1.5555555555555p-2

%q writes a newline as a backslash followed by a real newline, and floats in hexadecimal so that the exact value survives.
