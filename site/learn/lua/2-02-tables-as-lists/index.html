Tables as Lists

lesson 2.022 of 5 in milestone 25 min1 practice task

The table as Lua's only data structure, lists that start at index 1, the length operator, adding and removing with table.insert and table.remove, ipairs, and why holes in a list break #.

One structure for everything

Lua has exactly one way to group values: the table. A table maps keys to values. Used with the keys 1, 2, 3 and so on, it is a list (an array); with other keys it is a dictionary, a record or an object. This lesson is about lists.

Lua
local fruits = { "apple", "banana", "cherry" }
print(fruits[1], fruits[3], #fruits)
print(fruits[4])
Output
apple	cherry	3
nil
Lists start at 1

The first item is fruits[1], the last is fruits[#fruits]. fruits[0] is nil. Every library function counts from 1 too.

#t is the list's length. Reading past the end is not an error, it is nil.

Changing a list

Lua
local t = { 10, 20, 30 }
t[2] = 25                     -- replace
t[#t + 1] = 40                -- add at the end
table.insert(t, 50)           -- add at the end
table.insert(t, 1, 5)         -- insert at position 1, the rest move up
print(table.concat(t, ", "))

local last = table.remove(t)        -- remove the last, and return it
local first = table.remove(t, 1)    -- remove position 1, the rest move down
print(first, last, table.concat(t, ", "))
Output
5, 10, 25, 30, 40, 50
5	50	10, 25, 30, 40

table.concat(t, sep) joins a list of strings or numbers into one string. It is the quickest way to print a list; print(t) only shows something like table: 0x55d0c8a3e2a0.

Looping over a list

Lua
local scores = { 72, 95, 64 }

for i = 1, #scores do
    print(i, scores[i])
end

for i, score in ipairs(scores) do
    print("score " .. i .. " is " .. score)
end
Output
1	72
2	95
3	64
score 1 is 72
score 2 is 95
score 3 is 64

ipairs(t) gives each position and its value, in order, from 1 until the first nil. Use _ for a value you do not need: for _, score in ipairs(scores).

Do not insert into or remove from a list while looping over it forwards; positions move under you. Loop backwards (for i = #t, 1, -1) when removing.

Building a list

Lua
local squares = {}
for n = 1, 6 do
    squares[#squares + 1] = n * n
end
print(table.concat(squares, " "))

local evens = {}
for _, n in ipairs(squares) do
    if n % 2 == 0 then table.insert(evens, n) end
end
print(#evens, table.concat(evens, " "))
Output
1 4 9 16 25 36
3	4 16 36

Holes

A list must not have holes: nil in the middle. Setting an item to nil does not remove it from a list; it makes a hole, and then # may give either end of the hole, and ipairs stops at it:

Lua
local t = { "a", "b", "c", "d" }
t[2] = nil
for i, v in ipairs(t) do print(i, v) end
Output
1	a

To remove an item, use table.remove. To mark one as missing, store false or a special value, not nil.

Tables are values you share

A variable holds a reference to a table, not a copy. Two variables can name the same table:

Lua
local a = { 1, 2, 3 }
local b = a
b[1] = 99
print(a[1], a == b)
print({ 1, 2 } == { 1, 2 })
Output
99	true
false

== on tables asks "the same table?", not "the same contents?". Lesson 2.05 shows how to copy and compare by content.
