Values, Variables and Types

lesson 1.022 of 5 in milestone 15 min1 practice task

Lua's eight types and the type function, nil as "no value", local variables and why every variable should be local, assigning several variables at once, and swapping two values.

Values have types, variables do not

A variable in Lua is a name for a value. The value has a type; the variable does not, so the same variable can hold a number now and a string later:

Lua
local x = 42
print(x, type(x))
x = "forty-two"
print(x, type(x))
Output
42	number
forty-two	string

type(v) returns the type's name as a string. Lua has eight types:

Type Examples Used for
nil nil "no value here"
boolean true, false yes or no
number 42, 3.14, -7 integers and decimals
string "text", 'text' text, and any bytes
table {1, 2, 3}, {name = "Ada"} lists, dictionaries, records, objects: everything else
function print, function() end code you can call
userdata an open file data owned by C code
thread a coroutine lesson 6.03

The first five come up on every page of this course. Tables get all of milestone 2.

nil

nil means "nothing". A variable that was never given a value holds nil, and so does a table field that does not exist:

Lua
local score
print(score)
print(type(nil))
print(undefined_name)
Output
nil
nil
nil

Reading a name nobody created is not an error in Lua: it is simply nil. That is convenient, and it is also how a typo hides: pirnt would be nil, and the error only appears when you try to call it.

local

Write local the first time you introduce a variable:

Lua
local name = "Ada"
local year = 1843
print(name .. " wrote the first program in " .. year)
Output
Ada wrote the first program in 1843

Without local, the assignment creates a global variable, visible to the whole program, including every other file and library it loads. Globals are slower and invite clashes between unrelated parts of a program. Lesson 3.05 covers scope in full; until then the rule is simple:

Every new variable starts with local

local count = 0, never just count = 0. The only things you make global on purpose are functions a task asks for by name.

Names are letters, digits and _, not starting with a digit. They are case-sensitive. A few words are reserved:

Text
and  break  do  else  elseif  end  false  for  function  goto  if  in
local  nil  not  or  repeat  return  then  true  until  while

Several at once

One assignment can set several variables. The values on the right are all worked out first, then assigned:

Lua
local a, b, c = 1, 2, 3
print(a, b, c)

local x, y = 10      -- y gets nil: there is no second value
print(x, y)

local p, q = 1, 2, 3 -- the extra 3 is dropped
print(p, q)

a, b = b, a          -- swap, with no temporary variable
print(a, b)
Output
1	2	3
10	nil
1	2
2	1

Booleans

true and false, the results of comparisons:

Lua
local adult = 20 >= 18
print(adult, type(adult), not adult)
Output
true	boolean	false

Lesson 1.05 shows how decisions use them, and a rule that surprises people from other languages: in Lua, 0 and "" count as true. Only false and nil are false.
