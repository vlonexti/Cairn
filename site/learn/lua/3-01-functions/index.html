Functions

lesson 3.011 of 5 in milestone 35 min1 practice task

Defining functions with function ... end, local functions, parameters and return, returning several values and where the extra values go, and functions that return nothing.

Defining and calling

Lua
local function greet(name)
    return "Hello, " .. name .. "!"
end

print(greet("Ada"))
print(greet("Lua"))
Output
Hello, Ada!
Hello, Lua!

local function name(parameters) ... end defines a function. return hands a value back to the caller and leaves the function at once. A function is defined when Lua runs the definition, so define it above the code that calls it.

Like variables, functions should be local unless something else needs to find them by name. In the practice tasks, the functions the task names are global (function greet(name)) so the tests can call them.

Parameters

A parameter is a local variable that starts with the value the caller passed. Lua does not check how many arguments you pass: missing ones are nil, extra ones are dropped.

Lua
local function describe(name, age)
    return name .. " is " .. tostring(age)
end

print(describe("Ada", 36))
print(describe("Ada"))
print(describe("Ada", 36, "ignored"))
Output
Ada is 36
Ada is nil
Ada is 36

The next lesson uses this to give parameters default values.

Returning several values

A function can return several values, and the caller can take as many as it wants:

Lua
local function min_max(list)
    local lo, hi = list[1], list[1]
    for _, v in ipairs(list) do
        if v < lo then lo = v end
        if v > hi then hi = v end
    end
    return lo, hi
end

local lo, hi = min_max({ 4, 9, 2, 7 })
print(lo, hi)
local just_lo = min_max({ 4, 9, 2, 7 })
print(just_lo)
Output
2	9
2

Lua's own functions do this too: string.find returns a start and an end, pcall returns a success flag and a result.

Where the extra values go

Every value of a call is kept only when the call is the last item in a list (of arguments, of a table constructor, of a return). Anywhere else, the call is cut down to its first value:

Lua
local function two() return 1, 2 end

print(two())            -- 1 2
print(two(), "x")       -- 1 x : not last, so only the first value
print("x", two())       -- x 1 2
print((two()))          -- 1 : brackets cut it to one value

local t = { two(), two() }
print(#t)               -- 3 : {1, 1, 2}
Output
1	2
1	x
x	1	2
1
3

Functions that return nothing

A function without return, or with a plain return, returns no values. Using its result gives nil:

Lua
local function log(message)
    print("[log] " .. message)
end

local result = log("started")
print(result)
Output
[log] started
nil
Printing is not returning

A function that prints its answer cannot be used in a calculation. When a task says "returns", use return; the tests read the returned value, not the printed text.

return must be the last statement in its block. To leave a function early from the middle, put it inside an if, which is the usual way anyway:

Lua
local function sign(n)
    if n > 0 then return 1 end
    if n < 0 then return -1 end
    return 0
end
print(sign(-5), sign(0), sign(8))
Output
-1	0	1
