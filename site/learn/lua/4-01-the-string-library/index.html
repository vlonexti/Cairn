The String Library

lesson 4.011 of 5 in milestone 45 min1 practice task

Method syntax s:upper(), sub with positive and negative positions, upper, lower, rep, reverse, byte and char, find with plain text, and walking through a string character by character.

Method syntax

Every string function lives in the table string, and every string knows it. So string.upper(s) can be written s:upper(): the colon passes the string as the first argument.

Lua
local s = "Hello, Lua"
print(string.upper(s), s:upper(), s:lower())
print(("abc"):rep(3), ("abc"):rep(3, "-"), s:reverse())
print(s:len(), #s)
Output
HELLO, LUA	HELLO, LUA	hello, lua
abcabcabc	abc-abc-abc	auL ,olleH
10	10

A string literal needs brackets around it before the colon: ("abc"):rep(3).

sub: pieces of a string

s:sub(i, j) returns the characters from position i to j, both included, counting from 1. Negative positions count from the end: -1 is the last character.

Lua
local s = "programming"
print(s:sub(1, 3), s:sub(4), s:sub(-4), s:sub(-4, -2))
print(s:sub(5, 5), s:sub(20), s:sub(3, 1) == "")
Output
pro	gramming	ming	min
r		true

sub never fails: positions past the end are clamped, and an empty range gives "". To get one character, use s:sub(i, i).

Characters and their codes

s:byte(i) gives the numeric code of the byte at position i; string.char turns codes back into text:

Lua
print(("A"):byte(), ("abc"):byte(1, 3))
print(string.char(72, 105, 33))

local shifted = {}
for i = 1, #"HAL" do
    shifted[i] = string.char(("HAL"):byte(i) + 1)
end
print(table.concat(shifted))
Output
65	97	98	99
Hi!
IBM

Walking through a string

Lua
local word = "banana"
local count = 0
for i = 1, #word do
    if word:sub(i, i) == "a" then count = count + 1 end
end
print(count)

local reversed = {}
for i = #word, 1, -1 do reversed[#reversed + 1] = word:sub(i, i) end
print(table.concat(reversed))
Output
3
ananab

Building a new string by ..-ing one character at a time works but copies the whole string each time. For anything long, collect the pieces in a table and table.concat once at the end.

find

s:find(text, start, true) looks for text and returns where it starts and ends, or nil:

Lua
local s = "one, two, three"
print(s:find("two", 1, true))
print(s:find("four", 1, true))
print(s:find(",", 6, true))
print(s:find(".", 1, true), s:find("."))
Output
6	8
nil
9	9
nil	1	1

The fourth argument true means plain search. Without it, the text is a pattern (next lesson), where . means "any character", which is why the last find(".") matched at 1. Always pass 1, true when you are searching for literal text that might contain . % - + * ? [ ] ( ) ^ $.

Using find to split at a separator:

Lua
local function split_once(s, sep)
    local at = s:find(sep, 1, true)
    if not at then return s, nil end
    return s:sub(1, at - 1), s:sub(at + #sep)
end
print(split_once("key=value", "="))
print(split_once("no separator", "="))
Output
key	value
no separator	nil

Comparing and testing

Lua
local a, b = "Lua", "lua"
print(a == b, a:lower() == b:lower())
print(("hello"):sub(1, 2) == "he", ("file.txt"):sub(-4) == ".txt")
Output
false	true
true	true
