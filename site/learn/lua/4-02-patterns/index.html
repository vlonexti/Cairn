Patterns

lesson 4.022 of 5 in milestone 45 min1 practice task

Lua patterns as a small alternative to regular expressions, the character classes %d %a %s %w and friends, sets in square brackets, the repeat signs + * - ?, anchors, captures, and string.match.

A small language for text

Lua does not have regular expressions. It has patterns, which do most of the same work with a much smaller set of rules. string.match(s, pattern) returns the first part of s that matches, or nil:

Lua
print(("order 66 shipped"):match("%d+"))
print(("hello"):match("%d+"))
print(("Version 5.4.7"):match("%d+%.%d+"))
Output
66
nil
5.4

Character classes

Class Matches Upper case = the opposite
. any character
%a letters %A not a letter
%d digits 0-9 %D
%l / %u lower / upper case letters
%s whitespace (space, tab, newline) %S
%w letters and digits %W
%p punctuation %P
%x hex digits

% also escapes the special characters: %. is a real dot, %% a real percent sign, %- a real minus. (Lua uses % where other languages use \.)

A set in square brackets matches one character from it: [aeiou] a vowel, [%w_] a letter, digit or underscore, [0-9a-f] a range. [^...] matches any character not in the set: [^,] anything but a comma.

Repeats

Sign Means
+ one or more, as many as possible
* zero or more, as many as possible
- zero or more, as few as possible
? optional: zero or one
Lua
local s = "<b>bold</b> and <i>it</i>"
print(s:match("<.*>"))      -- greedy: as much as possible
print(s:match("<.->"))      -- lazy: as little as possible
print(("-42"):match("^-?%d+$"), ("4-2"):match("^-?%d+$"))
Output
<b>bold</b> and <i>it</i>
<b>
-42	nil

Repeat signs apply to one character class only. Lua patterns cannot repeat a group: there is no (ab)+. When you need that, use a loop or a real parser.

Anchors

^ at the start of a pattern means "only at the start of the text", $ at the end means "only at the end". With both, the whole text must match, which is how you validate input:

Lua
local function is_whole_number(s) return s:match("^%d+$") ~= nil end
local function is_name(s) return s:match("^[%a_][%w_]*$") ~= nil end
print(is_whole_number("123"), is_whole_number("12a"), is_whole_number(""))
print(is_name("player_1"), is_name("1player"))
Output
true	false	false
true	false

Captures

Brackets mark captures: the parts you want back. match then returns each capture instead of the whole match:

Lua
local date = "2026-11-16"
local y, m, d = date:match("(%d+)-(%d+)-(%d+)")
print(y, m, d, tonumber(m) + 1)

local key, value = ("  volume = 11 "):match("^%s*(%w+)%s*=%s*(.-)%s*$")
print("[" .. key .. "]", "[" .. value .. "]")

print(("John Smith"):match("(%a+) (%a+)"))
Output
2026	11	16	12
[volume]	[11]
John	Smith

Captures are always strings: convert numbers with tonumber. %s*(.-)%s*$ is the standard way to capture something with the spaces around it trimmed.

Trimming on its own is so common it is worth writing once:

Lua
local function trim(s) return (s:match("^%s*(.-)%s*$")) end
print("[" .. trim("   padded text  ") .. "]")
Output
[padded text]

find works with patterns too and returns the position followed by the captures:

Lua
print(("x = 10"):find("(%d+)"))
Output
5	6	10
