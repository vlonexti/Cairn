Numbers and Arithmetic

lesson 1.033 of 5 in milestone 15 min1 practice task

Integers and floats inside the one number type, the operators including / and // and ^, how % works with negatives, the math library, converting with tonumber and tostring, and rounding.

Two kinds of number

Every number has type number, but Lua 5.4 keeps two subtypes apart: whole-number integers (64-bit) and floats (decimals, 64-bit doubles). math.type tells them apart:

Lua
print(math.type(3), math.type(3.0), math.type(1e3))
print(3 == 3.0)
Output
integer	float	float
true

An integer and a float with the same value are equal. The difference shows when you print them: a float always prints with a decimal point, so 3.0 prints as 3.0.

The operators

Operator Meaning Example Result
+ - * add, subtract, multiply 7 * 6 42
/ division, always a float 7 / 2, 6 / 2 3.5, 3.0
// floor division: round down 7 // 2, -7 // 2 3, -4
% remainder 7 % 3 1
^ power, always a float 2 ^ 10 1024.0
- negation -x
Lua
print(7 / 2, 6 / 2, 7 // 2, 7.5 // 2)
print(2 ^ 10, 10 % 3, -7 // 2, -7 % 3)
Output
3.5	3.0	3	3.0
1024.0	1	-4	2

Integer operations stay integers (+ - * // % with two integers). As soon as a float takes part, or you use / or ^, the result is a float.

// rounds down, towards minus infinity, so -7 // 2 is -4, not -3. % matches it: the result has the sign of the divisor, and a == (a // b) * b + a % b always holds. That makes n % 2 == 0 a reliable even test, also for negative n.

Precedence is the one from school: ^ first (and it groups right to left, 2^3^2 is 2^9), then unary minus and not, then * / // %, then + -. Use brackets whenever it is not obvious.

-2 ^ 2 is -4.0

^ binds tighter than the minus in front, so this is -(2 ^ 2). Write (-2) ^ 2 for 4.0.

The math library

Lua
print(math.floor(3.7), math.ceil(3.2), math.abs(-5))
print(math.max(4, 9, 2), math.min(4, 9, 2))
print(math.sqrt(16), math.pi)
print(math.maxinteger)
print(math.fmod(7, 3), math.tointeger(5.0))
Output
3	4	5
9	2
4.0	3.1415926535898
9223372036854775807
1	5

math.floor and math.ceil return integers when they can. math.huge is infinity, and math.random(1, 6) gives a random whole number from 1 to 6.

Integers wrap around past math.maxinteger (it becomes the most negative integer); floats do not wrap but lose precision past about 2^53.

Text to number and back

Input arrives as text. tonumber turns a string into a number, or gives nil if it cannot:

Lua
print(tonumber("42"), tonumber("3.5"), tonumber("  12  "))
print(tonumber("12abc"), tonumber("ff", 16), tonumber("1e2"))
print(tostring(42) .. "!")
Output
42	3.5	12
nil	255	100.0
42!

Lua also converts on its own in arithmetic: "10" + 1 is 11. Do not rely on that; convert input explicitly with tonumber and check for nil.

Rounding and showing decimals

There is no math.round. Round to the nearest whole number with math.floor(x + 0.5). To show a number with a fixed number of decimals, use string.format:

Lua
local price = 2.5 * 3.3333
print(price)
print(string.format("%.2f", price))
print(math.floor(price + 0.5))
print(string.format("%d items", 3))
Output
8.33325
8.33
8
3 items

%.2f means "a float with two decimals", %d a whole number. Lesson 4.04 covers every format.

%d needs a whole number

string.format("%d", 3.5) is an error: "number has no integer representation". 3.0 is fine.
