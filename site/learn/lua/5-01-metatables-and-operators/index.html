Metatables and Operators

lesson 5.011 of 5 in milestone 55 min1 practice task

What a metatable is, setmetatable and getmetatable, giving tables arithmetic with __add and friends, comparisons with __eq, __lt and __le, __tostring, __len, __concat and __call, and sharing one metatable between many tables.

Changing what operators do

Adding two tables is normally an error. A metatable is an ordinary table that changes how another table behaves: it holds metamethods, functions with special names that Lua calls when an operation would otherwise fail or needs a decision.

Lua
local mt = {}
mt.__add = function(a, b)
    return { x = a.x + b.x, y = a.y + b.y }
end

local p = setmetatable({ x = 1, y = 2 }, mt)
local q = setmetatable({ x = 10, y = 20 }, mt)
local r = p + q
print(r.x, r.y, getmetatable(p) == mt)
Output
11	22	true

setmetatable(t, mt) gives t the metatable mt and returns t, so it fits on one line with the constructor. getmetatable(t) reads it back.

When Lua sees p + q and p is not a number, it looks for __add in p's metatable, then in q's, and calls the first one it finds with both operands.

A small vector type

The usual pattern: one metatable for all values of the type, and a function that makes new ones.

Lua
local Vec = {}
Vec.__index = Vec        -- explained in the next lesson

local function vec(x, y) return setmetatable({ x = x, y = y }, Vec) end

Vec.__add = function(a, b) return vec(a.x + b.x, a.y + b.y) end
Vec.__sub = function(a, b) return vec(a.x - b.x, a.y - b.y) end
Vec.__mul = function(a, b)
    if type(a) == "number" then return vec(a * b.x, a * b.y) end
    if type(b) == "number" then return vec(a.x * b, a.y * b) end
    return a.x * b.x + a.y * b.y            -- two vectors: the dot product
end
Vec.__unm = function(a) return vec(-a.x, -a.y) end
Vec.__eq = function(a, b) return a.x == b.x and a.y == b.y end
Vec.__tostring = function(a) return "(" .. a.x .. ", " .. a.y .. ")" end
Vec.__len = function(a) return math.sqrt(a.x * a.x + a.y * a.y) end

local a, b = vec(3, 4), vec(1, 2)
print(tostring(a + b), tostring(a - b), tostring(2 * b), tostring(-a))
print(a * b, #a, a == vec(3, 4), a ~= b)
print(a)
Output
(4, 6)	(2, 2)	(2, 4)	(-3, -4)
11	5.0	true	true
(3, 4)

print calls tostring, which uses __tostring, so a vector prints nicely. __eq is only asked when both sides are tables (or both userdata); a ~= b is simply not (a == b).

Comparisons and sorting

With __lt, values can be compared with <, which also lets table.sort sort them without a comparison function:

Lua
local Money = {}
local function money(cents) return setmetatable({ cents = cents }, Money) end
Money.__lt = function(a, b) return a.cents < b.cents end
Money.__le = function(a, b) return a.cents <= b.cents end
Money.__tostring = function(m) return string.format("$%d.%02d", m.cents // 100, m.cents % 100) end
Money.__concat = function(a, b) return tostring(a) .. tostring(b) end

local prices = { money(450), money(99), money(1200) }
table.sort(prices)
print(prices[1] .. " < " .. prices[2] .. " < " .. prices[3])
print(money(5) <= money(5), money(7) > money(3))
Output
$0.99 < $4.50 < $12.00
true	true

__concat receives the two operands, one of which may be a string, which is why it calls tostring on both.

Calling a table

__call makes a table callable. The table itself arrives as the first argument:

Lua
local greeter = setmetatable({ greeting = "Hello" }, {
    __call = function(self, name) return self.greeting .. ", " .. name .. "!" end,
})
print(greeter("Ada"))
greeter.greeting = "Hi"
print(greeter("Lua"))
Output
Hello, Ada!
Hi, Lua!

Only tables (from Lua)

From Lua code you can set metatables on tables only. Strings share one metatable set by the library, which is what makes s:upper() work: its __index is the string table.

Lua
print(getmetatable("").__index == string)
Output
true
