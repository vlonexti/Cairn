Optional and Variable Arguments

lesson 3.022 of 5 in milestone 35 min1 practice task

Default values with or, when or is wrong for booleans, functions that take any number of arguments with ..., select and table.pack, and named arguments passed in a table.

Defaults

A missing argument is nil, and x or default replaces nil:

Lua
local function repeat_text(text, times, sep)
    times = times or 2
    sep = sep or " "
    local parts = {}
    for i = 1, times do parts[i] = text end
    return table.concat(parts, sep)
end

print(repeat_text("ha"))
print(repeat_text("ha", 3))
print(repeat_text("ha", 3, "-"))
Output
ha ha
ha ha ha
ha-ha-ha
or swallows false

verbose = verbose or true makes verbose true even when the caller passed false. For a boolean (or any parameter where false is meaningful), test for nil: if verbose == nil then verbose = true end.

Any number of arguments

Three dots as the last parameter collect every extra argument. Inside the function, ... stands for all of them:

Lua
local function sum(...)
    local total = 0
    for _, n in ipairs({ ... }) do
        total = total + n
    end
    return total
end

print(sum(), sum(5), sum(1, 2, 3, 4))
Output
0	5	10

{ ... } packs them into a list. Named parameters can come first: local function printf(format, ...).

Lua
local function printf(format, ...)
    io.write(string.format(format, ...))
end

printf("%s has %d items, %.1f%% full\n", "bag", 3, 37.5)
Output
bag has 3 items, 37.5% full

Passing ... on to another function forwards every value unchanged. (%% in a format is a literal %.)

nil among the arguments

{ ... } and ipairs stop at the first nil, so they lose arguments after one. When nil can be an argument, use select or table.pack:

Lua
local function count(...)
    return select("#", ...)
end
print(count(1, nil, 3), count())

local function show_all(...)
    local args = table.pack(...)
    for i = 1, args.n do
        io.write(i, "=", tostring(args[i]), " ")
    end
    print()
end
show_all("a", nil, "c")

print(select(2, "a", "b", "c"))
Output
3	0
1=a 2=nil 3=c 
b	c
  • select("#", ...) is the number of arguments, nils included.
  • select(n, ...) gives argument n and everything after it.
  • table.pack(...) gives a table with the count in its field n.

Named arguments

When a function has many optional settings, take a single table and read fields from it. The call reads almost like a sentence, and you can leave out anything:

Lua
local function make_window(options)
    local title = options.title or "Untitled"
    local width = options.width or 640
    local height = options.height or 480
    return title .. " (" .. width .. "x" .. height .. ")"
end

print(make_window({ title = "Editor", width = 1024 }))
print(make_window{ height = 200 })
Output
Editor (1024x480)
Untitled (640x200)

When a function's only argument is a table constructor or a string literal, the brackets can be left out: make_window{ ... }, print "hi". You will see this in configuration files and in libraries. Use it sparingly in your own code.
