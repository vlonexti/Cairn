Lua

8 milestones38 lessons49 practice tasks40 projects

Lua is small, fast and made to live inside other programs: games, game engines, editors, databases and network tools use it for their scripting. Starting from the first line, the course covers values and types, numbers, strings and input, decisions and loops, the table (Lua's one data structure, used as list, dictionary, record and object), functions, closures and recursion, the string library and Lua patterns, metatables, classes and inheritance, modules, errors, iterators, coroutines, files, how Lua is embedded in a C program, and finally sandboxes for untrusted code, weak tables and the garbage collector, and bitwise operators and binary data, then data structures, functional style, serialisation and JSON, object patterns and performance. Every lesson has checked practice that runs real Lua 5.4, and every milestone ends with five projects, from small to large.
