Integers, Bitwise Operators and Binary Data

lesson 7.033 of 3 in milestone 75 min2 practice tasks

Lua's 64-bit integers in depth - integer and float subtypes, floor division and wrap-around, the bitwise operators &, |, ~, <<, >> and ~x, flags and masks, unsigned comparison with math.ult, and reading and writing binary formats with string.pack and string.unpack.

Two kinds of number

Since Lua 5.3 a number is either an integer (64-bit, exact) or a float (a double). They print and compare naturally, but they are different subtypes (lesson 1.03):

Lua
print(math.type(3), math.type(3.0), math.type("3"))   --> integer float nil
print(3 == 3.0, 7 // 2, 7.0 // 2, 7 / 2)               --> true 3 3.0 3.5
print(math.maxinteger + 1 == math.mininteger)          --> true: integers wrap around
print(math.tointeger(5.0), math.tointeger(5.5))        --> 5 nil

// is floor division (it rounds down, also for negative numbers: -7 // 2 is -4) and % follows it so that a == (a // b) * b + a % b. / always gives a float.

The bitwise operators

They work on integers (floats with an exact integer value are converted; others are an error):

Operator Meaning Example
a & b AND 0xF0 & 0x3C is 0x30
a | b OR 0xF0 | 0x0F is 0xFF
a ~ b exclusive OR 0xFF ~ 0x0F is 0xF0
~a NOT (flip every bit) ~0 is -1
a << n shift left 1 << 4 is 16
a >> n logical shift right (fills with zeros) -1 >> 60 is 15
Lua
local READ, WRITE, EXEC = 1 << 0, 1 << 1, 1 << 2

local perms = READ | EXEC
print(perms & WRITE ~= 0, perms & EXEC ~= 0)    --> false true
perms = perms | WRITE                           -- grant
perms = perms & ~EXEC                           -- revoke
perms = perms ~ READ                            -- toggle
print(perms)                                    --> 2: only WRITE is left

string.format has no binary format, so print bits yourself:

Lua
local function bits(n, width)
    local out = {}
    for i = width - 1, 0, -1 do
        out[#out + 1] = (n >> i) & 1
    end
    return table.concat(out)
end

print(bits(5, 8), bits(0xA5, 8))   --> 00000101 10100101
print(string.format("%x %X %08x", 255, 255, 0xBEEF))

Note that ~ means two different things: between two values it is XOR, in front of one value it is NOT. And ~= is still "not equal".

Unsigned numbers

Lua's integers are signed, but bit patterns are often unsigned (hashes, IDs, colours). Addition, multiplication and the bitwise operators give the same bits either way; only comparison and division differ. math.ult(a, b) compares as unsigned, and string.format("%u") is not available, but %x shows the bits:

Lua
local big = 0xFFFFFFFFFFFFFFFF               -- all 64 bits set
print(big, math.ult(1, big), 1 < big)        --> -1 true false

A 32-bit hash with masks

Many algorithms are defined for 32-bit unsigned arithmetic. Masking with & 0xFFFFFFFF after each step gives exactly that in Lua's 64-bit integers:

Lua
local function fnv1a(text)
    local hash = 0x811C9DC5
    for i = 1, #text do
        hash = hash ~ text:byte(i)
        hash = (hash * 0x01000193) & 0xFFFFFFFF
    end
    return hash
end

print(string.format("%08x", fnv1a("hello")))   --> 4f9f2cab

Binary data with string.pack

string.pack(format, ...) turns values into a string of bytes in an exact layout, and string.unpack(format, s, pos) reads them back, returning the values and the position after them (lesson 4.05 introduced them):

Code Meaning
< > little-endian, big-endian
b B signed, unsigned 1-byte integer
h H 2-byte integer
i4 I4 4-byte integer (any size from 1 to 16)
d f double, float
s1 s2 s4 a string preceded by its length in 1, 2 or 4 bytes
z a zero-terminated string
Lua
local record = string.pack("<I2 s1 d", 512, "Ada", 98.5)
print(#record, string.format(("%02x "):rep(#record), record:byte(1, -1)))

local id, name, score, next_pos = string.unpack("<I2 s1 d", record)
print(id, name, score, next_pos)              --> 512 Ada 98.5 15

Spaces in the format are ignored and help readability. string.packsize(fmt) gives the size of a format with no variable-length parts.
