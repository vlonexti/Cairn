Classes and Objects

lesson 5.033 of 5 in milestone 55 min1 practice task

Methods and the colon, self, the class pattern with a metatable whose __index is the class, a constructor called new, keeping methods shared and data per object, and the dot-versus-colon mistake.

Methods and self

A table can hold functions that work on that table. Lua passes the table explicitly, as a parameter named self by convention, and the colon writes that for you:

Lua
local account = { owner = "Ada", balance = 100 }

function account.deposit(self, amount)       -- the long way
    self.balance = self.balance + amount
end

function account:withdraw(amount)            -- the colon adds self
    self.balance = self.balance - amount
end

account.deposit(account, 50)                 -- the long way
account:withdraw(30)                         -- the colon passes account as self
print(account.balance)
Output
120

function t:name(args) means function t.name(self, args), and t:name(args) means t.name(t, args). That is all the colon does.

A class

One account is easy. For many, put the methods in one table, the class, and give every object a metatable whose __index is the class. Each object holds only its own data; a missing key (a method name) falls back to the class:

Lua
local Account = {}
Account.__index = Account

function Account.new(owner, balance)
    local self = setmetatable({}, Account)
    self.owner = owner
    self.balance = balance or 0
    return self
end

function Account:deposit(amount)
    if amount <= 0 then error("deposit must be positive", 2) end
    self.balance = self.balance + amount
    return self.balance
end

function Account:report()
    return string.format("%s has %d", self.owner, self.balance)
end

local a = Account.new("Ada", 100)
local b = Account.new("Grace")
a:deposit(25)
b:deposit(10)
print(a:report())
print(b:report())
print(a.deposit == b.deposit, rawget(a, "deposit"))
Output
Ada has 125
Grace has 10
true	nil

The pieces:

  • Account is both the class (it holds the methods) and the objects' metatable.
  • Account.__index = Account sends every missing key, every method name, to the class.
  • Account.new is the constructor: it makes a table, sets the metatable, fills in the fields.
  • Methods are defined once; every object shares them.

new is called with a dot (Account.new(...)) because it does not work on an existing object. Some code writes Account:new(...) and uses self as the class inside; both styles are common.

Metamethods in the class

Because the class is the metatable, metamethods go in the same table:

Lua
local Point = {}
Point.__index = Point

function Point.new(x, y) return setmetatable({ x = x, y = y }, Point) end
function Point:distance_to(other)
    return math.sqrt((self.x - other.x) ^ 2 + (self.y - other.y) ^ 2)
end
function Point.__tostring(p) return "Point(" .. p.x .. ", " .. p.y .. ")" end
function Point.__eq(a, b) return a.x == b.x and a.y == b.y end

local p, q = Point.new(0, 0), Point.new(3, 4)
print(p, q, p:distance_to(q), p == Point.new(0, 0))
Output
Point(0, 0)	Point(3, 4)	5.0	true

Dot or colon?

The most common object bug in Lua

Calling a method with a dot, a.deposit(25), passes 25 as self and nothing as amount, and the error is confusing: "attempt to index a number value (local 'self')". Methods are called with a colon: a:deposit(25).

Lua
local Counter = {}
Counter.__index = Counter
function Counter.new() return setmetatable({ n = 0 }, Counter) end
function Counter:add() self.n = self.n + 1 end

local c = Counter.new()
print(pcall(c.add))      -- like c.add() : self is nil
c:add()
print(c.n)
Output
false	main.lua:4: attempt to index a nil value (local 'self')
1

Private data

Fields of a table are visible to anyone who has the table. When a value must stay private, keep it in a closure instead of a field. Each object then carries its own functions, which costs more memory but nothing outside can reach the data:

Lua
local function new_stack()
    local items = {}                         -- private: only the functions below see it
    return {
        push = function(v) items[#items + 1] = v end,
        pop = function() return table.remove(items) end,
        size = function() return #items end,
    }
end

local s = new_stack()
s.push(1); s.push(2); s.push(3)
print(s.pop(), s.size(), s.items)
Output
3	2	nil

These are called with a dot: they are closures, not methods, and need no self.
