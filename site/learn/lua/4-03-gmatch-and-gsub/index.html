gmatch and gsub

lesson 4.033 of 5 in milestone 45 min1 practice task

Looping over every match with gmatch, splitting text into words, lines and fields, replacing with gsub using a string, %1 captures, a table or a function, counting replacements, and %f for whole words.

gmatch: every match

s:gmatch(pattern) gives every match in turn, for use in a for loop:

Lua
local text = "The quick brown fox, the lazy dog."
local words = {}
for word in text:gmatch("%a+") do
    words[#words + 1] = word:lower()
end
print(#words, table.concat(words, " "))

for key, value in ("a=1, b=22, c=333"):gmatch("(%w+)=(%w+)") do
    io.write(key, "->", value, " ")
end
print()
Output
7	the quick brown fox the lazy dog
a->1 b->22 c->333

With captures in the pattern, each round gets the captures.

Splitting

Lua has no split function; gmatch with a "not the separator" set does it:

Lua
local function split(s, sep)
    local out = {}
    for field in (s .. sep):gmatch("(.-)" .. sep:gsub("%p", "%%%0")) do
        out[#out + 1] = field
    end
    return out
end

local parts = split("red,green,,blue", ",")
print(#parts, table.concat(parts, "|"))

for line in ("first\nsecond\nthird"):gmatch("[^\n]+") do io.write("<", line, "> ") end
print()

local nums = {}
for n in ("4 8  15 16"):gmatch("%S+") do nums[#nums + 1] = tonumber(n) end
print(#nums, nums[3] + nums[4])
Output
4	red|green||blue
<first> <second> <third> 
4	31

The split function keeps empty fields (,, gives ""): adding one separator at the end makes every field end with a separator, and (.-) then takes each field up to it. sep:gsub("%p", "%%%0") escapes punctuation in the separator so that "." means a real dot. When you only need the non-empty pieces, [^,]+ and %S+ are simpler.

gsub: replacing

s:gsub(pattern, replacement) returns a new string with every match replaced, and the number of replacements:

Lua
print(("hello world"):gsub("o", "0"))
print(("hello world"):gsub("o", "0", 1))
local cleaned = ("too    many   spaces"):gsub("%s+", " ")
print(cleaned)
Output
hell0 w0rld	2
hell0 world	1
too many spaces

The optional fourth argument limits the number of replacements. Because gsub returns two values, print(s:gsub(...)) shows the count too; assign to one variable, or wrap it in brackets, to keep only the string.

Using the captures

In the replacement string, %1 is the first capture, %2 the second, %0 the whole match:

Lua
print(("2026-11-16"):gsub("(%d+)-(%d+)-(%d+)", "%3/%2/%1"))
print(("John Smith"):gsub("(%a+) (%a+)", "%2, %1"))
print(("cat dog"):gsub("%a+", "<%0>"))
Output
16/11/2026	1
Smith, John	1
<cat> <dog>	2

A table or a function as the replacement

With a table, each match is looked up in it; a match with no entry is left alone. With a function, it is called with the captures and its result is used (returning nil or false keeps the original):

Lua
local vars = { name = "Ada", lang = "Lua" }
print((("Hi $name, welcome to $lang. $missing stays."):gsub("%$(%w+)", vars)))

local function title_case(s)
    return (s:gsub("(%a)(%a*)", function(first, rest)
        return first:upper() .. rest:lower()
    end))
end
print(title_case("the LORD of the rings"))

print((("1 2 3 4"):gsub("%d+", function(n) return tostring(tonumber(n) * 10) end)))
Output
Hi Ada, welcome to Lua. $missing stays.
The Lord Of The Rings
10 20 30 40

Templates, escaping, renaming: almost every text tool in Lua is a gsub with a function.

Counting

The second result of gsub makes counting easy. Replace each match with itself ("%0") or with anything, and keep only the count:

Lua
local text = "she sells sea shells"
local _, s_count = text:gsub("s", "s")
local _, words = text:gsub("%S+", "")
print(s_count, words)
Output
6	4

Whole words

%f[set] is a frontier: it matches the empty position where the previous character is not in the set and the next one is. %f[%w]word%f[%W] finds word only as a whole word:

Lua
local s = "cat concat cat's catalogue"
print((s:gsub("%f[%w]cat%f[%W]", "DOG")))
Output
DOG concat DOG's catalogue
