What Lua Is and Running Code

lesson 1.011 of 5 in milestone 15 min1 practice task

Where Lua came from and where it runs today (games, editors, databases, network tools), how a Lua program runs from top to bottom, print, comments, and how to read an error message.

A language made to live inside programs

Lua (Portuguese for moon) was created in 1993 at the Pontifical Catholic University of Rio de Janeiro by Roberto Ierusalimschy, Luiz Henrique de Figueiredo and Waldemar Celes. They needed a small language that engineers could use to configure and script their programs, and they built one that fits in a few hundred kilobytes, starts instantly and is written in plain C.

That design is why Lua turns up inside so many other programs. A program written in C or C++ embeds Lua: it carries the Lua interpreter along, and lets users write Lua scripts that call into it. You have probably used Lua without knowing:

Where What Lua does there
Roblox Its scripting language, Luau, grew out of Lua 5.1
World of Warcraft Every add-on and interface mod is Lua
LÖVE, Defold, Solar2D Whole 2D games are written in Lua
Neovim Its configuration and plugins are Lua
Redis Scripts that run inside the database
nginx (OpenResty), HAProxy Request handling in web servers
Wireshark Protocol decoders
Adobe Lightroom Much of the application itself

This course teaches Lua 5.4, the current standard version. What you learn carries over directly to Luau, LuaJIT and every embedded Lua; lesson 6.05 lists the differences.

The first program

Lua
print("Hello, Lua!")
Output
Hello, Lua!

Press Run on any example in these lessons to run it yourself. print writes its arguments and ends the line. A Lua program is a list of statements run from the top down; there is no main to write.

print takes any number of values and separates them with a tab:

Lua
print("one", 2, 3.5)
print()
print("after an empty line")
Output
one	2	3.5

after an empty line

Statements may end with ;, but nobody writes it. Line breaks do not matter to Lua either; you could put two statements on one line. Write one per line, indented with four spaces where something is inside something else.

Comments

Lua
-- Two dashes start a comment that runs to the end of the line.
print("code")   -- after code, too

--[[
    A long comment spans
    several lines.
]]
print("done")
Output
code
done

When something goes wrong

Lua reads the whole file before it runs anything. A syntax error stops it from starting at all, and the message names the file, the line and what was wrong near where:

Lua
print("Hello"
print("again")
Text
main.lua:2: ')' expected (to close '(' at line 1) near 'print'

The mistake is on line 1 (a missing )), but Lua only notices when it reaches line 2. Look at the line named and the line before it.

A run-time error happens while the program runs. Everything before it has already happened:

Lua
print("first")
print(10 + nil)
print("never printed")
Output
first
lua: main.lua:2: attempt to perform arithmetic on a nil value
stack traceback:
	main.lua:2: in main chunk

The stack traceback lists where the program was, newest first. For now, the first line is the one to read: main.lua:2 and what went wrong.

Lua is case-sensitive

print, Print and PRINT are three different names. Only the first one exists.
