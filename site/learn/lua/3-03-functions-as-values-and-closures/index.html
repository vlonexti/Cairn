Functions as Values and Closures

lesson 3.033 of 5 in milestone 35 min1 practice task

Functions are values you can store, pass and return, anonymous functions, writing map, filter and reduce, closures that remember the variables around them, counters and factories, and the loop variable being fresh each round.

Functions are values

local function add(a, b) ... end is a shorter way of writing local add = function(a, b) ... end. A function is a value of type function, like a number or a table, so it can be stored in variables and tables, passed to other functions and returned from them:

Lua
local function double(x) return x * 2 end
local twice = double
print(twice(21), type(double))

local ops = {
    add = function(a, b) return a + b end,
    mul = function(a, b) return a * b end,
}
print(ops.add(2, 3), ops["mul"](2, 3))
Output
42	function
5	6

A function written without a name (function(a, b) ... end) is an anonymous function. You met one already as the comparison passed to table.sort.

Functions that take functions

A function that takes or returns another function is a higher-order function. The three classic ones work on lists:

Lua
local function map(list, f)
    local out = {}
    for i, v in ipairs(list) do out[i] = f(v) end
    return out
end

local function filter(list, keep)
    local out = {}
    for _, v in ipairs(list) do
        if keep(v) then out[#out + 1] = v end
    end
    return out
end

local function reduce(list, f, start)
    local acc = start
    for _, v in ipairs(list) do acc = f(acc, v) end
    return acc
end

local nums = { 1, 2, 3, 4, 5, 6 }
print(table.concat(map(nums, function(x) return x * x end), " "))
print(table.concat(filter(nums, function(x) return x % 2 == 0 end), " "))
print(reduce(nums, function(a, b) return a + b end, 0))
Output
1 4 9 16 25 36
2 4 6
21

Lua has none of these built in; programs write them (or take them from a library) when they want them.

Closures

A function can use the local variables of the function it was written inside, even after that outer function has returned. The inner function together with the variables it remembers is a closure:

Lua
local function make_counter()
    local count = 0
    return function()
        count = count + 1
        return count
    end
end

local a = make_counter()
local b = make_counter()
print(a(), a(), a())
print(b())
Output
1	2	3
1

Each call of make_counter creates a new count, and the returned function keeps it alive. a and b have separate counters. The remembered variables are called upvalues.

Closures are how Lua code keeps private state without objects:

Lua
local function make_multiplier(factor)
    return function(x) return x * factor end
end

local triple = make_multiplier(3)
local half = make_multiplier(0.5)
print(triple(7), half(7))
Output
21	3.5

Shared, not copied

A closure shares the variable itself, not a copy of its value. Two closures made in the same call share the same variable:

Lua
local function make_account(balance)
    local function deposit(n) balance = balance + n end
    local function get() return balance end
    return deposit, get
end

local deposit, get = make_account(100)
deposit(25)
deposit(5)
print(get())
Output
130

The loop variable of a for is a new local in every round, so closures made in a loop each remember their own value:

Lua
local buttons = {}
for i = 1, 3 do
    buttons[i] = function() return "button " .. i end
end
print(buttons[1](), buttons[3]())
Output
button 1	button 3

(In some languages every one of those would say "button 3". In Lua each round has its own i.)
