Strings and Formatting

lesson 1.044 of 5 in milestone 15 min1 practice task

Working with text - string literals, escapes, verbatim and raw strings, interpolation with format specifiers and alignment, the common string methods, comparing strings, characters, and building text efficiently with StringBuilder.

String literals

C#
string plain = "Tab:\tQuote:\" Backslash:\\ Newline:\nnext line";
string path = @"C:\Users\Ada\notes.txt";        // verbatim: backslashes are literal
string json = """
    { "name": "Ada", "tags": ["math"] }
    """;                                         // raw string: no escaping at all
Console.WriteLine(plain);
Console.WriteLine(path);
Console.WriteLine(json);

Raw strings (three or more quotes) keep everything exactly, which suits JSON, SQL and regular expressions. The indentation of the closing quotes is removed from every line.

Interpolation and formatting

C#
string name = "Ada";
decimal price = 1234.5m;
double ratio = 0.4567;
int n = 42;
Console.WriteLine($"{name} paid {price:C2}");         // currency, depends on the machine's culture
Console.WriteLine($"{price:N2}");                     // 1,234.50
Console.WriteLine($"{price:F1}");                     // 1234.5
Console.WriteLine($"{ratio:P1}");                     // 45.7 %
Console.WriteLine($"{n:D5} {n:X}");                   // 00042 2A
Console.WriteLine($"[{name,8}] [{name,-8}]");         // right- and left-aligned in 8 characters
Console.WriteLine($"[{price,10:F2}]");                // alignment and format together
Console.WriteLine($"{(n > 40 ? "big" : "small")}");   // expressions in parentheses

After the value, ,width aligns (negative means left) and :format formats. Common formats: F2 fixed decimals, N2 with thousands separators, P percent, D5 zero-padded integer, X hexadecimal, C currency. For dates: {DateTime.Now:yyyy-MM-dd}.

N, C and dates follow the computer's culture. Output meant for files or other programs should use CultureInfo.InvariantCulture: price.ToString("F2", CultureInfo.InvariantCulture).

String methods

Strings never change: each method returns a new string.

Code Gives
s.Length, s[0], s[^1] Length, first character, last character
s.Substring(start, length), s[2..5] Part of the string
s.ToUpper(), s.ToLower(), s.Trim() Case, without surrounding spaces
s.Contains(x), s.StartsWith(x), s.EndsWith(x) Tests
s.IndexOf(x), s.LastIndexOf(x) Position, or -1
s.Replace(a, b), s.Insert(i, x), s.Remove(i, n) New strings with changes
s.Split(','), string.Join(", ", parts) Split into an array, join back
s.PadLeft(5, '0'), s.PadRight(10) Padded
string.IsNullOrWhiteSpace(s) Null, empty or only spaces
C#
string line = "  Ada Lovelace, 1815 , mathematician ";
string[] parts = line.Split(',', StringSplitOptions.TrimEntries);
Console.WriteLine(parts[0].ToUpper());
Console.WriteLine(int.Parse(parts[1]) + 200);
Console.WriteLine(string.Join(" | ", parts));
Console.WriteLine("banana".Replace("an", "AN") + " " + "banana".IndexOf('n') + " " + "banana"[1..4]);

[1..4] is a range: from index 1 up to, not including, 4. ^1 counts from the end.

Comparing

== compares string contents. For case-insensitive comparison, use string.Equals(a, b, StringComparison.OrdinalIgnoreCase); for sorting, string.Compare(a, b, StringComparison.Ordinal).

Characters

C#
char c = 'b';
Console.WriteLine(char.IsLetter(c) + " " + char.IsDigit('7') + " " + char.ToUpper(c));
Console.WriteLine((int)c);            // 98: its character code
Console.WriteLine((char)(c + 1));     // 'c'
foreach (char ch in "hi!") Console.Write($"[{ch}]");
Console.WriteLine();

Building strings

Because strings are immutable, += in a loop copies the whole string each time. For many pieces, use a StringBuilder:

C#
using System.Text;

var sb = new StringBuilder();
for (int i = 1; i <= 5; i++) sb.Append(i).Append(i < 5 ? ", " : "\n");
sb.AppendLine("done");
Console.Write(sb.ToString());
