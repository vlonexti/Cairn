Variables and Types

lesson 1.022 of 5 in milestone 15 min1 practice task

Declaring variables with explicit types and var, the built-in value types - int, long, double, decimal, bool, char - and string, constants, default values, value versus reference types, and converting between types with casts, Parse, TryParse and Convert.

Declaring variables

Every variable in C# has a type that never changes:

C#
int count = 3;
double price = 2.50;
string name = "Ada";
bool done = false;
char grade = 'A';                  // a single character, in single quotes

var total = count * price;         // var: the compiler infers the type (double here)
const int MaxPlayers = 4;          // a constant: fixed at compile time

count = count + 1;                 // fine
// count = "four";                 // error CS0029: cannot convert string to int
Console.WriteLine($"{name}: {count} x {price} = {total}, max {MaxPlayers}, grade {grade}, done {done}");

var is still statically typed: var total is a double, decided once. Use var when the type is obvious from the right-hand side (var list = new List<int>()), and the explicit type when it helps the reader.

Names use camelCase for local variables and PascalCase for constants, methods, classes and properties.

Number types

Type Holds Example
int Whole numbers, about ±2.1 billion 42
long Whole numbers, about ±9.2 × 10¹⁸ 42L
double Floating point, about 15 digits 3.14
float Floating point, about 7 digits 3.14f
decimal Exact decimal, 28 digits: money 19.99m
byte 0 to 255 (byte)200
C#
Console.WriteLine(0.1 + 0.2);          // 0.30000000000000004: binary floating point
Console.WriteLine(0.1m + 0.2m);        // 0.3: decimal is exact for decimal fractions
Console.WriteLine(int.MaxValue);
int big = int.MaxValue;
big = big + 1;                          // wraps around silently
Console.WriteLine(big);
Console.WriteLine(1_000_000);           // underscores make long numbers readable

Use int for counts, double for measurements and science, and decimal for money. checked { ... } turns silent overflow into an OverflowException.

Value types and reference types

Numbers, bool, char and structs (lesson 3.02) are value types: the variable holds the value itself, and assigning copies it. Strings, arrays, lists and classes are reference types: the variable holds a reference to an object, and assigning copies the reference, so both variables see the same object.

C#
int a = 1;
int b = a;          // a copy
b = 2;
Console.WriteLine(a);              // 1

int[] x = { 1, 2, 3 };
int[] y = x;        // the same array
y[0] = 99;
Console.WriteLine(x[0]);           // 99

string is a reference type that behaves like a value: strings can never be changed (they are immutable), so sharing them is safe.

Converting

C#
int whole = (int)3.99;                 // explicit cast: cuts off to 3
double d = 7;                          // int to double is automatic (no information lost)
long l = 5;                            // int to long too
int parsed = int.Parse("123");         // text to number; throws FormatException for "12x"
bool ok = int.TryParse("12x", out int value);   // false, value is 0: no exception
double rate = double.Parse("2.5", System.Globalization.CultureInfo.InvariantCulture);
string text = 42.ToString();
Console.WriteLine($"{whole} {d} {l} {parsed} {ok} {value} {rate} {text}");

Conversions that may lose information need a cast (type). For user input, prefer TryParse: it returns false instead of throwing. Parsing decimals depends on the computer's culture (2.5 or 2,5), so pass CultureInfo.InvariantCulture when reading data files.

Default values

Fields and array elements start with default values: 0 for numbers, false, '\0', and null for reference types. Local variables have no default: using one before assigning it is error CS0165.
