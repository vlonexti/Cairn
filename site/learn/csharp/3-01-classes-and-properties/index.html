Classes and Properties

lesson 3.011 of 5 in milestone 35 min1 practice task

Defining classes with fields, constructors and methods, properties with get, set, init and validation, auto-properties and required members, primary constructors, access modifiers and encapsulation, object initializers, ToString, and reference semantics.

A class

A class describes a kind of object: the data each one holds and what it can do. new creates an instance:

C#
var acc = new BankAccount("Ada", 100m);
acc.Deposit(50m);
Console.WriteLine(acc.Withdraw(500m));     // False
Console.WriteLine(acc);                    // calls ToString

public class BankAccount
{
    private decimal _balance;              // a field: private data

    public BankAccount(string owner, decimal opening)    // the constructor
    {
        Owner = owner;
        Deposit(opening);
    }

    public string Owner { get; }           // a read-only auto-property

    public decimal Balance => _balance;    // a computed, read-only property

    public void Deposit(decimal amount)
    {
        if (amount < 0) throw new ArgumentOutOfRangeException(nameof(amount), "must not be negative");
        _balance += amount;
    }

    public bool Withdraw(decimal amount)
    {
        if (amount > _balance) return false;
        _balance -= amount;
        return true;
    }

    public override string ToString() => $"{Owner}: {_balance:F2}";
}

Encapsulation: the balance can only change through Deposit and Withdraw, which keep it valid. Nothing outside the class can set it to -1000.

Modifier Visible to
public All code
private Only this class (the default for members)
protected This class and classes derived from it
internal This project (assembly); the default for classes

Properties

A property looks like a field from outside but runs code. Auto-properties generate the hidden field for you:

C#
var p = new Product { Name = "Tea", Price = 2.5m };
p.Price = 3m;
Console.WriteLine($"{p.Name} {p.Price} {p.Sku}");
try { p.Price = -1; } catch (ArgumentException e) { Console.WriteLine(e.Message); }

public class Product
{
    public required string Name { get; init; }      // must be set when created, then fixed
    public string Sku { get; } = Guid.NewGuid().ToString()[..8];   // read-only, with an initial value

    private decimal _price;
    public decimal Price
    {
        get => _price;
        set
        {
            if (value < 0) throw new ArgumentException("price must not be negative");
            _price = value;                         // value is what was assigned
        }
    }
}
Accessors Meaning
{ get; set; } Read and write
{ get; } Set only in the constructor or initializer
{ get; init; } Set only when the object is created (in an object initializer)
{ get; private set; } Anyone reads, only the class writes

required makes the compiler insist the property is set in the object initializer new Product { Name = ... }.

Primary constructors

A class can take constructor parameters right after its name. They are in scope in the whole class:

C#
var t = new Temperature(21.5);
Console.WriteLine($"{t.Celsius} C = {t.Fahrenheit} F");

public class Temperature(double celsius)
{
    public double Celsius => celsius;
    public double Fahrenheit => celsius * 9 / 5 + 32;
}

Objects are references

Variables of a class type hold references. Two variables can point at the same object, and == checks whether they are the same object, not whether they hold equal data:

C#
var a = new Point { X = 1, Y = 2 };
var b = a;
var c = new Point { X = 1, Y = 2 };
b.X = 10;
Console.WriteLine($"{a.X} {a == b} {a == c}");    // 10 True False

public class Point { public int X { get; set; } public int Y { get; set; } }

For value-based equality, use a record (next lesson).

Designing a class

  • Keep fields private; expose what callers need through methods and properties.
  • Check arguments in constructors and setters, so an object can never be in an invalid state.
  • Make properties read-only (get / init) unless something really needs to change them later.
  • Name classes with nouns (Invoice) and methods with verbs (AddLine).
