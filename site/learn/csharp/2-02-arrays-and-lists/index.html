Arrays and Lists

lesson 2.022 of 5 in milestone 25 min1 practice task

Fixed-size arrays and growable List<T> - creating, indexing, ranges and Index from the end, iterating, adding, inserting and removing, searching, sorting with comparisons, copying versus sharing, collection expressions, and two-dimensional and jagged arrays.

Arrays

An array holds a fixed number of values of one type:

C#
int[] scores = new int[3];            // three zeros
scores[0] = 90;
scores[2] = 75;
string[] days = { "Mon", "Tue", "Wed" };
int[] primes = [2, 3, 5, 7, 11];      // a collection expression (C# 12)

Console.WriteLine(scores.Length);
Console.WriteLine(days[^1]);          // last item
Console.WriteLine(string.Join(",", primes[1..3]));   // 3,5
Console.WriteLine(string.Join(" ", scores));

Indexes start at 0. Reading scores[3] throws an IndexOutOfRangeException: C# always checks bounds.

List<T>

A List grows and shrinks. List<string> is a list of strings: the type in angle brackets is a type argument (generics, lesson 4.01).

C#
var names = new List<string> { "Grace", "Ada" };
names.Add("Linus");
names.Insert(0, "Ken");
names.Remove("Grace");               // by value; returns false if not found
names.RemoveAt(names.Count - 1);     // by index
Console.WriteLine($"{names.Count}: {string.Join(", ", names)}");
Console.WriteLine(names.Contains("Ada") + " " + names.IndexOf("Ada"));
names.AddRange(["Barbara", "Margaret"]);
Console.WriteLine(string.Join(", ", names));

Arrays use Length, lists use Count. Use an array when the size is fixed and known; use a list for everything that changes.

Iterating

C#
List<int> numbers = [4, 8, 15, 16, 23, 42];
int sum = 0;
foreach (int n in numbers) sum += n;

for (int i = numbers.Count - 1; i >= 0; i--)
{
    if (numbers[i] % 2 == 1) numbers.RemoveAt(i);   // removing: go backwards
}
Console.WriteLine($"{sum} {string.Join(" ", numbers)}");

Changing a list while foreach walks over it throws InvalidOperationException. Loop backwards with for, or use numbers.RemoveAll(n => n % 2 == 1).

Searching and sorting

C#
var words = new List<string> { "pear", "fig", "banana", "kiwi" };
words.Sort();                                         // alphabetical, in place
Console.WriteLine(string.Join(" ", words));
words.Sort((a, b) => a.Length.CompareTo(b.Length));   // by length
Console.WriteLine(string.Join(" ", words));
Console.WriteLine(words.Find(w => w.StartsWith("b")));
Console.WriteLine(words.Exists(w => w.Length > 5));
int[] arr = [5, 1, 4];
Array.Sort(arr);
Console.WriteLine(Array.BinarySearch(arr, 4));        // index 1: needs a sorted array

A comparison returns a negative number when a comes first, zero when equal, positive when b comes first; x.CompareTo(y) does that for numbers and strings. List.Sort is not stable: equal items may change order. LINQ's OrderBy (lesson 2.04) is stable and returns a new sequence.

Copying versus sharing

Arrays and lists are reference types:

C#
var a = new List<int> { 1, 2 };
var b = a;                 // the same list
var c = new List<int>(a);  // a copy
b.Add(3);
Console.WriteLine($"{a.Count} {c.Count}");    // 3 2
int[] x = [1, 2, 3];
int[] y = (int[])x.Clone();
y[0] = 9;
Console.WriteLine(x[0]);   // 1

A method that receives a list can change the caller's list. If it should not, accept IReadOnlyList<T> instead: the method then cannot call Add or Remove.

Two dimensions

C#
int[,] grid = new int[3, 4];            // rectangular: 3 rows, 4 columns
grid[1, 2] = 7;
Console.WriteLine($"{grid.GetLength(0)}x{grid.GetLength(1)}, {grid[1, 2]}");

int[][] jagged = [[1], [2, 3], [4, 5, 6]];   // an array of arrays, rows of any length
foreach (int[] row in jagged) Console.WriteLine(string.Join(" ", row));
