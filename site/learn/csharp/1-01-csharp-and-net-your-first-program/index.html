C# and .NET: Your First Program

lesson 1.011 of 5 in milestone 15 min1 practice task

What C# and .NET are, how a program is compiled and run, the dotnet command-line tool, top-level statements, Console.WriteLine and ReadLine, comments, and reading compiler errors.

C# and .NET

C# is a statically typed language from Microsoft, used for desktop and web applications, cloud services, tools and games (Unity and Godot use it). .NET is the platform it runs on: a runtime that executes the program, manages memory with a garbage collector, and a large standard library for text, collections, files, networking and much more. .NET is free, open source and runs on Windows, macOS and Linux.

Compiling turns C# into IL (intermediate language) stored in a .dll. When the program starts, the runtime compiles the IL to machine code for the processor it runs on (just-in-time compilation). You get the safety of a managed language with speed close to C++.

Your first program

C#
// Program.cs
Console.WriteLine("Hello, Xenon!");
Console.WriteLine(2 + 3);

This is a complete program. Code written at the top of Program.cs, outside any class, is made of top-level statements: the compiler wraps it in a Main method for you. Each statement ends with a semicolon.

Console.WriteLine prints a line; Console.Write prints without moving to a new line.

Reading input

C#
Console.Write("What is your name? ");
string? name = Console.ReadLine();
Console.WriteLine($"Hello, {name}!");

Console.Write("Your age? ");
int age = int.Parse(Console.ReadLine()!);
Console.WriteLine($"Next year you will be {age + 1}.");

Console.ReadLine() returns the line typed, or null when the input has ended, so its type is string? (a string that may be null; lesson 2.05). int.Parse turns text into a whole number. The $"..." string can include values in braces: an interpolated string (lesson 1.04).

The Run button on examples like this one asks for input below the output.

The dotnet tool

On your own computer, install the .NET SDK from dot.net. The dotnet command creates, builds and runs projects:

Terminal
dotnet new console -o Hello     # a new console project in the folder Hello
cd Hello
dotnet run                      # compile and run
dotnet build                    # compile only

A project is a folder with a .csproj file (the project's settings) and .cs source files. Visual Studio, VS Code with the C# Dev Kit, and JetBrains Rider all work with these projects. In this course, the practice editor compiles and runs your code on .NET 9 for you.

Compiler errors

C# checks your program before it runs. An error names the file, line and column, a code, and what is wrong:

Text
Program.cs(3,9): error CS0029: Cannot implicitly convert type 'string' to 'int'
Program.cs(5,1): error CS1002: ; expected

Read the first error first: later ones are often caused by it. The CS number can be searched for in Microsoft's documentation. Warnings (such as an unused variable) do not stop the build, but they usually point at real problems.
