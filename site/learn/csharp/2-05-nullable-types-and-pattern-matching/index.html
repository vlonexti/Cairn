Nullable Types and Pattern Matching

lesson 2.055 of 5 in milestone 25 min1 practice task

null and nullable reference types, the warnings that catch null bugs, the operators ?. ?? and ??=, nullable value types like int?, tuples, and pattern matching with is, switch expressions, type, relational, logical, property and list patterns.

null

A reference-type variable can hold null: no object at all. Using a member of null throws NullReferenceException, one of the most common crashes in any program.

Modern C# projects turn on nullable reference types (<Nullable>enable</Nullable>, the default for new projects). Then string means "never null" and string? means "may be null", and the compiler warns when you use a string? without checking:

C#
string? middleName = GetMiddleName();
Console.WriteLine(middleName.Length);     // warning CS8602: Dereference of a possibly null reference.
if (middleName != null) Console.WriteLine(middleName.Length);   // fine: checked first

Treat these warnings as errors: each one is a possible crash.

Null operators

C#
string? name = null;
Console.WriteLine(name?.Length);          // ?. gives null instead of throwing (prints an empty line)
int length = name?.Length ?? 0;           // ?? supplies a fallback for null
Console.WriteLine(length);
name ??= "anonymous";                     // assign only if null
Console.WriteLine(name);
string[]? tags = null;
Console.WriteLine(tags?[0] ?? "no tags");

The ! operator (name!.Length) tells the compiler "this is not null"; it changes nothing at run time, so use it only when you are sure.

Nullable value types

Value types cannot be null, unless you add ?: int? holds an int or null. It suits "no value yet" or "not given":

C#
int? score = null;
Console.WriteLine(score.HasValue);
score = 42;
Console.WriteLine(score.Value + 1);
int? missing = null;
Console.WriteLine((missing ?? -1) + " " + (missing + 5 == null));   // arithmetic with null gives null

Tuples

A tuple groups a few values without declaring a type, handy for returning several results:

C#
var (min, max) = MinMax([4, 9, 1, 7]);
Console.WriteLine($"{min} {max}");
(string Name, int Age) person = ("Ada", 36);
Console.WriteLine(person.Name);

static (int Min, int Max) MinMax(int[] values) => (values.Min(), values.Max());

Pattern matching

is tests a value against a pattern, and can capture it in a variable:

C#
object[] things = [42, "hello", 3.5, null!, new List<int> { 1, 2 }];
foreach (object thing in things)
{
    if (thing is int n && n > 40) Console.WriteLine($"a big int {n}");
    else if (thing is string s) Console.WriteLine($"a string of length {s.Length}");
    else if (thing is null) Console.WriteLine("null");
    else Console.WriteLine($"something else: {thing.GetType().Name}");
}

Switch expressions combine patterns into a value:

C#
Console.WriteLine(Classify(-5));
Console.WriteLine(Classify(0));
Console.WriteLine(Classify(7));
Console.WriteLine(Classify(150));
Console.WriteLine(Shipping(new Order(30, "NL", false)));
Console.WriteLine(Shipping(new Order(120, "NL", false)));
Console.WriteLine(Shipping(new Order(10, "US", true)));
Console.WriteLine(Describe([1, 2, 3]) + " " + Describe([]) + " " + Describe([7]));

static string Classify(int n) => n switch
{
    < 0 => "negative",
    0 => "zero",
    > 0 and <= 100 => "small",
    _ => "large",
};

static decimal Shipping(Order o) => o switch
{
    { Express: true } => 25m,                       // property pattern
    { Total: >= 100 } => 0m,
    { Country: "NL" or "BE" } => 4.95m,
    _ => 12m,
};

static string Describe(int[] xs) => xs switch
{
    [] => "empty",
    [var only] => $"one item {only}",
    [var first, .., var last] => $"from {first} to {last}",   // list pattern
};

record Order(decimal Total, string Country, bool Express);
Pattern Matches
42, "NL", null That constant
int n, string s That type, captured in a variable
< 0, >= 1 and <= 5 Relational, combined with and, or, not
{ Total: >= 100 } Objects whose properties match
[var a, .., var z] Arrays and lists by shape
_ Anything (the discard)

Arms are tried from top to bottom; the compiler warns when a switch expression does not cover every possible value, and when an arm can never be reached.
