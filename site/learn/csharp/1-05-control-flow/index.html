Control Flow

lesson 1.055 of 5 in milestone 15 min1 practice task

Making decisions with if, else if and else, the switch statement and switch expressions, loops with while, do-while, for and foreach, break and continue, nested loops, and input loops that keep asking until the input is valid.

if and else

C#
int temperature = 23;
if (temperature >= 30)
{
    Console.WriteLine("Hot");
}
else if (temperature >= 18)
{
    Console.WriteLine("Pleasant");
}
else
{
    Console.WriteLine("Cold");
}

Braces can be left out around a single statement, but always writing them avoids the classic bug where a second indented line is not actually part of the if.

switch

A switch statement compares one value against cases:

C#
string command = "stop";
switch (command)
{
    case "go":
    case "start":
        Console.WriteLine("Starting");
        break;
    case "stop":
        Console.WriteLine("Stopping");
        break;
    default:
        Console.WriteLine("Unknown command");
        break;
}

Each case ends with break (or return); C# does not let one case fall through into the next by accident.

A switch expression produces a value, which is usually neater:

C#
int day = 6;
string kind = day switch
{
    6 or 7 => "weekend",
    >= 1 and <= 5 => "weekday",
    _ => "not a day",
};
Console.WriteLine(kind);

_ matches anything. Patterns like or, and and >= 1 are covered fully in lesson 2.05.

while and do-while

C#
int n = 27, steps = 0;
while (n != 1)
{
    n = n % 2 == 0 ? n / 2 : 3 * n + 1;
    steps++;
}
Console.WriteLine($"{steps} steps");

do { ... } while (condition); runs the body at least once, which suits "ask, then check":

C#
int guess;
do
{
    Console.Write("Pick 1 to 3: ");
    string? line = Console.ReadLine();
    if (line == null) break;                       // the input has ended
    if (!int.TryParse(line, out guess)) guess = 0;
} while (guess < 1 || guess > 3);

for and foreach

C#
for (int i = 1; i <= 3; i++)
{
    Console.Write($"{i} ");
}
Console.WriteLine();

for (int i = 10; i > 0; i -= 3) Console.Write($"{i} ");
Console.WriteLine();

string[] names = { "Ada", "Grace", "Linus" };
foreach (string name in names)
{
    Console.WriteLine(name.ToUpper());
}

Use for when you need the index or a count, and foreach to visit every item of an array, list, string or any other collection.

break and continue

C#
int[] numbers = { 4, 7, -1, 12, 0, 9 };
int sum = 0;
foreach (int x in numbers)
{
    if (x < 0) continue;    // skip this one
    if (x == 0) break;      // stop the loop
    sum += x;
}
Console.WriteLine(sum);     // 4 + 7 + 12 = 23

Nested loops

C#
for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= 4; col++)
    {
        Console.Write($"{row * col,4}");
    }
    Console.WriteLine();
}

break leaves only the innermost loop. To leave several, move the loops into a method and return (lesson 2.01).
