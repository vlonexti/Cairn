Regular Expressions and Text

lesson 7.055 of 6 in milestone 75 min2 practice tasks

Finding and transforming text - the Regex class, patterns, groups and named groups, Matches and Replace with a MatchEvaluator, options, timeouts, [GeneratedRegex] for speed, and culture-aware comparison, formatting and normalisation of strings.

The Regex class

A regular expression describes a shape of text (the pattern language is the same in most languages). System.Text.RegularExpressions.Regex checks, finds and replaces:

C#
using System.Text.RegularExpressions;

Console.WriteLine(Regex.IsMatch("due 2026-11-20", @"\d{4}-\d{2}-\d{2}"));   // True

Match m = Regex.Match("Order #4512 shipped", @"#(\d+)\s+(\w+)");
Console.WriteLine($"{m.Success} {m.Groups[1].Value} {m.Groups[2].Value}");     // True 4512 shipped

Write patterns as verbatim strings (@"...") so backslashes need no doubling.

Pattern reminder

Pattern Matches
\d \w \s digit, word character, whitespace
[a-z] [^,] a character in a range, not a comma
* + ? {2,5} repeats; add ? to make them lazy
^ $ \b start, end, word boundary
(...) (?<name>...) (?:...) group, named group, group without capturing
a|b either

Named groups and every match

C#
using System.Text.RegularExpressions;

var line = "x=1, y=22, z=333";
foreach (Match m in Regex.Matches(line, @"(?<key>\w)=(?<value>\d+)"))
    Console.WriteLine($"{m.Groups["key"].Value} -> {int.Parse(m.Groups["value"].Value)} at {m.Index}");

Replacing

Regex.Replace takes a replacement string (with $1 or ${name}) or a MatchEvaluator, a function that builds each replacement:

C#
using System.Text.RegularExpressions;

Console.WriteLine(Regex.Replace("2026-11-20", @"(\d+)-(\d+)-(\d+)", "$3/$2/$1"));   // 20/11/2026
Console.WriteLine(Regex.Replace("make it loud", @"\b\w", m => m.Value.ToUpper()));  // Make It Loud
Console.WriteLine(string.Join("|", Regex.Split("a, b;c ,d", @"\s*[,;]\s*")));       // a|b|c|d

Options and timeouts

RegexOptions.IgnoreCase, Multiline (^ and $ per line), Singleline (. matches new lines) and IgnorePatternWhitespace (spaces and # comments in the pattern for readability). A badly written pattern on hostile input can take a very long time (catastrophic backtracking), so give patterns that run on user input a timeout:

C#
using System.Text.RegularExpressions;

var safe = new Regex(@"^(\w+\s?)+$", RegexOptions.None, TimeSpan.FromMilliseconds(100));
try { Console.WriteLine(safe.IsMatch(new string('a', 30) + "!")); }
catch (RegexMatchTimeoutException) { Console.WriteLine("gave up"); }

RegexOptions.NonBacktracking (.NET 7) guarantees linear time for patterns that do not need backtracking features.

[GeneratedRegex]

A pattern used often should be built once: keep it in a static readonly Regex field, created with RegexOptions.Compiled for speed. In a normal .NET project the best way is a source-generated regex (lesson 7.03): the compiler writes the matching code at build time, so there is no start-up cost at all. (Xenon compiles without source generators, so this example is for your own projects.)

C#
using System.Text.RegularExpressions;

Console.WriteLine(Patterns.Email().IsMatch("ada@example.com"));

static partial class Patterns
{
    [GeneratedRegex(@"^[^@\s]+@[^@\s]+\.[a-z]{2,}$", RegexOptions.IgnoreCase)]
    public static partial Regex Email();
}

Comparing text correctly

Text comparison has more traps than it looks:

C#
using System.Globalization;
using System.Text;

Console.WriteLine(string.Equals("FILE", "file", StringComparison.OrdinalIgnoreCase));   // True
Console.WriteLine("straße".Equals("STRASSE", StringComparison.InvariantCultureIgnoreCase));

var turkish = new CultureInfo("tr-TR");
Console.WriteLine("title".ToUpper(turkish));             // TİTLE: dotted capital İ in Turkish
Console.WriteLine("title".ToUpperInvariant());           // TITLE

string composed = "é";                                    // one character
string decomposed = "é";                            // e + combining accent
Console.WriteLine(composed == decomposed);                                        // False
Console.WriteLine(composed.Normalize() == decomposed.Normalize());                // True

Rules of thumb: use StringComparison.Ordinal or OrdinalIgnoreCase for identifiers, file names, keys and protocols; use a culture-aware comparison only for text shown to people and sorted for them; Normalize() text from different sources before comparing it.
