Operators and Math

lesson 1.033 of 5 in milestone 15 min1 practice task

Arithmetic and integer division, remainder, compound assignment and increment, comparison and logical operators with short-circuiting, the conditional operator, operator precedence, and the Math class for rounding, powers and roots.

Arithmetic

C#
int a = 17, b = 5;
Console.WriteLine(a + b);     // 22
Console.WriteLine(a - b);     // 12
Console.WriteLine(a * b);     // 85
Console.WriteLine(a / b);     // 3: int / int cuts off the fraction
Console.WriteLine(a % b);     // 2: the remainder
Console.WriteLine(a / 5.0);   // 3.4: one double operand makes it a double division
Console.WriteLine((double)a / b);
Console.WriteLine(-17 / 5);   // -3: rounds toward zero
Console.WriteLine(-17 % 5);   // -2: the remainder has the sign of the left side

Integer division and % are useful together: minutes / 60 hours and minutes % 60 left over. Dividing an int by zero throws DivideByZeroException; dividing a double by zero gives Infinity or NaN.

Assignment shortcuts

C#
int score = 10;
score += 5;      // score = score + 5
score *= 2;      // 30
score -= 1;      // 29
score++;         // 30
score--;         // 29
Console.WriteLine(score);
int i = 5;
Console.WriteLine(i++);   // prints 5, then i becomes 6
Console.WriteLine(++i);   // i becomes 7, then prints 7

Use ++ and -- as statements on their own line; inside larger expressions they are easy to misread.

Comparison and logic

Operator Meaning
==, != Equal, not equal
<, <=, >, >= Ordering
&& And: true when both are true
|| Or: true when either is true
! Not
C#
int age = 20;
bool hasTicket = true;
bool canEnter = age >= 18 && hasTicket;
bool discount = age < 12 || age >= 65;
Console.WriteLine($"{canEnter} {discount} {!canEnter}");

string? name = null;
if (name != null && name.Length > 3) Console.WriteLine("long name");   // safe: && stops early

&& and || short-circuit: if the left side already decides the result, the right side is not evaluated. That is what makes the name != null && name.Length > 3 check safe.

Conditions must be bool: if (count) is an error in C#, unlike C or JavaScript. Write if (count != 0).

The conditional operator

C#
int n = 7;
string parity = n % 2 == 0 ? "even" : "odd";
Console.WriteLine($"{n} is {parity}");

Precedence

*, / and % bind tighter than + and -; comparisons come next; then &&, then ||, then ?:, then assignment. When in doubt, add parentheses: (a + b) * c.

Math

C#
Console.WriteLine(Math.Sqrt(16));          // 4
Console.WriteLine(Math.Pow(2, 10));        // 1024
Console.WriteLine(Math.Abs(-3.5));         // 3.5
Console.WriteLine(Math.Max(3, 9));         // 9
Console.WriteLine(Math.Round(2.5));        // 2: rounds halves to even by default
Console.WriteLine(Math.Round(2.5, MidpointRounding.AwayFromZero));   // 3
Console.WriteLine(Math.Round(3.14159, 2)); // 3.14
Console.WriteLine(Math.Floor(-2.5) + " " + Math.Ceiling(2.1));       // -3 3
Console.WriteLine(Math.Clamp(15, 0, 10));  // 10
Console.WriteLine(Math.PI);

Math.Round uses banker's rounding (halves go to the even neighbour) unless you ask for MidpointRounding.AwayFromZero, which is the rounding taught in school and usually wanted for money.
