JSON with System.Text.Json

lesson 5.044 of 5 in milestone 55 min1 practice task

Converting objects to and from JSON with JsonSerializer - serialising records and collections, options for naming, indentation and enums, attributes like JsonPropertyName and JsonIgnore, deserialising safely with nullable results and validation, reading unknown JSON with JsonDocument and JsonNode, and saving settings files.

Objects to JSON and back

JSON is the standard text format for data: web APIs, configuration and save files. .NET includes System.Text.Json:

C#
using System.Text.Json;

var order = new Order(17, "Ada", [new("tea", 2, 2.50m), new("cake", 1, 4.25m)], DateTime.Parse("2026-03-14T09:30:00"));

string json = JsonSerializer.Serialize(order);
Console.WriteLine(json);

Order? back = JsonSerializer.Deserialize<Order>(json);
Console.WriteLine(back!.Lines[1].Item + " " + back.Placed.Hour);

record Order(int Id, string Customer, List<OrderLine> Lines, DateTime Placed);
record OrderLine(string Item, int Quantity, decimal Price);

Serialize writes every public property; Deserialize<T> builds a T from JSON, using its constructor for records. Lists become arrays, dictionaries become objects, and DateTime is written in ISO 8601 form.

Options

Web APIs usually use camelCase names, while C# properties are PascalCase. Options control this and more:

C#
using System.Text.Json;
using System.Text.Json.Serialization;

var options = new JsonSerializerOptions
{
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
    WriteIndented = true,
    DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull,
    Converters = { new JsonStringEnumConverter() },
};

var task = new TaskItem("Write report", Priority.High, null, ["work"]);
string json = JsonSerializer.Serialize(task, options);
Console.WriteLine(json);
var back = JsonSerializer.Deserialize<TaskItem>(json, options)!;
Console.WriteLine(back.Priority);

enum Priority { Low, Normal, High }
record TaskItem(string Title, Priority Priority, string? Notes, List<string> Tags);

Create one options object and reuse it: building a new one each time is slow. JsonSerializerOptions.Web is a ready-made set for web conventions.

Attributes

Attributes change how one property is handled:

C#
using System.Text.Json;
using System.Text.Json.Serialization;

var user = new User { Id = 7, Name = "Ada", PasswordHash = "secret-hash" };
Console.WriteLine(JsonSerializer.Serialize(user));

class User
{
    [JsonPropertyName("user_id")] public int Id { get; set; }
    public string Name { get; set; } = "";
    [JsonIgnore] public string PasswordHash { get; set; } = "";     // never written out
}

Reading JSON you do not control

Deserialize can return null (for the JSON text null) and throws JsonException for invalid JSON or wrong types. Data from outside should be checked like any input:

C#
using System.Text.Json;

foreach (string text in new[] { """{"Name":"Ada","Age":36}""", "{ broken", """{"Name":"Bo","Age":"old"}""", "null" })
{
    try
    {
        var p = JsonSerializer.Deserialize<Person>(text);
        if (p is null || string.IsNullOrWhiteSpace(p.Name)) Console.WriteLine("missing data");
        else Console.WriteLine($"ok: {p.Name} {p.Age}");
    }
    catch (JsonException e)
    {
        Console.WriteLine($"bad JSON: {e.Message[..30]}...");
    }
}

record Person(string Name, int Age);

Missing properties get default values (null, 0) rather than an error. Mark them required in a class, or check after deserialising.

When the shape is unknown or you only need a few values, read the JSON as a tree with JsonNode (editable) or JsonDocument (read-only, fast):

C#
using System.Text.Json.Nodes;

var node = JsonNode.Parse("""{"city":"Oslo","current":{"temp":-3.5,"wind":[4,7]}}""")!;
double temp = node["current"]!["temp"]!.GetValue<double>();
int gust = node["current"]!["wind"]![1]!.GetValue<int>();
Console.WriteLine($"{node["city"]}: {temp} C, gusts {gust}");
node["checked"] = true;
Console.WriteLine(node.ToJsonString());

Saving settings

A common use: keep an app's settings or data in a JSON file.

C#
using System.Text.Json;

var path = "settings.json";
var settings = Load(path);
settings = settings with { LaunchCount = settings.LaunchCount + 1 };
File.WriteAllText(path, JsonSerializer.Serialize(settings, new JsonSerializerOptions { WriteIndented = true }));
Console.WriteLine(File.ReadAllText(path));

static AppSettings Load(string path)
{
    try
    {
        return JsonSerializer.Deserialize<AppSettings>(File.ReadAllText(path)) ?? new AppSettings();
    }
    catch (Exception e) when (e is FileNotFoundException or JsonException)
    {
        return new AppSettings();       // first run, or a damaged file
    }
}

record AppSettings(string Theme = "light", int FontSize = 14, int LaunchCount = 0);
