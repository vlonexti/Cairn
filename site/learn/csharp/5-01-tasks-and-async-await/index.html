Tasks and async/await

lesson 5.011 of 5 in milestone 55 min1 practice task

Asynchronous code in C# - why waiting should not block a thread, Task and Task<T>, async methods and await, running work in sequence or at the same time with Task.WhenAll and WhenAny, exceptions in async code, async void and why to avoid it, ValueTask, async streams with IAsyncEnumerable, and never blocking with .Result.

Waiting without blocking

Much of a program's time is spent waiting: for a file, a database, a web server. A thread that sits waiting cannot do anything else. In a desktop app that freezes the window; in a server it wastes a thread that could serve another request.

Asynchronous code starts the operation, gives the thread back while waiting, and continues when the result is ready. In C#, an operation in progress is a Task: Task for one with no result, Task<T> for one that produces a T.

async and await

C#
Console.WriteLine("ordering");
string coffee = await MakeCoffeeAsync();
Console.WriteLine(coffee);

static async Task<string> MakeCoffeeAsync()
{
    Console.WriteLine("  grinding...");
    await Task.Delay(200);                 // waits 200 ms without blocking a thread
    Console.WriteLine("  brewing...");
    await Task.Delay(300);
    return "a flat white";
}
  • async on a method allows await inside it; the method returns Task or Task<T>.
  • await task pauses this method until the task finishes, then gives its result. The thread is free in the meantime.
  • Top-level statements may use await directly, as here.
  • By convention, async method names end in Async.

Sequence or at the same time

Each await waits before the next line starts. When operations do not depend on each other, start them all first and await them together:

C#
var sw = System.Diagnostics.Stopwatch.StartNew();
string a = await FetchAsync("a", 300);
string b = await FetchAsync("b", 300);
Console.WriteLine($"one after another: {a}{b} in ~{sw.ElapsedMilliseconds / 100 * 100} ms");

sw.Restart();
Task<string> ta = FetchAsync("a", 300);    // started
Task<string> tb = FetchAsync("b", 300);    // started too
string[] both = await Task.WhenAll(ta, tb);
Console.WriteLine($"together: {string.Join("", both)} in ~{sw.ElapsedMilliseconds / 100 * 100} ms");

sw.Restart();
Task<string> first = await Task.WhenAny(FetchAsync("slow", 500), FetchAsync("fast", 100));
Console.WriteLine($"first finished: {await first}");

static async Task<string> FetchAsync(string name, int ms)
{
    await Task.Delay(ms);
    return name;
}

Task.WhenAll finishes when all tasks have, with their results in the order given. Task.WhenAny finishes with the first task to complete.

Exceptions

An exception inside an async method is stored in its task and thrown again where the task is awaited, so ordinary try/catch works:

C#
try
{
    await LoadAsync(-1);
}
catch (ArgumentException e)
{
    Console.WriteLine($"caught: {e.Message}");
}

static async Task<int> LoadAsync(int id)
{
    await Task.Delay(10);
    if (id < 0) throw new ArgumentException("id must not be negative");
    return id * 2;
}

With Task.WhenAll, await throws the first exception; the task's Exception property holds all of them.

Rules that save you trouble

  • Async all the way: a method that awaits must itself be async and return a Task, up to the top (Main, an event handler, a web endpoint).
  • Never block on a task with .Result or .Wait(). In desktop apps it can deadlock; everywhere it wastes the thread that async was meant to free. await it instead.
  • Avoid async void. Nobody can await it, and an exception in it crashes the process. The only exception is event handlers, which must return void.
  • CPU work is different: await helps with waiting, not computing. To move heavy computation off the UI thread, use await Task.Run(() => Compute()) (lesson 5.02).
  • A method that usually completes at once (from a cache) can return ValueTask<T> to avoid an allocation; use plain Task unless you have measured.

Async streams

IAsyncEnumerable<T> is a sequence whose items arrive over time. Produce it with yield return in an async iterator and consume it with await foreach:

C#
await foreach (var reading in ReadSensorAsync(3))
{
    Console.WriteLine($"reading {reading}");
}

static async IAsyncEnumerable<int> ReadSensorAsync(int count)
{
    for (int i = 1; i <= count; i++)
    {
        await Task.Delay(50);            // e.g. waiting for the next value from a device
        yield return i * 10;
    }
}
