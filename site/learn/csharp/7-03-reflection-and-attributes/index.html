Reflection and Attributes

lesson 7.033 of 6 in milestone 75 min2 practice tasks

Programs that look at themselves - Type objects, reading properties and methods with reflection, creating objects and calling methods by name, attributes as labels on code, writing and reading your own attributes, and why source generators replace much of this today.

Types are data too

Every object knows its type, and a Type object describes it: name, properties, methods, attributes. Inspecting and using that at run time is reflection. Serializers, test frameworks, dependency injection and object mappers are built on it.

C#
var book = new Book("Dune", 1965);
Type type = book.GetType();               // or typeof(Book) when you have no object
Console.WriteLine($"{type.Name} in {type.Namespace ?? "(no namespace)"}");
foreach (var p in type.GetProperties())
    Console.WriteLine($"  {p.Name}: {p.PropertyType.Name} = {p.GetValue(book)}");

public record Book(string Title, int Year);

Members by name

C#
using System.Reflection;

var counter = new Counter();
Type t = typeof(Counter);

MethodInfo add = t.GetMethod("Add")!;
add.Invoke(counter, [5]);                 // like counter.Add(5)

PropertyInfo total = t.GetProperty("Total")!;
Console.WriteLine(total.GetValue(counter));          // 5

FieldInfo secret = t.GetField("_calls", BindingFlags.NonPublic | BindingFlags.Instance)!;
Console.WriteLine(secret.GetValue(counter));          // 1: private members are reachable too

object made = Activator.CreateInstance(t)!;          // new Counter() without naming it
Console.WriteLine(made.GetType().Name);

public class Counter
{
    private int _calls;
    public int Total { get; private set; }
    public void Add(int n) { Total += n; _calls++; }
}

Reflection is slow compared with normal calls and the compiler cannot check names written as strings, so a typo is only found when the code runs. Use nameof(Counter.Add) instead of "Add" where you can.

Attributes

An attribute is a label attached to code in square brackets. It does nothing by itself; code that reads it (the compiler, a framework, your own reflection) decides what it means. You have already met several:

Attribute Read by Effect
[Obsolete("use X")] the compiler a warning wherever it is used
[JsonPropertyName("id")] System.Text.Json (lesson 5.04) the JSON name of a property
[Fact], [Theory] xUnit (lesson 6.02) marks a test
[Flags] Enum.ToString prints combined flags as "Read, Write"

Your own attribute

An attribute is a class that derives from Attribute. AttributeUsage says what it can be put on:

C#
using System.Reflection;

foreach (var p in typeof(SignUp).GetProperties())
{
    var max = p.GetCustomAttribute<MaxLengthAttribute>();
    if (max is not null) Console.WriteLine($"{p.Name}: at most {max.Length} characters");
}

[AttributeUsage(AttributeTargets.Property)]
public sealed class MaxLengthAttribute(int length) : Attribute
{
    public int Length { get; } = length;
}

public class SignUp
{
    [MaxLength(20)] public string Name { get; set; } = "";
    [MaxLength(80)] public string Email { get; set; } = "";
    public int Age { get; set; }
}

The name MaxLengthAttribute can be written [MaxLength(...)]: the Attribute ending is optional where it is used.

Generic code and reflection together

A validator that works for any class, driven by attributes:

C#
using System.Reflection;

static List<string> Validate(object obj)
{
    var problems = new List<string>();
    foreach (var p in obj.GetType().GetProperties())
    {
        if (p.GetCustomAttribute<RequiredAttribute>() is not null && p.GetValue(obj) is null or "")
            problems.Add($"{p.Name} is required");
    }
    return problems;
}

Console.WriteLine(string.Join("; ", Validate(new Contact { Name = "" })));

[AttributeUsage(AttributeTargets.Property)]
public sealed class RequiredAttribute : Attribute;

public class Contact
{
    [Required] public string? Name { get; set; }
    [Required] public string? Phone { get; set; }
}

Source generators

Reflection decides at run time; a source generator reads your code (and its attributes) at compile time and writes extra C# for you. The result is as fast as hand-written code, works where reflection is restricted (trimmed and native AOT apps), and errors appear while compiling. System.Text.Json, logging ([LoggerMessage]) and regular expressions ([GeneratedRegex], lesson 7.05) all offer generated versions. When a library offers both, prefer the generated one.
