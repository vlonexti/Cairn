Iterators and yield

lesson 4.055 of 5 in milestone 45 min1 practice task

How foreach works with IEnumerable and IEnumerator, writing iterators with yield return and yield break, lazy and infinite sequences, deferred execution and its pitfalls, writing your own LINQ-style extension methods, and implementing IEnumerable<T> on a collection class.

How foreach works

foreach works on any type with a GetEnumerator() method, in practice anything that implements IEnumerable<T>. The enumerator has MoveNext() (go to the next item, returning false at the end) and Current:

C#
var e = new List<string> { "a", "b" }.GetEnumerator();
while (e.MoveNext()) Console.Write(e.Current + " ");
Console.WriteLine();

yield return

Writing an enumerator by hand is tedious. An iterator method uses yield return to hand out values one at a time, and the compiler writes the enumerator for you:

C#
foreach (int n in Range(1, 10, 3)) Console.Write($"{n} ");
Console.WriteLine();
foreach (string line in Countdown(3)) Console.WriteLine(line);

static IEnumerable<int> Range(int start, int end, int step)
{
    for (int i = start; i < end; i += step) yield return i;
}

static IEnumerable<string> Countdown(int from)
{
    while (from > 0) yield return $"{from--}...";
    yield return "lift-off!";
}

Each yield return pauses the method; the next MoveNext continues right after it. yield break ends the sequence early.

Lazy and infinite sequences

An iterator runs only as far as someone asks. A sequence can therefore be infinite, as long as the consumer stops:

C#
Console.WriteLine(string.Join(" ", Fibonacci().Take(10)));
Console.WriteLine(Fibonacci().First(f => f > 1000));
Console.WriteLine(string.Join(" ", Primes().Skip(10).Take(5)));

static IEnumerable<long> Fibonacci()
{
    long a = 0, b = 1;
    while (true)
    {
        yield return a;
        (a, b) = (b, a + b);
    }
}

static IEnumerable<int> Primes()
{
    for (int n = 2; ; n++)
        if (Enumerable.Range(2, (int)Math.Sqrt(n) - 1).All(d => n % d != 0)) yield return n;
}

Deferred execution

Calling an iterator method runs none of its code. The body starts on the first MoveNext, and runs again from the top every time the sequence is enumerated:

C#
var numbers = Noisy();
Console.WriteLine("before the loop");
foreach (var n in numbers.Take(2)) Console.WriteLine($"got {n}");
Console.WriteLine(numbers.Count());       // runs the whole body again

static IEnumerable<int> Noisy()
{
    Console.WriteLine("  (starting)");
    for (int i = 1; i <= 3; i++) yield return i;
}

Consequences:

  • Argument checks inside an iterator only run when enumeration starts. Put the check in a normal method that then returns the iterator (a local function works well).
  • Enumerating twice does the work twice: call ToList() once if you need the results more than once.
  • Iterators that read files or the network should be enumerated once and disposed: foreach does that for you.
C#
try { var chunks = Chunks(new[] { 1, 2, 3 }, 0); Console.WriteLine("no error yet?"); }
catch (ArgumentOutOfRangeException) { Console.WriteLine("checked at once"); }

static IEnumerable<T[]> Chunks<T>(IEnumerable<T> source, int size)
{
    ArgumentOutOfRangeException.ThrowIfLessThan(size, 1);     // runs immediately
    return Iterate();

    IEnumerable<T[]> Iterate()                                // the lazy part
    {
        var chunk = new List<T>(size);
        foreach (var item in source)
        {
            chunk.Add(item);
            if (chunk.Count == size) { yield return chunk.ToArray(); chunk.Clear(); }
        }
        if (chunk.Count > 0) yield return chunk.ToArray();
    }
}

Your own LINQ methods

LINQ's operators are iterator extension methods. Writing your own takes a few lines:

C#
var temps = new[] { 12, 15, 11, 18, 20 };
Console.WriteLine(string.Join(" ", temps.Pairwise().Select(p => p.Second - p.First)));
Console.WriteLine(string.Join(" ", temps.WhereIndex((t, i) => i % 2 == 0)));

public static class MoreLinq
{
    public static IEnumerable<(T First, T Second)> Pairwise<T>(this IEnumerable<T> source)
    {
        using var e = source.GetEnumerator();
        if (!e.MoveNext()) yield break;
        T previous = e.Current;
        while (e.MoveNext())
        {
            yield return (previous, e.Current);
            previous = e.Current;
        }
    }

    public static IEnumerable<T> WhereIndex<T>(this IEnumerable<T> source, Func<T, int, bool> keep)
    {
        int i = 0;
        foreach (var item in source) if (keep(item, i++)) yield return item;
    }
}

Making a class enumerable

Implement IEnumerable<T> with an iterator, and your class works with foreach and all of LINQ:

C#
var team = new Team("Rovers") { "Ada", "Grace", "Linus" };
foreach (var member in team) Console.Write(member + " ");
Console.WriteLine(team.Count(m => m.Length > 3));

public class Team(string name) : IEnumerable<string>
{
    private readonly List<string> _members = new();
    public string Name => name;
    public void Add(string member) => _members.Add(member);     // Add lets { ... } initializers work

    public IEnumerator<string> GetEnumerator()
    {
        foreach (var m in _members.OrderBy(m => m)) yield return m;
    }

    System.Collections.IEnumerator System.Collections.IEnumerable.GetEnumerator() => GetEnumerator();
}
