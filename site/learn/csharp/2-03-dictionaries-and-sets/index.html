Dictionaries and Sets

lesson 2.033 of 5 in milestone 25 min1 practice task

Dictionary<TKey, TValue> for lookups by key - adding, reading safely with TryGetValue, updating, counting and grouping, iterating key-value pairs - and HashSet<T> for unique values and set operations, with case-insensitive keys, sorted variants and queues and stacks.

Dictionary

A dictionary maps keys to values, with fast lookup by key:

C#
var ages = new Dictionary<string, int>
{
    ["Ada"] = 36,
    ["Grace"] = 85,
};
ages["Linus"] = 55;              // add or replace
ages.Add("Ken", 81);             // add; throws if the key exists
Console.WriteLine(ages["Ada"]);
Console.WriteLine(ages.ContainsKey("Bob"));
Console.WriteLine(ages.Count);
ages.Remove("Grace");
foreach (var (name, age) in ages) Console.WriteLine($"{name}: {age}");

Reading a missing key with ages["Bob"] throws KeyNotFoundException. Read safely with TryGetValue or GetValueOrDefault:

C#
var stock = new Dictionary<string, int> { ["apple"] = 3 };
if (stock.TryGetValue("pear", out int pears)) Console.WriteLine(pears);
else Console.WriteLine("no pears");
Console.WriteLine(stock.GetValueOrDefault("pear", 0));

Counting and grouping

Two patterns that come up constantly:

C#
string text = "the cat and the hat and the bat";
var counts = new Dictionary<string, int>();
foreach (string word in text.Split(' '))
{
    counts[word] = counts.GetValueOrDefault(word) + 1;
}
Console.WriteLine(string.Join(", ", counts.Select(kv => $"{kv.Key}={kv.Value}")));

var byFirstLetter = new Dictionary<char, List<string>>();
foreach (string word in new[] { "apple", "avocado", "banana", "blueberry", "cherry" })
{
    if (!byFirstLetter.TryGetValue(word[0], out var list))
    {
        list = new List<string>();
        byFirstLetter[word[0]] = list;
    }
    list.Add(word);
}
foreach (var (letter, words) in byFirstLetter) Console.WriteLine($"{letter}: {string.Join(" ", words)}");

LINQ's GroupBy and CountBy (lesson 2.04) do both in one line, but the loops show what happens.

A Dictionary does not promise any order. In practice it keeps insertion order until items are removed, but do not rely on it: sort the keys when the order matters, or use a SortedDictionary, which keeps keys sorted.

Keys

Keys must not change while in a dictionary, and two keys are the same when Equals says so. For text keys that should ignore case, pass a comparer:

C#
var users = new Dictionary<string, string>(StringComparer.OrdinalIgnoreCase) { ["Ada"] = "admin" };
Console.WriteLine(users["ADA"]);

HashSet

A HashSet holds unique values with fast Contains:

C#
var seen = new HashSet<string>();
foreach (string tag in new[] { "c#", "dotnet", "c#", "linq" })
{
    if (!seen.Add(tag)) Console.WriteLine($"duplicate: {tag}");   // Add returns false for repeats
}
var a = new HashSet<int> { 1, 2, 3, 4 };
var b = new HashSet<int> { 3, 4, 5 };
var both = new HashSet<int>(a);
both.IntersectWith(b);
var either = new HashSet<int>(a);
either.UnionWith(b);
a.ExceptWith(b);
Console.WriteLine($"{string.Join(",", both)} | {string.Join(",", either)} | {string.Join(",", a)}");

list.Contains(x) checks every item; set.Contains(x) takes about the same time however large the set is. When you check membership often, use a set.

Queues and stacks

C#
var queue = new Queue<string>();       // first in, first out
queue.Enqueue("first"); queue.Enqueue("second");
Console.WriteLine(queue.Dequeue());
var stack = new Stack<int>();          // last in, first out
stack.Push(1); stack.Push(2);
Console.WriteLine(stack.Pop() + " " + stack.Peek());

Queues suit work waiting its turn (and breadth-first search); stacks suit undo history and matching brackets.
