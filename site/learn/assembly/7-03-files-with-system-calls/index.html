Files with System Calls

lesson 7.033 of 5 in milestone 75 min2 practice tasks

Working with files without any library - open with its flags and permission mode, read and write loops that handle partial transfers, close, lseek to move and to find a size, unlink, and reading errors from the negative value the kernel returns.

Files are numbers

Lesson 1.04 wrote to the screen with system call 1, write, on file descriptor 1 (standard output). A file you open is just another descriptor: a small number the kernel hands out, which read, write and close then use.

Call rax Arguments Returns
read 0 rdi = fd, rsi = buffer, rdx = size bytes read, 0 at the end
write 1 rdi = fd, rsi = buffer, rdx = count bytes written
open 2 rdi = path (zero-terminated), rsi = flags, rdx = mode the new fd
close 3 rdi = fd 0
lseek 8 rdi = fd, rsi = offset, rdx = whence the new position
unlink 87 rdi = path 0

(Newer programs use openat, 257, which takes a directory fd first; open is the same with the current directory.)

Errors are negative

A system call that fails returns a negative error number in rax: −2 is ENOENT (no such file), −13 EACCES (permission denied), −9 EBADF (bad descriptor). C's errno is just that number made positive by the library. So every call is followed by a check:

Assembly
        syscall
        test    rax, rax
        js      .failed             ; negative: an error

Opening

The flags are bits ORed together:

Flag Value Meaning
O_RDONLY 0 read only
O_WRONLY 1 write only
O_RDWR 2 both
O_CREAT 0x40 create it if it does not exist
O_TRUNC 0x200 empty it if it does
O_APPEND 0x400 every write goes to the end

With O_CREAT, rdx is the permission mode of a new file, usually written in octal: 0o644 means the owner may read and write, everyone else may only read.

Write, then read back

Assembly
        global  _start
        section .data
path:   db      "xenon_demo.txt", 0
text:   db      "written by assembly", 10
length  equ     $ - text

        section .bss
buffer: resb    64

        section .text
_start:
        ; fd = open(path, O_WRONLY | O_CREAT | O_TRUNC, 0644)
        mov     eax, 2
        lea     rdi, [rel path]
        mov     esi, 0x241
        mov     edx, 0o644
        syscall
        test    rax, rax
        js      .fail
        mov     rbx, rax                ; keep the fd

        mov     eax, 1                  ; write(fd, text, length)
        mov     rdi, rbx
        lea     rsi, [rel text]
        mov     edx, length
        syscall

        mov     eax, 3                  ; close(fd)
        mov     rdi, rbx
        syscall

        mov     eax, 2                  ; fd = open(path, O_RDONLY)
        lea     rdi, [rel path]
        xor     esi, esi
        syscall
        test    rax, rax
        js      .fail
        mov     rbx, rax

        xor     eax, eax                ; n = read(fd, buffer, 64)
        mov     rdi, rbx
        lea     rsi, [rel buffer]
        mov     edx, 64
        syscall
        mov     r12, rax

        mov     eax, 3
        mov     rdi, rbx
        syscall

        mov     eax, 1                  ; show what came back
        mov     edi, 1
        lea     rsi, [rel buffer]
        mov     rdx, r12
        syscall

        mov     eax, 87                 ; unlink(path): tidy up
        lea     rdi, [rel path]
        syscall
        xor     edi, edi
        jmp     .exit
.fail:  mov     rdi, rax
        call    print_int               ; the negative error number
        call    print_newline
        mov     edi, 1
.exit:  mov     eax, 60
        syscall

Partial reads and writes

read may return fewer bytes than asked for, even before the end of the file (always with pipes and sockets), and write may write fewer than given. Robust code loops:

Assembly
; write_all: rdi = fd, rsi = buffer, rdx = count. Returns 0, or the negative error.
write_all:
.again: test    rdx, rdx
        jz      .ok
        mov     eax, 1
        push    rdi
        push    rsi
        push    rdx
        syscall
        pop     rdx
        pop     rsi
        pop     rdi
        test    rax, rax
        js      .error
        add     rsi, rax                ; skip what was written
        sub     rdx, rax
        jmp     .again
.ok:    xor     eax, eax
.error: ret

(The syscall instruction itself overwrites rcx and r11; the pushes here keep the arguments for the next round.)

lseek

lseek(fd, offset, whence) moves the read and write position: whence 0 (SEEK_SET) from the start, 1 (SEEK_CUR) from the current position, 2 (SEEK_END) from the end. lseek(fd, 0, SEEK_END) returns the file's size.
