The Stack push and pop

lesson 4.044 of 5 in milestone 45 min1 practice task

The stack is memory that grows downwards from a high address, and rsp always points at its top. push moves rsp down 8 bytes and stores a value; pop loads it and moves rsp back up. It saves registers that must be kept, holds temporary space reserved with sub rsp, and must end exactly where it started.

A stack of plates

The stack is a region of memory the operating system gives every program, a few megabytes in size. rsp points at the item on top. It grows downwards: pushing makes rsp smaller.

Instruction Same as
push rax sub rsp, 8 then mov [rsp], rax
pop rbx mov rbx, [rsp] then add rsp, 8

The last thing pushed is the first popped: a "last in, first out" stack.

Saving registers

The most common use: keeping a register's value safe while you need the register for something else. A function that wants to use rbx (which it must give back unchanged) saves it first:

Assembly
sum_squares:            ; rdi = a, rsi = b; returns a*a + b*b
        push    rbx             ; save the caller's rbx
        mov     rbx, rdi
        imul    rbx, rdi        ; rbx = a * a
        mov     rax, rsi
        imul    rax, rsi        ; rax = b * b
        add     rax, rbx
        pop     rbx             ; give rbx back
        ret

Pops must match pushes, in reverse order: push rbx, push r12 ... pop r12, pop rbx.

Temporary space

Subtracting from rsp reserves bytes on the stack; adding gives them back. This is how functions get local arrays and buffers without .bss:

Assembly
        global  _start
        section .text
_start:
        sub     rsp, 16                 ; 16 bytes of space at [rsp] to [rsp + 15]
        mov     byte [rsp], 'O'
        mov     byte [rsp + 1], 'K'
        mov     byte [rsp + 2], '!'
        mov     byte [rsp + 3], 10
        mov     eax, 1
        mov     edi, 1
        mov     rsi, rsp                ; the address of the bytes on the stack
        mov     edx, 4
        syscall
        add     rsp, 16                 ; give the space back
        mov     eax, 60
        xor     edi, edi
        syscall

Reversing with the stack

Since the stack reverses order, it can turn a string around: push every character, then pop them back in:

Assembly
        global  _start
        section .data
text:   db      "stressed", 0

        section .text
_start:
        lea     rsi, [rel text]
        xor     ecx, ecx                ; how many pushed
.push:  movzx   eax, byte [rsi + rcx]
        test    al, al
        jz      .popping
        push    rax
        inc     rcx
        jmp     .push
.popping:
        xor     edx, edx
.pop:   cmp     rdx, rcx
        jae     .done
        pop     rax
        mov     [rsi + rdx], al
        inc     rdx
        jmp     .pop
.done:
        lea     rdi, [rel text]
        call    print_str               ; desserts
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

Rules

Leave the stack as you found it
  • Every push needs a pop (or an add rsp) before the function returns, or ret will jump to a wrong address (lesson 5.01 shows why) and the program crashes.
  • Never read below rsp after the space is given back: the next push or system call overwrites it.
  • Before calling a function, rsp must be a multiple of 16 (lesson 5.02). The routines in this course do not mind, but C functions can crash otherwise.
