mov and Exit Codes

lesson 1.033 of 6 in milestone 15 min1 practice task

mov copies a value into a register - a constant, another register, or (later) memory. Both sides must be the same size. A program's exit code is the number it hands to the exit system call, and it is the simplest way to see a result. xor of a register with itself is the usual way to set it to 0.

mov copies

mov destination, source copies the source into the destination. The source is unchanged.

Assembly
        mov     eax, 42         ; a constant (an "immediate") into a register
        mov     ebx, eax        ; one register into another
        mov     rcx, -7         ; negative numbers are fine
        mov     edx, 0x2A       ; hex: also 42
        mov     esi, 0b101010   ; binary: also 42
        mov     edi, 'A'        ; a character: its code, 65

Rules:

  • The destination comes first: think eax = 42.
  • Both sides must be the same size: mov eax, rbx is an error ("invalid combination of opcode and operands"). Use mov eax, ebx or mov rax, rbx.
  • A constant cannot be the destination (mov 5, eax makes no sense).

The exit code: your first result

When a program ends, it hands a number to the operating system: its exit code. 0 means success; anything else usually means something went wrong. Exit is system call 60, and the code goes in rdi:

Assembly
        global  _start
        section .text
_start:
        mov     ebx, 20
        mov     ecx, 22
        mov     edi, ebx        ; the exit code will be 20...
        add     edi, ecx        ; ...plus 22
        mov     eax, 60         ; system call 60: exit
        syscall

Run it: the website shows exit code 42. Before you can print text, the exit code is a handy way to see a number. On Linux you would see it with echo $? after the program ends.

Exit codes are a single byte: 0 to 255. Exit with 300 and you get 44 (300 − 256), the lowest 8 bits.

Setting a register to zero

You will see this everywhere:

Assembly
        xor     eax, eax        ; eax = eax XOR eax, which is always 0

It means the same as mov eax, 0, but the instruction is 2 bytes instead of 5, and processors recognise it and do it for free. Compilers always use it, and so does this course.

Swapping and order

Instructions run strictly in order, one after another. To swap two registers you need a third, or the special xchg instruction:

Assembly
        global  _start
        section .text
_start:
        mov     eax, 3
        mov     ebx, 9
        mov     ecx, eax        ; ecx = 3
        mov     eax, ebx        ; eax = 9
        mov     ebx, ecx        ; ebx = 3
        xchg    eax, ebx        ; and swap them back with one instruction
        mov     edi, eax        ; exit code: 3
        mov     eax, 60
        syscall
