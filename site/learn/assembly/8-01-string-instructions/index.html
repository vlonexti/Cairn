String Instructions

lesson 8.011 of 5 in milestone 85 min2 practice tasks

The x86 instructions built for blocks of memory - movsb, stosb, lodsb, scasb and cmpsb with rsi, rdi and rcx, the rep, repe and repne prefixes, the direction flag and cld, writing memcpy, memset, strlen and memcmp with them, and when a plain loop or SIMD is faster.

Instructions for blocks of bytes

Lesson 4.03 walked through strings one byte at a time with a loop. x86 also has string instructions that do one step of such a loop each, using fixed registers:

instruction does then
movsb copies the byte at [rsi] to [rdi] rsi++, rdi++
stosb stores al at [rdi] rdi++
lodsb loads the byte at [rsi] into al rsi++
scasb compares al with the byte at [rdi] (sets flags) rdi++
cmpsb compares [rsi] with [rdi] (sets flags) rsi++, rdi++

Each has w, d and q forms (movsq copies 8 bytes and moves the pointers by 8).

The pointers move forwards when the direction flag is clear, which the System V convention guarantees on entry to every function. cld clears it explicitly; std sets it to go backwards, and code that sets it must clear it again before calling anything.

rep: repeat rcx times

The rep prefix repeats the instruction rcx times, counting rcx down to 0. rep movsb is a whole memcpy, and rep stosb a whole memset:

Assembly
        global  _start

        section .data
src:    db      "assembly!", 0
src_len equ     $ - src

        section .bss
dst:    resb    32

        section .text
_start:
        cld
        lea     rdi, [rel dst]          ; fill dst with '*' first
        mov     al, '*'
        mov     ecx, 20
        rep stosb
        mov     byte [rdi], 0           ; rdi now points just past the 20 stars

        lea     rdi, [rel dst]
        call    print_str
        call    print_newline

        lea     rsi, [rel src]          ; then copy the string over the start
        lea     rdi, [rel dst]
        mov     ecx, src_len
        rep movsb

        lea     rdi, [rel dst]
        call    print_str
        call    print_newline

        mov     eax, 60
        xor     edi, edi
        syscall

Modern processors run rep movsb and rep stosb very fast for large blocks, so compilers often use them for memcpy and memset.

repne and repe: repeat while

repne ("repeat while not equal") repeats while rcx is not 0 and the comparison was not equal. With scasb, that searches for a byte, which gives a strlen:

Assembly
        global  _start

        section .data
text:   db      "hello, world", 0

        section .text
my_strlen:                              ; rdi = string, returns its length in rax
        xor     eax, eax                ; al = 0, the byte to find
        mov     rcx, -1                 ; as many steps as it takes
        mov     rdx, rdi
        repne scasb                     ; stops after the zero byte
        sub     rdi, rdx                ; bytes scanned, including the zero
        lea     rax, [rdi - 1]
        ret

_start:
        lea     rdi, [rel text]
        call    my_strlen
        mov     rdi, rax
        call    print_int               ; 12
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

repe ("repeat while equal") with cmpsb compares two blocks and stops at the first difference, a memcmp:

Assembly
        global  _start

        section .data
a:      db      "apple pie"
b:      db      "apple tart"

        section .text
my_memcmp:                              ; rdi, rsi, rdx = length; returns <0, 0 or >0
        mov     rcx, rdx
        xor     eax, eax
        test    rcx, rcx
        jz      .done
        repe cmpsb                      ; flags from the last compared pair
        je      .done                   ; all equal
        movzx   eax, byte [rsi - 1]     ; the first different bytes
        movzx   ecx, byte [rdi - 1]
        sub     rax, rcx                ; 64-bit, so a negative difference stays negative
.done:  ret

_start:
        lea     rsi, [rel a]
        lea     rdi, [rel b]
        mov     edx, 9
        call    my_memcmp
        mov     rdi, rax
        call    print_int
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

cmpsb compares [rsi] with [rdi], so here the first block is in rsi: "apple p" against "apple t" gives 'p' - 't', a negative number, meaning a sorts first.

lodsb: reading through a string

lodsb pairs naturally with a loop that transforms each byte:

Assembly
        global  _start

        section .data
msg:    db      "Shout This", 0

        section .bss
out:    resb    32

        section .text
_start:
        lea     rsi, [rel msg]
        lea     rdi, [rel out]
.next:  lodsb                           ; al = next byte, rsi++
        cmp     al, 'a'
        jb      .keep
        cmp     al, 'z'
        ja      .keep
        sub     al, 32                  ; lower to upper case
.keep:  stosb                           ; store it, rdi++
        test    al, al
        jnz     .next                   ; stop after copying the zero

        lea     rdi, [rel out]
        call    print_str
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

When to use them

  • rep movsb / rep stosb for copying and filling large blocks: short, and fast on current processors.
  • repne scasb and repe cmpsb are compact but slower than they look; compilers rarely use them, preferring loops or SIMD (lesson 6.04) that check 16 or 32 bytes at once.
  • Remember which registers they use: rsi, rdi and rcx change, so save anything you still need.
