Addressing Modes

lesson 4.011 of 5 in milestone 45 min1 practice task

Square brackets mean memory. An address can be built from a base register, an index register times 1, 2, 4 or 8, and a constant, or relative to rip for labels. The size comes from the register or is written as byte, word, dword or qword. movzx and movsx widen small values, and lea computes an address without reading it.

Brackets mean memory

Without brackets an operand is a register or a number; with brackets it is the memory at that address:

Assembly
        mov     rax, rbx        ; rax = rbx
        mov     rax, [rbx]      ; rax = the 8 bytes at the address in rbx
        mov     [rbx], rax      ; store rax's 8 bytes at that address

Only one operand of an instruction may be in memory: to copy memory to memory, go through a register.

Building an address

An x86 address can combine up to four parts:

Output
[ base + index * scale + displacement ]
Part Is
base any register
index any register except rsp
scale 1, 2, 4 or 8
displacement a constant, or a label

That covers almost everything a program needs in one instruction:

C Assembly (rdi = the array, rsi = i)
p->field at offset 16 [rdi + 16]
a[i] for 8-byte elements [rdi + rsi*8]
a[i] for 4-byte ints [rdi + rsi*4]
a[i + 1] [rdi + rsi*8 + 8]
bytes[i] [rdi + rsi]

Labels: rel

A label is an address fixed when the program is built. Programs today are often loaded at a random address (a protection called ASLR), so code refers to its data relative to rip, the address of the current instruction: [rel label]. The assembler works out the distance.

Assembly
        mov     rax, [rel total]        ; read the 8 bytes at total
        lea     rsi, [rel message]      ; the address of message itself

(default rel at the top of a file makes every [label] rip-relative, so you can leave out rel.)

Sizes

The register says how many bytes move: mov eax, [rdi] reads 4, mov al, [rdi] reads 1. When no register is involved, write the size:

Assembly
        mov     byte [rdi], 'A'         ; store one byte
        mov     dword [rdi + 4], 100    ; store 4 bytes
        add     qword [rel count], 1    ; add to 8 bytes

Widening: movzx and movsx

To read a small value into a big register, say how to fill the rest:

Instruction Fills the upper bits with For
movzx eax, byte [rdi] 0s unsigned bytes, characters
movsx rax, byte [rdi] copies of the sign bit signed bytes
movsx rax, word [rdi] signed 16-bit numbers
movsxd rax, dword [rdi] signed 32-bit numbers to 64

(32-bit unsigned needs nothing special: mov eax, [rdi] already clears the top half.)

lea: the address, not the contents

lea (load effective address) works out the address in brackets and puts the number in the register, without reading memory:

Assembly
        lea     rax, [rdi + rsi*8]      ; rax = the address of a[i]
        mov     rax, [rdi + rsi*8]      ; rax = a[i] itself

That is how C's &a[i] compiles, and it is also why lea doubles as an adder (lesson 2.03).

Assembly
        global  _start
        section .data
values: dq      10, 20, 30, 40

        section .text
_start:
        lea     rbx, [rel values]       ; the array's address
        mov     rdi, [rbx + 2*8]        ; values[2] = 30
        add     rdi, [rbx + 3*8]        ; + values[3] = 70
        call    print_int
        call    print_newline
        mov     qword [rbx], 99         ; values[0] = 99
        mov     rdi, [rbx]
        call    print_int
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall
