Loops

lesson 3.022 of 5 in milestone 35 min1 practice task

A loop is a jump backwards. Counting loops often count down to zero with dec and jnz, since dec sets the zero flag for free. A while loop tests at the top and a do-while at the bottom; compilers prefer the bottom test with one check in front. Reading until read_int reports the end of the input makes a loop over all the input.

A jump backwards

Assembly
        global  _start
        section .text
_start:
        mov     ebx, 1                  ; i = 1
.loop:
        mov     edi, ebx
        call    print_int
        call    print_newline
        inc     ebx                     ; i++
        cmp     ebx, 5
        jle     .loop                   ; while i <= 5, go round again
        mov     eax, 60
        xor     edi, edi
        syscall

The counter lives in rbx because print_int may change rcx, rdx, rsi and rdi.

Counting down to zero

dec sets ZF when it reaches zero, so a loop that counts down needs no cmp:

That is the classic assembly loop. (x86 even has a loop instruction that decrements rcx and jumps, but on modern processors it is slower than dec + jnz, so compilers never use it.)

while and do-while

A do-while tests at the bottom, so the body always runs at least once:

Assembly
.body:
        ; ...
        cmp     ...
        jcc     .body

A while loop must test first, in case it should run zero times. The straightforward version tests at the top and jumps back from the bottom:

Assembly
.test:
        cmp     ...
        jcc     .end            ; the opposite condition: leave the loop
        ; ... body ...
        jmp     .test
.end:

That is two jumps per round. Compilers turn it into a single test in front plus a do-while, called a rotated loop, which takes one jump per round:

Assembly
        cmp     ...
        jcc     .end            ; skip the loop entirely if it should not run
.body:
        ; ... body ...
        cmp     ...
        jcc     .body           ; one jump per round
.end:

Reading until the end of the input

read_int returns rdx = 0 when there are no more numbers. Testing it after each call makes a loop over the whole input:

Assembly
        global  _start
        section .data
s_count: db     " numbers, total ", 0

        section .text
_start:
        xor     ebx, ebx                ; total
        xor     r12d, r12d              ; count
.next:
        call    read_int
        test    rdx, rdx
        jz      .done                   ; no more numbers
        add     rbx, rax
        inc     r12
        jmp     .next
.done:
        mov     rdi, r12
        call    print_int
        lea     rdi, [rel s_count]
        call    print_str
        mov     rdi, rbx
        call    print_int
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

Try it with several numbers on several lines.

Loops inside loops

Keep each counter in its own register that survives the calls inside (here r12 and r13):

Assembly
        global  _start
        section .text
_start:
        mov     r12d, 1                 ; row
.row:
        mov     r13d, 1                 ; column
.col:
        mov     edi, '*'
        call    print_char
        inc     r13d
        cmp     r13d, r12d
        jle     .col                    ; columns 1..row
        call    print_newline
        inc     r12d
        cmp     r12d, 4
        jle     .row
        mov     eax, 60
        xor     edi, edi
        syscall
