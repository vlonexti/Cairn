Buffers and Input

lesson 4.055 of 5 in milestone 45 min1 practice task

Input arrives as bytes in a buffer, from the read system call or the read_line routine. Turning typed digits into a number is the reverse of printing - multiply what you have by 10 and add the next digit. Always pass the buffer's size, check what came back, and handle the end of the input.

The read system call

read (system call 0) copies up to a given number of bytes from a file into a buffer and returns how many it got: fewer than asked if that is all there is, 0 at the end of the input, negative on an error.

Assembly
        global  _start
        section .bss
buffer: resb    64

        section .text
_start:
        xor     eax, eax                ; read
        xor     edi, edi                ; standard input
        lea     rsi, [rel buffer]
        mov     edx, 64                 ; at most 64 bytes
        syscall
        test    rax, rax
        jle     .exit                   ; nothing read, or an error
        mov     rdx, rax                ; echo exactly the bytes that came in
        mov     eax, 1
        mov     edi, 1
        lea     rsi, [rel buffer]
        syscall
.exit:
        mov     eax, 60
        xor     edi, edi
        syscall

A single read may return part of a line, or several lines at once: it returns whatever bytes are ready. Real programs loop until they have what they need. That bookkeeping is what read_line and read_int do for you.

read_line

read_line (from lesson 1.06) fills a buffer with exactly one line, without the new line, ends it with a 0, and returns its length, or −1 at the end of the input. The buffer and its size are yours:

Assembly
        global  _start
        section .bss
line:   resb    100

        section .data
s_len:  db      " characters: ", 0

        section .text
_start:
.next:
        lea     rdi, [rel line]
        mov     esi, 100
        call    read_line
        cmp     rax, -1
        je      .exit
        mov     rdi, rax
        call    print_int
        lea     rdi, [rel s_len]
        call    print_str
        lea     rdi, [rel line]
        call    print_str
        call    print_newline
        jmp     .next
.exit:
        mov     eax, 60
        xor     edi, edi
        syscall

Digits into a number

Typed text "427" is the bytes 52, 50, 55. Converting it is printing in reverse: start at 0, and for each digit multiply by 10 and add the digit's value:

Character number × 10 + digit
0
'4' 0 × 10 + 4 = 4
'2' 4 × 10 + 2 = 42
'7' 42 × 10 + 7 = 427
Assembly
; rdi = a string of digits. Returns its value (stops at the first non-digit).
parse:
        xor     eax, eax
.loop:  movzx   ecx, byte [rdi]
        sub     ecx, '0'
        cmp     ecx, 9
        ja      .done                   ; not a digit (the 0 at the end included)
        imul    rax, rax, 10
        add     rax, rcx
        inc     rdi
        jmp     .loop
.done:  ret

The one unsigned compare checks for a digit (lesson 3.03). read_int is this loop, plus skipping spaces and handling a minus sign. Lesson 6.02 writes the whole thing.

Buffer rules

  • Pass the real size, and never write past it. read_line is told the size and cuts long lines short; your own loops must count too.
  • Remember what the buffer holds after a call: read does not add a 0, while read_line does.
  • Check the result before using the buffer: 0 bytes or −1 means there is nothing there.
