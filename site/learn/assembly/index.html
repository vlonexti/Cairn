Assembly

8 milestones41 lessons51 practice tasks40 projects

Write programs in the processor's own instructions: x86-64 assembly in Intel syntax with NASM, running on Linux. Starting from a program that prints with a system call, the course covers registers, data, Xenon's print and read routines, arithmetic, multiplying and dividing, bit operations and the flags, how numbers become printed digits, compares and jumps, loops, signed and unsigned conditions, if and switch as the compiler writes them, branch-free code, addressing modes, arrays, strings, the stack, buffers and input, call and ret, the System V calling convention, stack frames, recursion, calling and being called from C, reading compiler output, parsing numbers, optimisation, SIMD, ARM64, and finally floating point with SSE, NASM macros, files through system calls, structures, and bit scanning and atomic instructions, then string instructions, division by magic numbers, jump tables, memory from mmap, and arguments and the environment. Every lesson has checked practice, assembled with NASM and run for real, and every milestone ends with five projects, from small to large.
