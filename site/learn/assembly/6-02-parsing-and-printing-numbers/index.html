Parsing and Printing Numbers

lesson 6.022 of 5 in milestone 65 min1 practice task

Now you can write the routines you have been borrowing. Parsing skips spaces, reads an optional sign, and multiplies and adds digit by digit, with any base and an overflow check. Printing divides by the base to produce digits from the right, handles the sign and the most negative number, and maps digits above 9 to letters.

Parsing in any base

The rule from lesson 4.05 works for every base: value = value × base + digit. Hex digits a to f (or A to F) are worth 10 to 15.

Assembly
; parse: rdi = a string, rsi = the base (2 to 16).
; Returns the value in rax, and in rdx a pointer to the first character it did not use.
parse:
        xor     eax, eax
.next:  movzx   ecx, byte [rdi]
        lea     edx, [rcx - '0']
        cmp     edx, 9
        jbe     .have                   ; '0'..'9'
        or      ecx, 0x20               ; lower case
        lea     edx, [rcx - 'a']
        cmp     edx, 5
        ja      .stop                   ; not 'a'..'f' either
        add     edx, 10
.have:  cmp     rdx, rsi
        jae     .stop                   ; a digit too big for this base
        imul    rax, rsi
        add     rax, rdx
        inc     rdi
        jmp     .next
.stop:  mov     rdx, rdi
        ret

Returning "where it stopped" lets the caller check that the whole text was a number (it should stop at the 0), just like C's strtol.

Overflow

imul and add silently wrap if the number is too big. A careful parser checks the overflow flag after each step: jo .too_big right after the imul, and again after the add. For unsigned numbers, check the carry flag (jc) after add, and use mul (which sets CF and OF when the high half is not zero).

Printing in any base

Printing divides by the base: each remainder is the next digit from the right.

Assembly
        global  _start
        section .data
digits: db      "0123456789abcdef"

        section .bss
out:    resb    72

        section .text
; print_base: rdi = an unsigned number, rsi = the base (2 to 16). Prints it.
print_base:
        lea     r8, [rel out + 71]      ; the end of the buffer
        lea     r9, [rel digits]
        mov     rax, rdi
.digit: xor     edx, edx
        div     rsi                     ; rdx = the next digit, from the right
        movzx   ecx, byte [r9 + rdx]    ; its character, from the table
        mov     [r8], cl
        dec     r8
        test    rax, rax
        jnz     .digit
        inc     r8                      ; the first digit
        lea     rdx, [rel out + 72]
        sub     rdx, r8                 ; the length
        mov     rsi, r8
        mov     eax, 1
        mov     edi, 1
        syscall
        ret

_start:
        mov     edi, 3054
        mov     esi, 10
        call    print_base
        call    print_newline
        mov     edi, 3054
        mov     esi, 16
        call    print_base              ; bee
        call    print_newline
        mov     edi, 3054
        mov     esi, 2
        call    print_base
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

Looking digits up in a table, [r9 + rdx], avoids an if for digits above 9.

Signed numbers

To print a signed number: if it is negative, print - and print its negation as unsigned. That even works for the most negative number, −2⁶³: neg leaves it unchanged (it has no positive twin), but read as unsigned it is 2⁶³, exactly the right digits.

To parse one: remember whether there was a -, parse the digits, then neg at the end.

Skipping and checking

A friendly parser also skips leading spaces and tabs, and the caller decides what to do with leftovers: "12abc" stops at a, so it is not a clean number. That is all read_int does: skip spaces, check for -, parse digits, and put back the character that stopped it, for the next read.
