Compare and Jump

lesson 3.011 of 5 in milestone 35 min1 practice task

jmp always jumps to a label. A conditional jump such as je, jne, jl or jg jumps only when the flags say so, which usually means right after cmp or test. An if statement becomes a compare, a jump over the code that should not run, and a label. Labels starting with a dot are local to the label above them.

jmp

jmp label makes the processor continue at the label instead of the next line: it just puts a new address in rip.

Assembly
        jmp     done            ; skip everything up to done
        mov     eax, 99         ; never runs
done:

Conditional jumps

A conditional jump looks at the flags and jumps only if its condition holds; otherwise it carries on with the next line. After cmp a, b:

Jump Jumps if Meaning
je / jz ZF = 1 a == b (or: the result was zero)
jne / jnz ZF = 0 a != b
jl SF ≠ OF a < b, signed
jle ZF = 1 or SF ≠ OF a <= b, signed
jg ZF = 0 and SF = OF a > b, signed
jge SF = OF a >= b, signed
jb CF = 1 a < b, unsigned ("below")
jbe CF = 1 or ZF = 1 a <= b, unsigned
ja CF = 0 and ZF = 0 a > b, unsigned ("above")
jae CF = 0 a >= b, unsigned
js / jns SF = 1 / 0 negative / not negative

You never need to remember the flag formulas: read cmp rax, rbx followed by jl as "jump if rax < rbx". Lesson 3.03 explains the signed and unsigned pairs.

if

C's

C
if (temperature < 0) {
    puts("Freezing");
}
puts("Done");

becomes a compare and a jump over the body, using the opposite condition:

Assembly
        global  _start
        section .data
freezing: db    "Freezing", 10, 0
done_msg: db    "Done", 10, 0

        section .text
_start:
        call    read_int                ; the temperature
        cmp     rax, 0
        jge     .after                  ; NOT below zero: skip the body
        lea     rdi, [rel freezing]
        call    print_str
.after:
        lea     rdi, [rel done_msg]
        call    print_str
        mov     eax, 60
        xor     edi, edi
        syscall

Try it with -5 and with 12 as the input.

if and else

With an else, the "then" part must jump over the "else" part when it is done:

Assembly
        cmp     rax, rbx
        jle     .else           ; not (rax > rbx)
        ; ... rax is bigger ...
        jmp     .end
.else:
        ; ... rbx is bigger or equal ...
.end:

This shorter pattern is common: put one answer in place, and jump past the line that would replace it.

Local labels

Every label in a file must be unique, which gets tedious: .after, .loop, .done would be needed many times. In NASM a label starting with a dot is local: it belongs to the most recent ordinary label above it, so each function can have its own .done.

Assembly
max:
        mov     rax, rdi
        cmp     rdi, rsi
        jge     .done           ; this is really max.done
        mov     rax, rsi
.done:  ret

min:
        mov     rax, rdi
        cmp     rdi, rsi
        jle     .done           ; min.done: no clash
        mov     rax, rsi
.done:  ret
