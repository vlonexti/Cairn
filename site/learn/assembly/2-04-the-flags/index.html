The Flags

lesson 2.044 of 5 in milestone 25 min1 practice task

Arithmetic and logic instructions record facts about their result in rflags - ZF when it is zero, SF when it is negative, CF when an unsigned result wrapped, OF when a signed result overflowed. cmp and test set flags without keeping a result. adc and sbb use the carry to work on numbers bigger than a register.

Notes about the last result

Most arithmetic and logic instructions leave notes about their result in the rflags register. Four of the single-bit flags matter most:

Flag Name Set when the result...
ZF zero is 0
SF sign has its top bit set: negative, read as signed
CF carry wrapped past the top or below 0, read as unsigned
OF overflow is wrong, read as signed: two positives gave a negative, or two negatives a positive

mov, lea, push and pop do not change the flags; add, sub, and, or, xor, neg, cmp, test and shifts do. (inc and dec change all but CF.)

Step through and read the flags after each line:

  1. 5 - 5 is 0: ZF.
  2. 0 - 1 is −1 (all 1s): SF, and CF, because as unsigned numbers 0 − 1 went below zero.
  3. 0x7FFFFFFF + 1: the biggest signed 32-bit number plus one becomes the most negative one: OF and SF. As unsigned it is fine (2,147,483,648), so no CF.
  4. 0xFFFFFFFF + 1 wraps to 0: CF and ZF. As signed it is −1 + 1 = 0, perfectly fine, so no OF.

The processor doesn't know whether you meant signed or unsigned, so it records both: CF for unsigned, OF for signed.

cmp and test

The next module's jumps read the flags. To set them without changing anything:

  • cmp a, b subtracts b from a, sets the flags, and throws the answer away. After cmp rax, rbx, ZF means they were equal, and CF means rax < rbx as unsigned numbers.
  • test a, b does an and, sets the flags and throws the answer away. test rax, rax sets ZF if rax is 0 and SF if it is negative.

Bigger than 64 bits: adc and sbb

The carry flag is the "carry the one" of long addition. adc (add with carry) adds the operand and CF, so you can add numbers of any size, 64 bits at a time:

Assembly
; a 128-bit number in rdx:rax plus another in rcx:rbx
        add     rax, rbx        ; the low halves; CF = the carry out
        adc     rdx, rcx        ; the high halves, plus that carry

sbb (subtract with borrow) does the same for subtraction. A neat trick: after cmp a, b, sbb eax, eax gives −1 if a < b as unsigned numbers and 0 otherwise, without any jump.

Keeping a flag as a number

adc with zero turns the carry into a number:

Assembly
        global  _start
        section .text
_start:
        mov     rax, -1                 ; the largest unsigned 64-bit number
        xor     ebx, ebx
        add     rax, 1                  ; wraps: CF = 1
        adc     rbx, 0                  ; rbx = 0 + 0 + CF = 1
        mov     rdi, rbx
        call    print_int
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall
