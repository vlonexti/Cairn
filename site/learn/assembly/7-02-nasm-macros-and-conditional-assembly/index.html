NASM Macros and Conditional Assembly

lesson 7.022 of 5 in milestone 75 min2 practice tasks

Writing less assembly by hand - single-line macros with %define, multi-line macros with %macro and their parameters, local labels with %%, repeating code with %rep and %assign, choosing code with %if and %ifdef, and macros that generate whole functions.

The preprocessor

Before NASM assembles anything, its preprocessor expands macros, much as C's preprocessor does (C course lesson 5.04). Macros remove repetition that functions cannot: saving the same registers in every function, unrolling a loop, defining a family of similar functions.

%define: single-line macros

Assembly
%define SYS_WRITE   1
%define SYS_EXIT    60
%define STDOUT      1
%define ELEMENT(base, i)  [base + (i) * 8]     ; a macro with parameters

        mov     eax, SYS_WRITE
        mov     rax, ELEMENT(rdi, 3)          ; becomes mov rax, [rdi + (3) * 8]

%define is pure text replacement. equ (lesson 1.05) defines a number the assembler knows; %define can stand for any text, including registers and operands.

%macro: multi-line macros

A multi-line macro has a name and a number of parameters; inside, %1, %2 ... are the arguments:

Assembly
        global  _start
        section .text

%macro EXIT 1
        mov     eax, 60
        mov     edi, %1
        syscall
%endmacro

%macro PRINT_NUMBER 1
        mov     rdi, %1
        call    print_int
        call    print_newline
%endmacro

_start:
        mov     rbx, 6
        imul    rbx, 7
        PRINT_NUMBER rbx            ; 42
        PRINT_NUMBER 100
        EXIT    0

A range like %macro SAVE 1-3 accepts one to three arguments; %0 is how many were given.

Local labels: %%

A label inside a macro would be defined twice if the macro is used twice. Prefixing it with %% makes NASM invent a fresh name at each use:

Assembly
        global  _start
        section .text

; CLAMP reg, low, high: keeps reg between low and high (registers or numbers).
%macro CLAMP 3
        cmp     %1, %2
        jge     %%not_low
        mov     %1, %2
%%not_low:
        cmp     %1, %3
        jle     %%done
        mov     %1, %3
%%done:
%endmacro

_start:
        mov     rax, -40
        CLAMP   rax, 0, 255
        mov     rdi, rax
        call    print_int               ; 0
        call    print_newline
        mov     rax, 900
        CLAMP   rax, 0, 255
        mov     rdi, rax
        call    print_int               ; 255
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

Repeating: %rep and %assign

%rep n ... %endrep copies its body n times. %assign sets a number the preprocessor can compute with, so each copy can be different. Together they unroll a loop:

Assembly
        global  _start
        section .data
numbers: dq     3, 1, 4, 1, 5, 9, 2, 6
        section .text

; sum8: rdi = an array of exactly 8 qwords. No loop counter, no jumps.
sum8:
        xor     eax, eax
%assign i 0
%rep 8
        add     rax, [rdi + i * 8]
%assign i i + 1
%endrep
        ret

_start:
        lea     rdi, [rel numbers]
        call    sum8
        mov     rdi, rax
        call    print_int               ; 31
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

The listing of the assembled program shows eight add instructions with offsets 0, 8, 16 ... 56.

Choosing code: %if and %ifdef

Assembly
%define DEBUG 1

%if DEBUG
        call    dump_registers          ; only assembled when DEBUG is non-zero
%endif

%ifdef WINDOWS
        ; the Windows calling convention
%else
        ; System V
%endif

Pass definitions on the command line with nasm -dDEBUG=1 ... to build different versions from one source.

Macros that write functions

A macro can produce a whole function, with names glued together from its parameters:

Assembly
        global  _start
        section .text

%macro MAKE_SCALER 2                    ; name, factor
scale_%1:
        mov     rax, rdi
        imul    rax, %2
        ret
%endmacro

MAKE_SCALER double, 2
MAKE_SCALER triple, 3
MAKE_SCALER dozen, 12

_start:
        mov     edi, 5
        call    scale_dozen
        mov     rdi, rax
        call    print_int               ; 60
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

When to use them

Macros are great for boilerplate that must be identical everywhere (prologues, system calls, error checks) and for unrolling. Overused, they hide what the code really does and make debugging harder, because the debugger shows the expanded instructions. A plain call to a function is often clearer and smaller.
