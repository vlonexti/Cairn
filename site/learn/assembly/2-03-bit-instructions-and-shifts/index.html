Bit Instructions and Shifts

lesson 2.033 of 5 in milestone 25 min1 practice task

and, or, xor and not work on every bit at once and make masks for testing, setting and clearing bits. shl and shr shift bits left and right - multiplying and dividing unsigned numbers by powers of two - while sar keeps the sign for signed numbers. rol and ror rotate, a variable shift count goes in cl, and lea multiplies by 3, 5 and 9 in one step.

and, or, xor, not

Instruction Each result bit is 1 when Typical use
and rax, rbx both bits are 1 keep some bits, clear the rest: and eax, 0xFF
or rax, rbx either bit is 1 set bits: or eax, 0x20
xor rax, rbx the bits differ flip bits; xor eax, eax is 0
not rax the bit was 0 flip every bit

test rax, rbx is an and that only sets the flags and throws the result away: the usual way to ask "is this bit set?" or "is this register zero?" (test rax, rax).

Assembly
        global  _start
        section .text
_start:
        mov     ebx, 'a'                ; 0110 0001
        and     ebx, 0xDF               ; clear bit 5: 'A' (0100 0001)
        mov     edi, ebx
        call    print_char
        or      ebx, 0x20               ; set bit 5 again: 'a'
        mov     edi, ebx                ; (print_char may change edi, so copy again)
        call    print_char
        call    print_newline
        mov     edi, 0xF0
        not     edi                     ; ...FFFFFF0F
        and     edi, 0xFF               ; keep the low byte: 0x0F
        call    print_hex
        call    print_newline
        mov     eax, 60
        xor     edi, edi
        syscall

The Fundamentals course shows why one bit separates upper and lower case in ASCII.

Shifts

Instruction Does Same as
shl rax, n bits move left n places, 0s come in × 2ⁿ
shr rax, n bits move right, 0s come in unsigned ÷ 2ⁿ
sar rax, n bits move right, copies of the sign bit come in signed ÷ 2ⁿ (rounding down)
rol rax, n / ror rax, n rotate: bits leaving one end come back at the other

The count is a constant, or the register cl for a count worked out at run time (shl rax, cl). Only 6 bits of the count are used, so shifting a 64-bit register by 64 shifts by 0.

shr treats −16 as a huge unsigned number; sar keeps it negative and gives −4.

Masks with shifts

Combine a shift and and to pull a field out of a number, like the C course's bit lessons:

Assembly
        mov     eax, edi
        shr     eax, 8          ; move bits 8..15 to the bottom
        and     eax, 0xFF       ; keep just them

and build a one-bit mask from a run-time position:

Assembly
        mov     ecx, esi        ; the bit number, which must be in cl
        mov     eax, 1
        shl     rax, cl         ; rax = 1 << n
        or      rdi, rax        ; set bit n of rdi

x86 also has single instructions for one bit: bt (test), bts (set), btr (clear), btc (flip).

Multiplying with lea and shifts

lea computes an address expression without touching memory, and the expression can be base + index × 1, 2, 4 or 8. That makes it a quick multiplier:

Assembly
        lea     rax, [rdi + rdi*2]      ; rax = rdi * 3
        lea     rax, [rdi + rdi*4]      ; rax = rdi * 5
        lea     rax, [rdi*8 + rdi]      ; rax = rdi * 9
        lea     rax, [rax + rax*4]
        add     rax, rax                ; with the line above: * 10

Compilers turn x * 10 into exactly that pair.
