Rust and Cargo: Your First Program

lesson 1.011 of 5 in milestone 15 min1 practice task

What Rust is for and what makes it different, installing it with rustup, creating and running a project with Cargo, the shape of a program with fn main, printing with println! and format strings, comments, and how to read the compiler's unusually helpful error messages.

Rust

Rust is a systems language: it compiles to fast machine code with no garbage collector, like C and C++, so it suits operating systems, browsers, game engines, command-line tools, servers and embedded devices. What makes it different is that the compiler proves memory safety: no dangling pointers, no use-after-free, no data races between threads. The rules that guarantee this (ownership and borrowing, milestone 2) are checked when you compile, so they cost nothing when the program runs.

The price is a stricter compiler. Rust programmers say they "fight the borrow checker" at first; the compiler's messages are excellent, and the bugs it stops are the ones that are hardest to find in other languages.

Installing and Cargo

Install Rust with rustup from rust-lang.org. It provides rustc (the compiler) and Cargo, the build tool and package manager you use for everything:

Terminal
cargo new hello          # a new project folder with Cargo.toml and src/main.rs
cd hello
cargo run                # compile and run (debug build)
cargo build --release    # an optimised build in target/release
cargo check              # type-check quickly without producing a program

Cargo.toml describes the project and its dependencies (crates, from crates.io). The practice editor here compiles your code on Rust 1.99 (edition 2024) for you.

Your first program

Rust
fn main() {
    println!("Hello, Xenon!");
    let name = "Ada";
    let year = 1815;
    println!("{name} was born in {year}.");
    println!("{} + {} = {}", 2, 3, 2 + 3);
}
  • fn main() is where the program starts. Functions are declared with fn.
  • println! prints a line. The ! means it is a macro, not a function: macros can take a format string and a variable number of arguments, checked at compile time.
  • {} in the format string is filled by the next argument; {name} uses a variable of that name directly.
  • Statements end with ;. Blocks are in braces.

Formatting

Rust
fn main() {
    let pi = 3.14159265;
    let item = "tea";
    println!("[{pi:.2}]");                  // 2 decimals: 3.14
    println!("[{item:>8}] [{item:<8}] [{item:^8}]");   // right, left, centred in 8
    println!("[{:05}] [{:+}] [{:x}] [{:b}]", 42, 7, 255, 5);   // zero-padded, sign, hex, binary
    println!("{:?}", vec![1, 2, 3]);       // {:?} is the Debug format: for developers
    eprintln!("this goes to standard error");
    let s = format!("{item} costs {:.2}", 2.5);     // format! builds a String instead of printing
    println!("{s}");
}

Compiler errors

Rust's error messages show the code, point at the problem and often suggest the fix:

Text
error[E0384]: cannot assign twice to immutable variable `x`
 --> src/main.rs:3:5
  |
2 |     let x = 5;
  |         - first assignment to `x`
3 |     x = 6;
  |     ^^^^^ cannot assign twice to immutable variable
  |
help: consider making this binding mutable
  |
2 |     let mut x = 5;
  |         +++

Read the first error first, and read the help: lines: they are usually right. rustc --explain E0384 prints a long explanation of any error code.
