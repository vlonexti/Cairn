Pattern Matching in Depth

lesson 5.055 of 5 in milestone 55 min1 practice task

Everywhere patterns appear (let, match, if let, while let, let else, function parameters, for loops), destructuring structs, enums, tuples, references and nested data, slice patterns, ranges, bindings with @, guards, ignoring with _ and .., refutable versus irrefutable patterns, and matches!.

Patterns everywhere

Patterns are not just for match. They appear wherever a value is bound to names:

Rust
struct Point { x: i32, y: i32 }

fn print_coords(&(x, y): &(i32, i32)) {            // a pattern in a parameter
    println!("({x}, {y})");
}

fn main() {
    let (a, b, c) = (1, "two", 3.0);                // a tuple pattern in let
    let Point { x, y: height } = Point { x: 5, y: 9 };   // a struct pattern, renaming y
    println!("{a} {b} {c} {x} {height}");
    print_coords(&(3, 4));

    for (i, ch) in "abc".chars().enumerate() {      // in a for loop
        print!("{i}{ch} ");
    }
    println!();

    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {             // while let: loop while the pattern matches
        print!("{top} ");
    }
    println!();
}

Destructuring nested data

Rust
#[derive(Debug)]
enum Shape { Circle { r: f64 }, Rect { w: f64, h: f64 } }

#[derive(Debug)]
enum Event {
    Click { x: i32, y: i32 },
    Key(char),
    Draw(Shape, (u8, u8, u8)),
    Quit,
}

fn describe(e: &Event) -> String {
    match e {
        Event::Click { x: 0, y: 0 } => "click at the origin".into(),
        Event::Click { x, y } if x == y => format!("click on the diagonal at {x}"),
        Event::Click { x, .. } => format!("click with x = {x}"),
        Event::Key(c @ ('a'..='z' | 'A'..='Z')) => format!("letter {c}"),
        Event::Key(c) => format!("other key {c:?}"),
        Event::Draw(Shape::Circle { r }, (255, _, _)) => format!("a red-ish circle of radius {r}"),
        Event::Draw(Shape::Rect { w, h }, color) => format!("a {w}x{h} rectangle in {color:?}"),
        Event::Draw(shape, _) => format!("some other {shape:?}"),
        Event::Quit => "quit".into(),
    }
}

fn main() {
    let events = [
        Event::Click { x: 0, y: 0 }, Event::Click { x: 4, y: 4 }, Event::Click { x: 7, y: 1 },
        Event::Key('q'), Event::Key('7'),
        Event::Draw(Shape::Circle { r: 2.0 }, (255, 10, 10)),
        Event::Draw(Shape::Rect { w: 3.0, h: 1.0 }, (0, 0, 255)),
        Event::Draw(Shape::Circle { r: 1.0 }, (0, 0, 0)),
        Event::Quit,
    ];
    for e in &events {
        println!("{}", describe(e));
    }
}
Pattern Matches
0, 'a', "text" (on &str), true A literal
x Anything, binding it to x
_ Anything, without binding
.. The remaining fields or items
1..=9, 'a'..='z' An inclusive range
A | B Either pattern
name @ pattern Matches the pattern and binds the whole value
Some(x), Point { x, .. }, (a, b) Destructuring
&x Dereferences a reference
pattern if condition A guard (only in match)

Slice patterns

Rust
fn summary(values: &[i32]) -> String {
    match values {
        [] => "empty".into(),
        [one] => format!("one: {one}"),
        [first, second] => format!("two: {first}, {second}"),
        [first, .., last] if first == last => format!("starts and ends with {first}"),
        [first, middle @ .., last] => format!("{first} .. {} middle .. {last}", middle.len()),
    }
}

fn main() {
    for v in [&[][..], &[7][..], &[1, 2][..], &[5, 0, 0, 5][..], &[1, 2, 3, 4, 5][..]] {
        println!("{}", summary(v));
    }
}

Refutable and irrefutable

A pattern that can fail to match (Some(x)) is refutable; one that always matches ((a, b) for a pair) is irrefutable. let and function parameters need irrefutable patterns; if let, while let, match arms and let ... else accept refutable ones:

Rust
fn parse_point(s: &str) -> Option<(i32, i32)> {
    let Some((a, b)) = s.split_once(',') else { return None };     // refutable: needs else
    let (Ok(x), Ok(y)) = (a.trim().parse(), b.trim().parse()) else { return None };
    Some((x, y))
}

fn main() {
    println!("{:?} {:?} {:?}", parse_point("3, 4"), parse_point("3;4"), parse_point("a,1"));
    let ok = matches!(parse_point("1,2"), Some((x, _)) if x > 0);   // matches!: a pattern test as a bool
    println!("{ok}");
}
