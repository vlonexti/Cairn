Control Flow

lesson 1.044 of 5 in milestone 15 min1 practice task

if and else as expressions, loop with break values, while, for over ranges and collections, labelled breaks, a first look at match with ranges and multiple patterns, and choosing the right loop.

if

Rust
fn main() {
    let temperature = 23;
    if temperature >= 30 {
        println!("Hot");
    } else if temperature >= 18 {
        println!("Pleasant");
    } else {
        println!("Cold");
    }
    let label = if temperature % 2 == 0 { "even" } else { "odd" };
    println!("{label}");
}

The condition must be a bool: if count { } does not compile. Braces are required; parentheses around the condition are not used.

loop, while and for

Rust
fn main() {
    // loop runs until break; break can return a value
    let mut n = 27u64;
    let mut steps = 0;
    let result = loop {
        if n == 1 {
            break steps;
        }
        n = if n % 2 == 0 { n / 2 } else { 3 * n + 1 };
        steps += 1;
    };
    println!("{result} steps");

    // while: repeat while a condition holds
    let mut countdown = 3;
    while countdown > 0 {
        print!("{countdown} ");
        countdown -= 1;
    }
    println!("lift-off");

    // for: over a range or a collection
    for i in 1..=5 {
        print!("{} ", i * i);
    }
    println!();
    let names = ["Ada", "Grace", "Linus"];
    for (index, name) in names.iter().enumerate() {
        println!("{index}: {name}");
    }
    for i in (0..10).rev().step_by(3) {
        print!("{i} ");
    }
    println!();
}

for is the most common loop: it cannot go out of bounds and needs no index variable. enumerate() adds the index when you need it.

break and continue

Rust
fn main() {
    let numbers = [4, 7, -1, 12, 0, 9];
    let mut sum = 0;
    for x in numbers {
        if x < 0 { continue; }
        if x == 0 { break; }
        sum += x;
    }
    println!("{sum}");

    'outer: for i in 0..5 {
        for j in 0..5 {
            if i * j == 6 {
                println!("found {i} x {j}");
                break 'outer;           // leaves both loops
            }
        }
    }
}

match

match compares a value against patterns, in order, and must cover every possible value:

Rust
fn main() {
    for day in [1, 6, 7, 9] {
        let kind = match day {
            1..=5 => "weekday",
            6 | 7 => "weekend",
            _ => "not a day",          // _ matches anything else
        };
        println!("{day}: {kind}");
    }
}

If you leave out the _ arm, the compiler refuses: "non-exhaustive patterns". This exhaustiveness check catches forgotten cases at compile time. match becomes much more powerful with enums (lesson 2.05).

Choosing a loop

Situation Loop
Over a collection or a range for
Until a condition becomes false while
Until something inside decides (retry, read until done) loop with break
