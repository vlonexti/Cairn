Rust

8 milestones40 lessons50 practice tasks40 projects

Rust from the first program to safe concurrency: Cargo, types and expressions, ownership, borrowing and slices, structs, enums and pattern matching, vectors, strings and hash maps, error handling with Result, modules and tests, generics and traits, lifetimes and trait objects, closures and iterators, smart pointers, threads, channels and shared state, a complete command-line tool, and finally the advanced language: macros, Deref and Cow, unsafe code and FFI, files and processes, and type-state with PhantomData, then error types, operators and conversions, collections, advanced traits and parsers. Best after a first language; the C++ memory milestones make the ownership rules feel familiar. Practice compiles and runs in your browser.
