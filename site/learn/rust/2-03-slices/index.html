Slices

lesson 2.033 of 5 in milestone 25 min1 practice task

Borrowing part of a collection with slices - string slices &str and their byte ranges, array and vector slices &[T], ranges in indexing, slice methods (len, first, last, split_at, chunks, windows, contains, iter), mutable slices &mut [T], and writing functions that take slices to accept arrays, vectors and parts of them.

String slices

A slice is a reference to a contiguous part of a collection. &s[start..end] borrows bytes start up to (not including) end:

Rust
fn main() {
    let s = String::from("hello world");
    let hello: &str = &s[0..5];
    let world = &s[6..];               // to the end
    let all = &s[..];                  // the whole string
    println!("[{hello}] [{world}] [{all}]");
    println!("{}", first_word("the quick brown fox"));
}

fn first_word(text: &str) -> &str {
    match text.find(' ') {
        Some(i) => &text[..i],
        None => text,
    }
}

first_word returns a slice into its argument, without copying. The borrow checker makes sure the original string outlives the slice: you cannot clear the String while a slice of it is in use.

String slice ranges are in bytes, and must fall on character boundaries. &"héllo"[0..2] panics, because é takes two bytes and the range cuts it in half. For text from users, prefer chars() and the string methods (lesson 3.02).

Array and vector slices

&[T] is a slice of any sequence of T: part of an array, part of a vector, or all of either.

Rust
fn main() {
    let array = [3, 8, 1, 9, 4];
    let vector = vec![10, 20, 30];
    println!("{} {} {}", sum(&array), sum(&vector), sum(&array[1..3]));
    println!("{:?}", largest(&array));
    println!("{:?}", largest(&[]));
}

fn sum(values: &[i32]) -> i32 {
    let mut total = 0;
    for v in values {
        total += v;
    }
    total
}

fn largest(values: &[i32]) -> Option<i32> {
    let mut best = *values.first()?;          // ? returns None early for an empty slice
    for &v in values {
        if v > best { best = v; }
    }
    Some(best)
}

Write functions that only read a sequence to take &[T] (and text as &str): they then work with arrays, vectors and sub-ranges alike, and never need to own the data.

Slice methods

Rust
fn main() {
    let data = [5, 1, 4, 2, 8, 7];
    println!("{} {:?} {:?} {}", data.len(), data.first(), data.last(), data.contains(&4));
    let (left, right) = data.split_at(2);
    println!("{left:?} {right:?}");
    for pair in data.windows(2) {
        print!("{} ", pair[1] - pair[0]);         // differences between neighbours
    }
    println!();
    for chunk in data.chunks(4) {
        print!("{chunk:?} ");
    }
    println!();
    println!("{:?}", data.iter().position(|&x| x == 2));
    let mut sorted = data;                         // arrays are Copy when their items are
    sorted.sort();
    println!("{sorted:?} {:?}", sorted.binary_search(&7));
}

Mutable slices

&mut [T] lets a function change the items in place, without being able to change the length:

Rust
fn main() {
    let mut v = vec![1, 2, 3, 4, 5];
    double_all(&mut v[1..4]);
    reverse_in_place(&mut v);
    println!("{v:?}");
}

fn double_all(values: &mut [i32]) {
    for x in values.iter_mut() {
        *x *= 2;
    }
}

fn reverse_in_place(values: &mut [i32]) {
    let n = values.len();
    for i in 0..n / 2 {
        values.swap(i, n - 1 - i);
    }
}
