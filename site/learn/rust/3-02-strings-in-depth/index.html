Strings in Depth

lesson 3.022 of 5 in milestone 35 min1 practice task

How Rust strings really work - UTF-8 bytes, chars and why there is no indexing by position, char_indices and safe slicing, building strings with push, push_str, + and format!, splitting, trimming and searching, case conversion, parsing, and converting between String, &str, char and bytes.

UTF-8

A String is a vector of bytes that is always valid UTF-8. ASCII characters take one byte, but others take two, three or four:

Rust
fn main() {
    for s in ["hello", "héllo", "日本", "🦀"] {
        println!("{s}: {} bytes, {} chars", s.len(), s.chars().count());
    }
    let word = "naïve";
    for (byte_index, c) in word.char_indices() {
        print!("{byte_index}:{c} ");
    }
    println!();
    println!("{:?}", word.as_bytes());
}

That is why s[0] does not compile: a byte position is not a character position, and returning half a character would be wrong. Use:

  • s.chars() to go through characters (Unicode scalar values);
  • s.char_indices() to get each character with its byte position, for slicing safely;
  • s.bytes() when you really work with raw bytes (protocols, ASCII-only formats).

s.chars().nth(i) finds the i-th character, but it walks from the start: O(i). If you need random access, collect into a Vec<char> first.

User-perceived characters can be several chars (an e plus a combining accent, or an emoji with a skin tone). For full text segmentation, the unicode-segmentation crate splits grapheme clusters.

Building strings

Rust
fn main() {
    let mut s = String::with_capacity(32);
    s.push_str("Hello");
    s.push(',');
    s += " world";                              // += takes a &str
    let greeting = s.clone() + "!";             // + takes ownership of the left side
    let parts = vec!["a", "b", "c"];
    let joined = parts.join("/");
    let repeated = "ab".repeat(3);
    let built = format!("{greeting} [{joined}] {repeated} {}", 42);
    println!("{built}");
    let from_chars: String = ['R', 'u', 's', 't'].iter().collect();
    let reversed: String = "stressed".chars().rev().collect();
    println!("{from_chars} {reversed}");
}

Searching, splitting and trimming

Rust
fn main() {
    let text = "  name=Ada; lang=Rust;year=2026  ";
    let t = text.trim();
    println!("{:?} {:?}", t.find("lang"), t.find('z'));
    for pair in t.split(';').map(str::trim).filter(|p| !p.is_empty()) {
        if let Some((key, value)) = pair.split_once('=') {
            println!("{key} -> {value}");
        }
    }
    println!("{:?}", "a,b,,c".split(',').collect::<Vec<_>>());
    println!("{:?}", "one  two\tthree\n".split_whitespace().collect::<Vec<_>>());
    println!("{:?}", "line1\nline2\r\nline3".lines().collect::<Vec<_>>());
    println!("{}", "Hello".to_lowercase() == "hello");
    println!("{}", "Straße".eq_ignore_ascii_case("STRASSE"));      // false: ASCII-only comparison
    println!("{:?}", "x=1".strip_prefix("x="));
    println!("{}", "cat".replace('c', "b"));
}

Slicing safely

String slices use byte ranges and panic if a range cuts a character in half. To take "the first n characters" safely, find the byte position with char_indices:

Rust
fn first_chars(s: &str, n: usize) -> &str {
    match s.char_indices().nth(n) {
        Some((byte_index, _)) => &s[..byte_index],
        None => s,
    }
}

fn main() {
    println!("{}", first_chars("héllo wörld", 4));
    println!("{}", first_chars("hi", 10));
}
