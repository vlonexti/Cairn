Vectors

lesson 3.011 of 5 in milestone 35 min1 practice task

Vec<T> in depth - creating with vec! and Vec::new, pushing, popping, inserting and removing, indexing versus get, iterating by reference, by mutable reference and by value, sorting and deduplicating, retain, extend and drain, capacity, and the borrow rules that apply to vectors.

Creating and growing

A Vec<T> is a growable array on the heap: Rust's most used collection.

Rust
fn main() {
    let mut v: Vec<i32> = Vec::new();
    v.push(3);
    v.push(1);
    v.push(4);
    let mut w = vec![1, 5, 9, 2, 6];             // the vec! macro
    let zeros = vec![0; 4];
    println!("{v:?} {w:?} {zeros:?} len={} cap>={}", v.len(), v.capacity());

    let last = w.pop();                          // Some(6)
    w.insert(0, 100);                            // shifts everything right: O(n)
    let removed = w.remove(1);                   // returns the removed item
    w.extend([7, 7, 8]);
    println!("{last:?} {removed} {w:?}");
}

Reading items

Indexing with v[i] panics when i is out of range; v.get(i) returns an Option instead:

Rust
fn main() {
    let v = vec![10, 20, 30];
    println!("{}", v[1]);
    match v.get(10) {
        Some(x) => println!("found {x}"),
        None => println!("no item 10"),
    }
    println!("{:?} {:?} {}", v.first(), v.last(), v.contains(&20));
    if let [first, .., last] = v.as_slice() {    // a slice pattern
        println!("{first}..{last}");
    }
}

Use indexing when an out-of-range index would be a bug, and get when it is a normal possibility (user input, searching).

Iterating

Rust
fn main() {
    let mut scores = vec![72, 95, 88];

    for s in &scores {                  // borrow each item: s is &i32
        print!("{s} ");
    }
    println!();

    for s in &mut scores {              // borrow each item mutably: s is &mut i32
        *s += 5;
    }

    let total: i32 = scores.iter().sum();
    let doubled: Vec<i32> = scores.iter().map(|s| s * 2).collect();
    println!("{scores:?} {total} {doubled:?}");

    for s in scores {                   // by value: the vector is moved and consumed
        print!("{s} ");
    }
    println!();
    // println!("{scores:?}");          // error: scores was moved by the loop
}
Loop Item type The vector afterwards
for x in &v / v.iter() &T Unchanged, still usable
for x in &mut v / v.iter_mut() &mut T Changed in place
for x in v / v.into_iter() T Moved, gone

Changing in bulk

Rust
fn main() {
    let mut v = vec![5, 3, 8, 3, 1, 8, 8, 2];
    v.sort();                                    // in place
    v.dedup();                                   // removes consecutive repeats
    println!("{v:?}");
    v.retain(|&x| x % 2 == 1 || x > 4);          // keep the matching items
    println!("{v:?}");
    let mut words = vec!["pear", "Fig", "apple"];
    words.sort_by_key(|w| w.to_lowercase());
    println!("{words:?}");
    let mut nums = vec![3.2, 1.5, 2.7];
    nums.sort_by(|a, b| a.partial_cmp(b).unwrap());   // f64 has no total order: sort_by
    let drained: Vec<f64> = nums.drain(..2).collect();
    println!("{drained:?} {nums:?}");
    v.clear();
    println!("{} {}", v.is_empty(), v.capacity() > 0);
}

f64 cannot use sort() because NaN makes the order partial; sort_by with partial_cmp (or f64::total_cmp) says how to compare.

Vectors and the borrow rules

While you hold a reference into a vector, you cannot push to it (lesson 2.02): pushing may move the whole buffer. Collect what you need first, or work with indexes:

Rust
fn main() {
    let mut v = vec![1, 2, 3];
    let first = v[0];             // copy the value out (i32 is Copy), no borrow kept
    v.push(first * 10);
    let len = v.len();
    v.push(len as i32);
    println!("{v:?}");
}

Capacity

A vector keeps spare room and doubles its capacity when it runs out, so push is amortised O(1). If you know the final size, Vec::with_capacity(n) avoids repeated growth.
