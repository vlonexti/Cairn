Implementing Iterator

lesson 5.033 of 5 in milestone 55 min1 practice task

Writing your own iterators - a struct with state and a next method, getting every adapter for free, infinite iterators, iterators that borrow from a collection, IntoIterator so your type works in for loops, std::iter helpers (from_fn, successors, repeat, once), and extension traits that add your own adapters.

A struct with next

Implement Iterator by choosing the Item type and writing next. Everything else (map, filter, sum...) comes for free:

Rust
struct Countdown {
    current: u32,
}

impl Iterator for Countdown {
    type Item = u32;

    fn next(&mut self) -> Option<u32> {
        if self.current == 0 {
            return None;
        }
        self.current -= 1;
        Some(self.current + 1)
    }
}

fn main() {
    let launch: Vec<u32> = Countdown { current: 5 }.collect();
    println!("{launch:?}");
    let even_sum: u32 = Countdown { current: 10 }.filter(|n| n % 2 == 0).sum();
    println!("{even_sum}");
    for n in (Countdown { current: 3 }).map(|n| n * 100) {
        print!("{n} ");
    }
    println!();
}

Infinite iterators

An iterator may never return None; the consumer decides when to stop:

Rust
struct Fibonacci {
    a: u64,
    b: u64,
}

impl Iterator for Fibonacci {
    type Item = u64;
    fn next(&mut self) -> Option<u64> {
        let value = self.a;
        let next = self.a.checked_add(self.b)?;     // stop instead of overflowing
        self.a = self.b;
        self.b = next;
        Some(value)
    }
}

fn fibonacci() -> Fibonacci {
    Fibonacci { a: 0, b: 1 }
}

fn main() {
    println!("{:?}", fibonacci().take(10).collect::<Vec<_>>());
    println!("{:?}", fibonacci().find(|&f| f > 1000));
    println!("{}", fibonacci().count());            // stops when the next value would overflow u64
}

Iterators that borrow

An iterator over part of your data borrows it, so it needs a lifetime:

Rust
struct Words<'a> {
    rest: &'a str,
}

impl<'a> Iterator for Words<'a> {
    type Item = &'a str;
    fn next(&mut self) -> Option<&'a str> {
        let trimmed = self.rest.trim_start();
        if trimmed.is_empty() {
            return None;
        }
        let end = trimmed.find(char::is_whitespace).unwrap_or(trimmed.len());
        let (word, rest) = trimmed.split_at(end);
        self.rest = rest;
        Some(word)
    }
}

fn main() {
    let text = String::from("  the quick   brown fox ");
    let longest = Words { rest: &text }.max_by_key(|w| w.len());
    println!("{longest:?} {}", Words { rest: &text }.count());
}

IntoIterator: making for loops work

for x in thing calls IntoIterator::into_iter(thing). Implement it (usually for &YourType) so your collection works in for loops:

Rust
struct Playlist {
    songs: Vec<String>,
}

impl<'a> IntoIterator for &'a Playlist {
    type Item = &'a String;
    type IntoIter = std::slice::Iter<'a, String>;
    fn into_iter(self) -> Self::IntoIter {
        self.songs.iter()
    }
}

fn main() {
    let p = Playlist { songs: vec!["Intro".into(), "Theme".into(), "Outro".into()] };
    for song in &p {
        print!("{song} ");
    }
    println!();
}

Small helpers in std::iter

Many custom iterators need no struct at all:

Rust
use std::iter;

fn main() {
    let mut n = 0;
    let squares = iter::from_fn(|| { n += 1; if n <= 5 { Some(n * n) } else { None } });
    println!("{:?}", squares.collect::<Vec<_>>());
    let powers: Vec<u32> = iter::successors(Some(1u32), |&x| x.checked_mul(10)).collect();
    println!("{powers:?}");
    let line: String = iter::repeat('-').take(10).chain(iter::once('>')).collect();
    println!("{line}");
}

Your own adapters

An extension trait adds methods to every iterator, just like the built-in ones:

Rust
trait EveryOther: Iterator + Sized {
    fn every_other(self) -> std::iter::StepBy<Self> {
        self.step_by(2)
    }
}

impl<I: Iterator> EveryOther for I {}

fn main() {
    println!("{:?}", (1..=9).every_other().collect::<Vec<_>>());
}
