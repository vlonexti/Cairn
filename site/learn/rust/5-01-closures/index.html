Closures

lesson 5.011 of 5 in milestone 55 min1 practice task

Anonymous functions that capture their environment - closure syntax and type inference, capturing by reference, by mutable reference and by value with move, the Fn, FnMut and FnOnce traits, passing closures to functions with generics or impl Fn, returning closures, storing them in structs and boxing them as dyn Fn.

Closure syntax

A closure is an anonymous function that can use variables from the scope where it is created:

Rust
fn main() {
    let add_one = |x: i32| x + 1;                    // types can be written...
    let double = |x| x * 2;                          // ...or inferred from the first use
    let greet = |name: &str| -> String { format!("Hello, {name}!") };
    println!("{} {} {}", add_one(5), double(21), greet("Ada"));

    let threshold = 10;
    let is_big = |n: i32| n > threshold;             // captures threshold
    let values = vec![4, 12, 9, 30];
    let big: Vec<i32> = values.iter().copied().filter(|&n| is_big(n)).collect();
    println!("{big:?}");
}

Unlike fn items, closures can capture the variables around them. They are used everywhere iterators, sorting, threads and callbacks take "a bit of code".

How closures capture

The compiler picks the least powerful way that works:

  1. By shared reference if the closure only reads a variable.
  2. By mutable reference if it changes it.
  3. By value (moving it in) if it consumes it, or if you write move.
Rust
fn main() {
    let name = String::from("Ada");
    let print = || println!("{name}");               // borrows name
    print();
    print();
    println!("still usable: {name}");

    let mut count = 0;
    let mut tick = || count += 1;                    // borrows count mutably
    tick();
    tick();
    println!("count = {count}");                     // the mutable borrow ended after the last tick

    let words = vec!["a".to_string(), "b".to_string()];
    let consume = move || words.len();               // move: the closure owns words now
    println!("{}", consume());
    // println!("{words:?}");                        // error: words was moved into the closure
}

move is needed when the closure must outlive the current scope, for example when it is returned from a function or sent to another thread.

Fn, FnMut and FnOnce

Every closure implements one or more of these traits, depending on what it does with its captures:

Trait The closure Can be called
Fn Only reads its captures Any number of times, even at the same time
FnMut Changes its captures Many times, one at a time (needs mut)
FnOnce Moves something out of its captures Once

Functions that take closures choose the least demanding bound they can accept:

Rust
fn apply_twice<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 {
    f(f(x))
}

fn repeat<F: FnMut()>(times: usize, mut f: F) {
    for _ in 0..times { f(); }
}

fn finish<F: FnOnce() -> String>(f: F) -> String {
    f()
}

fn main() {
    println!("{}", apply_twice(|x| x * 3, 2));
    let mut log = Vec::new();
    repeat(3, || log.push("tick"));
    println!("{log:?}");
    let name = String::from("done");
    println!("{}", finish(move || name));             // gives away name: FnOnce
}

Plain functions work too wherever a closure is expected: apply_twice(i32::abs, -4).

Returning and storing closures

Each closure has its own unique, unnamed type. Return one with impl Fn, or box it as a trait object when several different closures must share one type:

Rust
fn multiplier(k: i32) -> impl Fn(i32) -> i32 {
    move |x| x * k                                   // move: k must live inside the closure
}

struct Button {
    label: String,
    on_click: Box<dyn Fn(&str) -> String>,
}

fn main() {
    let triple = multiplier(3);
    println!("{}", triple(14));

    let buttons = vec![
        Button { label: "save".into(), on_click: Box::new(|l: &str| format!("saving via {l}")) },
        Button { label: "quit".into(), on_click: Box::new(move |l: &str| format!("{l} after {}", triple(1))) },
    ];
    for b in &buttons {
        println!("{}", (b.on_click)(&b.label));
    }

    let mut ops: Vec<(&str, Box<dyn Fn(f64) -> f64>)> = Vec::new();
    ops.push(("square", Box::new(|x: f64| x * x)));
    ops.push(("half", Box::new(|x: f64| x / 2.0)));
    for (name, op) in &ops {
        println!("{name}(6) = {}", op(6.0));
    }
}

Call a closure stored in a field with parentheses around the field: (b.on_click)(...).
