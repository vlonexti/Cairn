18 milestones154 lessons114 practice tasks90 projects

What a computer is really doing when a game runs: bits, memory and addresses, the CPU and assembly, Windows and its processes, debuggers, game engines, modding and the kernel. You read, experiment with live simulations, and build real projects in Visual Studio. It assumes the first milestones of the C++ course.
