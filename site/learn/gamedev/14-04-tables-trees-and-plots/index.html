Tables, Trees and Plots

lesson 14.044 of 6 in milestone 145 min1 practice task

Tools mostly show data: lists of entities, hierarchies of objects, numbers over time. ImGui's tables give sortable, resizable, scrollable columns; trees show hierarchies such as a scene graph; plots show values over time. This lesson uses each for Delve's tools, including clipping long lists so a table of ten thousand rows stays fast.

Tables

C++
const ImGuiTableFlags flags{ ImGuiTableFlags_Borders | ImGuiTableFlags_RowBg | ImGuiTableFlags_Resizable
                           | ImGuiTableFlags_Sortable | ImGuiTableFlags_ScrollY };
if (ImGui::BeginTable("monsters", 4, flags, { 0, 300 }))
{
    ImGui::TableSetupScrollFreeze(0, 1);                       // keep the header row visible when scrolling
    ImGui::TableSetupColumn("Id", ImGuiTableColumnFlags_DefaultSort);
    ImGui::TableSetupColumn("Kind");
    ImGui::TableSetupColumn("Position");
    ImGui::TableSetupColumn("HP");
    ImGui::TableHeadersRow();

    if (ImGuiTableSortSpecs* sort{ ImGui::TableGetSortSpecs() }; sort && sort->SpecsDirty)
    {
        sortRows(m_rows, sort->Specs[0].ColumnIndex, sort->Specs[0].SortDirection == ImGuiSortDirection_Ascending);
        sort->SpecsDirty = false;                              // sort only when the user changed the order
    }

    for (const Row& r : m_rows)
    {
        ImGui::TableNextRow();
        ImGui::TableNextColumn(); ImGui::Text("%d", r.id);
        ImGui::TableNextColumn(); ImGui::TextUnformatted(r.kind.c_str());
        ImGui::TableNextColumn(); ImGui::Text("%d, %d", r.x, r.y);
        ImGui::TableNextColumn(); ImGui::Text("%d", r.hp);
    }
    ImGui::EndTable();
}

ImGui handles the header clicks, resizing and scrolling; your code sorts the data when SpecsDirty says the order changed. A filter box above the table (InputText with a hint) completes it. The practice task writes the sorting and filtering logic, with stable sorting so rows with equal values keep their relative order.

Long lists: clipping

Describing ten thousand rows every frame is wasteful when only thirty are visible. ImGuiListClipper tells you which rows are on screen:

C++
ImGuiListClipper clipper;
clipper.Begin(static_cast<int>(m_rows.size()));
while (clipper.Step())
    for (int i{ clipper.DisplayStart }; i < clipper.DisplayEnd; ++i)
        drawRow(m_rows[static_cast<size_t>(i)]);

It is lesson 10.04's culling, for interfaces: the cost depends on what is visible, not on the size of the data.

Trees

Hierarchies (a scene graph, lesson 3.09; folders; a struct's members, lesson 9.09) use tree nodes:

C++
void drawNode(const SceneNode& n)
{
    const ImGuiTreeNodeFlags flags{ n.children.empty() ? ImGuiTreeNodeFlags_Leaf : ImGuiTreeNodeFlags_None };
    if (ImGui::TreeNodeEx(&n, flags, "%s  (%.1f, %.1f)", n.name.c_str(), n.x, n.y))   // the pointer is the id
    {
        for (const auto& child : n.children) drawNode(*child);
        ImGui::TreePop();
    }
}

TreeNodeEx returns true when the node is open, and you then draw its children and call TreePop. Selection, drag and drop and context menus (BeginPopupContextItem) build an editor's hierarchy panel from the same pieces.

Plots

ImGui::PlotLines and PlotHistogram draw simple graphs from an array, enough for lesson 12.05's frame times:

C++
ImGui::PlotLines("##frame", m_frameMs.data(), static_cast<int>(m_frameMs.size()), 0,
                 "frame ms", 0.0f, 33.0f, ImVec2(-FLT_MIN, 80));

For real charting (several series, axes, zoom, markers) the separate ImPlot library (also in vcpkg) extends ImGui with full plotting. A frame-time plot with a line at 16.7 ms (lesson 8.08's budget) makes stutter obvious.

Common mistakes

Sorting every frame

Sort only when SpecsDirty is set, or when the data changes.

Describing every row of a huge list

Use ImGuiListClipper.

Unstable sorting

Rows with equal values jump around each time the list is re-sorted. Use a stable sort with a tie-breaker.
