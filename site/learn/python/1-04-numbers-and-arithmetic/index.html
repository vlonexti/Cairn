Numbers and Arithmetic

lesson 1.044 of 5 in milestone 15 min1 practice task

Calculating in Python - the arithmetic operators, true division versus floor division, remainders, powers, precedence, the math module, and the surprises of floating-point numbers.

Operators

Operator Meaning Example Result
+ - * Add, subtract, multiply 7 * 6 42
/ Division, always gives a float 7 / 2 3.5
// Floor division: rounds down 7 // 2 3
% Remainder (modulo) 7 % 2 1
** Power 2 ** 10 1024
-x Negation -(3 - 5) 2

Unlike C++, / between two ints gives a float (6 / 2 is 3.0). Use // for whole-number division.

Floor division rounds towards minus infinity, and % follows it, so for negative numbers: -7 // 2 is -4 and -7 % 2 is 1. That is often what you want: minute % 60 is always between 0 and 59.

divmod(a, b) gives both at once:

Python
total_seconds = 3725
minutes, seconds = divmod(total_seconds, 60)
hours, minutes = divmod(minutes, 60)
print(f"{hours}:{minutes:02}:{seconds:02}")     # 1:02:05

Precedence

** binds tightest, then unary minus, then * / // %, then + -. Use parentheses whenever it helps the reader:

Python
print(2 + 3 * 4)       # 14
print((2 + 3) * 4)     # 20
print(-2 ** 2)         # -4: the power happens first
print(2 ** 3 ** 2)     # 512: ** groups from the right, 2 ** 9

Integers do not overflow

Python's int grows as needed, so there is no overflow:

Python
print(2 ** 100)
print(len(str(2 ** 1000)), "digits")

Floats are approximations

Floats are binary fractions, so most decimal fractions are stored approximately:

Python
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False
import math
print(math.isclose(0.1 + 0.2, 0.3))   # True

Never compare floats with == after calculations; use math.isclose or a tolerance. For money, count in whole cents with ints, or use the decimal module.

round(x, 2) rounds to two decimals, and rounds exact halves to the even neighbour (round(2.5) is 2, round(3.5) is 4), which avoids a bias when many values are rounded.

The math module

Python
import math
print(math.sqrt(16), math.pi, math.floor(-2.5), math.ceil(2.1))
print(math.hypot(3, 4))       # 5.0: the length of a 3-4 diagonal
print(math.gcd(12, 18))       # 6

abs(x), min(...), max(...), sum(...) and round(...) are built in, without an import.
