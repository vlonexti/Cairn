Generics and Advanced Typing

lesson 8.033 of 6 in milestone 85 min2 practice tasks

Type hints that say more - generic functions and classes with type parameters, bounded types, Callable, TypedDict for dictionaries with fixed keys, Literal and Final, overloads, Protocols revisited, and how type checkers use all of it while Python itself ignores it.

Hints that follow the data

Lesson 5.05 introduced type hints like def total(prices: list[float]) -> float. Some functions work for any type, but the types of their inputs and outputs are linked. first(items) returns an element of the list, whatever the list holds:

Python
def first[T](items: list[T]) -> T:
    return items[0]

name = first(["ada", "bob"])     # a type checker knows: str
count = first([3, 4])            # int
print(name.upper(), count + 1)
Output
ADA 4

[T] after the name declares a type parameter (Python 3.12 and later). Older code writes the same thing with T = TypeVar("T") at the top of the file; you will see both.

Python does not check any of this when the program runs. Tools such as mypy and Pyright (built into many editors) read the hints and warn about mistakes before you run anything.

Generic classes

Python
class Stack[T]:
    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        return self._items.pop()

    def __len__(self) -> int:
        return len(self._items)

s = Stack[int]()
s.push(1)
s.push(2)
print(s.pop(), len(s))
Output
2 1

With Stack[int], a checker refuses s.push("x").

Bounds

Sometimes "any type" is too wide. A bound says the type must have some ability:

Python
from typing import Protocol

class HasLength(Protocol):
    def __len__(self) -> int: ...

def longest[T: HasLength](items: list[T]) -> T:
    return max(items, key=len)

print(longest(["fig", "banana", "kiwi"]))
print(longest([[1], [1, 2, 3]]))
Output
banana
[1, 2, 3]

T: HasLength means "any type that has __len__", and the result is still the specific type that went in.

Functions as values

Callable[[ArgTypes...], ReturnType] describes a function:

Python
from collections.abc import Callable

def apply_all(values: list[int], fn: Callable[[int], int]) -> list[int]:
    return [fn(v) for v in values]

print(apply_all([1, 2, 3], lambda v: v * 10))
Output
[10, 20, 30]

Dictionaries with known keys

JSON and configuration often arrive as dictionaries with fixed keys. TypedDict describes them without turning them into classes:

Python
from typing import NotRequired, TypedDict

class User(TypedDict):
    name: str
    age: int
    email: NotRequired[str]

def greet(user: User) -> str:
    return f"Hello {user['name']} ({user['age']})"

u: User = {"name": "Ada", "age": 36}
print(greet(u), isinstance(u, dict))
Output
Hello Ada (36) True

At run time u is an ordinary dict; only the checker knows its keys.

Exact values: Literal and Final

Python
from typing import Final, Literal

Mode = Literal["r", "w", "a"]
MAX_RETRIES: Final = 3

def open_log(mode: Mode) -> str:
    return f"opened in {mode} mode"

print(open_log("a"))

A checker refuses open_log("x"), and refuses any later assignment to MAX_RETRIES.

Overloads

When the return type depends on the arguments in a way a single signature cannot say, list the cases with @overload, then write one real implementation:

Python
from typing import Literal, overload

@overload
def parse(text: str, as_int: Literal[True]) -> int: ...
@overload
def parse(text: str, as_int: Literal[False]) -> str: ...

def parse(text, as_int):
    return int(text) if as_int else text.strip()

print(parse("42", True) + 1, parse(" hi ", False))
Output
43 hi

The @overload versions are only for the checker; Python runs the last definition.

Using hints well

  • Hint the edges of your code (function parameters and results, class attributes); local variables are usually inferred.
  • Prefer abstract types in parameters (Iterable[int], Mapping[str, int]) and concrete ones in results (list[int]).
  • object means "anything, and I will check before using it"; Any means "stop checking", so use it rarely.
