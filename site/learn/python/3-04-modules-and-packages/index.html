Modules and Packages

lesson 3.044 of 5 in milestone 35 min1 practice task

Splitting a program into files - modules and import, the forms of import, the name == "main" idiom, packages, how Python finds modules, the standard library, and installing third-party packages with pip in a virtual environment.

Modules

Every .py file is a module. Another file can import it to use its functions and variables:

Python
# geometry.py
import math

def circle_area(r):
    return math.pi * r * r
Python
# main.py
import geometry
print(geometry.circle_area(2))

The forms of import:

Form Use as
import geometry geometry.circle_area(2)
import geometry as geo geo.circle_area(2)
from geometry import circle_area circle_area(2)
from geometry import * Everything public; avoid: it hides where names come from

A module's code runs once, the first time it is imported; later imports reuse it.

The main guard

When a file is run directly, its __name__ is "__main__"; when it is imported, __name__ is the module's name. That lets a file be both a module and a script:

Python
# geometry.py
def circle_area(r):
    return 3.14159 * r * r

if __name__ == "__main__":
    print(circle_area(2))      # only when run as a script, not on import

Put demonstration and start-up code under this guard so importing the module has no side effects.

Packages

A package is a folder of modules (traditionally with an __init__.py file):

Output
shapes/
    __init__.py
    circles.py
    polygons.py
Python
from shapes.circles import area
from shapes import polygons

__init__.py runs when the package is imported and can import the most useful names, so users can write from shapes import area.

How imports are found

Python searches the folder of the script being run first, then the standard library, then installed packages (sys.path lists the folders). Naming your own file like a standard module (random.py, json.py) shadows the real one: import random then imports your file, with confusing errors.

The standard library

Python comes "with batteries included": math, random, datetime, pathlib, json, csv, re, collections, itertools, statistics, urllib, sqlite3 and many more. Look there first: milestone 6 uses several of them.

Python
import random, statistics
rolls = [random.randint(1, 6) for _ in range(1000)]
print(statistics.mean(rolls))

Third-party packages

Thousands more packages live on PyPI (the Python Package Index) and are installed with pip. Use a virtual environment per project, so each project has its own packages and versions:

Output
python -m venv .venv
.venv\Scripts\activate          (Windows; source .venv/bin/activate on Linux and macOS)
pip install requests
pip freeze > requirements.txt   (record the versions; pip install -r requirements.txt restores them)
