Context Managers

lesson 7.022 of 6 in milestone 75 min2 practice tasks

What a with-block really does - the enter and exit methods, cleaning up even when an error happens, writing context managers as classes and with contextlib.contextmanager, suppress, redirecting output, and ExitStack for a varying number of resources.

Setup and cleanup that cannot be forgotten

You have used with open(...) as f: since lesson 3.05: the file is closed when the block ends, even if the block raises. That guarantee works for any object that follows the context manager protocol:

Python
with EXPRESSION as name:
    body
  1. Python evaluates EXPRESSION and calls its __enter__(). Whatever that returns is bound to name.
  2. The body runs.
  3. However the body ends (normally, return, break or an exception), Python calls __exit__(exc_type, exc_value, traceback).

It is the same idea as RAII in C++: the cleanup is attached to the block, so it always happens.

A context manager as a class

Python
import time

class Timer:
    def __enter__(self):
        self.start = time.perf_counter()
        return self                       # this is what "as t" receives

    def __exit__(self, exc_type, exc_value, traceback):
        self.elapsed = time.perf_counter() - self.start
        print(f"took {self.elapsed * 1000:.2f} ms")
        return False                      # do not swallow exceptions

with Timer() as t:
    total = sum(range(100_000))
print(total, t.elapsed > 0)

__exit__ receives the exception (or three Nones if there was none). Returning True tells Python the exception is handled and should not continue; returning False (or nothing) lets it carry on. Swallow exceptions only when that is the whole point of the manager.

Cleanup when things go wrong

Python
class Transaction:
    def __init__(self, account):
        self.account = account

    def __enter__(self):
        self.saved = dict(self.account)       # remember the state
        return self.account

    def __exit__(self, exc_type, exc_value, traceback):
        if exc_type is not None:              # something failed: undo
            self.account.clear()
            self.account.update(self.saved)
        return False

account = {"balance": 100}
try:
    with Transaction(account) as acc:
        acc["balance"] -= 30
        raise ValueError("card declined")
except ValueError:
    pass
print(account)        # {'balance': 100}: the change was rolled back

The quick way: contextlib.contextmanager

Most context managers are "do something, run the body, undo it". A generator (lesson 5.02) with one yield says exactly that:

Python
from contextlib import contextmanager

@contextmanager
def indented(level):
    print(f"{'  ' * level}begin")
    try:
        yield level + 1           # the body runs here; this value goes to "as"
    finally:
        print(f"{'  ' * level}end")

with indented(0) as inner:
    print(f"{'  ' * inner}working")

Everything before yield is __enter__; everything after it is __exit__. Put the after-part in finally so it runs when the body raises.

Ready-made context managers

Python
import contextlib
import io

# Ignore one kind of error
with contextlib.suppress(FileNotFoundError):
    open("does-not-exist.txt")
print("carried on")

# Capture what print writes
buffer = io.StringIO()
with contextlib.redirect_stdout(buffer):
    print("hidden")
print(repr(buffer.getvalue()))     # 'hidden\n'

Others you will meet: threading.Lock (lesson 7.05), tempfile.TemporaryDirectory, decimal.localcontext, and the unittest.mock.patch used in tests.

Several at once, and a varying number

One with can open several managers; they are closed in reverse order:

Python
with open("in.txt") as src, open("out.txt", "w") as dst:
    dst.write(src.read())

When the number is only known at run time, ExitStack collects them:

Python
from contextlib import ExitStack, contextmanager

@contextmanager
def resource(name):
    print("open", name)
    yield name
    print("close", name)

with ExitStack() as stack:
    names = [stack.enter_context(resource(n)) for n in ["a", "b", "c"]]
    print("using", names)
