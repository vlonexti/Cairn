Loops: for and while

lesson 2.033 of 5 in milestone 25 min1 practice task

Repeating work - for loops over lists, strings and ranges, enumerate and zip, while loops that run until a condition changes, break and continue, the loop else, and common loop patterns such as counting, accumulating and searching.

for loops over anything

A for loop runs its body once for each item of a sequence:

Python
for name in ["Ada", "Grace", "Linus"]:
    print("Hello,", name)

for letter in "abc":
    print(letter.upper())

range produces numbers: range(5) is 0 to 4, range(2, 6) is 2 to 5, range(10, 0, -2) is 10, 8, 6, 4, 2.

Python
total = 0
for n in range(1, 101):
    total += n
print(total)          # 5050

enumerate and zip

To have the position as well as the item, use enumerate instead of counting yourself:

Python
for i, name in enumerate(["Ada", "Grace"], start=1):
    print(i, name)

zip walks several sequences side by side, stopping at the shortest:

Python
names = ["Ada", "Grace"]
scores = [95, 88]
for name, score in zip(names, scores):
    print(f"{name}: {score}")

while loops

A while loop repeats as long as its condition is true. Use it when you do not know in advance how many times:

Python
n = 27
steps = 0
while n != 1:
    n = n // 2 if n % 2 == 0 else 3 * n + 1
    steps += 1
print(steps)          # 111

Make sure something in the body moves towards the end, or the loop runs forever (stop a runaway program with Ctrl+C).

break and continue

break leaves the loop at once; continue skips to the next round:

Python
while True:
    line = input("Command (quit to stop): ")
    if line == "quit":
        break
    if line == "":
        continue
    print("You said", line)

while True with a break is the standard shape for "repeat until the user says stop".

The loop else

A loop's else runs when the loop finished without break: perfect for searches.

Python
target = 7
for n in [2, 4, 6]:
    if n == target:
        print("found")
        break
else:
    print("not found")

Patterns

Pattern Shape
Count count = 0 before, count += 1 when it matches
Accumulate total = 0 / result = [] before, add to it inside
Best so far best = None before; replace when better
Search break when found; else for not found

Do not change a list's length while looping over it; loop over a copy (for x in xs[:]) or build a new list.
