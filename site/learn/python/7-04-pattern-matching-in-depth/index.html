Pattern Matching in Depth

lesson 7.044 of 6 in milestone 75 min2 practice tasks

Everything match can take apart - literal, capture and wildcard patterns, sequences with *rest, dictionaries with **rest, objects by class and attribute, match_args, nested patterns, alternatives, guards, and when match is clearer than if.

More than a switch

Lessons 1.05 and 5.03 used match to choose between strings and to split commands by length. A case is a pattern: a description of a shape. If the value has that shape, the names in the pattern are bound to its parts and the block runs. The first matching case wins.

The basic patterns

Pattern Matches
42, "stop", None, True that exact value
name anything, and binds it to name
_ anything, binds nothing
a | b either pattern
[x, y] a sequence of exactly two items
[first, *rest] a sequence of one or more items
{"type": t} a mapping that has at least that key
Point(x=0, y=yy) an object of that class whose attributes match

A bare name always captures. To compare with a constant, use a dotted name such as Color.RED: dotted names are compared, not bound.

Sequences

Python
def describe(items):
    match items:
        case []:
            return "empty"
        case [only]:
            return f"one item: {only}"
        case [first, second]:
            return f"a pair: {first} and {second}"
        case [first, *rest]:
            return f"{first} and {len(rest)} more"

for value in ([], [1], [1, 2], [1, 2, 3, 4]):
    print(describe(value))

Strings are not treated as sequences here, so "ab" does not match [a, b].

Dictionaries

A mapping pattern checks the keys you name and ignores any others. That is perfect for JSON (lesson 6.02):

Python
def handle(event):
    match event:
        case {"type": "click", "x": x, "y": y}:
            return f"click at {x},{y}"
        case {"type": "key", "key": "q" | "Q"}:
            return "quit"
        case {"type": "key", "key": key}:
            return f"key {key}"
        case {"type": other, **details}:
            return f"unknown {other} with {sorted(details)}"
        case _:
            return "not an event"

print(handle({"type": "click", "x": 3, "y": 4, "button": 1}))
print(handle({"type": "key", "key": "Q"}))
print(handle({"type": "scroll", "dy": -1}))

Objects

A class pattern checks the type with isinstance and then the attributes:

Python
from dataclasses import dataclass

@dataclass
class Point:
    x: float
    y: float

@dataclass
class Circle:
    centre: Point
    radius: float

def where(shape):
    match shape:
        case Circle(centre=Point(x=0, y=0), radius=r):
            return f"circle of radius {r} at the origin"
        case Circle(centre=Point(x=x, y=y)):
            return f"circle at {x},{y}"
        case Point(x=0, y=0):
            return "the origin"
        case Point(x=x, y=0):
            return f"on the x axis at {x}"
        case _:
            return "something else"

print(where(Circle(Point(0, 0), 2)))
print(where(Point(5, 0)))

Patterns nest: the circle's centre is matched by a Point pattern inside the Circle pattern.

Positional class patterns and match_args

Writing Point(x=..., y=...) every time is long. A dataclass sets __match_args__ to its fields in order, so the attributes can be given by position:

Python
from dataclasses import dataclass

@dataclass
class Move:
    dx: int
    dy: int

match Move(0, -1):
    case Move(0, dy) if dy < 0:
        print("up by", -dy)
    case Move(dx, 0):
        print("sideways", dx)

For an ordinary class, set __match_args__ = ("dx", "dy") yourself.

Guards and binding a whole match

if after a pattern adds a condition (a guard). as binds what an inner pattern matched:

Python
def classify(value):
    match value:
        case int(n) if n < 0:
            return "negative int"
        case int() | float() as number if number == 0:
            return "zero"
        case int() | float():
            return "a number"
        case str() as text if text.isdigit():
            return "digits in a string"
        case str():
            return "text"
        case _:
            return type(value).__name__

for v in (-3, 0, 2.5, "42", "hi", [1]):
    print(v, "->", classify(v))

int(n) is the shortcut for built-in types: it matches an int and binds it to n.

When to use it

match shines when the decision depends on the shape of data: commands, JSON messages, syntax trees, events. For a plain test like if x > 10, keep using if.
