Values, Variables and Types

lesson 1.022 of 5 in milestone 15 min1 practice task

Every value in Python has a type - int, float, str, bool, None - and variables are names that refer to values. This lesson covers assignment, naming, dynamic typing, converting between types and checking a value's type.

Values have types

Every value in Python has a type that decides what you can do with it:

Type Examples Holds
int 42, -7, 1_000_000 Whole numbers, as big as you like
float 3.14, 2.0, 1e-3 Numbers with a fractional part (about 15 significant digits)
str "hello", 'Ada' Text
bool True, False Truth values
NoneType None "No value"
Python
print(type(42), type(3.14), type("hi"), type(True), type(None))

Variables are names

A variable is a name that refers to a value. = makes the name refer to the value on the right:

Python
score = 10
score = score + 5        # the name now refers to 15
player = "Ada"
print(player, "has", score, "points")

Unlike C++, a variable has no type of its own: the value has the type, and the same name can later refer to a value of another type. This is dynamic typing. It is flexible, and it means mistakes such as adding text to a number are found only when that line runs:

Python
lives = 3
lives = "three"          # allowed, but now lives + 1 would fail

Several names can be assigned at once, and +=, -=, *= update a variable:

Python
x, y = 2, 5              # x = 2, y = 5
x, y = y, x              # swap: x = 5, y = 2
x += 1                   # x = 6
print(x, y)

Naming

Names use letters, digits and _, cannot start with a digit, and are case-sensitive (score and Score are different). Python's style guide (PEP 8) uses lower_case_with_underscores for variables and functions, and UPPER_CASE for constants:

Python
MAX_LIVES = 3
player_name = "Ada"

Converting between types

Functions named after types convert values:

Python
print(int("42") + 1)        # 43: text to number
print(float("2.5") * 2)     # 5.0
print(str(7) + " days")     # "7 days": number to text
print(int(3.99))            # 3: int() cuts off the fraction, it does not round
print(round(3.99))          # 4
print(bool(0), bool(""), bool("no"))   # False False True

A conversion that makes no sense raises an error: int("hello") stops the program with ValueError. Lesson 4.05 shows how to handle that.

Truthiness

In conditions (lesson 1.05), every value counts as true or false: 0, 0.0, "", None, and empty collections are falsy; everything else is truthy. So if name: means "if the name is not empty".
