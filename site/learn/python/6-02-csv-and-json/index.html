CSV and JSON

lesson 6.022 of 5 in milestone 65 min1 practice task

The two data formats you meet everywhere - reading and writing CSV with the csv module (quoting, DictReader and DictWriter, converting types), and JSON with the json module (loading, dumping, pretty printing, and what maps to what).

CSV

CSV (comma-separated values) is how spreadsheets and databases exchange tables:

Output
name,city,score
Ada,London,95
"Hopper, Grace",New York,88

Splitting lines on commas breaks on the second row: a field that contains a comma is quoted. The csv module handles quoting, embedded quotes and line breaks correctly:

Python
import csv, io

data = 'name,city,score\nAda,London,95\n"Hopper, Grace",New York,88\n'
reader = csv.DictReader(io.StringIO(data))          # with a real file: open(path, newline="", encoding="utf-8")
rows = list(reader)
print(rows[1]["name"], rows[1]["score"])            # Hopper, Grace  88
total = sum(int(r["score"]) for r in rows)          # every field is TEXT: convert it
print(total)

csv.reader gives each row as a list; csv.DictReader uses the header row to give dictionaries, which is clearer. Open CSV files with newline="" so the module can handle line endings itself.

Writing:

Python
import csv, io

out = io.StringIO()
writer = csv.DictWriter(out, fieldnames=["name", "score"])
writer.writeheader()
writer.writerow({"name": "Hopper, Grace", "score": 88})
writer.writerows([{"name": "Ada", "score": 95}])
print(out.getvalue())

The writer adds quotes where needed. Spreadsheets in some countries use ; as the separator: pass delimiter=";".

JSON

JSON is the format of web APIs and many configuration files. It maps directly to Python values:

JSON Python
object {...} dict
array [...] list
string str
number int or float
true / false True / False
null None
Python
import json

text = '{"name": "Ada", "languages": ["en", "fr"], "active": true, "manager": null}'
person = json.loads(text)                  # text -> Python
print(person["languages"][1], person["active"], person["manager"])
person["score"] = 95
print(json.dumps(person))                  # Python -> text
print(json.dumps(person, indent=2, sort_keys=True))

With files, json.load(f) and json.dump(obj, f, indent=2) read and write directly. Pass ensure_ascii=False to write accented characters as they are rather than as é escapes.

Only these types can be written. Dates, sets, tuples (written as lists) and your own classes need converting first, for example with dataclasses.asdict(obj) or a default= function. Keys of JSON objects are always strings: a dict with int keys comes back with string keys.

Errors in data

Real files contain surprises: missing columns, empty fields, numbers with spaces, invalid JSON. Validate as you convert (lesson 4.05): json.loads raises json.JSONDecodeError (a ValueError) with the line and column of the problem; for CSV, check each row and collect errors rather than stopping at the first one. The final project does exactly that.
