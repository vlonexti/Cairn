Files and Paths

lesson 3.055 of 5 in milestone 35 min1 practice task

Reading and writing text files safely with with-blocks, reading line by line, encodings, appending, working with paths using pathlib, listing and finding files, and the difference between text and binary files.

Opening files with with

Python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("first line\n")
    f.write("second line\n")

with open("notes.txt", encoding="utf-8") as f:
    text = f.read()
print(text)

The with block closes the file when it ends, even if an error happens inside. Always use it.

Mode Meaning
"r" Read (the default); error if missing
"w" Write: creates the file, empties it if it exists
"a" Append: writes at the end
"x" Create: error if it already exists
"rb", "wb" Binary (bytes instead of text)

Always pass encoding="utf-8" for text: the default depends on the computer, and a file written on one machine can be unreadable on another.

Reading line by line

A file object is iterable, one line at a time, which works for files of any size:

Python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("apples 3\npears 5\n\nplums 2\n")

total = 0
with open("notes.txt", encoding="utf-8") as f:
    for line in f:
        line = line.strip()          # remove the "\n" (and spaces)
        if not line:
            continue                 # skip blank lines
        name, count = line.split()
        total += int(count)
print(total)

f.read() reads everything as one string; f.readlines() gives a list of lines (with their \n); f.read().splitlines() gives lines without them.

Writing

write takes a string and does not add a new line; print(..., file=f) does:

Python
scores = {"Ada": 95, "Grace": 88}
with open("scores.txt", "w", encoding="utf-8") as f:
    for name, score in scores.items():
        print(f"{name},{score}", file=f)

Paths with pathlib

pathlib.Path represents a path and has methods for everything you do with files:

Python
from pathlib import Path

folder = Path("reports")
folder.mkdir(exist_ok=True)                  # create if missing
report = folder / "2026-11.txt"              # / joins path parts on every system
report.write_text("total: 42\n", encoding="utf-8")
print(report.exists(), report.name, report.stem, report.suffix, report.parent)
print(report.read_text(encoding="utf-8"))
for path in sorted(folder.glob("*.txt")):    # files matching a pattern; rglob searches subfolders
    print(path.name, path.stat().st_size, "bytes")

Path.home() is the user's home folder, Path.cwd() the current folder, and path.resolve() the full absolute path.

When files are missing

Opening a missing file for reading raises FileNotFoundError. Check first with path.exists() or handle the error (lesson 4.05). Paths in a script are relative to the current working directory, not to the script's folder; Path(__file__).parent is the script's own folder when you need files next to it.

Text and binary

Text files are decoded into str using an encoding; binary files ("rb") give bytes, for images, zip files and anything that is not text. Path.read_bytes() and write_bytes() are the binary versions.
