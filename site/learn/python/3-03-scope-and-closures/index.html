Scope and Closures

lesson 3.033 of 5 in milestone 35 min1 practice task

Where names live - local and global scope, the LEGB lookup order, global and nonlocal, functions defined inside functions, closures that remember values, and lambda expressions.

Local and global

A name assigned inside a function is local: it exists only while the function runs and does not affect a name outside with the same spelling:

Python
count = 10

def reset():
    count = 0          # a new LOCAL name; the global count is untouched
    return count

reset()
print(count)           # 10

Names are looked up in the order Local, Enclosing functions, Global (the module), Built-in (print, len): the LEGB rule. Reading a global inside a function works; assigning to it creates a local, unless you say otherwise.

global and nonlocal

Python
total = 0

def add(n):
    global total
    total += n

add(5)
print(total)            # 5

global is rarely a good idea: functions that change globals are hard to test and reason about. Pass values in and return results instead. nonlocal does the same for a variable of an enclosing function, which is how closures keep state (below).

A common error: reading a variable that is assigned later in the same function raises UnboundLocalError, because the assignment makes it local for the whole function.

Functions inside functions

A function can define another function, which can see the outer function's names:

Python
def make_greeter(greeting):
    def greet(name):
        return f"{greeting}, {name}!"
    return greet

hello = make_greeter("Hello")
howdy = make_greeter("Howdy")
print(hello("Ada"), howdy("Grace"))

greet remembers greeting even after make_greeter has returned. A function together with the variables it remembers is a closure.

Closures with state

With nonlocal, a closure can update what it remembers:

Python
def make_counter():
    count = 0
    def next_value():
        nonlocal count
        count += 1
        return count
    return next_value

counter = make_counter()
print(counter(), counter(), counter())    # 1 2 3

Each call to make_counter creates a separate count. For anything larger, a class (lesson 4.01) is usually clearer.

lambda

A lambda is a small anonymous function written as an expression: lambda parameters: expression. It is handy where a short function is passed to another:

Python
square = lambda x: x * x
print(square(7))
pairs = [("Ada", 36), ("Grace", 85), ("Linus", 21)]
print(sorted(pairs, key=lambda pair: pair[1]))

Keep lambdas to one simple expression; anything more deserves a def with a name.

A closure trap

Closures remember variables, not values. Lambdas made in a loop all see the loop variable's final value:

Python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])               # [2, 2, 2]
funcs = [lambda i=i: i for i in range(3)] # a default captures the current value
print([f() for f in funcs])               # [0, 1, 2]
