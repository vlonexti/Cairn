Dictionaries and Sets

lesson 2.055 of 5 in milestone 25 min1 practice task

Looking things up by key with dictionaries - creating, reading with get, updating, looping over items, counting and grouping - and sets for unique values and fast membership, with union, intersection and difference.

Dictionaries

A dictionary maps keys to values, and finds a value by its key instantly, however big it is:

Python
ages = {"Ada": 36, "Grace": 85}
print(ages["Ada"])           # 36
ages["Linus"] = 21           # add
ages["Ada"] = 37             # replace
del ages["Grace"]            # remove
print(ages, len(ages), "Ada" in ages)

Keys must be immutable (strings, numbers, tuples); values can be anything. Dictionaries keep the order in which keys were added.

Reading safely

d[key] raises KeyError for a missing key. When a key may be missing, use get with a default:

Python
stock = {"apples": 4}
print(stock.get("pears", 0))         # 0
print(stock.get("apples", 0))        # 4

Looping

Python
prices = {"tea": 2.5, "cake": 3.0}
for item in prices:                   # keys
    print(item)
for item, price in prices.items():    # pairs
    print(f"{item}: {price:.2f}")
print(list(prices.values()), sum(prices.values()))

Counting and grouping

Two patterns come up constantly:

Python
words = "the cat and the hat".split()

counts = {}
for w in words:
    counts[w] = counts.get(w, 0) + 1
print(counts)                 # {'the': 2, 'cat': 1, 'and': 1, 'hat': 1}

by_length = {}
for w in words:
    by_length.setdefault(len(w), []).append(w)
print(by_length)              # {3: ['the', 'cat', 'and', 'the', 'hat']}

setdefault(key, default) returns the value for the key, inserting the default first if it is missing. collections.Counter and defaultdict (lesson 5.04) make both even shorter.

Sets

A set holds unique values, in no particular order, with very fast in:

Python
seen = {"Ada", "Grace"}
seen.add("Ada")                       # no effect: already there
print(len(seen), "Grace" in seen)
unique = set([3, 1, 3, 2, 1])         # remove duplicates
print(sorted(unique))                 # [1, 2, 3]

Sets do maths with other sets:

Operation Meaning
a | b Union: in either
a & b Intersection: in both
a - b Difference: in a but not b
a ^ b In exactly one of them
a <= b a is a subset of b
Python
monday = {"Ada", "Grace", "Linus"}
tuesday = {"Grace", "Barbara"}
print(monday & tuesday, monday - tuesday, monday | tuesday)

{} is an empty dictionary; an empty set is set().

Choosing a collection

Need Use
Ordered items, by position list
A fixed record tuple
Look up by a key dict
Unique values, membership tests set

Testing x in some_list checks every item; x in some_set is instant. For large collections that you search often, that difference is huge.
