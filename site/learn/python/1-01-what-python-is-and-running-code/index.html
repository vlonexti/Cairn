What Python Is and Running Code

lesson 1.011 of 5 in milestone 15 min1 practice task

Python is a language you can read almost like English and run without a separate compile step. This lesson explains what that means, runs a first program, and shows the two ways to run Python - scripts and the interactive prompt.

A language built for people

Python was designed to be easy to read. Compare printing the numbers 1 to 3:

Python
for number in range(1, 4):
    print(number)

No semicolons, no braces, no type declarations: the indentation shows the structure, and the words say what happens. That makes Python the language people reach for when they want an idea working quickly: scripts that rename a thousand files, tools that read a spreadsheet and send a report, data analysis, web servers, machine learning, and glue between other programs.

The price is speed: Python runs much slower than C++ for heavy computation. In practice that rarely matters, because the slow parts are done by libraries written in C (which is what NumPy and friends are), and most programs spend their time waiting for files and networks anyway.

How Python runs your code

C++ is compiled to machine code before it runs. Python is run by an interpreter: the python program reads your source, turns it into compact bytecode, and executes it straight away. There is no separate build step: you edit and run.

flowchart LR
    S[hello.py] --> I[python interpreter] --> B[bytecode] --> R[runs immediately]

One consequence: many mistakes are found only when the line runs. A typo in a function that is never called goes unnoticed. That is why testing (lesson 5.05) matters even more in Python.

Your first program

Python
print("Hello, Xenon!")
print("Python is", 3 * 11, "years old in 2024")

print writes its arguments separated by spaces and ends with a new line. Text goes between quotes (single or double, both work); numbers do not.

Press Run on any example in these lessons to run it, and edit it to try things out.

Running Python yourself

On your own computer, install Python from python.org (on Windows, tick "Add python.exe to PATH") or the Microsoft Store. Then there are two ways to run it:

Way How Good for
Script Save code in hello.py, run python hello.py Programs you keep
Interactive prompt (REPL) Run python with no file, type a line, see the result Trying things out, a calculator

At the interactive prompt, the result of each expression is shown automatically:

Output
>>> 2 ** 10
1024
>>> "ab" * 3
'ababab'

In a script, nothing is shown unless you print it. Editors such as VS Code (with the Python extension) run scripts with one key and show errors as you type.

Comments

Everything after # on a line is a comment, ignored by Python:

Python
# Work out the area of a 3 by 4 rectangle.
width = 3
height = 4
print(width * height)   # prints 12

Write comments for the why, not the what: the code already says what it does.
