Dataclasses and Enums

lesson 4.044 of 5 in milestone 45 min1 practice task

Less boilerplate for data-holding classes - @dataclass generates init, repr and eq, with defaults, field(default_factory), ordering, frozen instances and post_init validation - and Enum for a fixed set of named values.

Dataclasses

Many classes mostly hold data. Writing __init__, __repr__ and __eq__ by hand for them is tedious; @dataclass generates them from annotated fields:

Python
from dataclasses import dataclass, field

@dataclass
class Book:
    title: str
    author: str
    year: int
    tags: list[str] = field(default_factory=list)    # a NEW list per instance
    read: bool = False

b = Book("Dune", "Frank Herbert", 1965)
b.tags.append("sci-fi")
print(b)
print(b == Book("Dune", "Frank Herbert", 1965, ["sci-fi"]))

The type annotations (str, int) document the fields; Python does not check them at run time. Fields with defaults come after fields without. Use field(default_factory=list) for mutable defaults: a plain = [] is refused for exactly the reason of lesson 3.02.

Options

Option Effect
@dataclass(order=True) Adds <, <=, >, >= comparing fields in order, so instances sort
@dataclass(frozen=True) Instances cannot be changed after creation, and become hashable
@dataclass(slots=True) Uses less memory per instance
Python
@dataclass(frozen=True, order=True)
class Version:
    major: int
    minor: int
    patch: int = 0

print(sorted([Version(2, 0), Version(1, 9, 3), Version(1, 10)]))
releases = {Version(1, 0): "first"}       # frozen: usable as a key

Validation

__post_init__ runs after the generated __init__ and can check or compute fields:

Python
@dataclass
class Rectangle:
    width: float
    height: float

    def __post_init__(self):
        if self.width <= 0 or self.height <= 0:
            raise ValueError("sides must be positive")

    @property
    def area(self):
        return self.width * self.height

print(Rectangle(2, 3).area)

Dataclasses are ordinary classes: they can have methods and properties, and inherit.

Enums

An enum is a fixed set of named values, much safer than strings like "red" that can be misspelt:

Python
from enum import Enum, auto

class Status(Enum):
    TODO = auto()
    DOING = auto()
    DONE = auto()

s = Status.DOING
print(s, s.name, s.value, s is Status.DOING)
print([status.name for status in Status])
print(Status["DONE"], Status(1))       # by name, by value

Enums are compared with is or ==, can be iterated, and work well with match (lesson 1.05). StrEnum and IntEnum make members that also behave as strings or numbers, handy when the values are written to files.
