Dates and Times

lesson 6.033 of 5 in milestone 65 min1 practice task

Working with dates and times in Python - date, time, datetime and timedelta, parsing and formatting with ISO 8601 and strftime, date arithmetic, time zones with zoneinfo, and measuring durations with time.perf_counter.

The types

Python
from datetime import date, time, datetime, timedelta

d = date(2026, 11, 15)
t = time(14, 30)
dt = datetime(2026, 11, 15, 14, 30, 5)
print(d, t, dt, d.weekday(), d.isoweekday(), d.strftime("%A"))
print(date.today(), datetime.now())

weekday() is 0 for Monday to 6 for Sunday. All these objects are immutable: methods such as replace return new ones.

Parsing and formatting

ISO 8601 (2026-11-15, 2026-11-15T14:30:05) is the unambiguous standard format: use it for files and data.

Python
from datetime import date, datetime

d = date.fromisoformat("2026-11-15")
dt = datetime.fromisoformat("2026-11-15T14:30:05")
print(dt.isoformat(), d.isoformat())

For other formats, strptime parses and strftime formats with codes:

Code Meaning Example
%Y / %y Year 2026 / 26
%m / %d Month / day, two digits 11 / 15
%B / %b Month name / short November / Nov
%A / %a Weekday name / short Sunday / Sun
%H / %I / %p Hour (24 h) / hour (12 h) / AM-PM 14 / 02 / PM
%M / %S Minutes / seconds 30 / 05
Python
from datetime import datetime

dt = datetime.strptime("15/11/2026 14:30", "%d/%m/%Y %H:%M")
print(dt.strftime("%A %d %B %Y, %H:%M"))
print(f"{dt:%Y-%m-%d}")            # format codes work inside f-strings too

Month and day names depend on the system language; for fixed output, prefer numbers.

Arithmetic

Subtracting dates gives a timedelta; adding a timedelta moves a date:

Python
from datetime import date, timedelta

start = date(2026, 11, 15)
print(start + timedelta(days=30))
print((date(2026, 12, 25) - start).days, "days to go")
week = [start + timedelta(days=i) for i in range(7)]
print([d.strftime("%a") for d in week])

timedelta has days, seconds and microseconds; there is no "add one month" because months differ in length: compute it explicitly (practice 6.03).

Time zones

A datetime without time zone information is naive: it just says "14:30" without saying where. For events that people in different places see, attach a zone with zoneinfo:

Python
from datetime import datetime
from zoneinfo import ZoneInfo

meeting = datetime(2026, 11, 15, 14, 30, tzinfo=ZoneInfo("Europe/London"))
print(meeting.astimezone(ZoneInfo("America/New_York")))
print(meeting.astimezone(ZoneInfo("UTC")).isoformat())

Store times in UTC, convert to local time only for display (the Win32 course's lesson 2.03 gives the same advice). On Windows, pip install tzdata provides the zone database.

Measuring durations

For timing code, use time.perf_counter(), a high-resolution clock that never jumps:

Python
import time

start = time.perf_counter()
total = sum(i * i for i in range(200_000))
print(f"took {time.perf_counter() - start:.4f} s")

Never time code with datetime.now(): the wall clock can be adjusted while the program runs.
