Strings in Depth

lesson 2.011 of 5 in milestone 25 min1 practice task

Working with text - indexing and slicing, the most useful string methods, splitting and joining, searching, escape sequences and raw strings, multi-line strings, and why strings cannot be changed in place.

Indexing and slicing

A string is a sequence of characters, numbered from 0. Negative indexes count from the end:

Python
word = "Python"
print(word[0], word[5], word[-1], word[-2])   # P n n o
print(len(word))                               # 6

A slice s[start:stop:step] takes a part: from start up to but not including stop. Missing values mean "from the beginning", "to the end", "step 1":

Python
word = "Python"
print(word[0:2])     # Py
print(word[2:])      # thon
print(word[:-1])     # Pytho
print(word[::2])     # Pto
print(word[::-1])    # nohtyP: reversed

Slices never raise errors for out-of-range bounds: word[2:100] is just "thon". Indexing does: word[10] is an IndexError.

Strings are immutable

A string cannot be changed in place: word[0] = "J" is an error. Every "change" builds a new string:

Python
word = "Python"
word = "J" + word[1:]
print(word)          # Jython

Useful methods

Method Does Example
upper(), lower(), title() Change case "ada lovelace".title() → Ada Lovelace
strip(), lstrip(), rstrip() Remove whitespace (or given characters) at the ends " hi \n".strip() → hi
split(sep) Break into a list (on whitespace by default) "a,b,c".split(",") → ['a', 'b', 'c']
sep.join(list) Join a list of strings "-".join(["a", "b"]) → a-b
replace(old, new) Replace every occurrence "aaa".replace("a", "b") → bbb
find(sub) Index of the first occurrence, or -1 "banana".find("na") → 2
count(sub) Number of occurrences "banana".count("a") → 3
startswith, endswith Test the ends "photo.jpg".endswith(".jpg") → True
isdigit(), isalpha(), isspace() Test every character "2024".isdigit() → True
center, ljust, rjust, zfill Pad "7".zfill(3) → 007

Methods return new strings; the original is unchanged. in tests for a substring: "ana" in "banana".

Escape sequences and raw strings

Inside quotes, \n is a new line, \t a tab, \\ a backslash, \" a quote. A raw string r"..." turns escapes off, which is useful for Windows paths and regular expressions (lesson 6.01):

Python
print("line one\nline two\ttabbed")
print(r"C:\new\table")

Triple quotes allow strings over several lines:

Python
poem = """Roses are red,
Violets are blue."""
print(poem.splitlines())

Characters and code points

Each character has a Unicode code point: ord("A") is 65, chr(97) is "a". Python strings are Unicode, so "café" and "日本" work like any other text, and len("日本") is 2.

Building strings efficiently

Joining many pieces with + in a loop creates a new string each time. Collect the pieces in a list and "".join(pieces) once at the end.
