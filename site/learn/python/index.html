Python

8 milestones42 lessons53 practice tasks40 projects

The fastest language to get an idea working in. Starting from the first line, the course covers values, strings and collections, loops and functions, modules and files, classes and errors, the idioms that make Python code short and clear, working with text, CSV, JSON and dates to automate real tasks, and finally the advanced language: decorators, context managers, descriptors, pattern matching, threads and asyncio, and then the practice of real projects: logging, testing with mocks, generic types, binary data, databases and packaging. Every lesson has checked practice that runs real Python 3.13, and every milestone ends with five projects, from small to large.
