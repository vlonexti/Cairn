Functions

lesson 3.011 of 5 in milestone 35 min1 practice task

Packaging code under a name - def, parameters and return values, returning several values, functions without a return, docstrings, and why small functions with one job make programs easier to change and test.

Defining a function

Python
def area(width, height):
    """Return the area of a width x height rectangle."""
    return width * height

print(area(3, 4))       # 12
print(area(2.5, 2))     # 5.0
  • def names the function and its parameters.
  • The indented body runs each time the function is called.
  • return sends a value back and ends the function at once.
  • The string right after the def line is the docstring: help(area) shows it, and editors display it.

A function must be defined before the line that calls it runs, but it can call functions defined later in the file, as long as they exist by the time the call happens.

Return values

A function without return (or with a bare return) returns None:

Python
def greet(name):
    print(f"Hello, {name}!")

result = greet("Ada")
print(result)           # None

Mixing up "prints" and "returns" is a classic mistake: a function that prints its answer cannot be used in a calculation. Prefer functions that return values and leave printing to the code that calls them.

Return several values as a tuple and unpack them (lesson 2.04):

Python
def stats(values):
    return min(values), max(values), sum(values) / len(values)

low, high, mean = stats([4, 8, 6])
print(low, high, mean)

Early returns

Returning early keeps the main path of a function unindented:

Python
def describe(age):
    if age < 0:
        return "invalid"
    if age < 13:
        return "child"
    if age < 18:
        return "teenager"
    return "adult"

Why functions

  • Name a piece of logic, so the code reads as a series of steps.
  • Reuse it instead of copying it.
  • Test it on its own: every unit test in this course calls functions.
  • Change it in one place.

A good function does one thing, has a name that says what (a verb: load_scores, is_valid), and is short enough to read at a glance. If you need "and" to describe it, it may be two functions.

Functions are values

A function is an object like any other: it can be stored in a variable, put in a list, or passed to another function:

Python
def shout(text):
    return text.upper() + "!"

def whisper(text):
    return text.lower() + "..."

for style in [shout, whisper]:
    print(style("Hello"))
