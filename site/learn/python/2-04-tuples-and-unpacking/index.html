Tuples and Unpacking

lesson 2.044 of 5 in milestone 25 min1 practice task

Tuples are fixed sequences for values that belong together - coordinates, records, several return values. This lesson covers creating them, unpacking with *, swapping, and when to choose a tuple over a list.

Tuples

A tuple is like a list that cannot be changed: written with parentheses (or just commas):

Python
point = (3, 4)
person = ("Ada", 1815, "London")
single = (42,)          # the comma makes it a tuple; (42) is just 42
print(point[0], len(person), person[1:])

Tuples support indexing, slicing, in, len, count and index, but not append or item assignment.

When to use a tuple

List Tuple
Many items of the same kind that may change: a list of scores A fixed group of values with different meanings: a point, a date, a record
Grows and shrinks Fixed size
Cannot be a dictionary key Can be a dictionary key (if its items can)

A good rule: if the position of an item has a meaning (index 0 is the name, index 1 the year), it is a tuple; if all items mean the same thing, it is a list.

Unpacking

Assigning a tuple (or any sequence) to several names unpacks it:

Python
name, year, city = ("Ada", 1815, "London")
x, y = (3, 4)
a, b = b_and_a = (1, 2)
print(name, year, x + y)

The number of names must match, unless one name has a *, which collects the rest into a list:

Python
first, *rest = [1, 2, 3, 4]
*body, last = "hello"
head, *_, tail = range(10)
print(first, rest, body, last, head, tail)

_ is the conventional name for a value you do not need.

Swapping and multiple return values

Python
a, b = 1, 2
a, b = b, a             # swap, no temporary variable

def min_max(values):
    return min(values), max(values)    # returns one tuple

low, high = min_max([3, 9, 1])
print(low, high)

Unpacking in loops is where it is used most:

Python
for name, score in [("Ada", 95), ("Grace", 88)]:
    print(name, score)

Named tuples

When a tuple has many fields, positions become hard to remember. collections.namedtuple (or dataclasses, lesson 4.04) gives them names:

Python
from collections import namedtuple
Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p.y, p)
