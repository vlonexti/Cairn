Input, Output and f-strings

lesson 1.033 of 5 in milestone 15 min1 practice task

Programs that talk to the user - print with its separators and endings, input that always returns text, converting what was typed, and f-strings for building text with values and formatting numbers.

print in detail

print takes any number of values, separates them with a space, and ends with a new line. Both can be changed:

Python
print("a", "b", "c")                 # a b c
print("a", "b", "c", sep="-")        # a-b-c
print("no new line", end="")
print(" ... continued")
print()                              # an empty line

input

input(prompt) shows the prompt, waits for the user to type a line, and returns it as text (without the Enter):

Python
name = input("What is your name? ")
print("Hello,", name)

Because input always returns a str, numbers must be converted:

Python
age = int(input("How old are you? "))
print("Next year you will be", age + 1)

Forgetting the conversion is the most common beginner bug: input() + 1 fails, and input() * 2 repeats the text ("55" from "5").

f-strings

An f-string has an f before the quote, and any expression inside {} is evaluated and inserted:

Python
name = "Ada"
score = 1234.5678
print(f"{name} scored {score} points")
print(f"In two years: {2026 + 2}")

After a colon inside the braces comes a format specification:

Spec Example Gives
.2f f"{3.14159:.2f}" 3.14 (2 decimals)
, f"{1234567:,}" 1,234,567
>8 / <8 / ^8 f"{'x':>8}" right / left / centre in 8 characters
08.3f f"{3.5:08.3f}" 0003.500 (zero-padded)
% f"{0.256:.1%}" 25.6%
= f"{score=}" score=1234.5678 (handy for debugging)
Python
for item, price in [("tea", 2.5), ("cake", 12.0)]:
    print(f"{item:<10}{price:>8.2f}")

Reading several values

split() breaks a line into words, so several numbers can be typed on one line:

Python
a, b = input("Two numbers: ").split()
print(int(a) + int(b))
