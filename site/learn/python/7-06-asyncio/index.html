asyncio

Thousands of waits on one thread - coroutines with async def and await, asyncio.run, running tasks at the same time with gather and TaskGroup, timeouts and cancellation, async with and async for, queues, and how to choose between asyncio, threads and processes.

One thread, many waits

Threads (lesson 7.05) overlap waiting, but each costs memory and switching between them is up to the operating system. asyncio overlaps waiting on a single thread: each task says where it is willing to pause (await), and an event loop runs another task while it waits. Servers and clients that juggle thousands of connections use it.

Coroutines

async def makes a coroutine function. Calling it does not run it; it returns a coroutine object, which runs when it is awaited or handed to the event loop:

Python
import asyncio

async def greet(name, delay):
    await asyncio.sleep(delay)          # pause here; other tasks may run
    print("hello", name)
    return name.upper()

result = asyncio.run(greet("Ada", 0.1))   # starts the event loop and runs until done
print(result)

await can only be used inside an async def. asyncio.run is the bridge from ordinary code: call it once, at the top.

Never call time.sleep (or any other blocking function) inside a coroutine: it freezes the whole loop, and every other task waits too. Use await asyncio.sleep.

Running several at once: gather

Awaiting one coroutine after another runs them one after another. To run them together, use asyncio.gather, which returns their results in the order given:

Python
import asyncio
import time

async def fetch(n):
    await asyncio.sleep(0.2)
    return n * 10

async def main():
    start = time.perf_counter()
    results = await asyncio.gather(*(fetch(n) for n in range(5)))
    print(results, f"{time.perf_counter() - start:.1f} s")   # [0, 10, 20, 30, 40] 0.2 s

asyncio.run(main())

TaskGroup

asyncio.TaskGroup (Python 3.11+) is the safer way to start tasks: when the async with block ends, all of them have finished, and if one fails the others are cancelled and the errors are raised together.

Python
import asyncio

async def work(name, seconds):
    await asyncio.sleep(seconds)
    return f"{name} done"

async def main():
    async with asyncio.TaskGroup() as group:
        a = group.create_task(work("a", 0.1))
        b = group.create_task(work("b", 0.2))
    print(a.result(), b.result())

asyncio.run(main())

Timeouts and cancellation

Python
import asyncio

async def slow():
    await asyncio.sleep(10)

async def main():
    try:
        async with asyncio.timeout(0.1):
            await slow()
    except TimeoutError:
        print("gave up after 0.1 s")

asyncio.run(main())

A timed-out or cancelled task receives asyncio.CancelledError at the await where it was paused, so try/finally inside it still cleans up.

async with, async for and queues

Some resources need to wait while opening or closing (a network connection); they are used with async with. Some produce values over time; they are looped over with async for. An async generator is an async def with yield:

Python
import asyncio

async def ticker(count):
    for i in range(count):
        await asyncio.sleep(0.05)
        yield i

async def main():
    async for tick in ticker(3):
        print("tick", tick)

asyncio.run(main())

asyncio.Queue works like queue.Queue from lesson 7.05, but put and get are awaited:

Python
import asyncio

async def producer(q):
    for n in range(5):
        await q.put(n)
    await q.put(None)

async def consumer(q, seen):
    while (item := await q.get()) is not None:
        seen.append(item * item)

async def main():
    q = asyncio.Queue(maxsize=2)
    seen = []
    await asyncio.gather(producer(q), consumer(q, seen))
    print(seen)

asyncio.run(main())

(:= is the assignment expression: it assigns and gives the value in one step.)

Blocking code inside asyncio

If you must call a slow ordinary function, hand it to a thread so the loop keeps running: await asyncio.to_thread(slow_function, arg).

Which one?

Situation Choose
a handful of slow calls, ordinary libraries ThreadPoolExecutor
thousands of connections, libraries that support asyncio asyncio
heavy calculation in Python ProcessPoolExecutor
