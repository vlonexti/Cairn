Parameters and Arguments

lesson 3.022 of 5 in milestone 35 min1 practice task

The flexible ways Python passes values to functions - positional and keyword arguments, default values and the mutable default trap, *args and **kwargs, keyword-only and positional-only parameters, and unpacking arguments.

Positional and keyword arguments

Arguments can be passed by position or by name:

Python
def describe(name, age, city):
    return f"{name}, {age}, from {city}"

print(describe("Ada", 36, "London"))
print(describe(city="London", name="Ada", age=36))   # any order
print(describe("Ada", city="London", age=36))         # positional first, then keywords

Keyword arguments make calls readable when there are several values of the same type: resize(width=800, height=600) cannot be confused.

Default values

Parameters can have defaults, used when the argument is left out:

Python
def greet(name, greeting="Hello", punctuation="!"):
    return f"{greeting}, {name}{punctuation}"

print(greet("Ada"))
print(greet("Ada", "Hi"))
print(greet("Ada", punctuation="."))

Parameters with defaults come after those without.

The mutable default trap

Default values are created once, when the function is defined. A list or dictionary default is shared between all calls:

Python
def add_item(item, basket=[]):          # WRONG: one list for every call
    basket.append(item)
    return basket

print(add_item("apple"))                # ['apple']
print(add_item("pear"))                 # ['apple', 'pear']  surprise!

The fix is None as the default and a new list inside:

Python
def add_item(item, basket=None):
    if basket is None:
        basket = []
    basket.append(item)
    return basket

Any number of arguments

*args collects extra positional arguments into a tuple; **kwargs collects extra keyword arguments into a dictionary:

Python
def total(*numbers):
    return sum(numbers)

def tag(name, **attributes):
    parts = " ".join(f'{k}="{v}"' for k, v in attributes.items())
    return f"<{name} {parts}>"

print(total(1, 2, 3))
print(tag("img", src="cat.png", alt="A cat"))

The reverse, unpacking, spreads a list or dictionary into arguments:

Python
values = [1, 2, 3]
print(total(*values))
options = {"greeting": "Hi", "punctuation": "?"}
print(greet("Ada", **options))

Keyword-only and positional-only

A * in the parameter list makes everything after it keyword-only; a / makes everything before it positional-only:

Python
def connect(host, port, /, *, timeout=10, retries=3):
    return f"{host}:{port} timeout={timeout} retries={retries}"

print(connect("example.org", 443, timeout=5))

Keyword-only parameters are good for options (timeout, reverse): callers must name them, so calls stay readable and the order can change later.

Arguments are references

Python passes references to objects. A function can change a mutable argument (a list, a dictionary) and the caller sees it, but assigning a new value to the parameter name does not affect the caller's variable. Documenting whether a function changes its arguments ("sorts the list in place") avoids surprises.
