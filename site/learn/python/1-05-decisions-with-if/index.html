Decisions with if

lesson 1.055 of 5 in milestone 15 min1 practice task

Making a program choose - comparisons, if, elif and else, indentation as structure, combining conditions with and, or and not, chained comparisons, the conditional expression, and match for many cases.

Comparisons

Comparisons give True or False:

Operator Meaning
==, != Equal, not equal
<, <=, >, >= Ordering
in, not in Membership: "a" in "cat"
is, is not Same object: use only for None (x is None)

Python can chain comparisons, which reads like maths: 0 <= x < 10.

if, elif, else

Python
temperature = int(input("Temperature? "))
if temperature < 0:
    print("Freezing")
elif temperature < 15:
    print("Cold")
elif temperature < 25:
    print("Pleasant")
else:
    print("Hot")

The indentation (4 spaces by convention) is the structure: the indented lines belong to the if above them. A colon ends each condition line. Only the first branch whose condition is true runs; else runs when none did.

Combining conditions

and, or and not combine truth values:

Python
age = 15
has_ticket = True
if age >= 12 and has_ticket:
    print("Welcome")
if not has_ticket or age < 12:
    print("Sorry")

They short-circuit: a and b does not evaluate b if a is false, which allows guards such as if items and items[0] > 0: (no error on an empty list).

The conditional expression

For choosing between two values in one line:

Python
score = 72
grade = "pass" if score >= 50 else "fail"
print(grade)

match

When one value is compared against many cases, match (Python 3.10+) is clearer than a chain of elif:

Python
command = input("> ").strip().lower()
match command:
    case "start" | "go":
        print("Starting")
    case "stop":
        print("Stopping")
    case _:
        print("Unknown command")

| means "or", and case _ matches anything. match can also take apart lists and objects (lesson 5.03 shows more).

Common mistakes

  • if x = 5: is a syntax error: comparison is ==.
  • Mixing tabs and spaces in indentation causes IndentationError; editors insert spaces when you press Tab.
  • if x == 1 or 2: is always true (2 is truthy). Write if x == 1 or x == 2: or if x in (1, 2):.
