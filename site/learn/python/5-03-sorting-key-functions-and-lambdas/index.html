Sorting, Key Functions and Lambdas

lesson 5.033 of 5 in milestone 55 min1 practice task

Putting things in order - sorted and sort with key functions, sorting by several criteria, stable sorting, reverse order per field, operator.itemgetter and attrgetter, min and max with keys, and structural pattern matching on sequences.

Key functions

sorted(items, key=f) sorts by f(item) instead of the items themselves. key takes any function of one argument:

Python
words = ["banana", "Apple", "cherry", "fig"]
print(sorted(words))                    # ['Apple', 'banana', 'cherry', 'fig']: capitals first
print(sorted(words, key=str.lower))     # case-insensitive
print(sorted(words, key=len))           # by length: ['fig', 'Apple', 'banana', 'cherry']

min and max take a key too: max(words, key=len) is the longest word.

Several criteria

Return a tuple from the key: tuples compare item by item, so the second item breaks ties of the first:

Python
people = [("Ada", 36), ("Grace", 85), ("Alan", 36), ("Bob", 85)]
print(sorted(people, key=lambda p: (p[1], p[0])))      # by age, then name

To sort one field descending and another ascending, negate the number: key=lambda p: (-p[1], p[0]) is "oldest first, then by name". For text fields that cannot be negated, use stability (below).

Stable sorting

Python's sort is stable: items with equal keys keep their original order. That allows sorting in several passes, least important key first:

Python
people = [("Ada", 36), ("Grace", 85), ("Alan", 36), ("Bob", 85)]
by_name = sorted(people, key=lambda p: p[0], reverse=True)    # names Z-A
result = sorted(by_name, key=lambda p: p[1])                  # then ages ascending, names stay Z-A
print(result)

operator helpers

operator.itemgetter and attrgetter build key functions that are clearer and a little faster than lambdas:

Python
from operator import itemgetter, attrgetter
from dataclasses import dataclass

rows = [{"name": "Ada", "score": 95}, {"name": "Bob", "score": 72}]
print(sorted(rows, key=itemgetter("score"), reverse=True))

@dataclass
class Player:
    name: str
    level: int

team = [Player("Ada", 7), Player("Bob", 3)]
print(sorted(team, key=attrgetter("level")))

Sorting your own objects

Objects without a key need __lt__ (lesson 4.02) or @dataclass(order=True) (lesson 4.04) to be sortable. A key function is usually better: it does not fix one "natural" order for a class that can be sorted many ways.

match on sequences

match (lesson 1.05) can also take sequences apart by shape, which helps when processing commands or records:

Python
def describe(command):
    match command.split():
        case ["go", direction]:
            return f"going {direction}"
        case ["take", *items] if items:
            return f"taking {', '.join(items)}"
        case ["quit" | "exit"]:
            return "bye"
        case _:
            return "unknown"

for c in ["go north", "take key lamp", "exit", "dance"]:
    print(describe(c))

Each case matches the list's length and literal words, binds the other positions to names, and can add a guard with if.
