Comprehensions

lesson 5.011 of 5 in milestone 55 min1 practice task

Building lists, dictionaries and sets in one readable expression - list comprehensions with conditions, nested comprehensions, dictionary and set comprehensions, conditional expressions inside them, and when a plain loop is clearer.

List comprehensions

A very common loop builds a new list from an old one:

Python
squares = []
for n in range(1, 6):
    squares.append(n * n)

A list comprehension says the same in one expression:

Python
squares = [n * n for n in range(1, 6)]
print(squares)                         # [1, 4, 9, 16, 25]

Read it as "n × n for each n in the range". The parts are: the expression to collect, then for name in iterable.

Filtering

An if at the end keeps only some items:

Python
words = ["apple", "Kiwi", "banana", "fig", "Cherry"]
long_words = [w for w in words if len(w) > 4]
capitalised = [w for w in words if w[0].isupper()]
print(long_words, capitalised)

To transform some items rather than drop them, put a conditional expression (lesson 1.05) at the front:

Python
numbers = [3, -1, 4, -5]
print([n if n >= 0 else 0 for n in numbers])     # [3, 0, 4, 0]

if at the end filters; if ... else at the front chooses a value.

Nested loops

Several for clauses work like nested loops, read left to right:

Python
pairs = [(x, y) for x in range(3) for y in range(3) if x != y]
grid = [[0] * 4 for _ in range(3)]               # 3 separate rows of 4 zeros
flat = [cell for row in [[1, 2], [3, 4]] for cell in row]
print(pairs[:3], flat)

Dictionary and set comprehensions

Python
words = ["apple", "fig", "banana"]
lengths = {w: len(w) for w in words}              # dict
initials = {w[0] for w in words}                  # set
inverted = {v: k for k, v in {"a": 1, "b": 2}.items()}
print(lengths, initials, inverted)

Generator expressions

With parentheses instead of brackets, the same syntax makes a generator that produces items one at a time without building a list (lesson 5.02). Passed straight to a function, the extra parentheses can be dropped:

Python
print(sum(n * n for n in range(1_000_000)))
print(any(w.startswith("b") for w in ["apple", "banana"]))
print(max(len(w) for w in ["apple", "fig", "banana"]))

When not to use one

Comprehensions are for building a collection. If the loop's job is a side effect (printing, writing files), use a plain for. If the expression needs several steps or nested conditions, a loop with good variable names is clearer than a comprehension that has to be read three times. A good rule: one for, at most one condition, one short expression.
