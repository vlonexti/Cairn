Lists

lesson 2.022 of 5 in milestone 25 min1 practice task

Python's general-purpose collection - creating lists, indexing and slicing, adding and removing items, sorting, searching, lists of lists, and the important difference between copying a list and naming it twice.

Creating and reading lists

A list holds values in order, of any types, and can grow and shrink:

Python
scores = [72, 95, 88]
mixed = ["Ada", 36, True]
empty = []
print(scores[0], scores[-1], len(scores))   # 72 88 3
print(scores[1:])                           # [95, 88]

Indexing and slicing work exactly as for strings (lesson 2.01).

Changing lists

Unlike strings, lists are mutable:

Operation Does
xs[i] = v Replace one item
xs.append(v) Add at the end
xs.insert(i, v) Insert before index i
xs.extend(other) / xs += other Add every item of another list
xs.pop() / xs.pop(i) Remove and return the last item / item i
xs.remove(v) Remove the first item equal to v (error if missing)
del xs[i] / del xs[a:b] Delete by index or slice
xs.clear() Remove everything
Python
tasks = ["write", "test"]
tasks.append("ship")
tasks.insert(0, "plan")
done = tasks.pop(0)
print(done, tasks)          # plan ['write', 'test', 'ship']

Searching and counting

Python
xs = [3, 1, 4, 1, 5]
print(4 in xs, xs.index(4), xs.count(1))     # True 2 2
print(min(xs), max(xs), sum(xs))             # 1 5 14

Sorting

xs.sort() sorts the list in place; sorted(xs) returns a new sorted list and leaves xs alone. Both take reverse=True and a key (lesson 5.03):

Python
names = ["carol", "Ada", "bob"]
print(sorted(names))                      # ['Ada', 'bob', 'carol']: capitals sort first
print(sorted(names, key=str.lower))       # ['Ada', 'bob', 'carol']
names.sort(reverse=True)
print(names)

xs.reverse() reverses in place; xs[::-1] makes a reversed copy.

Names, not boxes

A variable refers to a list; assigning it to another name does not copy it:

Python
a = [1, 2, 3]
b = a            # b and a are the SAME list
b.append(4)
print(a)         # [1, 2, 3, 4]
c = a.copy()     # or a[:] or list(a): a new list
c.append(5)
print(a, c)

This matters for functions too: a function that changes a list it was given changes the caller's list.

Lists of lists

A grid is a list of rows:

Python
grid = [[0] * 3 for _ in range(2)]     # two rows of three zeros (lesson 5.01 explains this form)
grid[1][2] = 9
print(grid)                            # [[0, 0, 0], [0, 0, 9]]

Beware [[0] * 3] * 2: it repeats the same inner list twice, so changing one row changes both.
