Project: A Data Report Tool

lesson 6.055 of 5 in milestone 65 min

Bring the whole course together in a command-line tool that reads sales data from CSV, validates it, groups and summarises it by month and product, and writes a text report and a JSON file. This lesson is the design, the structure and the order to build it in.

What it does

Output
python sales_report.py sales.csv --from 2026-01-01 --to 2026-06-30 --json summary.json

Sales report 2026-01-01 to 2026-06-30
Rows: 1 204 read, 1 198 used, 6 rejected (see errors below)

Month       Orders     Revenue
2026-01        201    12 450.50
2026-02        188    11 980.00
...
Top products
  1. Green tea        3 120.00
  2. Mug              2 400.00
  ...
Errors
  line 17: quantity is not a number: "two"
  ...

The input is a CSV file with a header date,product,quantity,unit_price.

Structure

Keep the tool in small, testable functions, with input and output only at the edges:

Python
def read_rows(lines) -> tuple[list[Sale], list[str]]: ...      # parse and validate
def in_range(sales, start, end) -> list[Sale]: ...
def by_month(sales) -> dict[str, tuple[int, float]]: ...        # month -> (orders, revenue)
def top_products(sales, n) -> list[tuple[str, float]]: ...
def format_report(...) -> str: ...
def main(argv=None) -> int: ...                                  # the only function that touches files

read_rows takes lines rather than a path, so tests can pass a list of strings; main opens the file and passes open(path) to it. The final project of this milestone is exactly these functions, checked by tests.

Money

Revenue is a sum of quantity × unit_price. Floats can show tiny errors over thousands of rows (lesson 1.04). Either round only when displaying, or work in whole cents (round(float(price) * 100)), or use decimal.Decimal for exact decimal arithmetic. The project uses cents.

Order to build in

  1. read_rows with tests for good rows, each kind of bad row, and blank lines.
  2. by_month and top_products, tested on a few hand-made sales.
  3. format_report, compared against an expected text in a test.
  4. main with argparse; try it on a real CSV exported from a spreadsheet.
  5. Date filtering and JSON output.
  6. Run it on messy data: an extra column, a missing header, a different delimiter, an empty file; make each fail clearly.
