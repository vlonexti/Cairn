The Standard Library Toolbox

lesson 5.044 of 5 in milestone 55 min1 practice task

The modules that make everyday code short - collections (Counter, defaultdict, deque, namedtuple), itertools (chain, groupby, product, combinations, accumulate), functools (lru_cache, partial, reduce) and a few more worth knowing.

collections

Counter counts things:

Python
from collections import Counter
words = "the cat and the hat and the bat".split()
counts = Counter(words)
print(counts["the"], counts["dog"])          # 3 0: missing keys count as 0
print(counts.most_common(2))                 # [('the', 3), ('and', 2)]
print(Counter("hello") + Counter("world"))   # counters add up

defaultdict creates missing values automatically, which makes grouping one line:

Python
from collections import defaultdict
by_letter = defaultdict(list)
for word in ["apple", "avocado", "banana", "blueberry", "cherry"]:
    by_letter[word[0]].append(word)
print(dict(by_letter))

deque is a list with fast adding and removing at both ends, ideal for queues and "the last N items":

Python
from collections import deque
recent = deque(maxlen=3)
for page in ["home", "about", "shop", "cart"]:
    recent.append(page)
print(list(recent))                          # ['about', 'shop', 'cart']
queue = deque(["a", "b"])
queue.appendleft("z")
print(queue.popleft(), queue)

itertools

Function Gives
chain(a, b) The items of a, then of b
islice(it, n) The first n items
groupby(sorted_items, key) Runs of consecutive items with the same key
product(a, b) Every pair (nested loops)
permutations(xs, r), combinations(xs, r) Orderings, selections
accumulate(xs) Running totals
count(start), cycle(xs), repeat(x) Infinite sequences
pairwise(xs) Overlapping pairs: (a, b), (b, c), ...
Python
from itertools import groupby, combinations, accumulate, pairwise
scores = sorted([("Ada", "A"), ("Bob", "B"), ("Cy", "A")], key=lambda s: s[1])
for grade, group in groupby(scores, key=lambda s: s[1]):
    print(grade, [name for name, _ in group])
print(list(combinations("ABC", 2)))
print(list(accumulate([3, 1, 4, 1])))         # [3, 4, 8, 9]
print([b - a for a, b in pairwise([1, 4, 9, 16])])

groupby only groups consecutive items: sort by the same key first.

functools

Python
from functools import lru_cache, partial, reduce

@lru_cache(maxsize=None)          # remembers results: a ready-made version of practice 3.03's memoize
def ways(n):
    return 1 if n <= 1 else ways(n - 1) + ways(n - 2)
print(ways(80))

int_from_binary = partial(int, base=2)        # a function with some arguments filled in
print(int_from_binary("1011"))

print(reduce(lambda a, b: a * b, [1, 2, 3, 4]))   # 24: combine items pairwise
