Reading Documentation

5 milestones20 lessons20 practice tasks25 projects

The skill under every other course: finding the right documentation and reading it precisely. How reference pages are laid out, reading C++ signatures, preconditions and undefined behaviour, cppreference and the standard library's return values, complexity and invalidation rules, Microsoft's Win32 pages with SAL annotations, error codes and versioned structures, Python, MDN and Node documentation, man pages, headers and specifications, and finally turning examples into robust code, checking your understanding with small experiments, coping with docs that are wrong, and writing documentation of your own. The practice has you implement functions exactly as documented, including every edge case. It assumes the C++ course up to classes.
