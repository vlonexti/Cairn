Finding Your Way Around cppreference

lesson 2.011 of 4 in milestone 25 min1 practice task

How cppreference.com is organised - by header and by topic - the layout of a class page with its member tables and version markers, what a function page adds (possible implementation, defect reports, examples), how it relates to the C++ standard, and fast ways to land on the right page.

The reference for C++

cppreference.com is the reference most C++ programmers use every day. It is written by volunteers, closely follows the C++ standard, and covers the language and the whole standard library, version by version. The standard itself (the ISO document, with free drafts at eel.is/c++draft) is the final word; cppreference is its readable map.

Two ways in

  • By header: the "Standard library headers" page lists every header (<vector>, <string>, <charconv> ...) and what it declares. Use it when you know where something lives or want to see what a header offers.
  • By topic: the main page groups the library: containers, algorithms, strings, numerics, input/output, filesystem, concurrency and so on. Use it when you know what you want to do but not the name.

The fastest route in practice is a web search with the site name and the exact name: cppreference std::from_chars, cppreference vector insert.

A class page

The page for a class such as std::vector is mostly tables:

Part What it gives you
declaration template<class T, class Allocator = std::allocator<T>> class vector;, and the header
description what it is, its guarantees (contiguous storage), its requirements on T
member types value_type, size_type, iterator ...
member functions every member, grouped: element access, iterators, capacity, modifiers
non-member functions operator==, std::erase, std::swap ...
deduction guides, notes, example, see also as on any page

Each row links to a page of its own. Markers such as (C++11), (C++20), (deprecated in C++17), (removed in C++20) tell you which version a member belongs to (lesson 2.04). A member listed as (constexpr since C++20) works in older versions too, just not at compile time.

A function page

Function pages follow the anatomy of lesson 1.02, with a few extras:

  • Overloads numbered (1), (2) ..., each with version markers, and the description refers to them by number.
  • Template parameter requirements: "InputIt must meet the requirements of LegacyInputIterator", with a link explaining exactly what that means.
  • Return value and Exceptions sections that cover every overload.
  • Complexity stated precisely: "Exactly last - first applications of the predicate".
  • Possible implementation: a short version of the code. Excellent for understanding; but the real library may differ, so rely on the stated behaviour, not on the sample code.
  • Defect reports: corrections to the standard after publication ("LWG 2192: behaviour changed for ..."). If your compiler behaves differently from the page, look here.
  • Example: a complete program with its output. You can usually run it on Compiler Explorer with one click.

Reading a page for real

Here is how you would answer "does std::stoi accept leading spaces, and what happens with "12abc"?":

  1. Open the page for std::stoi. The signature shows int stoi(const std::string& str, std::size_t* pos = nullptr, int base = 10);.
  2. The description says it discards leading whitespace and then reads as many characters as form a valid number, like std::strtol. So "12abc" gives 12.
  3. The pos parameter: if not null, it receives the number of characters processed. So you can tell that "abc" was left over.
  4. Exceptions: std::invalid_argument if no conversion could be performed, std::out_of_range if the value does not fit.

And the neighbour in "see also", std::from_chars, works differently: it never skips whitespace, never throws, does not accept a leading +, and reports both where it stopped and an error code. Same job, different contract; the pages tell you which you need.

C++
#include <charconv>
#include <iostream>
#include <string>

int main()
{
    std::size_t used{ 0 };
    std::cout << std::stoi("  12abc", &used) << " used " << used << '\n';

    const std::string text{ "+12" };
    int value{ 0 };
    const auto [ptr, ec] { std::from_chars(text.data(), text.data() + text.size(), value) };
    std::cout << "from_chars on +12: " << (ec == std::errc{} ? "ok" : "failed") << '\n';
}
