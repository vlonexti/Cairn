Pointers to Pointers

lesson 3.022 of 5 in milestone 35 min1 practice task

A pointer is a variable, so it has an address, and a pointer can point at it. int** lets a function change which address the caller's pointer holds. Arrays of pointers, argv, and the pointer-to-pointer trick that removes items from a linked list without special cases.

One more level

A pointer is an ordinary variable with an address of its own, so another pointer can hold that address:

C++
#include <iostream>

int main()
{
    int score{ 42 };
    int* p{ &score };     // p holds the address of score
    int** pp{ &p };       // pp holds the address of p

    std::cout << **pp << '\n';  // follow twice: 42
    **pp = 50;                  // writes score
    std::cout << score << '\n'; // 50
}
Text
   pp                 p                  score
 [ 0x2010 ] ----> [ 0x2000 ] ----> [ 50 ]
  at 0x2020         at 0x2010        at 0x2000

*pp is p, and **pp is score. Each star follows one arrow. There is nothing special about two levels; int*** is three arrows, though you will rarely want more than two.

Changing the caller's pointer

Lesson 1.04 passed int* so a function could change the caller's int. By the same logic, to change the caller's pointer, pass its address, an int**:

C++
// Makes *target point at the larger of two values.
void aimAtLarger(int** target, int* a, int* b)
{
    *target = (*a >= *b) ? a : b;     // changes the caller's pointer variable
}

int* chosen{ nullptr };
aimAtLarger(&chosen, &x, &y);         // chosen now holds &x or &y

The C and Windows APIs use this pattern for functions that hand you a newly created object: HRESULT CreateSomething(..., IThing** result). You pass the address of your pointer, and the function fills it in.

In C++ the same effect is often written with a reference to a pointer, int*& target, but the ** form is everywhere in C interfaces, so you need to read it fluently.

Arrays of pointers

An array whose elements are pointers is common and useful: a list of strings, a list of objects that live elsewhere.

C++
const char* names[]{ "Ada", "Grace", "Linus" };   // three pointers to text
const char** cursor{ names };                       // pointer to the first pointer
std::cout << *cursor << '\n';                        // Ada
std::cout << *(cursor + 2) << '\n';                  // Linus
std::cout << **(cursor + 1) << '\n';                 // G: first char of Grace

main's second parameter is exactly this:

C++
int main(int argc, char** argv)
// argv[0] is the program's path, argv[1] ... argv[argc - 1] are the arguments, argv[argc] is nullptr

The pointer-to-pointer trick

Removing an item from a singly linked list usually needs a special case for the first node, because removing it changes head while removing any other node changes the previous node's next:

C++
struct Node { int value; Node* next; };

// the usual way: two cases
void removeValue(Node*& head, int value)
{
    if (head && head->value == value) { Node* dead{ head }; head = head->next; delete dead; return; }
    for (Node* n{ head }; n && n->next; n = n->next)
        if (n->next->value == value) { Node* dead{ n->next }; n->next = dead->next; delete dead; return; }
}

But head and every next are all just pointers to Node, and a Node** can point at any of them. Walk a pointer to "the link that points at the current node", and there is only one case:

C++
void removeValue(Node** link, int value)
{
    while (*link && (*link)->value != value)
        link = &(*link)->next;           // move to the next link
    if (*link)
    {
        Node* dead{ *link };
        *link = dead->next;              // bypass the node, whether *link is head or a next
        delete dead;
    }
}

removeValue(&head, 7);

link starts at &head; after one step it is &head->next, and so on. When it stops, *link is the matching node, and assigning to *link updates whichever pointer pointed at it. Linus Torvalds famously called this version "good taste", because the special case disappears instead of being handled.

Reading the declarations

Declarations with several stars and const read right to left:

Declaration Reads as
int** pp pp is a pointer to a pointer to int
const char** names names is a pointer to a pointer to const char
char* const* argv argv is a pointer to a const pointer to char
int*& r r is a reference to a pointer to int
