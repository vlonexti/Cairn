Working with APIs

6 milestones30 lessons30 practice tasks30 projects

How programs talk to other programs, in Python: HTTP requests and JSON, reading an API's documentation, API keys, tokens and OAuth with PKCE, signed requests, paging, rate limits, retries with backoff, idempotency and caching, receiving and verifying webhooks, joining two services together with mapping, incremental sync and failure handling, and finally calling C libraries with ctypes. The practice uses small fake servers, so every task runs anywhere and every edge case can be tested; each milestone ends with five projects, from small to large. It assumes the Python course.
