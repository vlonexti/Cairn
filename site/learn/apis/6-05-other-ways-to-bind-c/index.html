Other Ways to Bind C

lesson 6.055 of 5 in milestone 65 min1 practice task

Beyond ctypes - cffi working from C declarations, extension modules and pybind11 for speed and C++, generating bindings from headers - and how other languages call the same C API - C# P/Invoke, JavaScript through N-API and FFI packages, Rust's extern blocks and bindgen - and how to choose.

cffi: from the declarations

cffi (pip install cffi) reads C declarations directly, so you paste from the header instead of translating each type:

Python
from cffi import FFI

ffi = FFI()
ffi.cdef("""
    typedef struct { int x; double y; } point;
    int get_position(point *out);
""")
lib = ffi.dlopen("./mylib.dll")
pos = ffi.new("point *")
if lib.get_position(pos) == 0:
    print(pos.x, pos.y)

It can also compile a small C module ahead of time ("API mode"), which is faster and checks the declarations against the real header.

Extension modules, pybind11 and Cython

When speed matters or the library is C++, bindings are compiled:

  • A C extension module uses Python's C API directly. Most control, most code.
  • pybind11 (and the newer nanobind) wraps C++ functions and classes with a few lines of C++ templates, converting std::string, std::vector and exceptions automatically.
  • Cython writes Python-like code that compiles to C and can call C functions directly.

These need a compiler for every platform you ship to, usually built into wheels by CI.

Generating bindings

Large APIs are rarely bound by hand. Tools read the header and generate the binding: ctypeslib and pyclibrary for ctypes, cffi itself, bindgen for Rust, SWIG for many languages at once. Even then, a person decides ownership rules and error handling, which no header states completely. The milestone project writes a small generator for a subset of C, which shows what such tools do.

The same C API from other languages

Language Mechanism Example
C# P/Invoke [DllImport("mylib")] static extern int get_position(out Point p); with [StructLayout(LayoutKind.Sequential)]
JavaScript (Node) N-API addons in C/C++, or FFI packages an addon compiled with node-gyp, or a runtime FFI library describing types like ctypes
Rust extern "C" blocks, bindgen to generate them unsafe { get_position(&mut p) }
Go cgo import "C" with the header in a comment
Java the Foreign Function and Memory API (Java 22+), JNI before it Linker.nativeLinker().downcallHandle(...)

The questions are the same in every language: the exact types and layout, who owns which memory, how errors are reported, and which thread may call what. Answer them once, from the header and documentation, and the binding in any language follows.

Choosing

  • A few functions, no compiler available: ctypes.
  • A larger C API, especially one under active development: cffi.
  • Performance-critical code or C++ classes: pybind11 or an extension module.
  • An existing popular library: look for a maintained Python package first; someone has probably done the work.
