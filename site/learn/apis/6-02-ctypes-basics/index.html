ctypes Basics

lesson 6.022 of 5 in milestone 65 min1 practice task

Calling a C function from Python with ctypes - loading a library on Windows, Linux and macOS, the ctypes types that match C types, why argtypes and restype must always be set, how ints, bytes, str and None are passed, and translating a function's declaration from its header line by line.

Loading a library

Python
import ctypes, ctypes.util, sys

if sys.platform == "win32":
    kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)   # Windows API functions
    libc = ctypes.CDLL("msvcrt")                                 # the old C runtime, for examples
else:
    libc = ctypes.CDLL(ctypes.util.find_library("c"))            # libc.so.6 or libSystem
mylib = ctypes.CDLL("./mylib.dll")                               # your own library, by path

CDLL uses the C calling convention; WinDLL uses stdcall, which the Windows API uses on 32-bit Windows (on 64-bit Windows both are the same, but WinDLL documents intent). Library functions are attributes: libc.strlen, kernel32.GetTickCount64.

Beware long: it is 32 bits on Windows and 64 bits on Linux and macOS, so c_long changes size between systems. Prefer fixed-width types (int32_t, c_int32) in your own C APIs.

Always set argtypes and restype

Without declarations, ctypes guesses: every return value is treated as a C int, and arguments are converted from whatever Python value you pass. The guess is wrong for anything returning a pointer, a double or a 64-bit value, and the error is silent: a 64-bit pointer is cut to 32 bits, and later use crashes. So, for every function, write both from its declaration:

Python
# C:  size_t strlen(const char *s);
libc.strlen.argtypes = [ctypes.c_char_p]
libc.strlen.restype = ctypes.c_size_t
print(libc.strlen(b"hello"))            # 5

# C:  double pow(double x, double y);
libm.pow.argtypes = [ctypes.c_double, ctypes.c_double]
libm.pow.restype = ctypes.c_double
print(libm.pow(2.0, 10.0))              # 1024.0

# C:  void free_thing(struct thing *t);
mylib.free_thing.argtypes = [ctypes.c_void_p]
mylib.free_thing.restype = None         # void

With argtypes set, ctypes also checks the arguments: passing a str where c_char_p is declared raises ArgumentError instead of handing C a pointer to the wrong thing.

Text across the boundary

C strings are bytes. A c_char_p argument takes bytes: encode your text first ("café".encode("utf-8")), and decode results you get back. Wide wchar_t* strings, which the W functions of the Windows API use, map to str with c_wchar_p. A function returning c_char_p gives you a copy as bytes; the original memory still belongs to the library (lesson 6.03 is about ownership).
