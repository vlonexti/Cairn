A Webhook Receiver

lesson 4.044 of 5 in milestone 45 min1 practice task

The HTTP side of a webhook endpoint - what a raw request looks like on the wire, parsing the request line, headers and body by Content-Length, choosing status codes for every failure, a minimal receiver with Python's http.server, and what production adds (a framework, HTTPS, a queue).

The request on the wire

A webhook delivery is an ordinary HTTP request. On the wire, before any framework has touched it:

Text
POST /webhooks HTTP/1.1\r\n
Host: hooks.example.org\r\n
Content-Type: application/json\r\n
Content-Length: 58\r\n
Webhook-Signature: t=1793523600,v1=...\r\n
\r\n
{"id":"evt_1","type":"order.paid","data":{"order":"o_42"}}
  • The request line: method, path, version.
  • Headers, one per line, Name: value; names are case-insensitive.
  • An empty line, then the body, exactly Content-Length bytes.

Frameworks parse this for you, but knowing the shape helps when debugging (what exactly arrived?) and is the clearest way to see which bytes the signature covers. Practice 4.04 parses it by hand.

Every way it can fail

A receiver should answer each failure with a status that tells the sender the truth:

Problem Status
malformed request (bad request line, header without :, body shorter than Content-Length) 400
wrong path 404
method other than POST 405
missing or invalid signature, timestamp out of range 401 (or 400)
body is not valid JSON, or not an event 400
your own failure while storing 500
accepted (new or duplicate) 200

A minimal receiver

Python's standard library can run a small HTTP server, enough for development and for understanding:

Python
import json
from http.server import BaseHTTPRequestHandler, HTTPServer

SECRETS = [os.environ["WEBHOOK_SECRET"].encode()]

class Handler(BaseHTTPRequestHandler):
    def do_POST(self):
        if self.path != "/webhooks":
            return self.reply(404)
        length = int(self.headers.get("Content-Length", "0"))
        raw = self.rfile.read(length)                      # the raw bytes: verify these
        if not verify(self.headers.get("Webhook-Signature"), raw, SECRETS, now=time.time()):
            return self.reply(401)
        try:
            event = json.loads(raw)
        except ValueError:
            return self.reply(400)
        queue.put(event)                                   # process later
        self.reply(200)

    def reply(self, status):
        self.send_response(status)
        self.end_headers()

HTTPServer(("127.0.0.1", 8080), Handler).serve_forever()

In production

  • Run it in a real web framework (Flask, FastAPI, Django) behind a production server, with HTTPS: services refuse to deliver to plain HTTP, and secrets travel in these requests.
  • Put events on a durable queue or table, and process them in a worker (lesson 4.03).
  • Log each delivery's event id, type, signature result and status (redacted, lesson 2.05).
  • Limit the body size: a receiver that reads any Content-Length can be made to allocate gigabytes.
