Clipboard, Drag and Drop and the Shell

lesson 5.055 of 5 in milestone 55 min1 practice task

Exchanging data with other programs - copying and pasting text through the clipboard, its formats and line endings, accepting files dropped from Explorer, file associations and the Recent list, and notifications in the taskbar.

The clipboard

The clipboard holds data in one or more formats at once: the same copied text can be offered as Unicode text, HTML and RTF, and the pasting program picks the richest one it understands.

C++
bool copyText(HWND owner, const std::wstring& text)
{
    if (!OpenClipboard(owner)) return false;               // another program may have it open: retry briefly
    EmptyClipboard();                                      // we become the owner
    const size_t bytes = (text.size() + 1) * sizeof(wchar_t);
    HGLOBAL mem = GlobalAlloc(GMEM_MOVEABLE, bytes);
    if (mem)
    {
        memcpy(GlobalLock(mem), text.c_str(), bytes);
        GlobalUnlock(mem);
        if (!SetClipboardData(CF_UNICODETEXT, mem)) GlobalFree(mem);   // on success the clipboard owns the memory
    }
    CloseClipboard();
    return mem != nullptr;
}

std::wstring pasteText(HWND owner)
{
    std::wstring text;
    if (!OpenClipboard(owner)) return text;
    if (HANDLE h = GetClipboardData(CF_UNICODETEXT))
    {
        if (auto* p = static_cast<const wchar_t*>(GlobalLock(h))) { text = p; GlobalUnlock(h); }
    }
    CloseClipboard();
    return text;
}

Keep the clipboard open as briefly as possible: while one program has it open, nobody else can use it. Note who owns the memory: after a successful SetClipboardData, the clipboard does, and you must not free it; the data you get from GetClipboardData also belongs to the clipboard.

Line endings

Clipboard text uses CRLF (\r\n) line endings by convention. A program that stores \n internally converts to \r\n when copying and back when pasting; a pasted text may also contain lone \r or \n from other programs, so normalise all three. The practice writes these conversions.

Other formats

  • CF_HDROP: a list of files, as Explorer copies them (also used for drag and drop).
  • RegisterClipboardFormatW(L"HTML Format"): HTML with a small header giving offsets, which browsers and Office use.
  • Your own format, registered by name, to copy rich objects between instances of your program, plus CF_UNICODETEXT as a fallback for everyone else.

To keep "Paste" enabled only when it makes sense, check IsClipboardFormatAvailable(CF_UNICODETEXT) in WM_INITMENUPOPUP (lesson 2.04).

Dropping files

The simplest way to accept files dragged from Explorer:

C++
DragAcceptFiles(hwnd, TRUE);          // in WM_CREATE

case WM_DROPFILES:
{
    HDROP drop = reinterpret_cast<HDROP>(wParam);
    const UINT count = DragQueryFileW(drop, 0xFFFFFFFF, nullptr, 0);
    for (UINT i = 0; i < count; ++i)
    {
        const UINT len = DragQueryFileW(drop, i, nullptr, 0);
        std::wstring path(len, L'\0');
        DragQueryFileW(drop, i, path.data(), len + 1);
        openFile(path);
    }
    DragFinish(drop);
    return 0;
}

Inside, an HDROP is a DROPFILES header followed by the paths as a double-null-terminated list (each path null-terminated, an extra null at the end), the same layout as lesson 3.02's filters and REG_MULTI_SZ. Full OLE drag and drop (RegisterDragDrop with an IDropTarget) is needed to show a drop effect, accept text, or drag out of your program; it is more code but the same idea.

File associations

"Double-click a .xenonnote file to open it in my program" is a set of registry keys under HKCU\Software\Classes (lesson 5.02): a ProgID with the open command, and the extension pointing to it:

Output
HKCU\Software\Classes\.xenonnote               (default) = Xenon.Note
HKCU\Software\Classes\Xenon.Note\shell\open\command   (default) = "C:\...\XenonNotes.exe" "%1"

The "%1" (in quotes, for paths with spaces) is replaced by the file's path, which then arrives in your command line (lesson 5.03). After changing associations, call SHChangeNotify(SHCNE_ASSOCCHANGED, SHCNF_IDLIST, nullptr, nullptr) so Explorer notices. Installers usually write these keys.

The Recent list

SHAddToRecentDocs(SHARD_PATHW, path) adds a file to the user's recent documents, the taskbar jump list and the Start menu's recommendations, so the user can reopen it from outside your program.

Notifications

For "the search finished" while the window is in the background, flash the taskbar button (FlashWindowEx with FLASHW_TRAY | FLASHW_TIMERNOFG) or show progress on it (ITaskbarList3::SetProgressValue). A notification-area icon (Shell_NotifyIconW) suits programs that run in the background.
