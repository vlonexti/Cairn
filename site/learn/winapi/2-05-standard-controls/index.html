Standard Controls

lesson 2.055 of 5 in milestone 25 min1 practice task

Buttons, check boxes, edit boxes, list boxes and combo boxes are child windows of classes Windows provides. This lesson creates them, talks to them with messages, handles their notifications, gives them the right font, and moves the keyboard focus between them with Tab.

Controls are windows

A control is a child window of a predefined class. Create it in the parent's WM_CREATE with WS_CHILD | WS_VISIBLE, and give it an id in the menu parameter:

C++
constexpr int IDC_NAME = 1001, IDC_ADD = 1002, IDC_LIST = 1003, IDC_SHOUT = 1004;

case WM_CREATE:
{
    const auto instance = reinterpret_cast<CREATESTRUCTW*>(lParam)->hInstance;
    CreateWindowExW(WS_EX_CLIENTEDGE, L"EDIT", L"", WS_CHILD | WS_VISIBLE | WS_TABSTOP | ES_AUTOHSCROLL,
                    10, 10, 200, 24, hwnd, reinterpret_cast<HMENU>(IDC_NAME), instance, nullptr);
    CreateWindowExW(0, L"BUTTON", L"&Add", WS_CHILD | WS_VISIBLE | WS_TABSTOP | BS_DEFPUSHBUTTON,
                    220, 10, 80, 24, hwnd, reinterpret_cast<HMENU>(IDC_ADD), instance, nullptr);
    CreateWindowExW(0, L"BUTTON", L"&Shout", WS_CHILD | WS_VISIBLE | WS_TABSTOP | BS_AUTOCHECKBOX,
                    10, 44, 200, 24, hwnd, reinterpret_cast<HMENU>(IDC_SHOUT), instance, nullptr);
    CreateWindowExW(WS_EX_CLIENTEDGE, L"LISTBOX", L"", WS_CHILD | WS_VISIBLE | WS_TABSTOP | WS_VSCROLL | LBS_NOTIFY,
                    10, 78, 290, 200, hwnd, reinterpret_cast<HMENU>(IDC_LIST), instance, nullptr);
    return 0;
}
Class Control Common styles
BUTTON Push button, check box, radio button, group box BS_PUSHBUTTON, BS_DEFPUSHBUTTON, BS_AUTOCHECKBOX, BS_AUTORADIOBUTTON, BS_GROUPBOX
EDIT Text box ES_AUTOHSCROLL, ES_MULTILINE, ES_NUMBER, ES_PASSWORD, ES_READONLY
STATIC Label, picture, frame SS_LEFT, SS_RIGHT, SS_CENTER
LISTBOX List of strings LBS_NOTIFY, LBS_SORT, LBS_EXTENDEDSEL
COMBOBOX Drop-down list CBS_DROPDOWNLIST, CBS_DROPDOWN
SCROLLBAR A separate scroll bar SBS_HORZ, SBS_VERT

Talking to controls

Controls are driven by messages. GetDlgItem(parent, id) finds a control's window:

C++
HWND list = GetDlgItem(hwnd, IDC_LIST);
SendMessageW(list, LB_ADDSTRING, 0, reinterpret_cast<LPARAM>(L"Granite"));
const int selected = static_cast<int>(SendMessageW(list, LB_GETCURSEL, 0, 0));      // LB_ERR (-1) for none
const bool shout = SendMessageW(GetDlgItem(hwnd, IDC_SHOUT), BM_GETCHECK, 0, 0) == BST_CHECKED;

wchar_t name[256];
GetDlgItemTextW(hwnd, IDC_NAME, name, 256);           // SetDlgItemTextW to change it

Each control family has its prefix: BM_ buttons, EM_ edits, LB_ list boxes, CB_ combo boxes. Reading text of unknown length: ask GetWindowTextLengthW first, then size the buffer.

Notifications

Controls tell their parent about events with WM_COMMAND: LOWORD(wParam) is the control's id, HIWORD(wParam) is the notification code, and lParam is the control's window:

C++
case WM_COMMAND:
    switch (LOWORD(wParam))
    {
    case IDC_ADD:
        if (HIWORD(wParam) == BN_CLICKED) addName();
        return 0;
    case IDC_NAME:
        if (HIWORD(wParam) == EN_CHANGE) updateAddButton();       // the text changed
        return 0;
    case IDC_LIST:
        if (HIWORD(wParam) == LBN_DBLCLK) openSelected();
        return 0;
    }
    break;

Newer controls (lesson 3.05) use WM_NOTIFY with a structure instead, because two numbers are not enough to describe their events.

Fonts

Controls created this way use the old bitmap "System" font, which looks wrong. Give every control the system's message font once they are created:

C++
NONCLIENTMETRICSW m{ sizeof(m) };
SystemParametersInfoW(SPI_GETNONCLIENTMETRICS, sizeof(m), &m, 0);
m_font = CreateFontIndirectW(&m.lfMessageFont);                 // delete it in WM_DESTROY
EnumChildWindows(hwnd, [](HWND child, LPARAM font) { SendMessageW(child, WM_SETFONT, font, TRUE); return TRUE; },
                 reinterpret_cast<LPARAM>(m_font));

With high DPI (lesson 3.04), use SystemParametersInfoForDpi so the font has the right size on each monitor.

Tab between controls

In an ordinary window, Tab does nothing. IsDialogMessageW adds dialog-style keyboard navigation (Tab and Shift+Tab between WS_TABSTOP controls, arrows within groups, Enter for the default button, Alt+letter for & mnemonics) to any window:

C++
while (GetMessageW(&msg, nullptr, 0, 0) > 0)
{
    if (!IsDialogMessageW(hwnd, &msg)) { TranslateMessage(&msg); DispatchMessageW(&msg); }
}

The Tab order is the order the controls were created in, so create them in reading order.
