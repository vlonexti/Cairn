Windows Programming with the Win32 API

7 milestones33 lessons33 practice tasks35 projects

A full course on the Windows API in C++: handles, errors and Unicode strings, windows and the message loop, painting, input, menus and resources, controls and dialogs, high DPI, Direct2D and DirectWrite, files, the registry, processes and threads, the clipboard and the shell, and packaging, a text editor and a file finder, and then deeper system topics: virtual memory, the console, overlapped I/O and completion ports, services, access tokens and privileges, and COM. It assumes the first milestones of the C++ course. You build the programs in Visual Studio; the practice on the site checks the logic inside them.
