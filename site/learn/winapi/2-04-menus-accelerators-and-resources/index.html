Menus, Accelerators and Resources

lesson 2.044 of 5 in milestone 25 min1 practice task

Adding a menu bar and context menus, handling WM_COMMAND, enabling and checking items as the program's state changes, keyboard shortcuts with accelerator tables, and the resource file that holds menus, icons, strings and version information.

Resources

A resource file (.rc) describes data that is compiled into the .exe: menus, icons, cursors, dialogs, string tables, version information. Visual Studio has editors for them; the text format is simple:

C++
// resource.h
#define IDR_MAINMENU   101
#define IDR_ACCEL      102
#define IDI_APP        103
#define ID_FILE_NEW    40001
#define ID_FILE_OPEN   40002
#define ID_FILE_SAVE   40003
#define ID_FILE_EXIT   40004
#define ID_VIEW_STATUS 40010

// app.rc
#include "resource.h"
IDI_APP ICON "app.ico"

IDR_MAINMENU MENU
BEGIN
    POPUP "&File"
    BEGIN
        MENUITEM "&New\tCtrl+N",    ID_FILE_NEW
        MENUITEM "&Open...\tCtrl+O", ID_FILE_OPEN
        MENUITEM "&Save\tCtrl+S",   ID_FILE_SAVE
        MENUITEM SEPARATOR
        MENUITEM "E&xit",           ID_FILE_EXIT
    END
    POPUP "&View"
    BEGIN
        MENUITEM "&Status Bar",     ID_VIEW_STATUS, CHECKED
    END
END

& marks the letter underlined for Alt navigation (Alt, F, S saves). \t separates the shortcut text shown on the right; it is only text: the shortcut itself comes from the accelerator table below. "..." means the item opens a dialog before doing anything.

Load the menu by giving the class wc.lpszMenuName = MAKEINTRESOURCEW(IDR_MAINMENU), or with LoadMenuW and SetMenu.

WM_COMMAND

Choosing a menu item sends WM_COMMAND with the item's id in LOWORD(wParam):

C++
case WM_COMMAND:
    switch (LOWORD(wParam))
    {
    case ID_FILE_NEW:  newDocument(); return 0;
    case ID_FILE_SAVE: save(); return 0;
    case ID_FILE_EXIT: SendMessageW(hwnd, WM_CLOSE, 0, 0); return 0;   // the same path as the close button
    }
    break;

HIWORD(wParam) tells where the command came from: 0 for a menu, 1 for an accelerator, or a notification code for a control (lesson 2.05).

Keeping items up to date

"Save" should be greyed out when there is nothing to save, and "Status Bar" should show a check mark when the bar is visible. Update the items just before the menu opens, in WM_INITMENUPOPUP, from the program's state:

C++
case WM_INITMENUPOPUP:
{
    HMENU menu = reinterpret_cast<HMENU>(wParam);
    EnableMenuItem(menu, ID_FILE_SAVE, MF_BYCOMMAND | (m_doc.dirty ? MF_ENABLED : MF_GRAYED));
    CheckMenuItem(menu, ID_VIEW_STATUS, MF_BYCOMMAND | (m_statusVisible ? MF_CHECKED : MF_UNCHECKED));
    return 0;
}

Deriving the menu's state from the program's state every time, instead of updating items whenever something changes, means they can never get out of step.

Context menus

Right-clicking sends WM_CONTEXTMENU (also sent by the Menu key and Shift+F10, with position -1, -1: then show the menu at the selection instead):

C++
case WM_CONTEXTMENU:
{
    HMENU menu = CreatePopupMenu();
    AppendMenuW(menu, MF_STRING, ID_EDIT_CUT, L"Cu&t");
    AppendMenuW(menu, MF_STRING, ID_EDIT_COPY, L"&Copy");
    TrackPopupMenu(menu, TPM_RIGHTBUTTON, GET_X_LPARAM(lParam), GET_Y_LPARAM(lParam), 0, hwnd, nullptr);
    DestroyMenu(menu);
    return 0;
}

Accelerators

An accelerator table maps key combinations to command ids, so Ctrl+S sends the same WM_COMMAND as the menu item:

C++
IDR_ACCEL ACCELERATORS
BEGIN
    "N", ID_FILE_NEW,  VIRTKEY, CONTROL
    "O", ID_FILE_OPEN, VIRTKEY, CONTROL
    "S", ID_FILE_SAVE, VIRTKEY, CONTROL
    VK_F5, ID_VIEW_REFRESH, VIRTKEY
END

The message loop translates them before anything else:

C++
HACCEL accel = LoadAcceleratorsW(instance, MAKEINTRESOURCEW(IDR_ACCEL));
while (GetMessageW(&msg, nullptr, 0, 0) > 0)
{
    if (!TranslateAcceleratorW(hwnd, accel, &msg))
    {
        TranslateMessage(&msg);
        DispatchMessageW(&msg);
    }
}

Accelerator tables can also be built at run time with CreateAcceleratorTableW, which lets users choose their own shortcuts. Parsing a shortcut such as "Ctrl+Shift+S" into key and modifier flags, and spotting two commands with the same shortcut, is the practice.

Strings and versions

A string table keeps user-visible text out of the code (LoadStringW(instance, IDS_TITLE, ...)), which is how a program is translated. A VERSIONINFO resource gives the file version, product name and copyright shown in the file's Properties dialog.
