Images with WIC

lesson 4.044 of 4 in milestone 45 min1 practice task

The Windows Imaging Component decodes and encodes PNG, JPEG, GIF, TIFF and more. This lesson loads an image file, converts it to the pixel format Direct2D wants, draws it scaled with good quality, makes thumbnails, and explains premultiplied alpha.

WIC

WIC (Windows Imaging Component) is the system's image codec library: PNG, JPEG, GIF, BMP, TIFF, ICO, HEIF and WebP (with the store extensions), and camera RAW formats. Like Direct2D it is COM:

C++
#include <wincodec.h>
#pragma comment(lib, "windowscodecs.lib")

ComPtr<IWICImagingFactory> wic;
CoCreateInstance(CLSID_WICImagingFactory, nullptr, CLSCTX_INPROC_SERVER, IID_PPV_ARGS(&wic));

Loading an image for Direct2D

C++
HRESULT loadBitmap(ID2D1RenderTarget* target, const wchar_t* path, ComPtr<ID2D1Bitmap>& out)
{
    ComPtr<IWICBitmapDecoder> decoder;
    HRESULT hr = wic->CreateDecoderFromFilename(path, nullptr, GENERIC_READ, WICDecodeMetadataCacheOnDemand, &decoder);
    ComPtr<IWICBitmapFrameDecode> frame;
    if (SUCCEEDED(hr)) hr = decoder->GetFrame(0, &frame);                 // GIF and TIFF can have several frames
    ComPtr<IWICFormatConverter> converter;
    if (SUCCEEDED(hr)) hr = wic->CreateFormatConverter(&converter);
    if (SUCCEEDED(hr)) hr = converter->Initialize(frame.Get(), GUID_WICPixelFormat32bppPBGRA,
                                                  WICBitmapDitherTypeNone, nullptr, 0.0, WICBitmapPaletteTypeMedianCut);
    if (SUCCEEDED(hr)) hr = target->CreateBitmapFromWicBitmap(converter.Get(), nullptr, out.ReleaseAndGetAddressOf());
    return hr;
}

The decoder reads the file's format from its contents, not its extension. The format converter turns whatever the file contains (8-bit palette, 24-bit RGB, 48-bit, CMYK) into the one format Direct2D draws directly: 32bppPBGRA, 8 bits each of blue, green, red and alpha, with alpha premultiplied.

The ID2D1Bitmap is a device-dependent resource (lesson 4.02): keep the decoded WIC data, or the path, so it can be re-created after a device loss.

Premultiplied alpha

In straight alpha, a pixel stores its colour and, separately, how opaque it is: half-transparent red is (255, 0, 0, 128). In premultiplied alpha, the colour channels are already multiplied by the alpha: the same pixel is (128, 0, 0, 128).

Premultiplied is what GPUs prefer, for two reasons: blending becomes one multiply-add (result = source + destination × (1 - source alpha)), and filtering (scaling, blurring) mixes neighbouring pixels correctly; with straight alpha, a fully transparent pixel's "invisible" colour bleeds into the edges as dark or coloured fringes. The practice converts between the two and blends.

Drawing scaled

C++
const D2D1_SIZE_F size = bitmap->GetSize();
const D2D1_RECT_F dest = fitInto(size, box);      // keep the aspect ratio
m_target->DrawBitmap(bitmap.Get(), dest, 1.0f, D2D1_BITMAP_INTERPOLATION_MODE_LINEAR);

Fitting ("contain") scales the image to the largest size that fits inside the box with the same aspect ratio, leaving bars; filling ("cover") scales it so it covers the box, cropping the overflow. Image viewers use fit; thumbnails in a grid often use fill.

For pixel art, use NEAREST_NEIGHBOR interpolation; for photos, linear. Shrinking a large photo to a small thumbnail with plain linear filtering looks grainy, because each output pixel samples only a few input pixels. Make thumbnails with WIC's scaler instead (IWICBitmapScaler with WICBitmapInterpolationModeFant or HighQualityCubic), which averages all the input pixels; many cameras' JPEGs also contain a ready-made thumbnail (GetThumbnail).

Saving

Encoding is the reverse: create an encoder for a container format (GUID_ContainerFormatPng), initialise it on a stream, create a frame, set its size and pixel format, write the pixels and commit. Screenshots of a Direct2D drawing are made by drawing into a WIC bitmap render target (CreateWicBitmapRenderTarget) and encoding that.

Orientation

Phones store photos sideways and record the intended orientation in the EXIF metadata. Read it from the frame's metadata (/app1/ifd/{ushort=274} for JPEG) and rotate with IWICBitmapFlipRotator, or photos show up sideways.
