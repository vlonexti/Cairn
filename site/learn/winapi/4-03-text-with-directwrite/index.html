Text with DirectWrite

lesson 4.033 of 4 in milestone 45 min1 practice task

DirectWrite lays out and renders text with proper font fallback, ligatures, colour emoji and ClearType. This lesson creates text formats and layouts, draws them with Direct2D, measures them, and uses hit-testing to place a caret and select text with the mouse.

Why not just DrawText?

GDI's DrawTextW handles simple text, but modern text needs more: font fallback (a Latin font does not contain Chinese characters or emoji, so another font must be found for them), shaping (Arabic letters change form, "fi" can become one ligature), colour emoji, and subpixel positioning. DirectWrite does all of that and draws through Direct2D.

Formats and layouts

C++
#include <dwrite.h>
#pragma comment(lib, "dwrite.lib")

ComPtr<IDWriteFactory> dw;
DWriteCreateFactory(DWRITE_FACTORY_TYPE_SHARED, __uuidof(IDWriteFactory), reinterpret_cast<IUnknown**>(dw.GetAddressOf()));

ComPtr<IDWriteTextFormat> format;           // font, size, style: like a CSS class
dw->CreateTextFormat(L"Segoe UI", nullptr, DWRITE_FONT_WEIGHT_NORMAL, DWRITE_FONT_STYLE_NORMAL,
                     DWRITE_FONT_STRETCH_NORMAL, 14.0f /* DIPs */, L"en-us", &format);
format->SetWordWrapping(DWRITE_WORD_WRAPPING_WRAP);

A text format describes how text should look. A text layout is a particular string laid out in a particular box: line breaks done, every glyph positioned. Create the layout when the text or the width changes, then draw and query it as often as needed:

C++
ComPtr<IDWriteTextLayout> layout;
dw->CreateTextLayout(m_text.c_str(), UINT32(m_text.size()), format.Get(), width, height, &layout);
layout->SetFontWeight(DWRITE_FONT_WEIGHT_BOLD, DWRITE_TEXT_RANGE{ 0, 5 });   // formatting for a range
m_target->DrawTextLayout(D2D1::Point2F(10, 10), layout.Get(), m_textBrush.Get());

For one-off labels, m_target->DrawText(text, length, format, rect, brush) creates a temporary layout internally.

Measuring

C++
DWRITE_TEXT_METRICS m;
layout->GetMetrics(&m);         // m.width, m.height: the size actually used; m.lineCount

GetMetrics is how a control sizes itself to its text, or a label is centred. GetLineMetrics gives each line's length (in UTF-16 units) and height.

Hit-testing: from a point to text and back

An editor needs two conversions:

  • Where is the caret? From a text position to a point: HitTestTextPosition(index, isTrailing, &x, &y, &metrics).
  • Where did the user click? From a point to a text position: HitTestPoint(x, y, &isTrailing, &isInside, &metrics); metrics.textPosition plus 1 if isTrailing is the caret index.

"Trailing" means the click was on the right half of a character, so the caret goes after it. Text positions are UTF-16 indices, so a caret must never land between the two halves of a surrogate pair (lesson 1.02): DirectWrite's hit-testing respects clusters for you.

A selection is drawn by asking for the rectangles covering a range, one per line, with HitTestTextRange, and filling them before drawing the text. The practice computes exactly these: caret positions, hit-testing and selection rectangles, from the widths of the characters.

Font fallback and emoji

DirectWrite chooses fallback fonts automatically. For colour emoji, pass D2D1_DRAW_TEXT_OPTIONS_ENABLE_COLOR_FONT to DrawTextLayout (on a render target that supports it, such as an ID2D1DeviceContext). Text in right-to-left scripts needs SetReadingDirection; DirectWrite then handles mixed-direction lines.

Rendering quality

m_target->SetTextAntialiasMode(D2D1_TEXT_ANTIALIAS_MODE_CLEARTYPE) gives ClearType on opaque backgrounds; on transparent or animated surfaces use GRAYSCALE. Snap the text's origin to whole DIPs for the sharpest result.
