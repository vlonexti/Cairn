Common Controls

lesson 3.055 of 5 in milestone 35 min1 practice task

The list view, tree view, status bar, progress bar and tab control come from the Common Controls library. This lesson enables visual styles, creates these controls, handles WM_NOTIFY, and uses a virtual list view to show a hundred thousand rows instantly.

Enabling them, with visual styles

The common controls (comctl32.dll) add the controls Explorer uses. Version 6 draws them, and the standard controls, with the modern visual style. Ask for it in the manifest, conveniently with a linker directive, and initialise the library:

C++
#include <commctrl.h>
#pragma comment(lib, "comctl32.lib")
#pragma comment(linker, "\"/manifestdependency:type='win32' name='Microsoft.Windows.Common-Controls' \
version='6.0.0.0' processorArchitecture='*' publicKeyToken='6595b64144ccf1df' language='*'\"")

INITCOMMONCONTROLSEX icc{ sizeof(icc), ICC_LISTVIEW_CLASSES | ICC_TREEVIEW_CLASSES | ICC_BAR_CLASSES | ICC_TAB_CLASSES | ICC_PROGRESS_CLASS };
InitCommonControlsEx(&icc);

Without the manifest entry, buttons and check boxes look like Windows 95.

The controls

Class Control Typical use
WC_LISTVIEW List view: rows with columns, or icons Files, search results
WC_TREEVIEW Tree view Folders, outlines, settings categories
STATUSCLASSNAME Status bar Line and column, state, progress
PROGRESS_CLASS Progress bar Long operations
WC_TABCONTROL Tabs Pages of settings
TOOLTIPS_CLASS Tooltips Help on hover
TRACKBAR_CLASS, UPDOWN_CLASS Slider, spin buttons Numbers

A list view with columns

C++
HWND lv = CreateWindowExW(0, WC_LISTVIEW, L"", WS_CHILD | WS_VISIBLE | WS_TABSTOP | LVS_REPORT | LVS_SHOWSELALWAYS,
                          0, 0, 0, 0, hwnd, reinterpret_cast<HMENU>(IDC_FILES), instance, nullptr);
ListView_SetExtendedListViewStyle(lv, LVS_EX_FULLROWSELECT | LVS_EX_DOUBLEBUFFER);

LVCOLUMNW col{ LVCF_TEXT | LVCF_WIDTH };
col.pszText = const_cast<wchar_t*>(L"Name"); col.cx = scale(240); ListView_InsertColumn(lv, 0, &col);
col.pszText = const_cast<wchar_t*>(L"Size"); col.cx = scale(90);  ListView_InsertColumn(lv, 1, &col);

ListView_InsertColumn and friends are macros around SendMessageW with LVM_... messages, the same mechanism as lesson 2.05 with nicer names.

WM_NOTIFY

Common controls report events with WM_NOTIFY. lParam points to an NMHDR (the control's window, id and code), which is the first member of a bigger, code-specific structure:

C++
case WM_NOTIFY:
{
    const auto* hdr = reinterpret_cast<NMHDR*>(lParam);
    if (hdr->idFrom == IDC_FILES)
    {
        switch (hdr->code)
        {
        case NM_DBLCLK: openSelected(); return 0;
        case LVN_COLUMNCLICK: sortBy(reinterpret_cast<NMLISTVIEW*>(lParam)->iSubItem); return 0;
        case LVN_GETDISPINFOW: fillDisplayInfo(reinterpret_cast<NMLVDISPINFOW*>(lParam)); return 0;
        }
    }
    break;
}

Virtual list views

Adding 100 000 items one by one with ListView_InsertItem takes seconds and copies every string into the control. A virtual list view (LVS_OWNERDATA) stores nothing: you tell it how many rows there are, and it asks for the text of each row only when it needs to draw it:

C++
ListView_SetItemCountEx(lv, static_cast<int>(m_results.size()), LVSICF_NOSCROLL);

void fillDisplayInfo(NMLVDISPINFOW* info)
{
    const auto& row = m_results[info->item.iItem];
    if (info->item.mask & LVIF_TEXT)
    {
        const std::wstring text = info->item.iSubItem == 0 ? row.name : formatSize(row.size);
        wcsncpy_s(info->item.pszText, info->item.cchTextMax, text.c_str(), _TRUNCATE);
    }
}

Showing a million rows is now instant, and sorting means sorting your own vector and calling InvalidateRect. This is the list the file finder of milestone 6 uses. Formatting sizes the way Explorer does ("1.5 KB", "23.4 MB") is part of the practice.

The status bar

C++
m_status = CreateWindowExW(0, STATUSCLASSNAME, nullptr, WS_CHILD | WS_VISIBLE | SBARS_SIZEGRIP, 0, 0, 0, 0, hwnd, nullptr, instance, nullptr);
const int parts[] = { scale(200), scale(320), -1 };       // right edges; -1 = to the end
SendMessageW(m_status, SB_SETPARTS, 3, reinterpret_cast<LPARAM>(parts));
SendMessageW(m_status, SB_SETTEXTW, 0, reinterpret_cast<LPARAM>(L"Ln 12, Col 4"));
// in WM_SIZE: SendMessageW(m_status, WM_SIZE, 0, 0); it positions itself at the bottom
