Networking

6 milestones30 lessons30 practice tasks30 projects

How computers talk across networks, and how to write programs that do it: layers and packets, IP addresses and subnets, DNS, TCP and UDP, routing, the socket API, byte order, serving many connections, HTTP by hand, URLs, a tiny web server and what TLS does, capturing and decoding packets from Ethernet up, reliable messaging over UDP with sequence numbers and acknowledgements, and the techniques behind multiplayer games: snapshots, delta compression, interpolation, client-side prediction and lag compensation. It assumes the C++ course.
