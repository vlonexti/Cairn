Function Templates

lesson 4.022 of 7 in milestone 45 min3 practice tasks

A template is a pattern for a function with a placeholder type T. The compiler generates a real function for each type you use it with. Write it once and it works for int, double, std::string and more.

The problem: the same code for every type

Overloading lets these share a name, but you still write each body:

C++
int maxOf(int a, int b)          { return a > b ? a : b; }
double maxOf(double a, double b) { return a > b ? a : b; }
// ...and again for every other type

The bodies are identical. Only the type changes. A function template lets you write the body once and leave the type as a parameter.

C++
#include <iostream>
#include <string>

template <typename T>
T maxOf(T a, T b)
{
    return a > b ? a : b;
}

int main()
{
    std::cout << maxOf(3, 7) << '\n';              // T is int
    std::cout << maxOf(2.5, 1.5) << '\n';          // T is double
    std::cout << maxOf<char>('a', 'z') << '\n';    // T given explicitly
    return 0;
}

template <typename T> introduces T as a type parameter: a stand-in for a type that is filled in later.

Instantiation

A template is not a function. It is a recipe from which the compiler makes functions on demand.

flowchart TD
    T["template &lt;typename T&gt;<br/>T maxOf(T a, T b)"] -->|"maxOf(3, 7)"| I["int maxOf(int, int)"]
    T -->|"maxOf(2.5, 1.5)"| D["double maxOf(double, double)"]
    T -->|"maxOf(s1, s2)"| S["std::string maxOf(std::string, std::string)"]

Generating a concrete function from a template is called instantiation. It happens at compile time, once per distinct type, and the result is exactly as fast as a function written by hand.

Deducing T

Usually you do not say what T is. The compiler works it out from the arguments, which is called template argument deduction.

Call Result
maxOf(3, 7) Both are int, so T is int
maxOf(3, 7.5) Error: T cannot be both int and double
maxOf<double>(3, 7.5) You chose T; the 3 is converted to 3.0

Deduction does not apply conversions. Each argument must agree on T exactly.

More than one type parameter

When the arguments may legitimately have different types, give each its own parameter:

C++
template <typename T, typename U>
auto addMixed(T a, U b)
{
    return a + b;
}

addMixed(3, 7.5);    // T is int, U is double, the result is double

auto as the return type asks the compiler to work it out from the return statement.

The short form

Since C++20, auto in a parameter list makes a function a template without the template line:

C++
auto addMixed(auto a, auto b)
{
    return a + b;
}

Each auto parameter is its own independent type parameter.

The type has to support what the body does

A template compiles for a given type only if every operation in its body is valid for that type.

C++
struct Cat {};

maxOf(Cat{}, Cat{});    // error: Cat has no operator>

The error is reported at the point of instantiation, and for templates it can be long. C++20 concepts let a template state its requirements up front, which gives far clearer errors: 9.04 Concepts (C++20).

Templates live in headers

To instantiate a template, the compiler must see its full body at the place where it is used. A declaration alone is not enough.
