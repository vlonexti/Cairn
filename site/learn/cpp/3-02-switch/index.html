switch

lesson 3.022 of 8 in milestone 35 min3 practice tasks

switch compares one value against a list of fixed options and jumps to the matching case. End each case with break, or execution carries on into the next one.

One value, many options

A long if / else if chain that keeps testing the same variable against fixed values is clearer as a switch.

C++
#include <iostream>

int main()
{
    int choice{};
    std::cin >> choice;

    switch (choice)
    {
    case 1:
        std::cout << "Starting a new game\n";
        break;
    case 2:
        std::cout << "Loading\n";
        break;
    case 3:
        std::cout << "Goodbye\n";
        break;
    default:
        std::cout << "Not an option\n";
        break;
    }
    return 0;
}

Part Meaning
switch (value) The value to examine
case 1: Where to jump to when the value is 1
break; Leave the switch
default: Where to jump to when no case matches

Fall-through

A case is only a label: a place to jump to. It is not a block with an end. Without break, execution simply continues into whatever comes next.

Output
 switch (2)
 case 1:   print "one"
 case 2:   print "two"      jumps in here
 case 3:   print "three"    no break above, so this runs too
 default:  print "other"    and so does this

 Output: two three other

Forgetting a break is the classic switch bug.

Fall-through is useful in one situation: several values that share the same code.

C++
switch (letter)
{
case 'a':
case 'e':
case 'i':
case 'o':
case 'u':
    std::cout << "vowel\n";
    break;
default:
    std::cout << "consonant\n";
    break;
}
Marking it as deliberate

If a case does some work and you want it to continue into the next, write [[fallthrough]]; at that point. It tells the compiler and the reader that the missing break is intended.

return also leaves

Inside a function, a return ends the function, and therefore the switch. No break is needed after it.

C++
std::string_view dayName(int day)
{
    switch (day)
    {
    case 1: return "Monday";
    case 2: return "Tuesday";
    case 3: return "Wednesday";
    default: return "unknown";
    }
}

The rules

Rule Detail
The value must be integer-like int, char, bool or an enum. Not std::string, not double.
Each case must be a constant A literal, or a constexpr value. Not an ordinary variable.
No ranges There is no case 1 to 5. Use if for ranges.
Variables inside a case need braces case 1: { int x{ 5 }; ... break; }

switch or if?

Use switch when Use if when
Comparing one value against several fixed values Testing ranges, such as score >= 90
Menus, commands, single characters, enums Text, decimals or conditions that combine several variables

switch becomes much more valuable once you meet enums in 4.05 Enums, where the compiler can warn you if you forget one of the options.
