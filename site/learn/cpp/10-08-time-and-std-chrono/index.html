Time and std::chrono

lesson 10.088 of 9 in milestone 105 min2 practice tasks

<chrono> models time with three ideas: durations (how long), clocks (where time comes from) and time points (a moment on a clock). The types make unit mistakes impossible. C++20 adds calendar dates, time zones and formatting.

Three building blocks

flowchart LR
    C["Clock<br/>system_clock: wall time<br/>steady_clock: never adjusted"] -->|"now()"| TP["time_point<br/>a moment"]
    TP -->|"tp2 - tp1"| D["duration<br/>a length of time"]
    D -->|"tp + d"| TP
Concept Is Example
Duration A length of time, with its unit in the type 1500ms
Clock A source of the current time std::chrono::steady_clock
Time point A specific moment, measured on one clock The result of now()

The arithmetic is restricted to what makes sense: two time points subtract to a duration, a time point plus a duration is a time point, and two time points cannot be added.

Durations

C++
#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono_literals;

    const auto a{ 1500ms };
    const auto b{ 2s };
    const auto total{ a + b };    // 3500ms

    const auto whole{ std::chrono::duration_cast<std::chrono::seconds>(total) };    // 3s
    const std::chrono::duration<double> fractional{ total };                        // 3.5 seconds

    std::cout << total.count() << ' ' << whole.count() << ' ' << fractional.count() << '\n';
    return 0;
}

using namespace std::chrono_literals; enables the suffixes. This is one of the few using namespace directives worth writing, and it belongs inside a function.

Literal Type
5h, 5min, 5s hours, minutes, seconds
5ms, 5us, 5ns milliseconds, microseconds, nanoseconds
std::chrono::days{ 3 } days; also weeks, months, years (C++20)

The unit is part of the type, so the compiler does the conversions and refuses the lossy ones.

Expression Result
2s + 500ms 2500ms: converted to the finer unit automatically
std::chrono::seconds s{ 1500ms }; Error: converting to a coarser unit loses information
duration_cast<seconds>(1500ms) 1s: an explicit, truncating conversion
duration<double> d{ 1500ms }; 1.5 seconds: a floating-point duration loses nothing

A whole class of bugs, "was that parameter in seconds or milliseconds?", cannot be written.

Measuring elapsed time

C++
const auto start{ std::chrono::steady_clock::now() };
doWork();
const auto end{ std::chrono::steady_clock::now() };

const auto elapsed{ std::chrono::duration_cast<std::chrono::milliseconds>(end - start) };
std::println("Took {}", elapsed);    // Took 42ms
Clock Represents Can jump Use for
system_clock The calendar time of day Yes: clock sync, a user changing the time Timestamps, dates
steady_clock Time since an arbitrary start Never Measuring intervals

[!tip] Always measure with steady_clock A system_clock adjusted mid-measurement can produce a negative or wildly wrong duration.

Sleeping

C++
#include <thread>

std::this_thread::sleep_for(500ms);
std::this_thread::sleep_until(std::chrono::steady_clock::now() + 2s);

A fixed-rate loop

C++
using Clock = std::chrono::steady_clock;

constexpr auto tick{ 16ms };    // about 60 updates per second
auto next{ Clock::now() };
while (running)
{
    update();
    render();
    next += tick;
    std::this_thread::sleep_until(next);
}

Sleeping until the next scheduled moment keeps the rate steady. Sleeping for 16 ms after each iteration would let the time taken by update and render accumulate as drift.

Calendar and time zones

C++20 added calendar types that read almost like the dates themselves.

C++
#include <chrono>
#include <print>

int main()
{
    using namespace std::chrono;

    const year_month_day today{ floor<days>(system_clock::now()) };
    std::println("{}", today);    // for example 2026-11-12

    const auto birthday{ 2000y / March / 14 };
    std::println("{}", birthday.ok());    // true: it is a real date

    const auto endOfFebruary{ 2028y / February / last };
    std::println("{}", endOfFebruary);    // 2028/Feb/last: "the last day of February 2028"

    const sys_days first{ 2026y / January / 1 };
    const sys_days christmas{ 2026y / December / 25 };
    std::println("{} days", (christmas - first).count());    // 358

    const weekday day{ sys_days{ 2026y / November / 11 } };
    std::println("{}", day);    // Wed
    return 0;
}
Type Is
year_month_day A calendar date as three fields. It can represent invalid dates; ok() checks.
sys_days A time point with a resolution of one day. Use it for arithmetic.
weekday A day of the week
zoned_time A time point paired with a time zone
C++
const zoned_time tokyo{ "Asia/Tokyo", system_clock::now() };
std::println("{:%Y-%m-%d %H:%M}", tokyo);

The % codes are the chrono format specifications (10.07 Formatting with std::format and std::print): %Y year, %m month, %d day, %H hour, %M minute, %S second.
