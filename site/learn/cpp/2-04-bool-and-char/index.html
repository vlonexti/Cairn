bool and char

lesson 2.044 of 9 in milestone 25 min4 practice tasks

bool holds true or false, stored as 1 or 0. char holds one character, stored as a small number: 'A' is 65.

bool: yes or no

A bool holds the answer to a yes/no question. It is the type every decision in a program is built on.

C++
#include <iostream>

int main()
{
    bool isAlive{ true };
    bool hasKey{ false };

    std::cout << isAlive << '\n';                      // 1
    std::cout << std::boolalpha << isAlive << '\n';    // true
    std::cout << !hasKey << '\n';                      // true
    return 0;
}

Two things to notice:

  • A bool prints as 1 or 0 unless you send std::boolalpha to std::cout first.
  • ! means not. It flips true to false and back.

Where bools come from

You rarely type true or false yourself. Usually a bool is the result of a comparison.

Expression Value when age is 20
age >= 18 true
age == 21 false
age % 2 == 0 true

A function that returns bool reads like a question. Name it that way: isEven, hasKey, canJump.

C++
bool isEven(int n)
{
    return n % 2 == 0;
}

Numbers and bools convert to each other

Converting Rule
A number to bool 0 becomes false. Anything else becomes true.
A bool to a number true becomes 1, false becomes 0.

char: a number wearing a costume

A char stores a small number. A standard table, called ASCII, says which character each number stands for.

Output
 'A' = 65    'B' = 66    ...   'Z' = 90
 'a' = 97    'b' = 98    ...   'z' = 122
 '0' = 48    '1' = 49    ...   '9' = 57
 ' ' = 32    '\n' = 10
flowchart LR
    A["char c{ 'A' }"] -->|"stored as"| B["65"]
    B -->|"printed as a char"| D["A"]
    B -->|"printed as an int"| C["65"]
C++
#include <iostream>

int main()
{
    char c{ 'A' };
    std::cout << c << '\n';                      // A
    std::cout << static_cast<int>(c) << '\n';    // 65
    return 0;
}

static_cast<int>(c) means "treat this value as an int". It gets a full lesson next: 2.05 Type Conversion and static_cast.

Why the table's order is useful

The letters are in order and so are the digits. That makes some common jobs a single subtraction.

Goal Expression Why it works
Turn the character '7' into the number 7 '7' - '0' 55 − 48 = 7
Find a letter's position in the alphabet 'c' - 'a' 99 − 97 = 2
The next letter after c static_cast<char>(c + 1) one further along the table

[!warning] '7' is not 7 The character '7' is stored as 55. If you read a digit as a char and do arithmetic with it directly, the answers come out wrong by 48.

For everyday checks, #include <cctype> has ready-made functions:

Function Question or action
std::isdigit(c) Is it a digit?
std::isalpha(c) Is it a letter?
std::isspace(c) Is it a space, tab or new line?
std::toupper(c) / std::tolower(c) Convert the case

Single quotes and double quotes

Written Type What it is
'A' char exactly one character
"A" text a string that happens to be one character long

They are different types and cannot be swapped. char c{ "A" }; does not compile.

Reading one character

C++
char answer{};
std::cin >> answer;    // skips spaces and new lines, then reads one character
