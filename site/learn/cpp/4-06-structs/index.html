Structs

lesson 4.066 of 7 in milestone 45 min4 practice tasks

A struct bundles related variables into one new type, such as struct Player { std::string name; int hp; };. Reach the members with ., or -> through a pointer. Pass structs by const&.

Data that belongs together

A player has a name, hit points and a level. As loose variables, two players already need six names, and nothing ties hp1 to name1.

A struct defines a new type that holds them as one unit.

C++
struct Player
{
    std::string name{};
    int hp{ 100 };
    int level{ 1 };
};

The variables inside are members. The value after each one is its default member initializer: what the member holds unless you say otherwise. Give every member one, for the same reason every variable gets a starting value.

Creating and using one

C++
#include <iostream>
#include <string>

struct Player
{
    std::string name{};
    int hp{ 100 };
    int level{ 1 };
};

int main()
{
    Player a{};                               // all defaults
    Player b{ "Aria", 80, 5 };                // values in member order
    Player c{ .name = "Bo", .level = 3 };     // by name; hp keeps its default

    b.hp -= 10;
    std::cout << b.name << " has " << b.hp << " HP\n";
    std::cout << c.name << " is level " << c.level << " with " << c.hp << " HP\n";
    return 0;
}
Form Name Notes
Player a{}; Value initialization Every member takes its default
Player b{ "Aria", 80, 5 }; Aggregate initialization Values are matched to members in declaration order
Player c{ .name = "Bo", .level = 3 }; Designated initializers (C++20) Names must appear in declaration order; skipped members keep their default

The dot in b.hp is the member access operator.

Structs and functions

Structs follow the parameter rules from 4.03 References. They are rarely cheap to copy, so:

C++
void printPlayer(const Player& p)    // only reads: const reference
{
    std::cout << p.name << " (level " << p.level << ") HP: " << p.hp << '\n';
}

void heal(Player& p, int amount)     // modifies: reference
{
    p.hp += amount;
}

Player makePlayer(std::string_view name)    // creates: return by value
{
    return Player{ std::string{ name }, 100, 1 };
}

Returning several values

A struct is the clean answer to "a function can return only one thing".

C++
struct MinMax
{
    int min{};
    int max{};
};

MinMax findMinMax(int a, int b)
{
    return a < b ? MinMax{ a, b } : MinMax{ b, a };
}

auto [low, high]{ findMinMax(9, 4) };    // low is 4, high is 9

The last line uses structured bindings: it unpacks the members into separate named variables, in order.

Structs inside structs

A member can be another struct.

C++
struct Vec2
{
    double x{};
    double y{};
};

struct Entity
{
    std::string name{};
    Vec2 position{};
    Vec2 velocity{};
};

Entity ball{ "Ball", { 0.0, 0.0 }, { 1.5, -2.0 } };
ball.position.x += ball.velocity.x;

Building types out of smaller types like this is called composition. Most of a real program's design is done this way.

Through a pointer

C++
Player* pp{ &a };
pp->hp = 50;    // the same as (*pp).hp = 50

Size and padding

A struct can be larger than the sum of its members.

C++
struct S
{
    char c{};
    int i{};
};
// sizeof(S) is usually 8, not 5
Output
 [ c ][pad][pad][pad][ i   i   i   i ]

Processors read an int fastest when it starts at an address that is a multiple of 4, so the compiler inserts unused padding bytes to arrange that. Declaring members from largest to smallest usually minimises it. The full story is in 13.02 Memory Layout, Alignment, Unions and Bit Fields.

What comes next

A struct can also contain functions. By convention, struct is used for plain bundles of data with everything accessible, and class for types that protect their data behind functions. That is Milestone 6: 6.01 Classes and Objects.
