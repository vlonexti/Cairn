Fixed-Size Arrays — std::array

lesson 5.044 of 11 in milestone 55 min3 practice tasks

std::array<T, N> is an array whose length N is fixed at compile time. It cannot grow, needs no separate memory block, and can be constexpr. Use it when the count never changes.

When the size never changes

Seven days in a week. Nine squares on a noughts-and-crosses board. Fifty-two cards. When the number of elements is fixed for ever, std::array states that in the type.

 std::vector<int> v{ 1, 2, 3 };            std::array<int, 3> a{ 1, 2, 3 };

 [pointer|size|capacity] ──▶ [1|2|3]        [1|2|3]
   the vector itself       a separate         the elements are
                          block elsewhere     the array itself

A vector holds a pointer to elements stored elsewhere. A std::array is its elements, with nothing extra.

std::vector<T> std::array<T, N>
Size decided While running; can change At compile time; fixed
Where the elements live A separately allocated block Inside the array object
push_back Yes No
Can be constexpr Limited Yes
Header <vector> <array>

Using one

C++
#include <array>
#include <iostream>

int main()
{
    std::array<int, 5> primes{ 2, 3, 5, 7, 11 };
    std::array<double, 3> zeros{};    // 0.0 0.0 0.0

    primes[0] = 1;
    std::cout << primes.size() << ' ' << primes.at(4) << '\n';    // 5 11

    for (int p : primes)
    {
        std::cout << p << ' ';
    }
    std::cout << zeros.size() << '\n';
    return 0;
}

The second template argument is the length. Everything you know from vectors that does not change the size works the same way: [], at, size, front, back and range-based loops.

Lookup tables at compile time

A constexpr array is a table the compiler builds into the program.

C++
constexpr std::array<int, 12> daysInMonth{ 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };

static_assert(daysInMonth[1] == 28);    // verified during the build

Reading from it at run time is a single memory access, and using it in other constexpr code costs nothing at all.

Indexing with an enum

Combine the count idiom from 4.05 Enums with an array to get a table with named slots.

C++
enum class Stat { strength, dexterity, intellect, count };

std::array<int, static_cast<std::size_t>(Stat::count)> stats{ 10, 14, 8 };
stats[static_cast<std::size_t>(Stat::dexterity)] += 2;

The casts are the price of enum class not converting silently. A small helper function that does the cast tidies it up.

Passing arrays to functions

The length is part of the type. std::array<int, 3> and std::array<int, 4> are as different as int and double.

C++
void print(const std::array<int, 5>& values);    // accepts length 5 only

To accept any length, make the length a template parameter:

C++
template <typename T, std::size_t N>
void printAny(const std::array<T, N>& values)
{
    for (const auto& x : values)
    {
        std::cout << x << ' ';
    }
    std::cout << '\n';
}

N here is a non-type template parameter: a value, not a type, that is fixed at compile time. They get a full treatment in 9.02 Non-Type Parameters and Template Specialization.

Arrays of structs

C++
struct Planet
{
    std::string_view name{};
    double gravity{};
};

constexpr std::array<Planet, 3> planets{ {
    { "Mercury", 3.7 },
    { "Earth", 9.8 },
    { "Mars", 3.7 },
} };

Note the double braces. The outer pair is for the std::array, and the inner pair is for the plain array it wraps. With simple element types the compiler lets you omit one pair; with structs you need both.
