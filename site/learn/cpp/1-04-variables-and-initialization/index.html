Variables and Initialization

lesson 1.044 of 10 in milestone 15 min4 practice tasks

A variable is a named box in memory that holds one value of one type. Always give it a starting value: int age{ 25 };

A variable is a labelled box

Programs need to remember things: a score, a name, a price. A variable is a piece of the computer's memory with a name on it, so you can put a value in and look at it later.

   int age{ 25 };           double price{ 9.99 };       char grade{ 'A' };

  ┌──────────────┐         ┌──────────────┐           ┌──────────────┐
  │      25      │         │     9.99     │           │     'A'      │
  └──────────────┘         └──────────────┘           └──────────────┘
       age                      price                      grade
     (an int)                 (a double)                  (a char)

Creating one takes three parts:

C++
int age{ 25 };
Part Here Meaning
Type int What kind of value the box can hold
Name age What you call it in the rest of the program
Starting value { 25 } What is in the box to begin with

Five types to start with

Type Holds Examples
int whole numbers 42, -7, 0
double numbers with a decimal point 3.14, -0.5
char one single character, in single quotes 'x', '7'
bool a yes/no answer true, false
std::string text, in double quotes (needs #include <string>) "Hello"

The type is fixed for the life of the variable. An int box can never hold text.

Always give a starting value

C++
int a{ 5 };     // a holds 5
int b{};        // empty braces: b holds 0
int c;          // DANGER: c holds whatever happened to be in that memory
Never leave a variable uninitialized

int c; reserves a box but puts nothing in it. The box contains leftover junk from whatever used that memory before. Your program might print 0, or 32767, or behave differently every time you run it. Always write the braces.

You will see two other ways to give a starting value in other people's code. They work, but braces are safer:

C++
int x = 4.7;    // builds, and quietly throws away the .7  (x is 4)
int y{ 4.7 };   // refuses to build: "narrowing conversion". The mistake is caught.

Giving a variable its first value is called initialization.

Changing the value later

C++
#include <iostream>

int main()
{
    int score{ 10 };       // create the box, holding 10
    score = 25;            // replace the contents with 25
    score = score + 5;     // read 25, add 5, store 30
    std::cout << score << '\n';
    return 0;
}
flowchart LR
    A["score: 10"] -->|"score = 25"| B["score: 25"] -->|"score = score + 5"| C["score: 30"]

Putting a new value into an existing variable is called assignment. The old value is gone.

[!note] = does not mean "equals" In C++, = means "work out the right-hand side, then store it in the variable on the left". That is why score = score + 5 makes sense: read the old score, add 5, store the result back.

Choosing names

Allowed Not allowed
playerHealth, max_speed, count2 2count (starts with a digit)
letters, digits and _ my-var, my var (hyphen, space)
words C++ already uses: int, return, class

A good name says what is in the box. secondsElapsed tells the reader something; s does not. This course uses camelCase: lower-case first word, a capital at the start of each later word.
