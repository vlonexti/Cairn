Anatomy of a Program

lesson 1.033 of 10 in milestone 15 min4 practice tasks

A program is a list of statements inside a function called main. They run from top to bottom. Each statement ends with ;. Comments are notes for humans.

Hello World, line by line

C++
#include <iostream>          // 1. bring in the tools for printing

int main()                   // 2. the program starts here
{                            // 3. main's instructions begin
    std::cout << "Hi!\n";    // 4. one instruction: print Hi!
    return 0;                // 5. finish, and report "all went well"
}                            // 6. main's instructions end
Piece What it means
#include <iostream> "I want to use the input/output tools." Without it, std::cout does not exist.
int main() The starting point. Every program has exactly one main.
{ and } Braces mark where a group of instructions begins and ends.
std::cout << "Hi!\n"; Send the text Hi! to the screen.
std:: "From the standard library", the toolbox that comes with C++.
; The end of an instruction, like a full stop ends a sentence.
return 0; End main. 0 tells the operating system that nothing went wrong.

Two words for what you just read:

  • A statement is one complete instruction. It ends with ;.
  • A function is a named group of statements. main is the one that runs first.

Statements run top to bottom

C++
#include <iostream>

int main()
{
    std::cout << "One\n";
    std::cout << "Two\n";
    std::cout << "Three\n";
    return 0;
}
Output
One
Two
Three
flowchart LR
    S["Start of main"] --> A["print One"] --> B["print Two"] --> C["print Three"] --> E["return 0<br/>program ends"]

The computer does one statement, then the next, and never skips ahead. When a program does something unexpected, walking through it one line at a time, in order, is how you find out why.

Comments

A comment is a note for whoever reads the code. The compiler ignores it completely.

C++
// Everything after two slashes, to the end of the line, is a comment.

/* A comment between these markers
   can run over several lines. */
Say why, not what

Weak: lives = lives + 1; // add one to lives. The code already says that. Useful: lives = lives + 1; // bonus life every 10,000 points. That is something the code cannot tell you.

Putting // in front of a line switches it off without deleting it. This is called commenting out, and it is handy when you are hunting for a problem.

Spacing is for people

The compiler does not care about extra spaces or blank lines. To the compiler, these are identical:

C++
std::cout<<"Hi";
std::cout     <<     "Hi"     ;

People care a great deal. Indent the statements inside braces by four spaces, as every example here does, and your code will show its own structure.

Four mistakes everybody makes

Mistake What the compiler says
Forgetting a ; expected ';' (often reported on the next line)
Writing Main or MAIN No starting point found. C++ is case-sensitive: capitals matter.
Leaving out #include <iostream> 'cout' is not a member of 'std'
A { without its } An error at the very end of the file
