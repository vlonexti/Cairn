Variadic Templates and Fold Expressions

lesson 9.033 of 6 in milestone 95 min3 practice tasks

A variadic template accepts any number of arguments of any types, written template <typename... Args>. The arguments form a parameter pack, which you expand with args.... Fold expressions apply an operator across a whole pack in one expression.

Parameter packs

C++
#include <iostream>

template <typename... Args>
void count(const Args&... args)
{
    std::cout << sizeof...(args) << " arguments:";
    ((std::cout << ' ' << args), ...);    // explained below
    std::cout << '\n';
}

int main()
{
    count();                 // 0 arguments:
    count(1, "hi", 3.5);     // 3 arguments: 1 hi 3.5
    return 0;
}
Syntax Name Holds
typename... Args A template parameter pack Zero or more types
const Args&... args A function parameter pack Zero or more values, one of each type
sizeof...(args) The number of elements, as a compile-time constant
args... A pack expansion The elements, separated by commas

For count(1, "hi", 3.5), Args is int, const char*, double.

A pack is not a container. You cannot index it or loop over it at run time. It can only be expanded, and the expansion happens entirely during compilation. This is the type-safe replacement for the C-style ... in 5.10 Function Pointers, Callbacks and Command-Line Arguments.

Fold expressions

A fold expression combines every element of a pack with a binary operator.

C++
#include <iostream>

template <typename... Ts>
auto sum(Ts... xs)
{
    return (xs + ...);
}

template <typename... Ts>
void printAll(const Ts&... xs)
{
    ((std::cout << xs << ' '), ...);
    std::cout << '\n';
}

int main()
{
    std::cout << sum(1, 2, 3, 4) << '\n';    // 10
    printAll(1, "two", 3.0, 'x');            // 1 two 3 x
    return 0;
}

The parentheses around a fold are required.

Form Name Expansion for a pack p1, p2, p3
(pack op ...) Unary right fold p1 op (p2 op p3)
(... op pack) Unary left fold (p1 op p2) op p3
(pack op ... op init) Binary right fold p1 op (p2 op (p3 op init))
(init op ... op pack) Binary left fold ((init op p1) op p2) op p3

Left or right matters for operators that are not associative. With the pack 10, 3, 2:

Output
 (... - xs)    is    (10 - 3) - 2    =  5
 (xs - ...)    is    10 - (3 - 2)    =  9
Empty packs

A unary fold over an empty pack is an error for most operators. (Only &&, || and the comma operator have defined results: true, false and nothing.) Use a binary fold with an initial value when the pack may be empty: (xs + ... + 0).

The comma fold

printAll folds over the comma operator: ((std::cout << xs << ' '), ...). The pattern inside the inner parentheses is repeated for each element, in order. This is the general way to "do something for every argument".

Useful folds

C++
template <typename... Ts>
bool allTrue(Ts... values) { return (values && ...); }

template <typename... Ts>
bool anyTrue(Ts... values) { return (values || ...); }

template <typename T, typename... Ts>
bool isOneOf(const T& value, const Ts&... options)
{
    return ((value == options) || ...);
}

isOneOf(command, "quit", "exit", "q");

In isOneOf, the pattern (value == options) is expanded once per option, and || short-circuits as usual.

The older technique: recursion

Before C++17, a pack was processed by peeling off one argument at a time.

C++
void print()
{
    std::cout << '\n';
}

template <typename T, typename... Rest>
void print(const T& first, const Rest&... rest)
{
    std::cout << first << ' ';
    print(rest...);
}
flowchart LR
    A["print(1, 'a', 2.5)"] --> B["prints 1<br/>calls print('a', 2.5)"] --> C["prints a<br/>calls print(2.5)"] --> D["prints 2.5<br/>calls print()"] --> E["new line"]

Each step instantiates a new function with one fewer parameter, until the non-template overload with no parameters ends the chain. It is recursion in form only: every "call" is to a different function, and they are usually all inlined.

if constexpr removes the need for a separate base case:

C++
template <typename T, typename... Rest>
void print2(const T& first, const Rest&... rest)
{
    std::cout << first << ' ';
    if constexpr (sizeof...(rest) > 0)
    {
        print2(rest...);
    }
}

if constexpr is evaluated during compilation, and the branch not taken is discarded: it is not instantiated at all. Without that, print2() with no arguments would have to exist. Prefer a fold where one fits; use recursion when each step depends on the previous one.

Forwarding a pack

A wrapper that passes its arguments straight on to another function, as std::make_unique does, expands a pack through std::forward:

C++
template <typename T, typename... Args>
std::unique_ptr<T> makeIt(Args&&... args)
{
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}

The expansion std::forward<Args>(args)... applies the pattern to each element in step, pairing each type with its value. What Args&& and std::forward achieve is the subject of 11.01 Value Categories and Perfect Forwarding.

Variadic class templates

Classes can be variadic too. std::tuple<int, std::string, double> and std::variant<int, std::string> are the two you will use most: 10.04 std::optional, std::variant, std::any and std::tuple.
