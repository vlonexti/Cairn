Operators and Expressions Basics

lesson 1.066 of 10 in milestone 15 min4 practice tasks

An expression is anything that works out to a value, such as 2 + 3 or price * count. Operators are the symbols that do the work. One surprise: with whole numbers, 7 / 2 is 3.

Doing arithmetic

The symbols +, -, *, / and % are called operators. Something that works out to a value, like 7 + 2, is called an expression.

Operator Meaning Example Result
+ add 7 + 2 9
- subtract 7 - 2 5
* multiply 7 * 2 14
/ divide 7 / 2 3 (see below)
% remainder 7 % 2 1

You can use an expression anywhere a value is expected:

C++
#include <iostream>

int main()
{
    int price{ 4 };
    int count{ 3 };
    int total{ price * count };          // store the result
    std::cout << total << '\n';          // 12
    std::cout << total + 10 << '\n';     // 22, worked out and printed directly
    return 0;
}

Dividing whole numbers throws away the decimals

This is the one that catches everybody.

Output
 7 / 2   is 3.5 in maths   but C++ gives   3
 9 / 10  is 0.9 in maths   but C++ gives   0

When both numbers are whole numbers (int), the answer is a whole number too. The part after the decimal point is cut off. It is not rounded.

If at least one side is a decimal number, you get a decimal answer:

Expression Result Why
7 / 2 3 both whole
7.0 / 2 3.5 one side is a decimal
7 / 2.0 3.5 one side is a decimal
An average that comes out wrong

int total{ 7 }; int count{ 2 }; then total / count is 3, not 3.5. To get the real answer from two int variables you convert one first. That is covered in 2.05 Type Conversion and static_cast.

The remainder operator %

% gives what is left over after dividing. Share 7 biscuits between 2 people:

Output
 7 biscuits, 2 people

 each person gets   7 / 2  =  3
 left on the plate  7 % 2  =  1

It looks minor, and it turns up everywhere:

Question Expression
Is n even? n % 2 is 0
What is the last digit of 1234? 1234 % 10 is 4
What is 1234 without its last digit? 1234 / 10 is 123
90 seconds is how many minutes and seconds? 90 / 60 is 1, 90 % 60 is 30

Which part is worked out first?

The same order as in school maths: *, / and % first, then + and -. Operators of equal rank go left to right.

flowchart LR
    E["2 + 3 * 4"] --> M["3 * 4 comes first<br/>2 + 12"] --> A["14"]

Brackets change the order: (2 + 3) * 4 is 20.

If you have to stop and think, add brackets

Brackets cost nothing, and the next reader (often you, next week) will not have to stop and think either.

Shortcuts for changing a variable

Changing a variable based on its own value is so common that there are shorter ways to write it.

Long form Short form Meaning
x = x + 5; x += 5; add 5 to x
x = x - 5; x -= 5; take 5 from x
x = x * 5; x *= 5; multiply x by 5
x = x / 5; x /= 5; divide x by 5
x = x + 1; ++x; add 1 to x
x = x - 1; --x; take 1 from x

You will also see x++. For now it does the same job as ++x. The small difference is explained in 2.08 Operators Deep Dive.
