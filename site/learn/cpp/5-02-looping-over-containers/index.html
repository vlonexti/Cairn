Looping Over Containers

lesson 5.022 of 11 in milestone 55 min4 practice tasks

Use the range-based for loop, for (const auto& x : v), whenever you need each element. Use an index loop when you need the position too. Remember that v.size() is unsigned.

The range-based for loop

When you want every element in turn, say exactly that:

C++
#include <iostream>
#include <string>
#include <vector>

int main()
{
    std::vector<std::string> names{ "Ann", "Bo", "Cy" };

    for (const auto& name : names)
    {
        std::cout << name << '\n';
    }
    return 0;
}
flowchart LR
    V["names: Ann, Bo, Cy"] --> L1["name is Ann"] --> L2["name is Bo"] --> L3["name is Cy"] --> E["done"]

Read it as "for each name in names". There is no index to get wrong and no way to run past the end.

Choosing the loop variable

The rules for auto from 4.07 auto, Type Deduction and Type Aliases apply directly.

Loop variable Copies each element? Can change the container? Use for
auto x Yes No, only the copy Small types such as int
const auto& x No No The default for reading
auto& x No Yes Modifying elements in place
C++
std::vector<int> nums{ 1, 2, 3 };
for (auto& n : nums)
{
    n *= 10;
}
// nums is now 10 20 30

Using plain auto here would multiply copies and leave the vector unchanged. That is a very common bug.

Index loops

Use one when the position matters: to print it, to compare neighbours, or to walk two containers together.

C++
for (std::size_t i{ 0 }; i < names.size(); ++i)
{
    std::cout << i << ": " << names[i] << '\n';
}

The unsigned trap

size() returns std::size_t, an unsigned type (2.02 Integers). Two problems follow.

Code Problem
for (int i{ 0 }; i < v.size(); ++i) Compares signed with unsigned: a warning, and wrong if i were ever negative
for (std::size_t i{ v.size() - 1 }; i >= 0; --i) Never ends: an unsigned value is always >= 0
v.size() - 1 on an empty vector Wraps round to a huge number

Two dependable fixes:

C++
// 1. Count forwards with std::size_t.
for (std::size_t i{ 0 }; i < v.size(); ++i) { /* ... */ }

// 2. For signed arithmetic, ask for a signed size.
for (auto i{ std::ssize(v) - 1 }; i >= 0; --i) { /* ... */ }

std::ssize(v) (C++20) is the size as a signed number, so a backwards loop terminates normally.

The standard loop shapes

Most loops over a container are one of five shapes. All use the accumulator idea from 3.03 Loops — while, do-while, for.

Goal Before the loop Inside the loop
Sum int sum{ 0 }; sum += x;
Count matches int count{ 0 }; if (matches(x)) { ++count; }
Maximum int best{ v[0] }; if (x > best) { best = x; }
Find int found{ -1 }; on a match, record the index and break
Filter std::vector<int> kept{}; if (matches(x)) { kept.push_back(x); }
C++
#include <iostream>
#include <vector>

int main()
{
    const std::vector<int> v{ 12, 75, 40, 91, 58 };

    int best{ v[0] };    // requires a non-empty vector
    std::vector<int> big{};
    for (int x : v)
    {
        if (x > best)
        {
            best = x;
        }
        if (x > 50)
        {
            big.push_back(x);
        }
    }
    std::cout << "largest " << best << ", " << big.size() << " values above 50\n";
    return 0;
}

The standard library provides ready-made versions of all five: 5.06 Iterators and STL Algorithms. Write them by hand first so you know what those functions do.

Do not add or remove elements during a range-based loop

push_back may move the whole vector to a new block of memory. The loop is still walking the old block, so it reads memory that no longer belongs to the vector. Collect the changes in a second vector and apply them afterwards.
