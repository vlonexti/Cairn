Operators Deep Dive

lesson 2.088 of 9 in milestone 25 min4 practice tasks

Comparisons (==, < ...) produce a bool. Logical operators (&&, ||, !) combine bools and stop early when the answer is settled. ++x and x++ differ in the value they give back. ?: chooses between two values.

Comparison operators

Each of these compares two values and produces a bool.

Operator Meaning 5 ? 3
== equal to false
!= not equal to true
< less than false
> greater than true
<= less than or equal to false
>= greater than or equal to true

[!danger] = stores, == compares x = 5 puts 5 into x. x == 5 asks whether x is 5. Writing one where you meant the other is among the most common mistakes in C++, and it compiles. The compiler warns about it, which is one more reason to read warnings.

Logical operators

These combine yes/no answers.

Operator Name True when
a && b AND both are true
a || b OR at least one is true
!a NOT a is false
a b a && b a || b !a
true true true true false
true false false true false
false true false true true
false false false false true
C++
bool canVote{ age >= 18 && isCitizen };
bool isWeekend{ day == 6 || day == 7 };
bool isTeen{ age >= 13 && age <= 19 };
Ranges need two comparisons

Maths lets you write 13 ≤ age ≤ 19. In C++, 13 <= age <= 19 compiles and is always true. It works out 13 <= age first, giving true or false, which is 1 or 0, and then compares that with 19.

Short-circuit evaluation

&& and || look at the left side first. If that already settles the answer, the right side is never run.

flowchart LR
    A["false && anything"] -->|"must be false"| B["right side skipped"]
    C["true || anything"] -->|"must be true"| D["right side skipped"]

This is a tool you can rely on, not just a speed-up:

C++
if (count != 0 && total / count > 10)

When count is 0 the division never happens, so there is no divide-by-zero.

Prefix and postfix ++

Both add one to the variable. They differ in the value the expression gives back.

Output
 int x{ 5 };

 int a{ ++x };    prefix:   add first, then give the new value    a is 6, x is 6
 int b{ x++ };    postfix:  give the old value, then add          b is 6, x is 7
flowchart LR
    P["++x"] --> P1["add 1 to x"] --> P2["give back the new x"]
    Q["x++"] --> Q1["remember the old x"] --> Q2["add 1 to x"] --> Q3["give back the old value"]

On a line of its own, ++x; and x++; do the same thing.

Two habits

Use prefix ++x unless you specifically need the old value. And never change a variable with ++ and also use it elsewhere in the same expression: x++ + x++ has no dependable answer.

The conditional operator ?:

It chooses between two values according to a condition.

C++
condition ? value if true : value if false
C++
int larger{ (a > b) ? a : b };
std::cout << (score >= 50 ? "Pass" : "Fail") << '\n';

Use it to pick a value. To choose between actions, use if: 3.01 if and else.

Precedence: what binds tightest

Higher rows are worked out first.

Level Operators
1 x++ x-- and function calls
2 ++x --x ! -x (negative) static_cast
3 * / %
4 + -
5 << >>
6 < <= > >=
7 == !=
8 &&
9 ||
10 ?: = += and the other assignments

You do not have to memorise this. Remember three facts: arithmetic comes before comparison, comparison before &&, and && before ||. For anything else, add brackets.

Printing a comparison needs brackets

std::cout << a < b; fails, because << is above < in the table. Write std::cout << (a < b);.
