Function Pointers, Callbacks and Command-Line Arguments

lesson 5.1010 of 11 in milestone 55 min3 practice tasks

Functions live in memory too, so a pointer can refer to one. A function pointer lets you pass "which function to call" as an argument: a callback. Modern C++ mostly uses lambdas, but C interfaces use function pointers. Also here: reading a program's command-line arguments.

A pointer to a function

A compiled function is a block of machine code at some address. A function pointer holds that address.

C++
#include <iostream>

int add(int a, int b) { return a + b; }
int multiply(int a, int b) { return a * b; }

int main()
{
    int (*op)(int, int){ &add };
    std::cout << op(3, 4) << '\n';    // 7
    op = &multiply;
    std::cout << op(3, 4) << '\n';    // 12
    return 0;
}

The same line op(3, 4) does different things depending on where op points.

Reading the declaration

 int  (*op)  (int, int)
  │     │        └── called with two ints
  │     └── op is a pointer
  └── to a function returning int

The parentheses around *op are required. Without them, int *op(int, int) declares a function that returns an int*.

An alias makes it bearable:

C++
using BinaryOp = int (*)(int, int);

BinaryOp op{ add };

A function's name converts to a pointer automatically, so the & is optional.

Callbacks

A callback is a function you hand to other code for it to call when needed. It lets a general routine leave one decision to its caller.

C++
bool ascending(int a, int b) { return a > b; }     // "is this pair out of order?"
bool descending(int a, int b) { return a < b; }

void selectionSort(std::vector<int>& v, bool (*outOfOrder)(int, int))
{
    for (std::size_t i{ 0 }; i < v.size(); ++i)
    {
        for (std::size_t j{ i + 1 }; j < v.size(); ++j)
        {
            if (outOfOrder(v[i], v[j]))
            {
                std::swap(v[i], v[j]);
            }
        }
    }
}
C++
selectionSort(numbers, ascending);
selectionSort(numbers, descending);
selectionSort(numbers, [](int a, int b) { return a % 2 > b % 2; });
flowchart LR
    C["selectionSort(v, descending)"] --> S["the sorting loop<br/>knows nothing about order"]
    S -->|"asks: outOfOrder(a, b)?"| CB["descending"]
    CB -->|"true or false"| S

One sort, any ordering. This is exactly how the comparator of std::sort works.

The last call passes a lambda. A lambda that captures nothing converts to a function pointer. One that captures cannot, because it carries data and a bare address has nowhere to keep it.

Three ways to accept a callable

Function pointer std::function Template or auto parameter
Accepts ordinary functions Yes Yes Yes
Accepts capturing lambdas No Yes Yes
Cost per call Very small Small None: the call can be inlined
Typical use C interfaces Storing callbacks Algorithms

In your own code, prefer a template or std::function (5.07 Lambdas). Use function pointers when a C library requires them.

Command-line arguments

Programs started from a terminal can be given arguments:

Terminal
app hello 42 --verbose

main receives them through two parameters.

C++
#include <iostream>

int main(int argc, char* argv[])
{
    std::cout << "Program: " << argv[0] << '\n';
    for (int i{ 1 }; i < argc; ++i)
    {
        std::cout << "Argument " << i << ": " << argv[i] << '\n';
    }
    return 0;
}
Parameter Meaning
argc "Argument count": how many there are, including the program's own name
argv "Argument vector": an array of C-strings (5.05 C-Style Arrays and C-Strings)
Output
 argc is 4
 argv[0]  "app"
 argv[1]  "hello"
 argv[2]  "42"            text, not a number
 argv[3]  "--verbose"

Every argument arrives as text. Convert with std::stoi(argv[2]) or std::stod, and always check argc before reading an index, since the user may have supplied fewer arguments than you expect.

C-style variadic functions

You may meet functions declared with ..., which accept any number of arguments of any type:

C++
double average(int count, ...);

The compiler checks neither the types nor the count, so mistakes become crashes. printf works this way. Modern C++ replaces it with std::initializer_list, std::span or variadic templates: 9.03 Variadic Templates and Fold Expressions.
