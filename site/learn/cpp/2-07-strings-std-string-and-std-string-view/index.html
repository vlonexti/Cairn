Strings — std::string and std::string_view

lesson 2.077 of 9 in milestone 25 min4 practice tasks

std::string owns its text and can change it. std::string_view is a cheap, read-only window onto text that lives somewhere else. Functions that only read text should take a std::string_view.

A string is a row of characters

 std::string name{ "Hello" };

 index:   0    1    2    3    4
        ┌────┬────┬────┬────┬────┐
        │ H  │ e  │ l  │ l  │ o  │      name.length() is 5
        └────┴────┴────┴────┴────┘
        name[0] is 'H'      name[4] is 'o'

Each character has a position, called its index. Counting starts at 0, so the last index is always the length minus one.

Stay inside the string

name[5] on a five-character string reads past the end. That is undefined behaviour. The compiler will not stop you.

Calling a string's own functions

A std::string comes with functions attached. You call them with a dot after the variable: name.length(). Functions attached to a value like this are called member functions.

C++
#include <iostream>
#include <string>

int main()
{
    std::string first{ "Ada" };
    std::string last{ "Lovelace" };
    std::string full{ first + ' ' + last };

    std::cout << full << " has " << full.length() << " characters\n";      // 12
    std::cout << "Initials: " << first[0] << last[0] << '\n';              // AL
    std::cout << "Surname starts at index " << full.find(last) << '\n';    // 4
    return 0;
}

The toolbox

Assume std::string s{ "Hi" }; for each row.

To Write Result
Get the length s.length() 2
Get one character s[0] 'H'
Join two strings s + " there" "Hi there"
Add to the end s += "!"; s is now "Hi!"
Compare s == "Hi" true
Check for empty s.empty() false
Find text s.find("i") 1
Take a piece s.substr(0, 1) "H" (start index, how many)
Insert s.insert(0, ">> ") ">> Hi"
Remove s.erase(0, 1) "i" (start index, how many)
Replace a piece s.replace(0, 1, "Oh") "Ohi"

Converting between text and numbers:

To Write Result
Number to text std::to_string(42) "42"
Text to int std::stoi("42") 42
Text to double std::stod("3.5") 3.5

[!note] When find finds nothing It returns a special value, std::string::npos. Always compare the result against it before using it as an index:

C++
if (s.find("x") == std::string::npos) { /* not there */ }

[!warning] "Hello" + " World" does not compile Text in quotes is a string literal, which is a more primitive thing than a std::string. The + only joins when at least one side is a real std::string: write std::string{ "Hello" } + " World".

std::string_view: look, do not copy

Passing a std::string to a function copies the whole text, as with any other argument. For long text that is wasted work when the function only wants to read it.

A std::string_view holds no text of its own. It records where some existing text is and how long it is.

flowchart LR
    S["std::string<br/>owns: Hello, World"] --- V1["string_view<br/>sees: Hello, World"]
    S --- V2["string_view<br/>sees: World"]
C++
#include <iostream>
#include <string>
#include <string_view>

void greet(std::string_view name)
{
    std::cout << "Hello, " << name << '\n';
}

int main()
{
    greet("Ada");                 // works with a literal
    std::string s{ "Grace" };
    greet(s);                     // works with a std::string, without copying it
    return 0;
}
std::string std::string_view
Owns the text Yes No
Can change the text Yes No
Cost of passing it to a function Copies every character Tiny: a location and a length
Use it for Text you store or modify Parameters that only read
A view must not outlive what it looks at
C++
std::string_view broken()
{
    std::string temp{ "oops" };
    return temp;    // temp is destroyed here; the view now points at nothing
}

A view is only valid while the text it refers to still exists. This idea, something referring to data that has gone, returns in Milestone 4 under the name dangling.
