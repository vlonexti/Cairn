Formatting with std::format and std::print

lesson 10.077 of 9 in milestone 105 min3 practice tasks

std::format("Hello, {}!", name) builds a string from {} placeholders: type-safe, fast and readable. std::print and std::println (C++23) write directly. Format specifications such as {:>8.2f} control width, alignment and precision.

The basics

C++
#include <format>
#include <print>
#include <string>

int main()
{
    const std::string name{ "Ann" };
    const int score{ 90 };

    const std::string text{ std::format("{} is {} years old", name, 31) };
    std::println("{}", text);
    std::println("{} scored {} points", name, score);
    std::print("no new line here\n");
    std::println("{1} before {0}", "world", "hello");    // hello before world
    return 0;
}
Function Header Does
std::format(fmt, args...) <format> Returns a std::string
std::print(fmt, args...) <print> Writes to standard output
std::println(fmt, args...) <print> The same, followed by a new line

Each {} is a replacement field, filled by the next argument. A number inside, as in {1}, selects an argument by position.

Compare with the stream version:

C++
std::cout << "Pos: (" << std::fixed << std::setprecision(2) << x << ", " << y << ")\n";
std::println("Pos: ({:.2f}, {:.2f})", x, y);

The format string shows the shape of the output at a glance, and no sticky state is left behind (10.05 Streams In Depth — istream, ostream, stringstream).

Format specifications

After a colon comes a specification, with its parts in a fixed order.

 { index : fill align sign # 0 width .precision type }
             │     │    │  │ │   │       │        └ d x X o b e f g s ...
             │     │    │  │ │   │       └ digits after the point, or maximum characters
             │     │    │  │ │   └ minimum width
             │     │    │  │ └ pad with zeros
             │     │    │  └ alternate form: 0x, 0b
             │     │    └ + or - or a space
             │     └ <  left     >  right     ^  centre
             └ any padding character
Specification Value Result
{:5} 42 42
{:<5} 42 42
{:^7} "hi" hi
{:*>6} 7 *****7
{:05} 42 00042
{:+} 5 +5
{:.2f} 3.14159 3.14
{:10.3f} 2.5 2.500
{:e} 1234.5 1.234500e+03
{:x}, {:#x}, {:X} 255 ff, 0xff, FF
{:b}, {:#010b} 5 101, 0b00000101
{:.3} "abcdef" abc

Numbers are right-aligned by default and text is left-aligned.

A width or precision can itself come from an argument, using a nested field:

C++
std::println("{:>{}}", "right", 12);    // the width is the second argument

A table

C++
std::println("{:<10}{:>8}{:>10}", "Item", "Qty", "Price");
for (const auto& item : cart)
{
    std::println("{:<10}{:>8}{:>10.2f}", item.name, item.quantity, item.price);
}
Output
Item           Qty     Price
Apple            3      1.50
Bread            1      2.25

Formatting your own types

A type becomes formattable by specializing std::formatter for it (9.02 Non-Type Parameters and Template Specialization).

C++
#include <format>
#include <print>

struct Vec2
{
    double x{};
    double y{};
};

template <>
struct std::formatter<Vec2> : std::formatter<double>
{
    auto format(const Vec2& v, std::format_context& context) const
    {
        std::format_to(context.out(), "(");
        std::formatter<double>::format(v.x, context);
        std::format_to(context.out(), ", ");
        std::formatter<double>::format(v.y, context);
        return std::format_to(context.out(), ")");
    }
};

int main()
{
    std::println("{:.1f}", Vec2{ 1.234, 5.678 });    // (1.2, 5.7)
    return 0;
}

A formatter has two jobs: parse reads the specification, and format writes the value. Inheriting from std::formatter<double> reuses its parse, so a Vec2 accepts every specification a double does and applies it to both coordinates.

C++23 also formats ranges and tuples directly: std::println("{}", std::vector{ 1, 2, 3 }); prints [1, 2, 3].

Why prefer it

Advantage Detail
Checked at compile time std::format("{:d}", "text") does not compile, and neither does a missing argument
No sticky state Each field is formatted independently
Faster than streams Considerably, for most uses
Reorderable Positional arguments let a translated string change the order

For control over where the output goes, std::format_to(iterator, fmt, args...) writes through an output iterator, avoiding the temporary string, and std::formatted_size reports how long the result would be.

Availability

<format> needs a C++20 standard library and <print> a C++23 one. Xenon's compiler has both. On an older toolchain, the {fmt} library provides the same interface as fmt::format and fmt::print.
