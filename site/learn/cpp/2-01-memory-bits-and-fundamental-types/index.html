Memory, Bits and Fundamental Types

lesson 2.011 of 9 in milestone 25 min3 practice tasks

Memory is a long row of numbered bytes. A byte is 8 bits. A variable's type decides how many bytes it gets and what the bits in them mean.

What the boxes are made of

In Milestone 1 a variable was "a labelled box". Now look inside the box. Knowing what is in there explains why whole numbers have limits, why decimals are slightly inexact and why types matter at all.

Bits and bytes

A bit is a switch that is either 0 or 1. Eight of them make a byte. Each bit is worth double the one to its right, and you add up the ones that are switched on:

Output
 worth:    128  64  32  16   8   4   2   1
 bits:    [ 0 ][ 1 ][ 0 ][ 0 ][ 0 ][ 0 ][ 0 ][ 1 ]
                64                            + 1    =  65

Every extra bit doubles how many different values you can store.

Bits Different values
1 2
8 (one byte) 256
16 65,536
32 about 4.3 billion
64 about 18 billion billion

Memory is a street of numbered houses

Your computer's memory is a very long row of bytes. Each one has a number, called its address.

 address:  1000   1001   1002   1003   1004   1005   1006   1007
         ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
         │      int score (4 bytes)  │ char │ bool │   free ...  │
         └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘

A variable is a run of neighbouring bytes with a name on it.

The type gives the bits a meaning

Bits on their own mean nothing. The pattern 01000001 is the number 65 if you treat it as a whole number, and the letter A if you treat it as a character.

flowchart LR
    B["01000001"] -->|"read as int"| I["65"]
    B -->|"read as char"| C["'A'"]

That is the job of a type. It tells the compiler two things: how many bytes to reserve, and how to interpret what is in them.

The fundamental types

These are built into the language. Everything else in C++ is made from them.

Kind Type Usual size Holds
True or false bool 1 byte true, false
Character char 1 byte one character
Whole number short 2 bytes about ±32 thousand
int 4 bytes about ±2.1 billion
long long 8 bytes about ±9.2 billion billion
Decimal number float 4 bytes about 7 significant digits
double 8 bytes about 15 significant digits
Nothing void none "no value"
Your defaults

Use int for whole numbers and double for decimals unless you have a reason not to. The others exist for special cases, which the next lessons cover.

Asking how big something is

sizeof reports the size of a type, or of a variable, in bytes.

C++
#include <iostream>

int main()
{
    std::cout << "bool:      " << sizeof(bool) << " bytes\n";
    std::cout << "char:      " << sizeof(char) << " bytes\n";
    std::cout << "int:       " << sizeof(int) << " bytes\n";
    std::cout << "long long: " << sizeof(long long) << " bytes\n";
    std::cout << "double:    " << sizeof(double) << " bytes\n";
    return 0;
}
Sizes are not identical everywhere

The language only promises minimum sizes. An int is 4 bytes on every ordinary computer today, but long is 4 bytes on Windows and 8 on Linux and macOS. When the exact size matters, there are types with the size in their name, such as std::int32_t. They are in 2.02 Integers.

Asking for the limits

Fewer bytes means a smaller range. The header <limits> tells you the exact ends of it.

C++
#include <iostream>
#include <limits>

int main()
{
    std::cout << std::numeric_limits<int>::max() << '\n';    // 2147483647
    std::cout << std::numeric_limits<int>::min() << '\n';    // -2147483648
    return 0;
}

Do not worry about the angle brackets yet. Read std::numeric_limits<int>::max() as "the largest int".
