std::vector Basics

lesson 5.011 of 11 in milestone 55 min4 practice tasks

std::vector<T> is a resizable list of elements stored side by side in memory. Reach elements with v[i] (fast, unchecked) or v.at(i) (checked). It is the container to reach for first.

Many values of one type

A program that handles a hundred scores does not want a hundred variables. A container holds a collection of values under one name, and std::vector is the standard general-purpose one.

C++
#include <vector>

std::vector<int> scores{ 90, 72, 85, 64 };
 index:     0      1      2      3
         ┌──────┬──────┬──────┬──────┐
 scores: │  90  │  72  │  85  │  64  │     scores.size() is 4
         └──────┴──────┴──────┴──────┘

The type in angle brackets is the element type. std::vector is a template (4.02 Function Templates), which is why one container works for any type.

The elements sit next to each other in one block of memory. They are contiguous, and that is what makes a vector fast: the address of element i is a single calculation, and the processor reads neighbouring memory quickly.

Creating a vector

Code Result
std::vector<int> a{}; Empty
std::vector<int> b{ 1, 2, 3 }; Three elements: 1, 2, 3
std::vector<int> c(5); Five elements, all 0
std::vector<int> d(5, 7); Five elements, all 7
std::vector e{ 1.5, 2.5 }; Element type deduced: std::vector<double>
Braces and parentheses mean different things here

std::vector<int> v{ 5 }; is one element with the value 5. std::vector<int> v(5); is five elements, all zero. Braces list the contents. Parentheses give a count. This is the one place in the course where you must use parentheses on purpose.

Reaching the elements

Code Meaning If the index is out of range
v[i] Element i Undefined behaviour: no check is made
v.at(i) Element i Throws a std::out_of_range error
v.front() The first element Undefined behaviour if empty
v.back() The last element Undefined behaviour if empty
v.size() The number of elements
v.empty() Whether the size is 0

Valid indexes run from 0 to v.size() - 1.

[!tip] Xenon's Debug build checks v[i] for you In a Debug build the standard library verifies indexes and stops the program with a clear message. In Release that check is gone, so the habit of staying in range has to be yours.

Adding and removing

C++
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> v{ 1, 2, 3 };
    v.push_back(4);             // 1 2 3 4
    v.pop_back();               // 1 2 3
    v.insert(v.begin(), 0);     // 0 1 2 3
    v.erase(v.begin() + 1);     // 0 2 3
    v.resize(5);                // 0 2 3 0 0
    std::cout << v.size() << '\n';
    v.clear();                  // empty
    return 0;
}
Operation Effect Cost
push_back(x) Add at the end Fast
pop_back() Remove the last Fast
insert(position, x) Insert before a position Slow in the middle: every later element shifts along
erase(position) Remove at a position Slow in the middle, for the same reason
resize(n) Change the size to n Adds default values or drops the tail
clear() Remove everything

v.begin() is the position of the first element, so v.begin() + 1 is the position of index 1. Positions like these are iterators, covered in 5.06 Iterators and STL Algorithms.

flowchart LR
    A["1 2 3"] -->|"push_back(4)"| B["1 2 3 4"]
    B -->|"pop_back()"| C["1 2 3"]
    C -->|"insert(begin, 0)"| D["0 1 2 3"]

Vectors and functions

A vector may hold millions of elements. Passing it by value copies all of them.

C++
double average(const std::vector<int>& v)    // reads: const reference
{
    if (v.empty())
    {
        return 0.0;
    }
    int sum{ 0 };
    for (int x : v)
    {
        sum += x;
    }
    return static_cast<double>(sum) / static_cast<double>(v.size());
}

void addBonus(std::vector<int>& v, int bonus)    // modifies: reference
{
    for (int& x : v)
    {
        x += bonus;
    }
}

std::vector<int> makeRange(int n)    // creates: return by value
{
    std::vector<int> result{};
    for (int i{ 0 }; i < n; ++i)
    {
        result.push_back(i);
    }
    return result;
}

Returning a vector by value is cheap: the contents are handed over, not copied. The mechanism is explained in 7.05 Move Semantics.

Vectors of structs

The element type can be anything, including your own types.

C++
struct Item
{
    std::string name{};
    double price{};
};

std::vector<Item> cart{ { "Milk", 1.99 }, { "Bread", 2.49 } };
cart.push_back({ "Eggs", 3.10 });
std::cout << cart[2].name << '\n';    // Eggs

A vector of structs is the workhorse data structure of most programs.
