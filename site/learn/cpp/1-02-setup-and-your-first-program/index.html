Hello, World!

This is the traditional first program. It puts one line of text on the screen. Press Run.

C++
#include <iostream>

int main()
{
    std::cout << "Hello, World!\n";
    return 0;
}

Output:

Output
Hello, World!

Do not worry about what each line means yet. That is the next lesson. For now, notice two things:

  • The text between the double quotes is what appears on the screen.
  • The \n at the end did not appear. It means "start a new line".

The loop you will repeat for the rest of your life

flowchart LR
    W["Write"] --> B["Build"]
    B -->|"errors"| F["Read the first error<br/>and fix it"]
    F --> B
    B -->|"built"| R["Run"]
    R -->|"wrong result"| D["Work out why"]
    D --> W
    R -->|"right result"| Done["Done"]

Nobody writes a program correctly in one go. Programming is this loop: write a little, run it, fix it, repeat. Small steps make it fast, because when something breaks you know it was the last thing you changed.

Break it on purpose

The quickest way to stop fearing error messages is to cause a few. In the program above:

  1. Delete the ; at the end of the std::cout line and press Run.
  2. Open the Problems tab. It names the line and explains the error in plain English.
  3. Put the ; back and run again.

Now try misspelling cout as cuot, and deleting the last }.

[!warning] Always read the first error first One mistake can confuse the compiler so badly that it reports twenty errors below it. Fix the top one, build again, and most of the rest usually vanish.

Type the code, do not paste it

Typing is slower, and that is the point. Your fingers learn where the brackets and semicolons go, and you make the small mistakes now, while they are cheap.

Later: on your own computer

Xenon is all you need for this course. When you start building bigger projects of your own, you will want a full development environment. On Windows the usual choice is Visual Studio Community (free) with the "Desktop development with C++" option. There is no hurry.
