Loops — while, do-while, for

lesson 3.033 of 8 in milestone 35 min7 practice tasks

Loops repeat code. while repeats as long as a condition holds. do-while runs the body at least once. for is built for counting. break leaves a loop and continue skips to the next round.

Three loops, one idea

All three repeat a block while a condition is true. They differ in when the condition is tested and where the counting lives.

One pass through the body is called an iteration.

while

C++
int count{ 1 };
while (count <= 5)
{
    std::cout << count << ' ';
    ++count;
}
// 1 2 3 4 5

The condition is tested before each iteration. If it is false at the start, the body never runs. If nothing in the body ever makes it false, the loop never ends: an infinite loop.

do-while

C++
int choice{};
do
{
    std::cout << "Enter 1 to 3: ";
    std::cin >> choice;
} while (choice < 1 || choice > 3);

The condition is tested after each iteration, so the body always runs at least once. That suits "ask, then check the answer". Note the ; after the closing bracket.

for

A counting loop needs three things: a starting value, a condition and a step. for puts all three on one line.

C++
//   start        condition   step
for (int i{ 0 };  i < 5;      ++i)
{
    std::cout << i << ' ';
}
// 0 1 2 3 4

Trace it:

i i < 5? Action
0 true print 0, then ++i
1 true print 1, then ++i
...
4 true print 4, then ++i
5 false the loop ends

The patterns you will write most:

To loop over Write
0 up to n − 1 (n iterations) for (int i{ 0 }; i < n; ++i)
1 up to n for (int i{ 1 }; i <= n; ++i)
10 down to 1 for (int i{ 10 }; i > 0; --i)
Every second value for (int i{ 0 }; i < 20; i += 2)

[!tip] Start at 0, test with < Programmers count from zero because indexes start at zero. for (int i{ 0 }; i < n; ++i) runs exactly n times and visits exactly the valid indexes of something with n elements. Make it your default shape.

Which loop?

Situation Loop
You know how many iterations, or you are counting for
You repeat until something happens, and it may already have happened while
The body must run once before you can test do-while

break and continue

C++
for (int i{ 1 }; i <= 10; ++i)
{
    if (i == 3)
    {
        continue;    // skip the rest of this iteration
    }
    if (i == 7)
    {
        break;       // leave the loop altogether
    }
    std::cout << i << ' ';
}
// 1 2 4 5 6
Statement Effect
break Ends the loop immediately
continue Ends this iteration; in a for loop the step still runs

A loop written as while (true) relies on a break inside it to end. That is a normal pattern when the exit test belongs in the middle of the body.

Nested loops

A loop inside a loop. The inner loop runs in full for every single iteration of the outer one.

C++
for (int row{ 1 }; row <= 3; ++row)
{
    for (int col{ 1 }; col <= 4; ++col)
    {
        std::cout << '*';
    }
    std::cout << '\n';
}
Output
****      outer loop: 3 iterations
****      inner loop: 4 iterations each time
****      12 stars in all

The inner loop's limit can depend on the outer variable. Changing col <= 4 to col <= row gives a triangle:

Output
*
**
***

Building up a result

A very common shape: create a variable before the loop and update it on each iteration. That variable is called an accumulator.

C++
int sum{ 0 };
for (int i{ 1 }; i <= 100; ++i)
{
    sum += i;
}
std::cout << sum << '\n';    // 5050

The same shape counts things, finds a maximum, builds a string, and much more.

Three classic bugs

Bug Cause Check
Off by one <= where you needed <, or the wrong start Trace the first and the last iteration by hand
Infinite loop Nothing in the body moves towards the exit Ask what changes on each iteration
Unsigned countdown for (unsigned i{ 5 }; i >= 0; --i) An unsigned value is always >= 0, so the test never fails
