Lambdas

lesson 5.077 of 11 in milestone 55 min4 practice tasks

A lambda is a function written inline, right where it is needed, such as [](int x) { return x * 2; }. Its capture list [ ] lets it use variables from the surrounding code. Lambdas are how you customise algorithms.

A function without a name

std::count_if needs to be told which elements to count. You could write a named function elsewhere in the file. A lambda lets you write it at the point of use.

   [captures]  (parameters)  { body }
       │            │           │
      [ ]        (int x)     { return x > 10; }
C++
#include <iostream>

int main()
{
    auto isBig{ [](int x) { return x > 10; } };
    std::cout << isBig(15) << ' ' << isBig(3) << '\n';    // 1 0
    return 0;
}
Part Meaning
[ ] The capture list: which outside variables the lambda may use
(int x) Parameters, as for any function
{ ... } The body

The return type is deduced from the return statement. You can state it with -> type after the parameters when you need to.

Lambdas with algorithms

C++
#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> v{ 5, 12, 8, 20, 3 };

    const auto over10{ std::count_if(v.begin(), v.end(), [](int x) { return x > 10; }) };
    const auto firstEven{ std::find_if(v.begin(), v.end(), [](int x) { return x % 2 == 0; }) };

    std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; });              // descending
    std::transform(v.begin(), v.end(), v.begin(), [](int x) { return x * 2; });     // double each

    std::cout << over10 << " over ten; first even was " << *firstEven << '\n';
    return 0;
}

A function that returns bool and is used to test elements is called a predicate. A function given to std::sort that decides whether one element goes before another is a comparator.

Sorting structs

This is the use you will reach for most often.

C++
struct Player
{
    std::string name{};
    int score{};
};

std::vector<Player> players{ { "Ann", 50 }, { "Bo", 90 }, { "Cy", 70 } };

std::sort(players.begin(), players.end(),
    [](const Player& a, const Player& b) { return a.score > b.score; });
// Bo 90, Cy 70, Ann 50

The comparator answers one question: "should a come before b?"

Captures

A lambda cannot see local variables from the surrounding function unless it captures them.

C++
int threshold{ 10 };
auto overThreshold{ [threshold](int x) { return x > threshold; } };
Capture Meaning
[] Nothing
[x] A copy of x, taken when the lambda is created
[&x] A reference to x: sees later changes and can modify it
[=] Copy everything the body uses
[&] Reference everything the body uses
[y = x * 2] A new variable y, initialized here
[this] The current object, inside a class (Milestone 6)

C++
int count{ 0 };
std::for_each(v.begin(), v.end(), [&count](int x) { if (x > 5) { ++count; } });
// count was updated by the lambda
A reference capture can dangle

If a lambda that captured by reference is stored and called after the captured variable has gone, it refers to nothing. When a lambda will outlive the current function, capture by value.

Prefer naming each capture over [=] and [&]. The list then documents exactly what the lambda depends on.

mutable

Variables captured by copy are read-only inside the lambda. mutable lifts that, letting the lambda change its own copy.

C++
auto counter{ [n = 0]() mutable { return ++n; } };
counter();    // 1
counter();    // 2

The copy belongs to the lambda and keeps its value between calls.

Generic lambdas

Use auto for a parameter and the lambda works for any type, like a template.

C++
auto print{ [](const auto& x) { std::cout << x << '\n'; } };
print(5);
print("hi");
print(3.14);

Storing and passing lambdas

Every lambda has its own unnamed type, which only the compiler knows. That is why they are stored with auto.

When you need a type you can actually write, for a container of callbacks or an ordinary parameter, use std::function. It can hold any callable with a matching signature.

C++
#include <functional>

std::function<int(int, int)> op{ [](int a, int b) { return a + b; } };
std::vector<std::function<void()>> callbacks{};

std::function<int(int, int)> reads "something callable with two ints that returns an int".

To accept a callable Write Trade-off
Fastest, most flexible A template parameter or auto parameter The function becomes a template
A fixed, nameable type const std::function<void(int)>& A small run-time cost per call
C++
void repeat(int n, const std::function<void(int)>& action)
{
    for (int i{ 0 }; i < n; ++i)
    {
        action(i);
    }
}

repeat(3, [](int i) { std::cout << "tick " << i << '\n'; });
