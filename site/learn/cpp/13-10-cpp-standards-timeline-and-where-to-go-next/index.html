C++ Standards Timeline and Where to Go Next

lesson 13.1010 of 10 in milestone 136 min

C++ gets a new standard every three years. Knowing what arrived when helps you read older code, choose compiler settings and know what you can rely on. After that: pick a field and go deep.

What each standard added

Standard Principal additions In this course
C++98 / 03 Classes, templates, exceptions, the containers and algorithms The foundation of everything
C++11 auto, lambdas, rvalue references and move semantics, unique_ptr and shared_ptr, threads and atomics, constexpr, range-based for, nullptr, enum class, variadic templates, override Milestones 4 to 12
C++14 Generic lambdas, std::make_unique, decltype(auto), binary literals, digit separators Milestones 2 and 5
C++17 optional, variant, any, string_view, filesystem, structured bindings, if constexpr, fold expressions, CTAD, inline variables, parallel algorithms, guaranteed copy elision Milestones 9 to 12
C++20 Concepts, ranges, coroutines, modules, <=>, std::format, span, jthread, semaphores and latches, consteval and constinit, designated initializers, calendars and time zones Milestones 9 to 13
C++23 std::print, std::expected, std::generator, mdspan, flat_map, import std, deducing this, ranges::to, views::zip and enumerate Milestones 10 to 13
C++26 Static reflection, contracts, std::execution, #embed, linear algebra, defined behaviour for uninitialized reads Mentioned in Milestones 11 to 13

C++11 was the turning point. Code written before it looks like a different language, with raw new and delete, hand-written iterator loops and no auto. "Modern C++" means C++11 and later.

A standard and its implementation are different things

A feature is usable only once your compiler and its standard library implement it, which can lag the standard by years. cppreference.com keeps a compiler-support table for each feature.

Reading older code

You will spend more time reading existing code than writing new code. A translation table:

In older code Today

A hand-written function object class A lambda

Since your aim is computer science, three subjects build directly on this course and are worth taking next: data structures and algorithms (trees, graphs, hashing, dynamic programming), computer architecture (what 13.04 Performance, Caches and Data-Oriented Design only sketched), and operating systems (what threads, memory and files really are). C++ is the language most of that material is taught and implemented in.

Four pieces of advice
Build things Every project you finish teaches more than any lesson. The projects in this course are a start; the ones you invent yourself teach the most.
Read other people's code Good libraries, and the standard library's own implementation, show how experienced programmers solve problems.
Keep the safety net on Warnings, sanitizers and tests, always: 13.09 Testing, Sanitizers, Static Analysis and Tooling
Simple first, clever later The best C++ is unremarkable to read. Reach for the advanced techniques of the last three milestones when a problem needs them, and not before.
