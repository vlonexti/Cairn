Enums

lesson 4.055 of 7 in milestone 45 min3 practice tasks

An enum is a type with a fixed list of named values, such as enum class Color { red, green, blue };. Use enum class: its names stay inside the enum and it does not silently turn into a number.

A type for "one of these"

Many values come from a small fixed set: a direction, a day of the week, the state of a game. You could store them as numbers.

C++
int direction{ 2 };    // 2 means... south? Nothing says so, and 57 is also accepted.

An enumeration (an enum) gives the set a type and each member a name.

C++
#include <iostream>

enum class Direction
{
    north,
    east,
    south,
    west,
};

int main()
{
    Direction d{ Direction::east };

    if (d == Direction::east)
    {
        std::cout << "Heading east\n";
    }
    return 0;
}

Each named value is an enumerator. Behind the scenes they are numbered from 0 in the order written:

Output
 Direction::north  is 0
 Direction::east   is 1
 Direction::south  is 2
 Direction::west   is 3
With an int With an enum
The meaning of 2 lives in your head Direction::south says what it is
Any number is accepted Only the listed values exist
A direction can be passed where a colour is expected Different enums are different types

Enums and switch

This is the pairing promised in 3.02 switch.

C++
std::string_view toString(Direction d)
{
    switch (d)
    {
    case Direction::north: return "north";
    case Direction::east:  return "east";
    case Direction::south: return "south";
    case Direction::west:  return "west";
    }
    return "unknown";
}

[!tip] Leave out default when switching on an enum With every enumerator listed and no default, the compiler warns you if you later add an enumerator and forget to handle it here. A default would hide that warning.

Converting to and from numbers

An enum class does not convert to an integer by itself. That strictness is deliberate: it stops enumerators being used in arithmetic by accident.

C++
int n{ static_cast<int>(Direction::south) };    // 2
Direction d{ static_cast<Direction>(3) };       // Direction::west

To print an enumerator's number, cast it. To print its name, write a function like toString above.

The older, unscoped enum

Without the word class you get the original C form. You will meet it in older code.

C++
enum Color { red, green, blue };
enum Fruit { apple, banana, red };    // error: red is already defined

Color c{ red };
int x{ c };                           // converts silently
enum enum class
How you write a value red Color::red
Names spill into the surrounding scope Yes No
Converts to int silently Yes No
Use it Rarely By default

Because its names are contained, enum class is also called a scoped enumeration.

Choosing the numbers and the size

C++
enum class HttpStatus
{
    ok = 200,
    notFound = 404,
    serverError = 500,
};

enum class Tile : std::uint8_t
{
    empty,
    wall,
    water,
};
Feature Effect
name = value Sets that enumerator's number. Later ones continue counting from it.
: type after the name Sets the underlying type used for storage. The default is int.

A Tile here occupies one byte, which matters when a map holds a million of them.

using enum

Inside a scope where the enum's name would be repeated many times, C++20 lets you import the enumerators:

C++
switch (d)
{
    using enum Direction;
case north: return "north";
case east:  return "east";
case south: return "south";
case west:  return "west";
}

Looping over an enum

There is no built-in way to visit every enumerator. The common idiom adds a final count entry, whose number equals how many real entries there are.

C++
enum class Suit { clubs, diamonds, hearts, spades, count };

for (int i{ 0 }; i < static_cast<int>(Suit::count); ++i)
{
    const Suit suit{ static_cast<Suit>(i) };
    // use suit
}

This works only when the enumerators have their default numbers, 0 upwards with no gaps.
