Static Members and Friends

lesson 6.055 of 9 in milestone 65 min3 practice tasks

A static member belongs to the class itself and is shared by all its objects. A friend is a function or class that has been granted access to another class's private members.

Static member variables

Ordinary members exist once per object. A static member exists once for the whole class.

C++
#include <iostream>

class Monster
{
public:
    Monster() : m_id{ ++s_count } {}
    ~Monster() { --s_count; }

    int id() const { return m_id; }
    static int count() { return s_count; }

private:
    static inline int s_count{ 0 };
    int m_id{};
};

int main()
{
    Monster a{};
    Monster b{};
    Monster c{};
    std::cout << Monster::count() << '\n';    // 3
    return 0;
}
          class Monster
        ┌──────────────────────┐
        │ s_count: 3   (one)   │◀──────────┐
        └──────────────────────┘           │ shared
   ┌─────────┐ ┌─────────┐ ┌─────────┐     │
   │ a: id 1 │ │ b: id 2 │ │ c: id 3 │─────┘
   └─────────┘ └─────────┘ └─────────┘
       each object has its own m_id

inline lets the variable be defined inside the class, in a header (3.06 Global Variables, static and Linkage). The s_ prefix marks it as static.

Static member functions

count() is a static member function. It is called on the class, with no object: Monster::count().

Ordinary member static member
How many copies One per object One per class
Accessed as object.x Class::x
Has a this pointer Yes No
Exists with no objects No Yes

Having no this, a static function cannot touch non-static members. It has no object to look in.

Constants that belong to a class

C++
class Config
{
public:
    static constexpr int maxPlayers{ 4 };
    static constexpr double gravity{ 9.81 };
};

int seats{ Config::maxPlayers };

Named constructors

A private constructor combined with static functions gives construction a meaningful name.

C++
class Temperature
{
public:
    static Temperature fromCelsius(double c) { return Temperature{ c + 273.15 }; }
    static Temperature fromFahrenheit(double f) { return Temperature{ (f - 32.0) * 5.0 / 9.0 + 273.15 }; }

    double kelvin() const { return m_kelvin; }

private:
    explicit Temperature(double kelvin) : m_kelvin{ kelvin } {}
    double m_kelvin{};
};

const auto t{ Temperature::fromCelsius(25.0) };

Temperature{ 25.0 } would leave the reader guessing the unit. Temperature::fromCelsius(25.0) does not. A static function used this way is a factory function.

Friends

Occasionally a function that is not a member genuinely needs a class's private data. The class can grant that with friend.

C++
class Vault
{
    friend void audit(const Vault& vault);    // this function may see the private members
    friend class Banker;                      // so may every member function of Banker

private:
    int m_gold{ 1000 };
};

void audit(const Vault& vault)
{
    std::cout << vault.m_gold << '\n';    // allowed
}

class Banker
{
public:
    void collect(Vault& vault) { vault.m_gold = 0; }    // allowed
};
flowchart LR
    V["Vault<br/>private: m_gold"]
    A["audit<br/>friend function"] -->|"allowed"| V
    B["Banker<br/>friend class"] -->|"allowed"| V
    X["any other code"] -.->|"refused"| V
Property Meaning
Granted, not taken Only the class itself can name its friends
One-way If A befriends B, A gains no access to B
Not inherited, not transitive A friend's friends and derived classes get nothing
Use friendship sparingly

Every friend is more code that can break the class's invariants. The standard legitimate use is operator overloads that need private access, such as operator<<: 6.07 Operator Overloading Basics.

A friend function may be defined right inside the class body. It is still a non-member function. That is a tidy way to keep an operator next to the class it serves.
