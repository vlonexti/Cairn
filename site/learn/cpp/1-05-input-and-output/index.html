Input and Output

lesson 1.055 of 10 in milestone 15 min4 practice tasks

std::cout << sends values out to the screen. std::cin >> brings values in from the keyboard. The arrows point the way the data moves.

Follow the arrows

A program that cannot show anything or ask anything is not much use. C++ gives you two tools for talking to the person at the keyboard.

flowchart LR
    V1["a value"] -->|"&lt;&lt;"| COUT["std::cout<br/>(the screen)"]
    KB["std::cin<br/>(the keyboard)"] -->|"&gt;&gt;"| V2["a variable"]
You write Read it as Data moves
std::cout << x; "send x to the screen" from x to the screen
std::cin >> x; "read from the keyboard into x" from the keyboard to x

If you ever forget which arrows go with which, look at where they point.

Printing with std::cout

C++
#include <iostream>

int main()
{
    int apples{ 5 };
    std::cout << "I have " << apples << " apples\n";
    std::cout << "Line 1\n" << "Line 2\n";
    return 0;
}
Output
I have 5 apples
Line 1
Line 2

Three things to notice:

  • You can chain several << in one statement. Each piece is printed in order.
  • Text in quotes is printed exactly as written. A variable name without quotes prints the value inside the variable.
  • std::cout adds nothing for you. No spaces, no new lines. If you want a space between two things, put it inside the quotes.

Special characters

A backslash inside quotes starts a code for a character you cannot simply type.

Code What it prints
\n the start of a new line
\t a tab (a jump to the next column)
\" a double quote
\\ one backslash

[!note] You will also see std::endl std::cout << "Hi" << std::endl; also ends the line. It does a little extra work each time, so this course uses \n, which is the normal choice.

Reading with std::cin

C++
#include <iostream>

int main()
{
    std::cout << "Enter your age: ";
    int age{};
    std::cin >> age;

    std::cout << "In 10 years you will be " << age + 10 << '\n';
    return 0;
}
Output
Enter your age: 21
In 10 years you will be 31

The steps are always the same:

flowchart LR
    A["Print a question"] --> B["Create a variable<br/>to hold the answer"] --> C["std::cin >> variable"] --> D["Use the variable"]

The program stops at std::cin >> and waits until the person types something and presses Enter.

Reading two values

C++
int width{};
int height{};
std::cin >> width >> height;

The person can type 3 7 on one line, or 3, Enter, 7, Enter. std::cin >> skips spaces and new lines to find the next value.

Reading a whole line of text

std::cin >> stops at the first space. That is fine for a number, but wrong for a full name.

C++
#include <iostream>
#include <string>

int main()
{
    std::cout << "Your full name: ";
    std::string name{};
    std::getline(std::cin >> std::ws, name);

    std::cout << "Hello, " << name << "!\n";
    return 0;
}
Typed std::cin >> name stores std::getline(std::cin >> std::ws, name) stores
Ada Lovelace Ada Ada Lovelace

For now, treat std::getline(std::cin >> std::ws, name) as the recipe for "read the rest of the line". The std::ws part skips any leftover Enter from an earlier answer.

Two mistakes to expect

Mistake What happens
Arrows the wrong way: std::cin << x A long, confusing compile error. Check the arrows first.
Typing letters when the program wants a number The read fails and the variable is left at 0. You will learn to handle this in 3.07 Input Validation and assert.
