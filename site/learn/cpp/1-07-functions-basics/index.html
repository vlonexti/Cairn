Functions Basics

lesson 1.077 of 10 in milestone 15 min5 practice tasks

A function is a named set of instructions you can use again and again. You hand it values (arguments), it does its work, and it can hand one value back (the return value).

A function is a machine

Put values in, get a result out. You have already written one function, main. Now you will write your own.

flowchart LR
    I1["3"] --> F["add"]
    I2["4"] --> F
    F --> O["7"]
C++
#include <iostream>

int add(int x, int y)
{
    return x + y;
}

int main()
{
    int sum{ add(3, 4) };
    std::cout << sum << '\n';    // 7
    return 0;
}

The parts of a function

   what it       its      what it needs
  hands back     name      to be given
      │           │            │
     int         add    (int x, int y)
     {
         return x + y;        the body: what it does
     }
Word Meaning In the example
Return type The type of value the function hands back int
Parameter A variable that receives a value when the function is used x and y
Call Using the function add(3, 4)
Argument A value you give in the call 3 and 4
Return value What comes back 7

What happens when you call it

sequenceDiagram
    participant M as main
    participant A as add
    M->>A: add(3, 4): x becomes 3, y becomes 4
    Note over A: works out x + y
    A-->>M: return 7
    Note over M: sum is 7, carry on with the next line
  1. main pauses at the call.
  2. The arguments are copied into the parameters.
  3. The function's body runs.
  4. return sends a value back, and main carries on where it stopped.
The function gets copies

Because the arguments are copied, changing x inside add changes nothing in main. The two functions have separate boxes. (When you do want a function to change the caller's variable, you use a reference: 4.03 References.)

Functions that hand nothing back

Some functions just do something. Their return type is void, which means "nothing".

C++
#include <iostream>

void printBanner()
{
    std::cout << "==========\n";
    std::cout << "  MY APP  \n";
    std::cout << "==========\n";
}

int main()
{
    printBanner();
    printBanner();    // written once, used twice
    return 0;
}

Empty brackets mean the function needs no values. You still have to write the brackets when you call it.

The compiler reads from the top

A function has to be known before the line that calls it. The simplest way is to write your functions above main.

The other way is to announce the function first and write it later. The announcement is called a declaration:

C++
#include <iostream>

int add(int x, int y);       // declaration: "this function exists"

int main()
{
    std::cout << add(3, 4) << '\n';
    return 0;
}

int add(int x, int y)        // definition: the actual instructions
{
    return x + y;
}

Variables inside a function stay inside

C++
void countCoins()
{
    int coins{ 5 };    // created here
}                      // gone here

int main()
{
    countCoins();
    // coins does not exist in main. Using it here is a compile error.
    return 0;
}

A variable created inside a function is called a local variable. It belongs to that function alone. Two functions can each have a variable called total without affecting each other.

Why bother?

Reason What it means
Reuse Write the instructions once, call them as often as you like
Readability calculateTax(price) says what is happening without showing how
Easier fixing A mistake lives in one place, so you fix it in one place
Smaller problems A big task becomes several small ones you can solve one at a time
One function, one job

If you cannot give a function a short, clear name, it is probably doing two jobs. Split it.

Three mistakes to expect

Mistake What happens
No return in a function that promised a value The compiler warns you, and the program misbehaves
Calling without brackets: printBanner; Nothing happens. The brackets are what make it a call.
Writing one function inside another Not allowed. Each function sits on its own, outside the others.
